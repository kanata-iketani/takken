# 第22章 地価公示・統計・免除科目

税以外の「その他」分野をまとめて学びます。地価公示・鑑定評価・住宅金融支援機構・広告ルール・統計・土地建物で例年6問前後。覚えることが少ないわりに出題は安定しており、直前期に伸びる得点源です。

## 1. 地価公示法と不動産鑑定評価

### 地価公示のしくみ

**土地鑑定委員会**が、公示区域内に**標準地**を選び、毎年**1月1日時点**の**正常な価格**を判定して官報で公示します。

- 標準地の鑑定評価は**2人以上の不動産鑑定士**が行います
- **正常な価格**とは、自由な取引で通常成立すると認められる価格のこと。その土地に**建物や借地権があっても、ないものとして**（いわば更地として）判定します
- 公示区域内で土地取引をする者は、公示価格を**指標として**取引するよう**努めなければなりません**（努力義務）

### 不動産鑑定評価の3手法

| 手法 | 考え方 |
|---|---|
| 原価法 | もう一度つくったらいくらかかる？（再調達原価） |
| 取引事例比較法 | 似た物件の取引はいくらだった？ |
| 収益還元法 | その物件はいくら稼げる？ |

🟡 ひっかけの定番は「建物付きでも**更地として**評価する」「一般の土地取引では公示価格は**努力義務**（従う義務ではない）」の2点です。

> 💡 「誰が・いつ・どこで・どんな価格を」＝「土地鑑定委員会が・1月1日時点で・標準地について・正常な価格を」とまとめて覚えましょう。

### 確認問題

**問1.** 地価公示において、標準地の正常な価格を判定して公示するのはどこでしょう？

1. 国土交通大臣
2. 都道府県知事
3. 土地鑑定委員会
4. 市町村長

<details><summary>答えと解説</summary>

正解: **3**

地価公示を行うのは土地鑑定委員会です。国土交通大臣や知事ではありません。「委員会」という聞き慣れない主体だからこそ、入れ替えのひっかけがよく出ます。

</details>

**問2.** 地価公示の「正常な価格」について、正しいものはどれでしょう？

1. 標準地に建物がある場合でも、建物がないものとして判定される
2. 標準地に建物がある場合は、建物の価格を含めて判定される
3. 売り急ぎなどの事情も反映した実勢価格である
4. 毎年4月1日時点の価格として判定される

<details><summary>答えと解説</summary>

正解: **1**

正常な価格は、建物や借地権などがあっても「ないものとして」、つまり更地としての価格で判定します。自由な取引で通常成立する価格なので、売り急ぎ等の特殊事情は反映しません。価格の判定時点は毎年1月1日です。

</details>

**問3.** 標準地の鑑定評価について、正しいものはどれでしょう？

1. 1人の不動産鑑定士が行えば足りる
2. 2人以上の不動産鑑定士が行う
3. 宅地建物取引士が行う
4. 市町村の職員が行う

<details><summary>答えと解説</summary>

正解: **2**

標準地の鑑定評価は2人以上の不動産鑑定士が行い、その結果を審査して土地鑑定委員会が正常な価格を判定します。1人では足りず、また鑑定は不動産鑑定士の仕事であって宅建士や市町村職員が行うものではありません。

</details>

**問4.** 公示区域内で一般の者（収用などの特別な場合でない者）が土地取引を行う場合、公示価格との関係はどうなるでしょう？

1. 必ず公示価格で取引しなければならない
2. 公示価格の2割の範囲内で取引しなければならない
3. 公示価格とまったく無関係に取引してよく、法律上の規定はない
4. 公示価格を指標として取引するよう努めなければならない

<details><summary>答えと解説</summary>

正解: **4**

一般の土地取引については「公示価格を指標として取引するよう努めなければならない」という努力義務です。義務ではないので、公示価格と異なる価格で取引しても違法ではありません。「必ず公示価格で」「2割以内で」という義務規定はありません。

</details>

## 2. 住宅金融支援機構と景品表示法

免除科目のうち、毎年ほぼ1問ずつ出る2テーマです。覚えるポイントは少なめです。

### 住宅金融支援機構

国の住宅ローン政策を支える機関です。**自ら直接融資するのは例外**で、中心は**証券化支援業務**。民間金融機関の長期・固定金利住宅ローン（いわゆるフラット35）の**債権を買い取る**しくみ（買取型）です。

- 直接融資の例外: **災害関連**の融資、子育て世帯向け・高齢者向け賃貸住宅の建設資金など
- **団体信用生命保険**（団信）の業務も行います

### 不動産の表示に関する公正競争規約

広告のルールです。数字がそのまま出題されます。

- 徒歩の所要時間: **道路距離80mにつき1分**で計算（1分未満の端数は**切り上げ**）
- **新築**と表示できるのは、建築後**1年未満**かつ**未使用**のもの
- 実在しない物件や取引する意思のない物件を広告する**おとり広告は禁止**

🟡 「徒歩1分＝80m・端数切り上げ」は最頻出です。

> 💡 道路距離81mなら「徒歩2分」。79mでも80mでも「徒歩1分」です。

### 確認問題

**問1.** 住宅金融支援機構の中心的な業務として、正しいものはどれでしょう？

1. 一般の個人への住宅ローンの直接融資
2. 民間金融機関の長期・固定金利住宅ローン債権の買取り（証券化支援業務）
3. 住宅の売買の媒介
4. 住宅地の造成・分譲

<details><summary>答えと解説</summary>

正解: **2**

機構の中心業務は証券化支援業務（買取型）で、民間金融機関が貸し出した長期・固定金利の住宅ローン債権を買い取ります。一般個人への直接融資は原則として行いません（災害関連などの例外のみ）。媒介や分譲は機構の業務ではありません。

</details>

**問2.** 住宅金融支援機構の業務について、正しいものはどれでしょう？

1. 直接融資は一切行っていない
2. 団体信用生命保険の業務は行っていない
3. 変動金利の住宅ローン債権のみを買い取る
4. 災害関連の資金については、例外的に直接融資を行う

<details><summary>答えと解説</summary>

正解: **4**

直接融資は「原則行わない」のであって、災害復興建築物の建設資金など例外的には行います（「一切行わない」は言い過ぎで誤り）。団信の業務は行っています。また買取りの対象は長期・固定金利のローン債権であり、変動金利のみというのも誤りです。

</details>

**問3.** 駅から物件まで道路距離が410mある場合、公正競争規約に基づく徒歩所要時間の表示として正しいものはどれでしょう？

1. 徒歩4分
2. 徒歩5分
3. 徒歩6分
4. 徒歩5.1分

<details><summary>答えと解説</summary>

正解: **3**

徒歩時間は道路距離80mにつき1分で計算し、1分未満の端数は切り上げます。410m÷80m＝5.125分なので、切り上げて徒歩6分と表示します。四捨五入や小数表示は認められません。

</details>

**問4.** 広告で「新築」と表示できる物件の条件として、正しいものはどれでしょう？

1. 建築後1年未満であって、かつ未使用のもの
2. 建築後3年未満であれば使用されていてもよい
3. 未使用であれば建築後何年たっていてもよい
4. 完成前の物件のみ

<details><summary>答えと解説</summary>

正解: **1**

「新築」と表示できるのは、建築後1年未満かつ未使用の物件です。1年未満でも誰かが住んだら新築とは表示できず、未使用でも1年を過ぎたら表示できません。2つの条件を両方満たす必要があります。

</details>

## 3. 統計問題の攻略法

統計は毎年1問、**試験直前の対策だけで取れる**サービス問題です。ただし数値は毎年変わるため、この教材では具体的な数値を扱いません。大事なのは「**何が出るか**」と「**どう準備するか**」です。

### 出題される4大指標

| 資料（公表時期の目安） | 見るポイント |
|---|---|
| 地価公示（国土交通省・3月） | 地価は上昇か下落か、何年連続か |
| 建築着工統計（国土交通省・1月） | 新設住宅着工戸数は増えたか減ったか |
| 土地白書（国土交通省・6月） | 土地取引件数の傾向 |
| 法人企業統計（財務省・9月） | 不動産業の売上高・経常利益の増減 |

### 準備のしかた

🟡 試験の**1〜2週間前**に、国土交通省などの**最新の公表値**を確認し、「**増えた／減った**」「**何年連続**」だけをメモして覚えます。テキストや過去問に載っている古い年度の数値を暗記するのは、むしろ逆効果です。

> 💡 覚えるのは方向（増減）と連続年数だけ。細かい数字の暗記は不要です。直前期のたった30分で1点取れる、コスパ最高の分野です。

### 確認問題

**問1.** 宅建試験の統計問題への対策として、最も適切なものはどれでしょう？

1. 数年前のテキストに載っている数値を正確に暗記する
2. 統計は難問なので最初から捨てる
3. 試験直前に国土交通省などの最新の公表値を確認し、増減の方向を押さえる
4. 過去問に出た年度の数値をすべて年表にして覚える

<details><summary>答えと解説</summary>

正解: **3**

統計の数値は毎年変わるため、直前期に最新の公表値を確認して「増えたか減ったか」「何年連続か」を押さえるのが正解です。古い数値の暗記は誤答のもとで逆効果です。また毎年1問出る取りやすい問題なので、捨てるのはもったいない分野です。

</details>

**問2.** 「新設住宅着工戸数」の動向が掲載されている資料はどれでしょう？

1. 建築着工統計
2. 地価公示
3. 法人企業統計
4. 路線価図

<details><summary>答えと解説</summary>

正解: **1**

新設住宅着工戸数は建築着工統計（国土交通省）で公表されます。地価公示は地価の動向、法人企業統計は不動産業の売上高や経常利益の動向を見る資料です。路線価図は相続税などの評価に使うもので、統計問題の定番資料ではありません。

</details>

**問3.** 統計問題で地価公示が出題された場合に押さえておくべきポイントとして、最も適切なものはどれでしょう？

1. 全国すべての標準地の価格
2. 地価が上昇したか下落したかの方向と、何年連続かという傾向
3. 標準地1地点ごとの正確な変動率
4. 10年前との価格差の正確な金額

<details><summary>答えと解説</summary>

正解: **2**

統計問題で問われるのは「上昇か下落か」「何年連続か」といった大きな傾向です。個々の標準地の価格や正確な変動率・金額まで覚える必要はありませんし、そもそも毎年変わるので直前に最新の公表値で確認します。

</details>

## 4. 土地・建物の知識

免除科目から、土地1問・建物1問が出ます。専門知識よりも「常識＋少しの知識」で解ける分野です。

### 宅地に向く土地・向かない土地

| 向く ○ | 向かない ✕ |
|---|---|
| 台地・丘陵地（水はけがよく地盤が安定） | 旧河道・埋立地・干拓地（軟弱地盤・液状化のおそれ） |
| 扇状地（ただし土石流には注意） | 低地・急傾斜地・台地や丘陵地の縁（へり） |

- **旧河道**（昔、川だった場所）は周囲より低く軟弱で、洪水や地震に弱い土地です
- 地形図では、等高線の間隔が**狭い**ほど傾斜が**急**です

### 建物構造のきほん

- **木造**: 筋かいや金物を入れて耐震性を高めます
- **鉄骨造**: 粘り強い構造ですが熱に弱く、**耐火被覆**が必要です
- **鉄筋コンクリート造**: 耐火性・耐久性に優れますが、自重が重い構造です。引張りに弱いコンクリートを鉄筋が補います

🟡 土地の問題は「高くて安定した地形＝○、水に関係する低い地形＝✕」のイメージで大半が解けます。

> 💡 迷ったら「そこに家を建てて安心して眠れるか？」と想像してみましょう。

### 確認問題

**問1.** 宅地として最も適しているのは、一般に次のどれでしょう？

1. 旧河道
2. 水はけのよい台地
3. 干拓地
4. 急傾斜地

<details><summary>答えと解説</summary>

正解: **2**

台地は水はけがよく地盤も安定しているため、一般に宅地に適しています。旧河道は軟弱で洪水・液状化に弱く、干拓地も低く軟弱、急傾斜地は崩壊のおそれがあり、いずれも宅地には適しません。

</details>

**問2.** 旧河道について、最も適切な記述はどれでしょう？

1. かつて川だった場所だが、現在は乾いているので宅地に適する
2. 周囲より高い場所にあるため水害に強い
3. 地盤が軟弱で、洪水や地震時の液状化の危険が高く、宅地に適さない
4. 等高線の間隔が広いので安全である

<details><summary>答えと解説</summary>

正解: **3**

旧河道は昔の川の跡で、周囲より低く、砂や泥がたまった軟弱地盤です。洪水時には水が集まりやすく、地震時には液状化もしやすいため宅地に適しません。「今は乾いているから安全」とは言えず、等高線の間隔は地形の傾斜を示すもので安全性の根拠にはなりません。

</details>

**問3.** 地形図の等高線について、正しいものはどれでしょう？

1. 等高線の間隔が狭いほど、傾斜が急である
2. 等高線の間隔が狭いほど、傾斜が緩やかである
3. 等高線は土地の所有者の境界を示す
4. 等高線の間隔と傾斜には関係がない

<details><summary>答えと解説</summary>

正解: **1**

等高線は同じ高さの地点を結んだ線なので、間隔が狭い＝短い距離で高さが変わる＝傾斜が急、ということです。間隔が広ければ緩やかです。所有者の境界とはまったく関係ありません。

</details>

**問4.** 建物の構造について、正しいものはどれでしょう？

1. 鉄筋コンクリート造は、木造よりも耐火性に劣る
2. 木造の耐震性を高めるには、筋かいを除去するのがよい
3. 鉄骨造は熱に弱いため、耐火構造とするには耐火被覆が必要である
4. コンクリートは引張りに強いので、鉄筋は不要である

<details><summary>答えと解説</summary>

正解: **3**

鉄骨は燃えない素材ですが熱で強度が落ちるため、耐火構造にするには耐火被覆が必要です。鉄筋コンクリート造は耐火性に優れます。筋かいは木造の耐震性を高めるために入れるものであり、除去すれば弱くなります。コンクリートは引張りに弱いからこそ鉄筋で補うのです。

</details>
