# 第17章 都市計画法

ここから「法令上の制限」です。土地には「どこに・何を・どれだけ建てられるか」のルールがあり、その大もとが都市計画法です。線引きと開発許可の数字(1000・3000・10000㎡)を押さえれば、本試験の得点源になります。

## 1. 都市計画の全体像 —— 市街化区域と市街化調整区域

都市計画法は「無秩序な街づくりを防ぎ、計画的に良い街をつくる」ための法律です。まず都道府県などが**都市計画区域**を指定します。これは「ここからここまでを計画的に街づくりするエリアにします」と、街の設計図を描く範囲を決めるイメージです。

### 線引き(区域区分)

都市計画区域の中は、さらに2つに分けられることがあります。これを**線引き**と呼びます。

| 区域 | 定義 | イメージ |
|---|---|---|
| **市街化区域** | すでに市街地の区域 + **おおむね10年以内**に優先的・計画的に市街化を図るべき区域 | どんどん建てて良い街 |
| **市街化調整区域** | 市街化を**抑制**すべき区域 | 建物を建てるのをがまんする田園エリア |

線引きは必ず行うわけではなく、していない都市計画区域は**非線引き区域**と呼ばれます。また、都市計画区域の**外**でも、高速道路のインター周辺など乱開発のおそれがある場所は**準都市計画区域**に指定できます。

> 💡コツ: 調整区域は市街化の「禁止」ではなく「**抑制**」。また市街化区域は「10年以内に」。この2つの言い回しがひっかけの定番です。

> 🔴 線引きの定義は毎年のように出ます。言葉を一字一句正確に覚えましょう。

### 確認問題

**問1.** 市街化区域の定義として、正しいものはどれでしょう?

1. 市街化を抑制すべき区域である
2. すでに市街地を形成している区域と、おおむね10年以内に優先的かつ計画的に市街化を図るべき区域である
3. すでに市街地を形成している区域と、おおむね20年以内に市街化を図るべき区域である
4. 建築物の建築が一切禁止される区域である

<details><summary>答えと解説</summary>

正解: **2**

市街化区域は「すでに市街地の区域+おおむね10年以内に優先的かつ計画的に市街化を図るべき区域」です。「20年以内」は数字のひっかけ、「抑制すべき区域」は市街化調整区域の定義です。市街化区域で建築が禁止されることはありません。

</details>

**問2.** 市街化調整区域の説明として、正しいものはどれでしょう?

1. 市街化を禁止すべき区域である
2. 市街化を促進すべき区域である
3. 市街化を抑制すべき区域である
4. 建物の高さを調整する区域である

<details><summary>答えと解説</summary>

正解: **3**

市街化調整区域は市街化を「抑制」すべき区域です。「禁止」ではない点が最重要で、一定の許可を受ければ建築もできます。「促進」は市街化区域のイメージであり、建物の高さの調整とは関係ありません。

</details>

**問3.** 線引き(区域区分)について、正しいものはどれでしょう?

1. すべての都市計画区域で、市街化区域と市街化調整区域の区分を必ず定めなければならない
2. 線引きがされていない都市計画区域(非線引き区域)も存在する
3. 市街化調整区域内では、いかなる建築物も建築できない
4. 線引きは市町村長が単独で自由に定める

<details><summary>答えと解説</summary>

正解: **2**

線引きは必ず行うものではなく、行っていない「非線引き区域」も存在します。したがって「必ず定めなければならない」は誤りです。調整区域でも許可等により建築できる場合があるので「いかなる建築物も不可」も誤り。区域区分は都道府県が都市計画として定めるものです。

</details>

**問4.** 準都市計画区域について、正しいものはどれでしょう?

1. 市街化区域の中に指定される
2. 市街化調整区域の別名である
3. 都市計画区域に指定される前の準備段階の呼び名で、1年で失効する
4. 都市計画区域の外で、放置すれば乱開発のおそれがある区域に指定される

<details><summary>答えと解説</summary>

正解: **4**

準都市計画区域は「都市計画区域の外」で、そのまま放置すると無秩序な開発が起きそうな土地(高速道路のインター周辺など)に指定されます。都市計画区域の内側に指定されるものではなく、調整区域の別名でも、期限付きの準備段階でもありません。

</details>

## 2. 用途地域と地域地区 —— 13種類をざっくりつかむ

市街化区域の中は、さらに「ここは住宅の街」「ここは商売の街」「ここは工場の街」とエリア分けされます。これが**用途地域**で、全部で**13種類**あります。住む環境と働く環境が混ざるとお互いに迷惑になるから分ける、という理屈です。

### 13種類は3グループで覚える

| グループ | 数 | 種類 |
|---|---|---|
| **住居系** | 8 | 第一種・第二種低層住居専用、田園住居、第一種・第二種中高層住居専用、第一種・第二種住居、準住居 |
| **商業系** | 2 | 近隣商業、商業 |
| **工業系** | 3 | 準工業、工業、工業専用 |

### どこに定める?

- **市街化区域**: **少なくとも用途地域を定める**(=必ず定める)
- **市街化調整区域**: **原則として定めない**(街づくりを抑制するエリアだから)

用途地域の上には、**防火地域**・**高度地区**などの「地域地区」を重ねて、きめ細かく規制できます。

> 💡コツ: 「住居系8・商業系2・工業系3」で合計13。全部の名前を暗記するより、まずグループ分けと数を押さえましょう。

> 🟡 13種類の個別の細かい定義より、「市街化区域には必ず・調整区域には原則なし」が問われます。

### 確認問題

**問1.** 用途地域について、正しいものはどれでしょう?

1. 用途地域は全部で12種類ある
2. 市街化調整区域には、必ず用途地域を定めなければならない
3. 市街化区域には、少なくとも用途地域を定めるものとされている
4. 用途地域は商業系の地域が最も種類が多い

<details><summary>答えと解説</summary>

正解: **3**

市街化区域には「少なくとも用途地域を定める」、つまり必ず定めます。逆に市街化調整区域は市街化を抑制するエリアなので原則として定めません。用途地域は13種類(12は誤り)で、最も多いのは住居系の8種類です。

</details>

**問2.** 用途地域のグループ分けとして、正しいものはどれでしょう?

1. 住居系8種類・商業系2種類・工業系3種類である
2. 住居系7種類・商業系3種類・工業系3種類である
3. 住居系と商業系の2グループしかない
4. 住居系5種類・商業系5種類・工業系3種類である

<details><summary>答えと解説</summary>

正解: **1**

用途地域は住居系8・商業系2・工業系3の合計13種類です。住居系には田園住居地域を含む8種類があります。他の選択肢は数の組み合わせが誤りで、工業系を含めた3グループ構成であることも押さえましょう。

</details>

**問3.** 防火地域や高度地区のような「地域地区」について、正しいものはどれでしょう?

1. 用途地域とは絶対に重ねて定めることができない
2. 用途地域に重ねて定め、きめ細かな規制を行うことができる
3. 市街化調整区域の別名である
4. 13種類の用途地域のうちの1つである

<details><summary>答えと解説</summary>

正解: **2**

防火地域などの地域地区は、用途地域の上に重ねて指定し、防火や高さなどの観点からきめ細かく規制するための仕組みです。「重ねられない」はまったく逆です。用途地域13種類の中の1つでも、調整区域の別名でもありません。

</details>

## 3. 開発許可とは —— 1000・3000・10000の面積基準

**開発行為**とは、建築物の建築などの目的で行う「土地の**区画形質の変更**」、つまり造成工事のことです。山を削って宅地を造るような行為を野放しにすると街が乱れるので、一定規模以上は**都道府県知事等の許可(開発許可)**が必要です。

### 面積基準(超重要!)

| どこで開発するか | 許可が必要な規模 |
|---|---|
| **市街化区域** | **1000㎡以上** |
| **市街化調整区域** | **面積にかかわらずすべて** |
| 非線引き区域・準都市計画区域 | **3000㎡以上** |
| 都市計画区域・準都市計画区域の**外** | **10000㎡(1ha)以上** |

> 💡コツ: ゴロは「**イチ(1000)・サン(3000)・イチマン(10000)**」。街の中心から外へ行くほど基準がゆるくなります。そして**調整区域だけは面積の例外なし**。市街化を抑制するエリアだから、小さな造成でも許可がいる、と理屈で覚えましょう。

> 🔴 この表は本試験で毎年のように問われます。「市街化区域で800㎡」「調整区域で500㎡」のような数字のひっかけに即答できるまで繰り返してください。

### 確認問題

**問1.** 市街化区域内で800㎡の開発行為を行う場合、開発許可は必要でしょうか?

1. 面積にかかわらず必要である
2. 1000㎡未満なので原則として不要である
3. 3000㎡未満なので原則として不要であるが、市長の承認は必要である
4. 500㎡を超えているので必要である

<details><summary>答えと解説</summary>

正解: **2**

市街化区域の基準は1000㎡以上なので、800㎡なら原則として許可不要です。「面積にかかわらず必要」なのは市街化調整区域の話です。3000㎡は非線引き区域等の基準、500㎡は開発許可の基準ではありません。

</details>

**問2.** 市街化調整区域内で500㎡の開発行為を行う場合、正しいものはどれでしょう?

1. 1000㎡未満なので許可は不要である
2. 3000㎡未満なので許可は不要である
3. 市街化調整区域では原則として面積にかかわらず許可が必要である
4. 市街化調整区域では開発行為自体が一切禁止されている

<details><summary>答えと解説</summary>

正解: **3**

市街化調整区域は市街化を抑制するエリアなので、面積の下限がなく、原則としてどんな規模でも許可が必要です。1000㎡は市街化区域、3000㎡は非線引き区域等の基準であり、調整区域には使えません。また禁止ではなく「許可制」です。

</details>

**問3.** 都市計画区域にも準都市計画区域にも含まれない区域で、8000㎡の開発行為を行う場合はどうなるでしょう?

1. 10000㎡未満なので原則として許可は不要である
2. 3000㎡以上なので許可が必要である
3. 1000㎡以上なので許可が必要である
4. 区域外では面積にかかわらず常に許可が必要である

<details><summary>答えと解説</summary>

正解: **1**

両区域外の基準は10000㎡(1ha)以上なので、8000㎡なら原則不要です。3000㎡は非線引き区域・準都市計画区域、1000㎡は市街化区域の基準です。区域の外は街づくりの計画外なので、基準が最もゆるくなっています。

</details>

**問4.** 開発行為の説明として、正しいものはどれでしょう?

1. 建築物の建築等の目的で行う土地の区画形質の変更をいう
2. 建築物を建築する行為そのものをいう
3. 土地の売買契約を締結する行為をいう
4. 農地を農地のまま売却する行為をいう

<details><summary>答えと解説</summary>

正解: **1**

開発行為とは、建築物の建築や特定工作物の建設の目的で行う「土地の区画形質の変更」、つまり造成などの土地いじりです。建物を建てる行為自体は建築基準法の建築確認の世界であり、土地の売買契約や農地の権利移動は開発行為ではありません。

</details>

## 4. 開発許可が不要な場合 —— 農林漁業・公益・事業施行

面積基準に当てはまっても、次の開発行為は**例外として許可不要**です。「規制するまでもない・むしろ応援したい行為」と考えると覚えやすいです。

### 許可不要となる主な開発行為

| 例外 | 内容 | 注意点 |
|---|---|---|
| **農林漁業用** | 畜舎・温室など + 農林漁業を営む者の**住宅** | **市街化区域では使えない例外**(市街化区域内なら1000㎡以上で許可必要) |
| **公益上必要** | **駅舎・図書館・公民館・変電所**など | **病院・学校・社会福祉施設は含まれない**(=許可必要) |
| **事業の施行** | 都市計画事業・土地区画整理事業・市街地再開発事業などとして行うもの | すでに公的チェック済みだから |
| その他 | 非常災害の応急措置、通常の管理行為・**軽微な行為** | 仮設建築物など |

> 💡コツ: ひっかけの二大定番は、①「**市街化区域内**の農業用畜舎」→ 農林漁業の例外は使えず1000㎡以上なら許可必要、②「**病院・学校**」→ 公益っぽいのに例外ではない、の2つです。

> 🔴 例外は「どれが入って、どれが入らないか」の暗記勝負。表の太字を確実に。

### 確認問題

**問1.** 市街化区域内で、農業を営む者が1200㎡の畜舎を建てる目的で開発行為を行う場合、正しいものはどれでしょう?

1. 農林漁業用の建築物なので、開発許可は不要である
2. 市街化区域内では農林漁業用の例外は適用されず、1000㎡以上なので開発許可が必要である
3. 畜舎は公益上必要な建築物なので、開発許可は不要である
4. 市街化区域内の開発行為は面積にかかわらずすべて許可不要である

<details><summary>答えと解説</summary>

正解: **2**

農林漁業用建築物の例外は「市街化区域以外」でのみ使えます。市街化区域内では通常どおり面積基準で判断し、1200㎡は1000㎡以上なので許可が必要です。畜舎は公益例外(駅舎・図書館など)でもありません。市街化区域が常に許可不要ということもありません。

</details>

**問2.** 開発許可が不要となる「公益上必要な建築物」に当たるものはどれでしょう?

1. 病院
2. 小学校
3. 駅舎
4. 社会福祉施設

<details><summary>答えと解説</summary>

正解: **3**

公益例外に当たるのは駅舎・図書館・公民館・変電所などです。病院・学校・社会福祉施設は公益的なイメージがありますが例外には含まれず、面積基準に該当すれば開発許可が必要です。ここは最頻出のひっかけです。

</details>

**問3.** 土地区画整理事業の施行として行う開発行為について、正しいものはどれでしょう?

1. 面積が1000㎡以上であれば開発許可が必要である
2. 市街化調整区域内の場合に限り開発許可が必要である
3. 開発許可は不要である
4. 都道府県知事への届出をすれば許可を受けたものとみなされる

<details><summary>答えと解説</summary>

正解: **3**

土地区画整理事業・都市計画事業・市街地再開発事業などの施行として行う開発行為は、すでに事業として公的なチェックを受けているため、区域や面積にかかわらず開発許可は不要です。面積基準での判断や届出制という仕組みではありません。

</details>

**問4.** 市街化調整区域内で、農業を営む者がその業務用の温室を建てる目的で開発行為を行う場合、正しいものはどれでしょう?

1. 面積にかかわらず開発許可が必要である
2. 3000㎡以上の場合に限り開発許可が必要である
3. 温室は建築物ではないので都市計画法の適用がない
4. 農林漁業用建築物に当たるため、開発許可は不要である

<details><summary>答えと解説</summary>

正解: **4**

市街化区域「以外」の区域では、温室・畜舎などの農林漁業用建築物のための開発行為は許可不要です。調整区域は本来「面積にかかわらず許可」ですが、この例外が優先します。3000㎡は非線引き区域等の基準です。

</details>

## 5. 開発許可の手続きと建築制限

開発許可の流れと、工事中・工事後の建築ルールを押さえます。

### 手続きの流れ

1. **事前協議**: 開発で影響を受ける**公共施設の管理者と協議し、同意**を得る(新設する公共施設は管理予定者と協議)
2. **申請**: **書面**で都道府県知事等に申請
3. **処分**: 知事は許可・不許可を**文書**で通知(不許可でも文書)
4. 工事 → 完了の検査 → **検査済証**の交付 → **工事完了の公告**

### 建築制限(いつから建てられる?)

| 時期 | ルール |
|---|---|
| **完了公告の前** | 原則、建築物を**建築できない**(例外: 工事用の仮設建築物など) |
| **完了公告の後** | **予定建築物以外**は原則建築できない(知事が許可した場合などを除く) |

> 💡コツ: 「造成が終わって公告されるまでは家を建てない。終わったら予定どおりの建物だけ」。順番のイメージで覚えれば忘れません。

> 🟡 「不許可の通知も文書で行う」「公告前でも工事用仮設はOK」が細かいけれど出るポイントです。

### 確認問題

**問1.** 開発許可を受けた開発区域内で、工事完了の公告「前」にできる行為はどれでしょう?

1. 予定建築物である分譲住宅の建築
2. 開発工事用の仮設建築物の建築
3. 予定建築物以外のオフィスビルの建築
4. あらゆる建築物の建築

<details><summary>答えと解説</summary>

正解: **2**

完了公告前は原則として建築物を建築できませんが、工事のために必要な仮設建築物などは例外として認められます。予定建築物であっても公告前は建てられず、予定外の建物はなおさら不可です。

</details>

**問2.** 工事完了の公告「後」の建築制限について、正しいものはどれでしょう?

1. どんな建築物でも自由に建築できる
2. 一切の建築物を建築できない
3. 原則として予定建築物以外の建築物は建築できない
4. 仮設建築物のみ建築できる

<details><summary>答えと解説</summary>

正解: **3**

公告後は、開発許可の際の予定建築物等以外は原則建築できません(知事が許可した場合などは別)。完全に自由になるわけでも、一切禁止されるわけでもありません。仮設建築物のみという制限は公告前の例外の話と混同させるひっかけです。

</details>

**問3.** 開発許可の手続きについて、正しいものはどれでしょう?

1. 許可の申請は口頭で行うことができる
2. 知事は許可の場合のみ文書で通知し、不許可の場合は通知しなくてよい
3. 開発行為に関係がある公共施設の管理者との協議・同意は不要である
4. 知事は許可・不許可いずれの処分も文書で申請者に通知しなければならない

<details><summary>答えと解説</summary>

正解: **4**

許可・不許可の処分はどちらも文書で通知します。「不許可は通知不要」が定番のひっかけです。申請は書面で行い、申請前には関係する公共施設の管理者と協議して同意を得る必要があります。

</details>
