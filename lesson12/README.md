# 第12章 物権変動と不動産登記

「買ったはずの土地が他人のものに!?」——不動産の権利争いは登記で決まります。二重譲渡、背信的悪意者、取消し・解除・時効と登記。この章は権利関係の最大の山場のひとつですが、考え方のパターンは少なく、A→B→Cの図さえ描ければ得点源になります。

## 1. 物権変動と対抗要件（二重譲渡は登記で勝負！）

### 二重譲渡という事件

Aさんは甲土地をBさんに売りました。ところがAはお金欲しさに、同じ甲土地をCさんにも売ってしまいました（**二重譲渡**）。

図式: B ←（売却①）── A ──（売却②）→ C

甲土地は、BとCのどちらのものになるのでしょうか。

### ルール: 登記で勝負

- 所有権は、**意思表示（契約）だけで移転**します。登記や引渡し、代金の支払は不要です（民法176条）
- しかし、不動産の物権変動は**登記をしなければ第三者に対抗できません**（民法177条）
- 🔴 二重譲渡では、**契約の先後ではなく、先に登記を備えた方が勝ちます**

Cが先に登記を備えれば、先に契約していたBは負け、Cが確定的に所有者になります。

### 単なる悪意者には勝てる？

Cが「AはすでにBに売った」と**知っていた（悪意）**場合でも、Cが先に登記すればCの勝ちです。これは自由競争の範囲内とされるからです（ただし、次のチャプターで学ぶ「背信的悪意者」は別です）。

なお、売主Aは「第三者」ではないので、Bは登記がなくてもAに対しては所有権を主張できます。

> 💡 コツ: 「不動産は登記した者勝ち。契約の早い遅いは関係ない」。まずこれだけで十分です。

### 確認問題

**問1.** Aは、自己所有の甲土地をBに売却した後、同じ甲土地をCにも売却し、Cが先に所有権移転登記を備えた。この場合に関する記述として正しいものはどれか。

1. 先に売買契約を締結したBが所有権の取得を対抗できる
2. BとCは、持分2分の1ずつで甲土地を共有する
3. Bは、登記がなくても所有権の取得をCに対抗できる
4. 先に登記を備えたCが、所有権の取得をBに対抗できる

<details><summary>答えと解説</summary>

正解: **4**

不動産が二重に譲渡された場合、契約の先後ではなく、先に登記を備えた方が所有権の取得を対抗できます（民法177条）。Bは契約が先でも、登記のない以上Cに対抗できません。共有になるわけでもありません。

</details>

**問2.** Aは甲土地をBに売却したが、Bは所有権移転登記をしていなかった。Cは、AB間の売買の事実を知りながらAから甲土地を買い受け、先に所有権移転登記を備えた。Cには、Bを害する意図など信義に反する事情はなかった。この場合に関する記述として正しいものはどれか。

1. Cは悪意であるため、Bは登記がなくてもCに所有権を対抗できる
2. 単に売買の事実を知っていたにすぎないCが先に登記を備えた以上、BはCに所有権を対抗できない
3. 悪意のCは、登記を備えても所有権の取得を対抗できない
4. BとCの優劣は、売買契約を締結した日付の先後によって決まる

<details><summary>答えと解説</summary>

正解: **2**

二重譲渡の勝敗を決める177条の「第三者」から排除されるのは背信的悪意者であり、単なる悪意者は含まれません。先に買った事実を知って買うこと自体は自由競争の範囲内だからです。したがって先に登記したCが勝ち、優劣が契約日で決まるわけではありません。

</details>

**問3.** AはBとの間で甲土地の売買契約を締結したが、代金の支払、登記の移転、引渡しはいずれもまだ行われていない。所有権の移転時期について特約はない。この場合に関する記述として正しいものはどれか。

1. 所有権は、売買契約の意思表示の合致によってBに移転している
2. 所有権は、所有権移転登記をした時に初めてBに移転する
3. 所有権は、Bが代金を完済した時に初めて移転する
4. 所有権は、甲土地の引渡しを受けた時に初めて移転する

<details><summary>答えと解説</summary>

正解: **1**

物権の変動は意思表示のみによって効力を生じます（民法176条）。特約がなければ、所有権は契約成立時にBへ移転しています。登記は第三者への対抗要件にすぎず、代金の支払や引渡しも所有権移転の要件ではありません。

</details>

**問4.** Aは甲土地をBに売却したが、Bはまだ所有権移転登記をしていない。この場合に関する記述として正しいものはどれか。

1. Bは、登記がなければ、売主Aに対しても所有権の取得を主張できない
2. Aは、登記名義が自分に残っている以上、Bへの甲土地の引渡しを拒むことができる
3. 売主Aは民法177条の「第三者」にあたらないため、Bは登記がなくてもAに所有権を主張できる
4. AはBに対し、Bが登記を備えるまでの間、甲土地を自由に第三者へ売却する権利を有することを主張できる

<details><summary>答えと解説</summary>

正解: **3**

登記が必要なのは「第三者」に対抗する場合であり、契約の当事者である売主Aは第三者にあたりません。したがってBは登記がなくてもAに所有権を主張でき、Aは引渡しを拒めません。Aが第三者に売ることは事実上可能ですが、それはBに対する権利ではなく、二重譲渡として債務不履行等の責任を生じさせる行為です。

</details>

## 2. 登記がなくても対抗できる相手

### 177条の「第三者」には入らない人たち

前のチャプターで「登記した者勝ち」と学びましたが、実は**登記がなくても勝てる相手**がいます。未登記の買主Bさんが、登記なしで所有権を対抗できる相手を整理します。

### 🔴 登記がなくても対抗できる相手

| 相手 | 理由 |
|---|---|
| **背信的悪意者** | 高値で売りつける目的など、単なる悪意を超えて信義に反する者。自由競争の範囲外 |
| **無権利者**（書類を偽造して登記した者など） | そもそも権利がないので保護する理由がない |
| **不法占拠者・不法行為者** | 同じく保護する理由がない |
| 詐欺・強迫によって**登記申請を妨げた者** | 自分で妨害しておいて「登記がない」とは言えない |
| 他人のために**登記を申請する義務を負う者** | 同上 |

### 逆に「登記がないと負ける」相手

普通の第三者（単なる悪意者を含む）に加え、その不動産の**対抗要件を備えた賃借人**も177条の第三者です。建物を買った新しい所有者は、**自分に登記を移さなければ**賃借人に賃料を請求できません。

> 💡 コツ: 「単なる悪意者には負ける、**背信的**悪意者には勝てる」。この線引きを確実にすれば十分です。

深入りは禁物です。表の顔ぶれを覚えれば、この論点は得点源になります。

### 確認問題

**問1.** Aは甲土地をBに売却したが、Bは所有権移転登記をしていなかった。Cは、Bに高値で売りつけて利益を得る目的で、AB間の売買の事実を知りながらAから甲土地を買い受け、所有権移転登記を備えた。この場合に関する記述として正しいものはどれか。

1. Cが先に登記を備えた以上、BはCに所有権を対抗できない
2. Bは、背信的悪意者であるCに対し、登記がなくても所有権を対抗できる
3. BがCに対抗するには、Cより先に登記を備えている必要があった
4. Cは、Bに対して甲土地の明渡しを請求することができる

<details><summary>答えと解説</summary>

正解: **2**

Bを害して利益を得る目的で買い受けたCは背信的悪意者であり、177条の「第三者」にあたりません。したがってBは登記がなくても所有権を対抗でき、Cは登記を備えていても勝てず、Bに明渡しを請求することもできません。単なる悪意者であれば登記の先後で決まる点と区別しましょう。

</details>

**問2.** Bは、Aから甲土地を買い受けたが、所有権移転登記をしていない。甲土地は、何の権原もないDが資材置場として占拠している。この場合に関する記述として正しいものはどれか。

1. Bは登記を備えていないため、Dに明渡しを請求できない
2. Bは、売主Aの協力がなければDに明渡しを請求できない
3. 不法占拠者Dは民法177条の「第三者」にあたらず、Bは登記がなくても明渡しを請求できる
4. BがDに明渡しを請求するには、Dの悪意を証明しなければならない

<details><summary>答えと解説</summary>

正解: **3**

不法占拠者は正当な利害関係を持たないため177条の「第三者」にあたらず、Bは登記なしで所有権を主張し明渡しを請求できます。Aの協力やDの悪意の証明は不要です。登記が必要なのは、正当な取引関係に立つ第三者と争う場合です。

</details>

**問3.** B所有の甲土地について、Eが登記関係書類を偽造して、自己名義の所有権移転登記をした。この場合に関する記述として正しいものはどれか。

1. Eは登記を備えている以上、所有権の取得をBに対抗できる
2. 登記には公信力があるため、E名義の登記を信じて買い受けた者は常に所有権を取得する
3. BがEに所有権を主張するには、Eより先に登記を備えていなければならない
4. 偽造によって登記名義を得たEは無権利者であり、Bは登記がなくても所有権を主張できる

<details><summary>答えと解説</summary>

正解: **4**

偽造による登記名義人はそもそも何の権利も取得しておらず、177条の「第三者」にあたりません。Bは登記がなくても（登記名義を奪われていても）所有権を主張できます。また日本の登記に公信力はないため、E名義を信じて買った者も原則として権利を取得できません。

</details>

**問4.** Aは、賃借人Gが賃借権の対抗要件を備えて居住している甲建物をBに売却した。Bは所有権移転登記をしないまま、Gに対して賃料の支払を請求した。この場合に関する記述として正しいものはどれか。

1. Bは、所有権移転登記を備えなければ、Gに対して賃料を請求できない
2. Gは賃借人にすぎないため、Bは登記がなくても当然に賃料を請求できる
3. Gが背信的悪意者である場合に限り、Bは賃料を請求できる
4. 甲建物が売却された時点で賃貸借契約は終了し、Gは退去しなければならない

<details><summary>答えと解説</summary>

正解: **1**

対抗要件を備えた賃借人は177条の「第三者」にあたるため、新所有者Bが賃貸人として賃料を請求するには所有権移転登記が必要です（判例）。賃借人だからといって登記なしで対抗できる相手ではありません。また対抗要件を備えた賃貸借は建物の売却によって終了せず、Gは住み続けられます。

</details>

## 3. 取消し・解除・時効と登記（前後で分ける）

### 「前か後か」で分けるのがコツ

Aが詐欺を理由にBへの売却を取り消した後、Bが残っていた登記名義を利用してCに転売したら、どうなるのでしょうか。このチャプターでは、取消し・解除・時効と第三者の関係を、「第三者が**その前に現れたか、後に現れたか**」で整理します。

図式: A →（売却）→ B →（転売）→ C。Cが現れたのは、取消し（解除・時効完成）の前？後？

### 🔴 整理表

| 場面 | 前に現れた第三者C | 後に現れた第三者C |
|---|---|---|
| 詐欺による**取消し** | **善意無過失**なら保護される | **登記の先後**で決まる（対抗関係） |
| 債務不履行による**解除** | **登記があれば**保護される（善意悪意は不問） | **登記の先後**で決まる |
| 取得**時効** | 時効取得者が**登記なしで勝つ** | **登記の先後**で決まる |

### 考え方

- 「後」はすべて共通です。取消しや解除で権利がAに戻ると、B を起点とした**二重譲渡と同じ対抗関係**になり、AとCのうち先に登記した方が勝ちます
- 「前」はそれぞれ違います。詐欺取消しは第三者の**善意無過失**、解除は第三者の**登記**、時効完成前の第三者には時効取得者が**登記なしで勝つ**、と覚えます

> 💡 コツ: 迷ったら「取消し・解除・時効完成の**後**に現れた第三者とは登記で勝負」と唱えましょう。前パターンの3つを押さえれば十分です。

### 確認問題

**問1.** AはBの詐欺によって甲土地をBに売却し、その後、詐欺に気づいて売買契約を取り消した。ところがBは、自己名義のまま残っていた登記を利用して、甲土地をCに売却し、Cは所有権移転登記を備えた。この場合に関する記述として正しいものはどれか。

1. 取消しによってBは無権利者となるため、Cは善意悪意を問わず所有権を取得できない
2. Cが善意無過失であれば、登記がなくても所有権を取得できる
3. 取消し後に現れたCとAは対抗関係に立ち、先に登記を備えたCが所有権の取得を対抗できる
4. Aは、取消しの時点で当然に登記名義を回復したものとみなされる

<details><summary>答えと解説</summary>

正解: **3**

取消し「後」に現れた第三者との関係は、復帰したAとCへの譲渡の二重譲渡類似の対抗関係として扱われ、登記の先後で決まります（判例）。本問ではCが先に登記を備えたのでCが勝ちます。取消し前の第三者に適用される善意無過失の保護（96条3項)とは場面が異なる点に注意しましょう。

</details>

**問2.** AはBの詐欺によって甲土地をBに売却した。Aが取消しをする前に、Bは事情を知らず知ることもできなかったCに甲土地を転売していた。その後、Aは詐欺を理由に売買契約を取り消した。この場合に関する記述として正しいものはどれか。

1. Aは取消しをCに対抗でき、甲土地を取り戻すことができる
2. Cは善意無過失の第三者として保護され、Aは取消しをCに対抗できない
3. Cは、登記を備えていなければ常にAに負ける
4. 詐欺による取消しの場合、取消し前の第三者は悪意であっても保護される

<details><summary>答えと解説</summary>

正解: **2**

取消し「前」に利害関係に入った第三者との関係では、民法96条3項により善意無過失の第三者が保護されます。本問のCは善意無過失なのでAは対抗できません。悪意の第三者は保護されず、また96条3項の第三者には登記まで要求されないと解されています。

</details>

**問3.** Aは甲土地をBに売却し、BはさらにCに転売して、Cは所有権移転登記を備えた。その後、AはBの代金不払いを理由にAB間の売買契約を解除した。この場合に関する記述として正しいものはどれか。

1. 解除により契約は遡及的に消滅するため、Cは所有権を失う
2. Cが解除の原因となったBの債務不履行について悪意であれば、Cは保護されない
3. Cが善意であっても、解除の時点に戻って対抗関係が判断されるため、Cは保護されない
4. Cは登記を備えているため、善意悪意を問わず保護され、Aは解除をCに対抗できない

<details><summary>答えと解説</summary>

正解: **4**

解除前に現れた第三者は、登記を備えていれば善意悪意を問わず保護されます（民法545条1項ただし書）。本問のCは登記を備えているので、Aは解除の効果をCに対抗できません。解除の遡及効は第三者の権利を害することができず、第三者の主観は問われません。

</details>

**問4.** Bは、A所有の甲土地を所有の意思をもって平穏かつ公然に占有し続けていた。Bの取得時効が完成する前に、Aは甲土地をCに売却し、Cは所有権移転登記を備えた。その後、Bの取得時効が完成した。この場合に関する記述として正しいものはどれか。

1. Bは、時効完成前に現れたCに対し、登記がなくても時効による所有権の取得を対抗できる
2. Cが先に登記を備えている以上、BはCに時効取得を対抗できない
3. Bが時効取得をCに対抗するには、時効完成前に自己名義の登記を備えておく必要があった
4. 時効完成後にAから甲土地を買い受けた者に対しても、Bは常に登記なくして対抗できる

<details><summary>答えと解説</summary>

正解: **1**

時効完成前に現れた第三者に対しては、時効取得者は登記なくして所有権の取得を対抗できます（Cは時効完成時の当事者のような立場になるため）。そもそも時効完成前のBには登記のしようがありません。一方、時効完成「後」に現れた第三者との関係は対抗関係となり、登記の先後で決まるので、「常に登記なくして対抗できる」は誤りです。

</details>

## 4. 不動産登記のきほんと相続登記の義務化

### 登記記録はこうなっている

登記記録（登記簿）は、1つの不動産ごとに次のような構成になっています。

| 部 | 何が書いてある？ | 例 |
|---|---|---|
| **表題部** | 不動産の**物理的な現況** | 土地の所在・地番・地目・地積、建物の種類・構造・床面積 |
| **権利部 甲区** | **所有権**に関する事項 | 所有者は誰か、差押えなど |
| **権利部 乙区** | **所有権以外**の権利 | 抵当権・地上権・賃借権など |

🟡 「甲区＝所有権、乙区＝それ以外（抵当権など）」は頻出です。

### 申請のきほん

- 権利に関する登記は、原則として登記権利者（買主など）と登記義務者（売主など）の**共同申請**です
- **登記事項証明書**は、手数料を納めれば**誰でも**交付を請求できます（利害関係は不要）

### 相続登記の義務化（2024年4月〜）

所有者不明土地の問題を受けて、**相続登記が義務化**されました。

- 相続により不動産を取得したことを**知った日から3年以内**に登記を申請しなければなりません
- 正当な理由なく怠ると、**10万円以下の過料**の対象になります
- 遺産分割の話し合いがまとまらないときは、ひとまず**相続人申告登記**をすれば義務を果たせます

制度の細部より、この骨組みが分かれば十分です。

### 確認問題

**問1.** Aは、自己所有の甲土地にB銀行のための抵当権を設定し、その登記をした。この抵当権の設定の登記が記録されるのはどこか。

1. 表題部
2. 権利部（甲区）
3. 権利部（乙区）
4. 抵当権は登記することができない

<details><summary>答えと解説</summary>

正解: **3**

抵当権など所有権以外の権利に関する登記は権利部の乙区に記録されます。甲区は所有権に関する事項、表題部は不動産の物理的現況を記録する部分です。抵当権は登記でき、登記が第三者への対抗要件になります。

</details>

**問2.** Aは、2025年に父の死亡による相続で甲土地を取得したことを知った。相続登記に関する記述として正しいものはどれか。

1. 相続登記の申請は任意であり、申請期限は定められていない
2. 取得を知った日から3年以内に相続登記を申請しなければならず、正当な理由なく怠ると10万円以下の過料の対象となる
3. 父の死亡の日から1年以内に登記をしなければ、Aは相続権を失う
4. 遺産分割協議がまとまらない間は、登記に関する義務を果たす方法はない

<details><summary>答えと解説</summary>

正解: **2**

2024年4月から相続登記は義務化され、相続による取得を知った日から3年以内の申請が必要で、正当な理由のない怠りは10万円以下の過料の対象です。義務違反でも相続権自体を失うわけではありません。遺産分割がまとまらない場合でも、相続人申告登記によって義務を果たすことができます。

**問3.** 不動産登記に関する次の記述のうち、正しいものはどれか。

1. 売買による所有権移転登記は、原則として買主が単独で申請することができる
2. 登記事項証明書の交付は、その不動産に利害関係を有する者でなければ請求できない
3. 表題部には、所有権に関する事項が記録される
4. 権利に関する登記は、原則として登記権利者と登記義務者が共同で申請する

<details><summary>答えと解説</summary>

正解: **4**

権利に関する登記は、登記の正確性を担保するため、登記権利者（買主など）と登記義務者（売主など）の共同申請が原則です。単独申請は相続など例外的な場合に限られます。登記事項証明書は手数料を納めれば誰でも請求でき、所有権に関する事項は表題部ではなく権利部の甲区に記録されます。

</details>
