# 第13章 抵当権と担保

住宅ローンを支えるしくみ「抵当権」の章です。お金を貸した銀行が、借りた人を家に住まわせたまま担保を取る——このイメージさえつかめば、難しそうな用語は怖くありません。例年1〜2問の出題。細かい論点は深追いせず、基本の型だけ押さえましょう。

## 1. 抵当権とは（住宅ローンと「使いながら担保」）

### 住宅ローンの例から

AさんはB銀行から3000万円を借りて自宅（甲建物）を買い、甲建物にB銀行の**抵当権**を設定しました。

図式: A（債務者・設定者）── 甲建物に抵当権 → B銀行（抵当権者）

Aが返済できなくなると、B銀行は甲建物を**競売**にかけ、その代金から**他の債権者より優先して**貸金を回収できます。これが抵当権です。

### 🔴 抵当権の特徴

- **使いながら担保**: 抵当権を設定しても、Aは甲建物を**使い続けられます**（占有を移さない）。これが質権との最大の違いです
- **設定**: AとB銀行の**抵当権設定契約**（合意）だけで成立します
- **対抗要件は登記**: 登記をしなければ第三者に対抗できません
- **目的にできるもの**: 不動産（土地・建物）のほか、**地上権・永小作権**にも設定できます（賃借権には設定できません）
- **物上保証**: 債務者以外の人（例: Aの親C）が、自分の不動産に抵当権を設定して他人の借金を担保することもできます

### 付従性・随伴性

- 被担保債権（貸金）が弁済などで消滅すれば、抵当権も**当然に消滅**します（付従性）
- 被担保債権が譲渡されれば、抵当権も**一緒に移転**します（随伴性）

ここまでのイメージができれば、抵当権の入口は十分です。

### 確認問題

**問1.** Aは、B銀行から3000万円を借り入れ、自己所有の甲建物に抵当権を設定し、その登記をした。この場合に関する記述として正しいものはどれか。

1. Aは、抵当権の設定後、甲建物をB銀行に引き渡さなければならない
2. Aは、抵当権の設定後も甲建物に住み続けることができる
3. 抵当権の設定により、甲建物を第三者に賃貸することは一切できなくなる
4. 抵当権の設定により、甲建物の所有権はB銀行に移転する

<details><summary>答えと解説</summary>

正解: **2**

抵当権は目的物の占有を抵当権者に移さない担保物権であり、設定者は従来どおり建物に住み続け、使用・収益を継続できます。引渡しが必要なのは質権です。所有権も移転せず、賃貸などの利用も原則として可能です。

</details>

**問2.** AとB銀行との間の抵当権の設定と対抗要件に関する記述として正しいものはどれか。

1. 抵当権は、登記をしなければ設定の効力自体が生じない
2. 抵当権の設定契約は、公正証書によってしなければ効力を生じない
3. 抵当権はAB間の設定契約（合意）のみで効力を生じるが、登記をしなければ第三者に対抗できない
4. 抵当権の対抗要件は、B銀行が甲建物の占有を取得することである

<details><summary>答えと解説</summary>

正解: **3**

抵当権は当事者の合意のみで成立し、書面や公正証書は効力要件ではありません。登記は効力発生要件ではなく、第三者への対抗要件です。抵当権者は占有を取得しないため、占有が対抗要件になることもありません。

</details>

**問3.** 次のうち、抵当権の目的とすることが【できない】ものはどれか。

1. 土地
2. 建物
3. 地上権
4. 建物の賃借権

<details><summary>答えと解説</summary>

正解: **4**

抵当権の目的にできるのは不動産（土地・建物）のほか、地上権と永小作権です。賃借権は債権であり、抵当権の目的とすることはできません。

</details>

**問4.** Aは、B銀行からの借入金の担保として自己所有の甲土地に抵当権を設定していたが、借入金の全額をB銀行に弁済した。この場合に関する記述として正しいものはどれか。

1. 被担保債権の消滅により、抵当権も当然に消滅する
2. 抵当権の登記を抹消するまでは抵当権は存続し、B銀行は競売を申し立てることができる
3. 抵当権は、B銀行が放棄の意思表示をして初めて消滅する
4. 弁済後も抵当権だけが独立して存続し、B銀行の別の債権の担保として当然に流用される

<details><summary>答えと解説</summary>

正解: **1**

抵当権には付従性があり、被担保債権が弁済で消滅すれば抵当権も当然に消滅します。登記の抹消や抵当権者の放棄の意思表示は消滅の要件ではありません（抹消登記は後始末にすぎません）。消滅した抵当権が別の債権の担保に当然流用されることもありません。

</details>

## 2. 抵当権の効力（優先弁済・順位・利息2年分）

### どこまで担保される？

Aさんの甲土地に、B銀行が1番抵当権（債権3000万円）、C銀行が2番抵当権（債権2000万円）を持っています。競売代金が4000万円のとき、配当は**登記の順位の順**です。

図式: 競売代金4000万 → ①1番のBに3000万 → ②2番のCに残り1000万

### 🟡 押さえるポイント

- **順位**: 同じ不動産に複数の抵当権を設定でき、順位は**登記の前後**で決まります。順位の変更は、各抵当権者の**合意**（利害関係者がいればその承諾も）と**登記**によってできます
- **利息の範囲**: 後順位抵当権者など他の債権者がいるとき、抵当権者が利息について優先弁済を受けられるのは、**満期となった最後の2年分**に限られます
- **効力の及ぶ範囲**: 抵当地の**付加一体物**（庭石・立木など）や設定当時の**従物**には効力が及びます。ただし土地と建物は別個の不動産なので、**土地への抵当権の効力は建物には及びません**
- **物上代位**: 抵当建物が火事で焼失しても、設定者が受け取る**火災保険金**に効力を及ぼせます。ただし、保険金が設定者に**払い渡される前に差押え**をすることが必要です

> 💡 コツ: 「順位は登記順」「利息は2年分」「保険金は払渡し前に差押え」。この3つで十分です。

### 確認問題

**問1.** Aの甲土地には、B銀行の1番抵当権（被担保債権3000万円）とC銀行の2番抵当権（被担保債権2000万円）が設定・登記されている。甲土地が競売され、代金4000万円が配当される場合に関する記述として正しいものはどれか（利息等は考慮しない）。

1. BとCは、債権額の割合に応じて按分した配当を受ける
2. Bが3000万円の配当を受け、Cは残額の1000万円の配当を受ける
3. 後から設定されたCの抵当権の方が新しいため、Cが優先する
4. Cは配当を一切受けられず、4000万円全額がBに配当される

<details><summary>答えと解説</summary>

正解: **2**

抵当権の順位は登記の前後で決まり、配当は順位の順に行われます。1番抵当権者Bがまず債権全額3000万円の弁済を受け、2番抵当権者Cが残額1000万円を受け取ります。按分されるのは抵当権のない一般債権者どうしの場合です。

</details>

**問2.** 抵当権によって担保される利息の範囲に関する記述として正しいものはどれか。

1. 後順位抵当権者がいる場合でも、抵当権者は利息の全額について常に優先弁済を受けられる
2. 抵当権によって担保されるのは元本のみであり、利息は一切担保されない
3. 後順位抵当権者など他の債権者がいる場合、利息については満期となった最後の2年分に限り優先弁済を受けられる
4. 利息については、満期となった最後の5年分まで優先弁済を受けられる

<details><summary>答えと解説</summary>

正解: **3**

後順位抵当権者などほかの債権者を保護するため、抵当権者が利息について優先弁済を受けられる範囲は満期となった最後の2年分に限られます（民法375条）。利息もこの範囲では担保されるので「一切担保されない」は誤りで、全額でも5年分でもありません。

</details>

**問3.** Aは、B銀行のために、A所有の甲土地（その上にはA所有の乙建物が建っている）に抵当権を設定した。この場合に関する記述として正しいものはどれか。

1. 甲土地の抵当権の効力は、当然に乙建物にも及ぶ
2. 乙建物は甲土地の従物であるため、抵当権の効力が及ぶ
3. 抵当権が実行されると、乙建物も当然に競売の対象となる
4. 土地と建物は別個の不動産であり、甲土地の抵当権の効力は乙建物には及ばない

<details><summary>答えと解説</summary>

正解: **4**

日本では土地と建物は別個の不動産として扱われるため、土地に設定した抵当権の効力は建物に及ばず、建物が当然に競売されることもありません。建物は土地の従物でもありません。なお、このままでは競売後に建物の敷地利用権が問題になるため、次のチャプターの法定地上権の制度があります。

</details>

**問4.** Aは、B銀行のために自己所有の甲建物に抵当権を設定していたが、甲建物が火災で焼失し、Aは保険会社に対する火災保険金請求権を取得した。この場合に関する記述として正しいものはどれか。

1. B銀行は、保険金がAに払い渡される前に差し押さえることにより、火災保険金に抵当権の効力を及ぼすことができる
2. 抵当権の効力は建物自体にしか及ばないため、B銀行は保険金について権利を行使できない
3. 保険金がAに支払われてAの他の財産と混ざった後でも、B銀行は当然に優先権を主張できる
4. 物上代位をするには、あらかじめ保険会社の承諾を得ておかなければならない

<details><summary>答えと解説</summary>

正解: **1**

抵当権には物上代位性があり、目的物の滅失によって設定者が受け取る火災保険金（の請求権）にも効力を及ぼせます。ただし払渡し前の差押えが必要で、保険金がAに支払われて他の財産に混入した後では行使できません。保険会社の承諾は要件ではありません。

</details>

## 3. 法定地上権と一括競売

### 建物が「宙に浮く」問題

Aさんは、甲土地と、その上に建つ乙建物の両方を所有しています。甲土地だけにB銀行の抵当権を設定し、競売の結果、Cさんが甲土地を買い受けました。

図式: 甲土地 →（競売）→ Cのもの ／ 乙建物 → Aのまま

このままでは、Aの乙建物はCの土地の上に**何の権利もなく**建っていることになり、取り壊すしかありません。それでは社会的な損失が大きいので、法律が自動的に土地利用権を発生させます。これが**法定地上権**です。

### 🟡 法定地上権の成立要件（4つ）

1. **抵当権設定当時**、土地の上に**建物が存在**していた
2. 設定当時、**土地と建物の所有者が同一**であった
3. 土地・建物の一方または双方に抵当権が設定された
4. 競売により、土地と建物の**所有者が別々**になった

特に1と2がひっかけどころです。**更地**に抵当権を設定した後に建物を建てても、法定地上権は**成立しません**（更地として高く評価した抵当権者を害するからです）。

### 一括競売

更地に抵当権を設定した後に建物が建てられた場合、抵当権者は土地と建物を**一括して競売**できます。ただし、優先弁済を受けられるのは**土地の代金からだけ**です。

ここまで分かれば、この論点は十分です。

### 確認問題

**問1.** Aは、自己所有の甲土地（その上にA所有の乙建物が存在）について、B銀行のために抵当権を設定した。その後抵当権が実行され、Cが競売により甲土地を買い受けた。この場合に関する記述として正しいものはどれか。

1. 乙建物のために法定地上権が成立し、Aは甲土地を利用して乙建物を所有し続けることができる
2. AとCが地上権設定契約を締結しない限り、Aは乙建物を収去しなければならない
3. 法定地上権は、建物に抵当権が設定された場合にしか成立しない
4. 競売により、Aは乙建物の所有権も失う

<details><summary>答えと解説</summary>

正解: **1**

抵当権設定当時に土地上に建物があり、土地と建物が同一所有者で、競売により所有者が別々になったので、法定地上権が成立します。法律上当然に成立するため、CとのA間の契約は不要です。土地・建物のどちらに抵当権を設定した場合でも成立し得ますし、建物の所有権が競売で失われることもありません。

</details>

**問2.** Aは、更地である甲土地にB銀行のための抵当権を設定し、その後、甲土地上に乙建物を建築した。抵当権が実行されて甲土地はCが買い受けた。この場合に関する記述として正しいものはどれか。

1. 法定地上権が成立し、Aは乙建物のために甲土地を利用できる
2. 抵当権設定当時に建物が存在しなかったため、法定地上権は成立しない
3. 建物が完成した時点で、法定地上権が成立する
4. B銀行が建築を承認していた場合には、法定地上権が成立する

<details><summary>答えと解説</summary>

正解: **2**

法定地上権の成立には、抵当権設定当時に土地上に建物が存在したことが必要です。更地に設定した後に建てられた建物のためには成立しません。土地を更地として高く評価した抵当権者の期待を害するからで、建物の完成や抵当権者の承認によって成立するものでもありません（判例）。

</details>

**問3.** 更地にB銀行の抵当権が設定された後、設定者Aがその土地上に乙建物を建築した場合の一括競売に関する記述として正しいものはどれか。

1. 一括競売をした場合、B銀行は土地と建物の双方の代金から優先弁済を受けられる
2. 更地への抵当権設定後に建物が建てられた場合、B銀行は土地のみしか競売できない
3. B銀行は土地とともに乙建物も一括して競売することができるが、優先弁済を受けられるのは土地の代金についてのみである
4. 一括競売をするには、建物所有者Aの同意を得なければならない

<details><summary>答えと解説</summary>

正解: **3**

更地に抵当権を設定した後に建物が築造された場合、抵当権者は土地と建物を一括して競売できます（建物だけ残っても使い道がないため）。ただし抵当権は土地にしか設定されていないので、優先弁済を受けられるのは土地の代金に限られます。設定者の同意は不要です。

</details>

## 4. 根抵当権と保証・連帯債務ざっくり

### 根抵当権（ねていとうけん）

卸売業を営むAさんは、B銀行と継続的に「借りては返す」を繰り返します。そのたびに抵当権を設定したり抹消したりするのは大変です。そこで、**極度額**（上限。例: 5000万円）を定めて、**一定の範囲に属する不特定の債権**をまとめて担保するのが**根抵当権**です。

- 極度額の範囲内であれば、利息も**2年分に限定されずに**担保されます
- **元本確定前**は、個々の債権が弁済されても根抵当権は消滅しません（付従性・随伴性がありません）

### 保証と連帯保証ざっくり

AのB銀行に対する借金を、Cさんが**保証**するケースです。

- 保証契約は、**書面（または電磁的記録）でしなければ無効**です
- 普通の保証人には、「まず主たる債務者Aに請求してほしい」と言える**催告の抗弁**と、「Aの財産から先に執行してほしい」と言える**検索の抗弁**があります
- **連帯保証人**には、この2つの抗弁が**ありません**（いきなり全額を請求されても拒めません）

### 連帯債務ざっくり

複数人がそれぞれ全額の支払義務を負うのが連帯債務で、債権者は誰に対してでも全額を請求できます。

⚪ この論点の出題頻度は低めです。「極度額」「保証は書面」「連帯保証には抗弁がない」の3点だけ押さえれば、ここまでで十分です。

### 確認問題

**問1.** 根抵当権に関する次の記述のうち、正しいものはどれか。

1. 根抵当権は、極度額を定めずに設定することができる
2. 元本の確定前に個々の被担保債権が弁済されると、根抵当権はその都度消滅する
3. 根抵当権は、極度額の範囲内で、一定の範囲に属する不特定の債権を担保する
4. 根抵当権で担保される利息は、普通の抵当権と同様に、常に満期となった最後の2年分に限られる

<details><summary>答えと解説</summary>

正解: **3**

根抵当権は、極度額を限度として、一定の範囲に属する不特定の債権を担保する抵当権です。極度額の定めは必須であり、元本確定前は付従性がないため個々の債権の弁済では消滅しません。また極度額の範囲内であれば、利息は2年分に限定されず担保されます。

</details>

**問2.** Cは、AのB銀行に対する借入金債務を保証することを、B銀行との間で口頭で約束した。この場合に関する記述として正しいものはどれか。

1. 保証は当事者の合意のみで成立するため、口頭の約束でも有効である
2. 保証契約は書面（または電磁的記録）でしなければ効力を生じないため、この保証契約は無効である
3. B銀行が承諾している以上、口頭の保証も有効である
4. この保証契約は、取り消すことができる契約として一応有効に成立する

<details><summary>答えと解説</summary>

正解: **2**

保証契約は、保証人が軽率に重い責任を負うことを防ぐため、書面（または電磁的記録）でしなければ効力を生じません。口頭の約束は無効であり、債権者が承諾していても同じです。「取り消せるが一応有効」ではなく、はじめから効力が生じない点に注意しましょう。

</details>

**問3.** Cは、AのB銀行に対する借入金債務について、書面により連帯保証人となった。この場合に関する記述として正しいものはどれか。

1. Cは、催告の抗弁権も検索の抗弁権も有しない
2. Cは、まずAに請求するようB銀行に求めることができる
3. Cは、Aの財産から先に執行するようB銀行に求めることができる
4. B銀行は、Aに請求した後でなければCに請求することができない
