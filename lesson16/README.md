# 第16章 相続・共有・区分所有法

人が亡くなったら財産はどうなる？　マンションのルールは誰が決める？　相続・共有・区分所有法という「複数人で財産に関わる」場面の章です。相続分の分数と区分所有法の決議の数字は、ゴロで固めれば確実な得点源になります。

## 1. 相続のきほん（誰が・どれだけ相続する？）

Aさんが亡くなり、妻Bさんと子C・Dさんが残されました。誰がどれだけ相続するのでしょうか。

### 相続人の順位

**配偶者は常に相続人**です。そのうえで、次の順位の人が配偶者と一緒に相続します。

| 順位 | 相続人 | 配偶者の相続分 | 血族側の相続分 |
|---|---|---|---|
| 第1順位 | **子** | **1/2** | **1/2** |
| 第2順位 | **直系尊属**（父母など） | **2/3** | **1/3** |
| 第3順位 | **兄弟姉妹** | **3/4** | **1/4** |

血族側が複数いるときは、その中で**均等に分けます**（妻Bが1/2、子C・Dが各1/4）。

> 💡 ゴロ：「血族側の分母は**ニ・サン・シ（2・3・4）**」——子は1/2、親は1/3、兄弟は1/4と、順位が下がるほど分母が増えます。

### 代襲相続

子Cが親Aより先に死亡していた場合、Cの子（Aの孫）Eが代わりに相続します。これが**代襲相続**です。子の系統は孫・ひ孫と**再代襲**しますが、兄弟姉妹の代襲は**甥・姪まで（一代限り）**です。なお、**相続放棄をした人の子は代襲しません**（放棄は代襲原因にならない）。

🔴 相続分の計算問題は毎年のように出ます。分数を即答できるまで練習しましょう。

### 確認問題

**問1.** Aが死亡し、相続人は妻Bと子C・Dの3人である。法定相続分として正しいものはどれでしょう？

1. B・C・Dが各3分の1
2. Bが2分の1、CとDが各4分の1
3. Bが3分の2、CとDが各6分の1
4. Bが4分の3、CとDが各8分の1

<details><summary>答えと解説</summary>

正解: **2**

配偶者と子が相続人のときは、配偶者が2分の1、子が全体で2分の1です。子が2人いるので、2分の1を均等に分けて各4分の1となります。3分の2は直系尊属と、4分の3は兄弟姉妹と相続する場合の配偶者の相続分です。

</details>

**問2.** Aが死亡した。Aに子はなく、相続人は妻Bと、Aの母Cである。法定相続分として正しいものはどれでしょう？

1. Bが2分の1、Cが2分の1
2. Bが4分の3、Cが4分の1
3. Bがすべてを相続し、Cは相続しない
4. Bが3分の2、Cが3分の1

<details><summary>答えと解説</summary>

正解: **4**

子がいないときは第2順位の直系尊属（母C）が配偶者とともに相続し、相続分は配偶者3分の2・直系尊属3分の1です。4分の3・4分の1は兄弟姉妹と相続する場合の割合であり、直系尊属がいる以上、配偶者がすべてを相続するわけではありません。

</details>

**問3.** Aが死亡したが、Aの子Cは、Aより先に死亡していた。Cには子E（Aの孫）がいる。Eの地位について正しいものはどれでしょう？

1. EはCを代襲してAの相続人となる
2. Cの相続分はAの妻Bにすべて帰属する
3. EはAの相続人にはならない
4. Eは家庭裁判所の許可を得た場合に限り相続人となる

<details><summary>答えと解説</summary>

正解: **1**

子が被相続人より先に死亡していたときは、その子（被相続人の孫）が代襲して相続人になります。代襲相続に家庭裁判所の許可は不要です。Cの相続分が配偶者に移るのではなく、代襲者Eが受け継ぎます。

</details>

**問4.** Aが死亡し、Aの子Cは家庭裁判所に申述して相続を放棄した。Cには子E（Aの孫）がいる。Eの地位について正しいものはどれでしょう？

1. EがCを代襲してAの相続人となる
2. Cは放棄を撤回して、Eに相続させることができる
3. 相続放棄は代襲相続の原因とならないため、EはAの相続人にならない
4. Eは兄弟姉妹の地位でAを相続する

<details><summary>答えと解説</summary>

正解: **3**

代襲相続の原因は死亡・欠格・廃除であり、相続放棄は含まれません。放棄した人は初めから相続人でなかったものとみなされるため、その子Eも代襲しません。放棄は原則として撤回できず、孫Eが兄弟姉妹の地位で相続することもありません。

</details>

## 2. 遺言と遺留分・相続の承認放棄

「財産はすべて長男に」——Aさんはこんな**遺言**を残せます。遺言は**15歳**からでき、いつでも撤回できます。

### 自筆証書遺言のルール

全文・日付・氏名を**自書**して押印するのが原則ですが、**財産目録はパソコンで作成してもOK**（ただし目録の各頁に署名押印が必要）です。法務局の保管制度を利用すれば、家庭裁判所の**検認も不要**になります。

### 遺留分——最低限の取り分

遺言でも奪えない相続人の最低限の取り分が**遺留分**です。

| 誰に | 割合 |
|---|---|
| 配偶者・子など | 相続財産の**1/2** |
| 直系尊属のみが相続人 | **1/3** |
| **兄弟姉妹** | **遺留分なし！** |

侵害されたら**遺留分侵害額請求**として**金銭**を請求します（遺贈自体が無効になるのではありません）。

### 承認・放棄は3か月以内

相続人は、**自己のために相続の開始があったことを知った時から3か月以内**に、単純承認・限定承認・放棄を選びます。放棄は**家庭裁判所への申述**が必要です。

> 💡 ゴロ：「**兄弟にイリュウブンなし**」「**迷えるのは3か月**」。

🟡 「兄弟姉妹には遺留分なし」と「3か月」の2点をまず確実に。

### 確認問題

**問1.** Aは「全財産を友人Fに遺贈する」という遺言を残して死亡した。Aの相続人は兄Gのみである。Gの遺留分について正しいものはどれでしょう？

1. Gは遺産の4分の1について遺留分を主張できる
2. 遺留分を侵害する遺贈なので、遺贈は無効である
3. Gは遺産の2分の1について遺留分を有する
4. 兄弟姉妹に遺留分はないため、Gは遺留分侵害額請求ができない

<details><summary>答えと解説</summary>

正解: **4**

兄弟姉妹には遺留分が認められていません。したがって兄Gは遺留分侵害額請求ができず、遺贈はそのまま有効です。なお遺留分を侵害する遺贈があっても遺贈自体が無効になるのではなく、遺留分権利者が金銭を請求できるにとどまります。

</details>

**問2.** 相続の放棄をしたい相続人がとるべき手続として、正しいものはどれでしょう？

1. 自己のために相続の開始があったことを知った時から3か月以内に、家庭裁判所に申述する
2. 相続開始の時から1年以内であれば、いつでも放棄できる
3. 他の相続人全員に放棄する旨を通知すれば、放棄の効力が生じる
4. 相続開始を知った時から10か月以内に税務署へ届け出る

<details><summary>答えと解説</summary>

正解: **1**

相続の放棄は、自己のために相続の開始があったことを知った時から3か月以内に、家庭裁判所に申述して行います。起算点は「相続開始の時」ではなく「知った時」です。他の相続人への通知や税務署への届出では放棄の効力は生じません（10か月は相続税の申告期限です）。

</details>

**問3.** 自筆証書遺言の方式について、正しいものはどれでしょう？

1. 遺言書の全文をパソコンで作成することができる
2. 本文は自書が必要だが、添付する財産目録はパソコンで作成できる（各頁に署名押印が必要）
3. 日付の記載は省略することができる
4. 作成には証人2人以上の立会いが必要である

<details><summary>答えと解説</summary>

正解: **2**

自筆証書遺言は全文・日付・氏名の自書と押印が原則ですが、法改正により財産目録に限ってはパソコン作成等が認められています（各頁に署名押印が必要）。本文まで含めた全文のパソコン作成は不可で、日付も省略できません。証人の立会いが必要なのは公正証書遺言です。

</details>

## 3. 配偶者居住権と相続登記の義務化

夫Aさんが死亡し、遺産は自宅（2,000万円）と預貯金（2,000万円）。妻Bさんが自宅の所有権を相続すると、それだけで相続分を使い切り、生活費の預貯金を受け取れません。そこで生まれたのが**配偶者居住権**です。自宅を「**所有権**（子が取得）」と「**居住権**（Bが取得）」に分けることで、Bさんは住み続けながら預貯金も確保できます。

### 配偶者居住権のポイント

- 存続期間は原則**終身**・無償で居住できる
- **登記が対抗要件**（居住建物の所有者は登記を備えさせる義務を負う。借家と違い「引渡し」では対抗できない）
- **譲渡はできない**。増改築や第三者への賃貸には所有者の承諾が必要

### 相続登記の義務化（2024年4月〜）

所有者不明土地の対策として、**2024年4月1日**から相続登記が**義務化**されました。

| 項目 | 内容 |
|---|---|
| 期限 | 相続で不動産の取得を**知った日から3年以内** |
| 怠ると | 正当な理由がなければ**10万円以下の過料** |
| 救済 | 遺産分割がまとまらなくても「**相続人申告登記**」で義務を果たせる |

> 💡 ゴロ：「相続登記は**サン（3）年・ジュウ（10）万**」。

🟡 どちらも比較的新しい制度で、出題者が大好きな論点です。

### 確認問題

**問1.** 配偶者居住権の性質について、正しいものはどれでしょう？

1. 配偶者居住権は、第三者に自由に譲渡することができる
2. 配偶者居住権の存続期間は、最長10年に制限されている
3. 配偶者居住権は、譲渡することができない
4. 配偶者居住権を取得した配偶者は、居住建物の所有権も当然に取得する

<details><summary>答えと解説</summary>

正解: **3**

配偶者居住権は配偶者本人の居住を保護するための権利なので、譲渡はできません。存続期間は原則として配偶者の終身の間です。また、所有権と居住権を分けることに意味がある制度なので、居住権を取得しても所有権を取得するわけではありません。

</details>

**問2.** 妻Bは配偶者居住権を取得して居住建物に住んでいる。その後、建物の所有者である子Cが建物を第三者Dに売却した。BがDに配偶者居住権を対抗するために必要なものはどれでしょう？

1. 居住の事実があれば、何もしなくても対抗できる
2. 配偶者居住権の登記をしていれば、Dに対抗できる
3. 建物の引渡しを受けていれば対抗できる（借家の場合と同じ）
4. 配偶者居住権を第三者に対抗する方法はない

<details><summary>答えと解説</summary>

正解: **2**

配偶者居住権の対抗要件は登記です。借地借家法上の建物賃借権は引渡しで対抗できますが、配偶者居住権にはその規定が適用されず、引渡しや居住の事実だけでは対抗できません。なお居住建物の所有者は、配偶者に登記を備えさせる義務を負います。

</details>

**問3.** 2024年4月1日に施行された相続登記の申請義務化について、正しいものはどれでしょう？

1. 相続により不動産の所有権を取得したことを知った日から3年以内に登記を申請しなければならず、正当な理由なく怠ると10万円以下の過料の対象となる
2. 相続登記はあくまで任意であり、怠っても制裁はない
3. 相続開始から1年以内に登記をしないと、不動産の所有権を失う
4. 登記を怠った場合の過料は100万円以下である

<details><summary>答えと解説</summary>

正解: **1**

相続登記は義務化され、取得を知った日から3年以内の申請が必要で、正当な理由なく怠ると10万円以下の過料の対象です。所有権を失うという効果はありません。遺産分割がまとまらない場合でも、相続人申告登記をすれば義務を履行したことになります。

</details>

## 4. 共有（ホは一人・カは過半数・ヘは全員）

A・B・Cさんの3人が、別荘を**持分各1/3**で共有しています。この別荘について「誰の同意があれば何ができるか」が共有の核心です。

### 行為の3段階

| 行為 | 例 | 必要な同意 |
|---|---|---|
| **保存行為** | 雨漏りの修理、不法占拠者への明渡請求 | **各共有者が単独で**できる |
| **管理行為** | 短期の賃貸借、賃料の決定、軽微な変更 | **持分の価格の過半数**（人数ではない！） |
| **変更行為**（重大） | 建替え、売却、農地への造成 | **全員の同意** |

注意点は2つ。①過半数は「人数」ではなく**持分の価格**で数えます。②法改正により、形状・効用の著しい変更を伴わない**軽微な変更**は、全員同意ではなく**過半数**でできるようになりました。

### 分割はいつでも請求できる

各共有者は**いつでも**共有物の分割を請求できます（ただし**5年以内**の不分割特約は有効）。

> 💡 ゴロ：「**ホ**（保存）は一人、**カ**（管理）は過半数、**ヘ**（変更）は全員」——ホ・カ・ヘで覚えましょう。

🟡 「どの行為がどの段階か」を事例で判定できれば十分です。

### 確認問題

**問1.** A・B・Cが持分各3分の1で建物を共有している。建物を不法に占拠するDに対する明渡請求について、正しいものはどれでしょう？

1. 持分の価格の過半数の同意がなければ請求できない
2. 保存行為として、各共有者が単独で請求できる
3. 共有者全員の同意がなければ請求できない
4. 持分が過半数を超える共有者だけが請求できる

<details><summary>答えと解説</summary>

正解: **2**

不法占拠者への明渡請求は共有物の現状を維持する保存行為なので、各共有者が単独でできます。過半数や全員の同意は不要です。保存行為に持分の大小は関係ありません。

</details>

**問2.** A・B・Cが持分各3分の1で共有する建物について、AとBは賛成、Cは反対のまま、期間3年の短期の賃貸借（管理行為に当たるもの）を設定したい。正しいものはどれでしょう？

1. 共有物の利用に関する事項なので、全員の同意がない以上できない
2. 管理行為であっても、各共有者が単独で決定できる
3. 賛成が持分の過半数に満たないため、できない
4. 持分の価格の過半数（3分の2）の賛成があるため、管理行為として行うことができる

<details><summary>答えと解説</summary>

正解: **4**

共有物の管理に関する事項は、持分の価格の過半数で決します。AとBの持分を合わせると3分の2で過半数に達するため、Cが反対していても行えます。管理行為は全員同意までは不要ですが、単独でできるのは保存行為だけです。

</details>

**問3.** 共有物に変更（その形状又は効用の著しい変更を伴うもの）を加える場合について、正しいものはどれでしょう？

1. 共有者全員の同意が必要である
2. 持分の価格の過半数の同意があればできる
3. 持分が最も多い共有者が単独で決定できる
4. 裁判所の許可があれば各共有者が単独でできる

<details><summary>答えと解説</summary>

正解: **1**

建替えや売却のような重大な変更行為には、共有者全員の同意が必要です。過半数で足りるのは管理行為（および軽微な変更）であり、持分が最大の者でも単独では変更できません。裁判所の許可で単独変更ができるという制度もありません。

</details>

## 5. 区分所有法（マンションの決議は過半数・3/4・4/5）

Bさんが分譲マンションの301号室を買いました。301号室のように独立して所有できる部分が**専有部分**、廊下・階段・エレベーターなどが**共用部分**です。共用部分の持分は、規約に別段の定めがない限り**専有部分の床面積の割合**によります。

マンション全体のことは、区分所有者の**集会**の決議で決めます（集会は少なくとも**年1回**招集）。

### 決議に必要な数（従来の原則）

| 決議事項 | 必要な賛成（区分所有者**及び**議決権の各〜） |
|---|---|
| 普通決議（管理者の選任など） | **過半数** |
| 規約の設定・変更・廃止 | **3/4以上** |
| **建替え** | **4/5以上** |

> 💡 ゴロ：「規約は**ミシ（3/4）**っと、建替え**シゴ（4/5）**と」。跳び箱のように 過半数 → 3/4 → 4/5 と上がっていくイメージです。

> ⚠️ **改正あり**：2026年4月施行の区分所有法改正で、建替え決議の多数決要件の緩和（所在不明者を母数から除く仕組みなど）が導入されます。上の表は**従来の原則**です。受験年度の最新情報を必ず確認してください。

🔴 決議の数字はマンション管理の問題でも使う頻出知識。表を丸ごと覚えましょう。

### 確認問題

**問1.** 区分所有法の従来の原則では、規約の設定・変更・廃止を行うために必要な集会の決議はどれでしょう？

1. 区分所有者及び議決権の各過半数
2. 区分所有者全員の同意
3. 区分所有者及び議決権の各4分の3以上の多数
4. 区分所有者及び議決権の各5分の4以上の多数

<details><summary>答えと解説</summary>

正解: **3**

規約の設定・変更・廃止は、区分所有者及び議決権の各4分の3以上の多数による集会の決議で行います（従来の原則）。過半数は普通決議、5分の4以上は建替え決議の要件であり、全員の同意までは不要です。

</details>

**問2.** 区分所有法の従来の原則では、建物の建替え決議に必要な集会の賛成はどれでしょう？

1. 区分所有者及び議決権の各4分の3以上
2. 区分所有者及び議決権の各5分の4以上
3. 区分所有者及び議決権の各過半数
4. 区分所有者全員の一致

<details><summary>答えと解説</summary>

正解: **2**

**問3.** 集会における管理者の選任（普通決議事項）について、規約に別段の定めがない場合、正しいものはどれでしょう？

1. 区分所有者及び議決権の各過半数で決する
2. 区分所有者及び議決権の各4分の3以上の多数が必要である
3. 区分所有者及び議決権の各5分の4以上の多数が必要である
4. 区分所有者全員の同意がなければ選任できない

<details><summary>答えと解説</summary>

正解: **1**

管理者の選任・解任のような普通決議事項は、規約に別段の定めがない限り、区分所有者及び議決権の各過半数で決します。4分の3や5分の4という特別多数は、規約の変更や建替えなどの特別決議事項に必要な数であり、全員の同意までは要求されません。

</details>

**問4.** マンションの共用部分に対する各区分所有者の持分について、規約に別段の定めがない場合、正しいものはどれでしょう？

1. 区分所有者の頭数で均等に分けられる
2. 専有部分の購入価格の割合による
3. 上の階に住む者ほど大きな持分を持つ
4. 専有部分の床面積の割合による

<details><summary>答えと解説</summary>

正解: **4**

共用部分の持分は、規約に別段の定めがない限り、各区分所有者が有する専有部分の床面積の割合によります。頭数や購入価格、階数で決まるわけではありません。

</details>
