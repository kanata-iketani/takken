**問1.** 【問1】詐欺または強迫による意思表示に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. Aが、Bの詐欺によってA所有の甲土地をBに売却した場合、Aは、取消し前にBから甲土地を買い受けた善意無過失の第三者Cに対しても、取消しを対抗できる
2. 第三者Dの詐欺によってAがBに甲土地を売却した場合、Bがその詐欺の事実を知らず、かつ知ることができなかったときでも、Aは売買契約を取り消すことができる
3. Aが、Bの強迫によってA所有の甲土地をBに売却した場合、Aは、取消し前にBから甲土地を買い受けた善意無過失の第三者Cに対しても、取消しを対抗できる
4. 強迫による意思表示は、取り消すまでもなく当然に無効である

<details><summary>答えと解説</summary>

正解: **3**

強迫による取消しは、詐欺と異なり善意無過失の第三者にも対抗できます。強迫された者には落ち度がないため保護が厚いのです。詐欺による取消しは善意無過失の第三者に対抗できないので肢1は誤り。第三者の詐欺の場合、相手方がその事実を知り、または知ることができたときに限り取り消せるため肢2も誤り。強迫による意思表示は無効ではなく「取り消すことができる」にとどまるので肢4も誤りです。

</details>

**問2.** 【問2】代理に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 委任による代理人は、本人の許諾を得たとき、またはやむを得ない事由があるときでなければ、復代理人を選任することができない
2. 代理人が、本人の許諾を得ずに当事者双方の代理人となってした契約は、当然に有効である
3. 復代理人を選任した代理人は、復代理人を選任したことにより自己の代理権を失う
4. 代理人が自己の利益を図る目的で代理権の範囲内の行為をした場合、相手方がその目的を知っていたときでも、その行為の効果は当然に本人に帰属する

<details><summary>答えと解説</summary>

正解: **1**

任意代理人（委任による代理人）が復代理人を選任できるのは、本人の許諾があるとき、またはやむを得ない事由があるときに限られます。双方代理は原則として無権代理行為とみなされるため、当然に有効とする肢2は誤り。復代理人を選任しても代理人自身の代理権は消滅しないので肢3も誤り。代理権の濫用は、相手方がその目的を知り、または知ることができたときは無権代理行為とみなされるため肢4も誤りです。

</details>

**問3.** 【問3】消滅時効に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 債権は、債権者が権利を行使することができることを知った時から10年間行使しないときに、時効によって消滅する
2. 裁判上の請求をした場合、訴えの取下げにより権利が確定することなく裁判が終了したときでも、時効は直ちに更新される
3. 時効の利益は、時効が完成する前であっても、あらかじめ放棄することができる
4. 債務者が債権者に対して債務を承認したときは、その時から新たに時効が進行する

<details><summary>答えと解説</summary>

正解: **4**

債務の承認は時効の更新事由であり、承認の時から新たに時効が進行します。債権の消滅時効は「権利を行使できることを知った時から5年」または「権利を行使できる時から10年」であり、肢1は組み合わせが誤りです。裁判上の請求が権利の確定に至らず終了した場合は、終了の時から6か月間の完成猶予が生じるだけで更新はされないので肢2も誤り。時効の利益はあらかじめ放棄できないため肢3も誤りです。

</details>

**問4.** 【問4】A・B・Cの3人が、Dに対して900万円の連帯債務を負っている（負担部分は各3分の1）。この場合に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. DがAに対して履行を請求すると、その効力はBおよびCにも及び、全員について時効の完成が猶予される
2. Aが900万円全額をDに弁済したときは、Aは、BおよびCに対し、それぞれの負担部分である300万円ずつを求償することができる
3. Aのために時効が完成したときは、BおよびCも、Aの負担部分について債務を免れる
4. DがAに対して債務の全部を免除したときは、BおよびCも、全額について支払義務を免れる

<details><summary>答えと解説</summary>

正解: **2**

連帯債務者の1人が全額を弁済したときは、他の債務者に対して各自の負担部分（本問では各300万円）を求償できます。改正民法では、連帯債務者の1人への履行の請求、時効の完成、免除はいずれも原則として他の債務者に効力が及ばない相対効とされているため、肢1・肢3・肢4はすべて誤りです（絶対効が認められるのは弁済のほか、更改・相殺・混同です）。

</details>

**問5.** 【問5】保証に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 保証契約は、口頭の合意によっても、その効力を生ずる
2. 連帯保証人は、債権者から履行を請求されたときは、まず主たる債務者に催告すべき旨を請求することができる
3. 個人が、一定の範囲に属する不特定の債務を主たる債務として保証する契約（個人根保証契約）は、極度額を定めなければ、その効力を生じない
4. 主たる債務者に生じた事由は、保証人に対して一切その効力を及ぼさない

<details><summary>答えと解説</summary>

正解: **3**

個人根保証契約（例えば建物賃貸借の個人の連帯保証人）は、書面等で極度額を定めなければ無効です。保証契約は書面（または電磁的記録）でしなければ効力を生じないので肢1は誤り。催告の抗弁権・検索の抗弁権は連帯保証人にはないため肢2も誤り。主たる債務者に生じた事由は付従性により原則として保証人にも効力が及ぶので、肢4の「一切及ぼさない」も誤りです。

</details>

**問6.** 【問6】抵当権に関する次の記述のうち、民法の規定および判例によれば正しいものはどれでしょう？

1. 抵当権者は、抵当権の目的である建物が焼失した場合、抵当権設定者が受け取るべき火災保険金について、その払渡し前に差し押さえることにより物上代位権を行使することができる
2. 抵当権設定登記後に賃貸借契約を締結して競売手続開始前から建物を使用している賃借人は、競売における買受人の買受けの時から1年間、建物の明渡しを猶予される
3. 抵当不動産を買い受けた第三取得者は、抵当権者に対して抵当権消滅請求をすることができない
4. 抵当権の順位は、いったん登記をした後は、変更することができない

<details><summary>答えと解説</summary>

正解: **1**

抵当権には物上代位性があり、目的物の滅失により設定者が受け取る火災保険金にも、払渡し前に差し押さえることで効力を及ぼせます。抵当権設定登記後の賃借人の明渡し猶予期間は買受けの時から6か月であり、1年とする肢2は誤り。第三取得者は抵当権消滅請求ができるので肢3も誤り。抵当権の順位は各抵当権者の合意（利害関係者がいればその承諾も必要）によって変更できるため肢4も誤りです。

</details>

**問7.** 【問7】Aを売主、Bを買主として甲建物の売買契約が締結された場合の目的物の滅失と危険の移転に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 甲建物の引渡し後に、当事者双方の責めに帰することができない事由により甲建物が滅失した場合、Bは契約を解除して代金の支払を免れることができる
2. 甲建物の引渡し後に、当事者双方の責めに帰することができない事由により甲建物が滅失した場合、Bは代金の支払を拒むことができない
3. 甲建物の引渡し前に、当事者双方の責めに帰することができない事由により甲建物が滅失した場合、Bは契約を解除することができない
4. 甲建物の引渡し前の滅失がBの責めに帰すべき事由によるものである場合、Bは代金の支払を拒むことができる

<details><summary>答えと解説</summary>

正解: **2**

目的物の引渡しによって滅失・損傷の危険は買主に移転するため、引渡し後に双方無責で滅失しても、買主は代金の支払を拒めず、解除や損害賠償請求もできません。したがって肢1は誤り、肢2が正しい記述です。引渡し前に双方無責で滅失した場合は履行不能として買主は無催告で解除できるので肢3は誤り。滅失が買主の帰責事由による場合、買主は代金の支払を拒めないため肢4も誤りです。

</details>

**問8.** 【問8】請負契約に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 請負契約は、書面を作成しなければ、その効力を生じない
2. 仕事の目的物に契約不適合がある場合でも、注文者は、請負人に対して報酬の減額を請求することができない
3. 注文者は、請負人が仕事を完成した後であっても、損害を賠償することなく、いつでも契約を解除することができる
4. 請負人が仕事を完成することができなくなった場合でも、既にした仕事の結果のうち可分な部分によって注文者が利益を受けるときは、請負人はその利益の割合に応じて報酬を請求することができる

<details><summary>答えと解説</summary>

正解: **4**

仕事の完成が不能となった場合などでも、既履行部分が可分であり注文者が利益を受けるときは、請負人はその割合に応じた報酬（割合的報酬）を請求できます。請負契約は諾成契約であり書面は不要なので肢1は誤り。仕事の目的物の契約不適合について注文者は追完請求・報酬減額請求・損害賠償・解除ができるため肢2も誤り。注文者が損害を賠償していつでも解除できるのは仕事の完成「前」に限られるので肢3も誤りです。

</details>

**問9.** 【問9】委任契約に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 無償で委任を受けた受任者は、自己の財産に対するのと同一の注意をもって委任事務を処理すれば足りる
2. 受任者は、特約がなくても、委任者に対して報酬を請求することができる
3. 委任契約は、各当事者が、いつでもその解除をすることができる
4. 委任契約は、委任者または受任者が死亡しても終了しない

<details><summary>答えと解説</summary>

正解: **3**

委任は当事者間の信頼関係を基礎とするため、各当事者はいつでも解除できます（相手方に不利な時期の解除などでは損害賠償が必要な場合があります）。受任者は報酬の有無にかかわらず善良な管理者の注意義務を負うので肢1は誤り。委任は無償が原則で、特約がなければ報酬を請求できないため肢2も誤り。委任は当事者の死亡・破産（受任者については後見開始も）により終了するので肢4も誤りです。

</details>

**問10.** 【問10】借地借家法の借地権に関する次の記述のうち、正しいものはどれでしょう？（定期借地権等は考えないものとします）

1. 借地権の存続期間が満了し、契約の更新がない場合、借地権者は、借地権設定者に対し、借地上の建物を時価で買い取るべきことを請求することができる
2. 建物買取請求権を行使するには、借地権設定者の承諾を得なければならない
3. 当初の存続期間中に建物が滅失し、借地権者が借地権設定者の承諾を得て残存期間を超えて存続すべき建物を再築した場合でも、借地権の期間は延長されない
4. 借地権者の債務不履行により借地契約が解除された場合でも、借地権者は建物買取請求権を行使することができる

<details><summary>答えと解説</summary>

正解: **1**

期間満了で更新がない場合、借地権者は建物買取請求権を行使して建物を時価で買い取らせることができます。建物買取請求権は一方的な意思表示で効果が生じる形成権であり、相手方の承諾は不要なので肢2は誤り。当初期間中の滅失後に承諾を得て再築した場合は、承諾日または築造日のいずれか早い日から20年間存続期間が延長されるため肢3も誤り。債務不履行解除の場合には建物買取請求権は認められないので肢4も誤りです。

</details>

**問11.** 【問11】借地借家法の建物賃貸借に関する次の記述のうち、正しいものはどれでしょう？

1. 賃貸人の同意を得て建物に付加した造作の買取請求権を排除する特約は、賃借人に不利なものとして無効である
2. 造作買取請求権は、賃借人の債務不履行により賃貸借契約が解除された場合にも行使することができる
3. 居住用建物の賃借人が相続人なしに死亡した場合、賃借人と事実上夫婦と同様の関係にあった同居者は、賃借人の権利義務を承継することができない
4. 適法に転貸借がされている建物の賃貸借が期間満了により終了する場合、賃貸人は転借人にその旨を通知しなければ終了を転借人に対抗できず、通知をしたときは転貸借は通知後6か月を経過することによって終了する

<details><summary>答えと解説</summary>

正解: **4**

賃貸借が期間満了または解約申入れで終了するときは、賃貸人は転借人への通知が必要で、通知から6か月の経過により転貸借が終了します。造作買取請求権を排除する特約は有効とされているので肢1は誤り。債務不履行解除の場合には造作買取請求権は行使できないため肢2も誤り。相続人なしに死亡した居住用建物の賃借人と事実上夫婦等の関係にあった同居者は、賃借人の権利義務を承継できるので肢3も誤りです。

</details>

**問12.** 【問12】相続に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 相続人は、自己のために相続の開始があったことを知った時から1か月以内に、単純承認・限定承認・相続放棄のいずれかをしなければならない
2. 配偶者居住権は、遺産分割や遺贈などによって取得するものであり、被相続人の配偶者は、相続開始時に居住していた被相続人所有の建物を、原則として終身の間、無償で使用収益することができる
3. 配偶者居住権は、登記をしなくても、居住建物を取得した第三者に対抗することができる
4. 相続人が相続財産の一部を処分した後であっても、限定承認をすることができる

<details><summary>答えと解説</summary>

正解: **2**

配偶者居住権は、遺産分割・遺贈等により取得し、原則として配偶者の終身の間、無償で居住建物を使用収益できる権利です。承認・放棄の熟慮期間は知った時から3か月であり、1か月とする肢1は誤り。配偶者居住権を第三者に対抗するには登記が必要（建物の引渡しでは対抗できません）なので肢3も誤り。相続財産の全部または一部を処分すると法定単純承認となり、限定承認や放棄はできなくなるため肢4も誤りです。

</details>

**問13.** 【問13】建物の区分所有等に関する法律における集会および規約に関する次の記述のうち、正しいものはどれでしょう？

1. 規約の設定・変更・廃止は、区分所有者および議決権の各4分の3以上の多数による集会の決議によって行う
2. 建替え決議は、区分所有者および議決権の各3分の2以上の多数で行うことができる
3. 集会の招集の通知は、会日より少なくとも2週間前に発しなければならず、規約でこれを伸縮することはできない
4. 管理者は、少なくとも毎年2回、集会を招集しなければならない

<details><summary>答えと解説</summary>

正解: **1**

規約の設定・変更・廃止は区分所有者および議決権の各4分の3以上の特別決議事項です。建替え決議にはさらに重い各5分の4以上の賛成が必要なので、3分の2とする肢2は誤り。集会の招集通知は会日の少なくとも1週間前に発すればよく、規約で伸縮もできるため肢3も誤り。管理者による集会の招集義務は少なくとも毎年1回なので肢4も誤りです。

</details>

**問14.** 【問14】不動産登記法に関する次の記述のうち、正しいものはどれでしょう？

1. 売買による所有権移転登記の申請は、登記権利者である買主が単独で行うことができる
2. 仮登記に基づいて本登記をした場合、その本登記の順位は、本登記をした時の順位による
3. 新築した建物の所有権を取得した者は、その所有権の取得の日から1か月以内に、表題登記を申請しなければならない
4. 登記の申請は、登記所に書面を提出する方法によらなければならず、オンラインによる申請は認められていない

<details><summary>答えと解説</summary>

正解: **3**

## 2. フル模試 第3回・後半戦（問26〜50）

### 模試3回分を得点に変える仕上げ手順

1. **分野別に採点をメモする** — 第3回を解き終えたら、3回分の模試の得点を分野別に並べ、弱い分野を特定します
2. **にがて帳で横断復習する** — 本番前の最重要作業です。模試3回分（とドリル）の誤答は**にがて帳**にすべて自動記録されています。レッスンの枠を越えて誤答だけを横断的に解き直し、全問正解になるまで繰り返しましょう。自分の弱点だけを集めた、世界に一冊の問題集です
3. **誤りの根拠を言語化する** — 解き直しの際、「この肢はどこが誤りか」を自分の言葉で説明できたら合格レベルです
4. **統計は直前に最新値を確認する** — 固定の数値を暗記するのではなく、試験直前に最新の公表値の増減の傾向を確認します

### 確認問題

**問1.** 【問26】宅地建物取引業の免許に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建業の免許を受けていない者であっても、宅建業を営む目的で広告をするだけであれば、宅建業法に違反しない

4. 宅建業の免許の有効期間は3年であり、更新を受けようとする者は、有効期間満了の日の90日前から30日前までの間に申請しなければならない

</details>

**問2.** 【問27】宅地建物取引業者の廃業等の届出に関する次の記述のうち、正しいものはどれでしょう？

1. 法人である宅建業者が破産手続開始の決定を受けた場合、その法人の代表役員が、30日以内に免許権者に届け出なければならない
2. 法人である宅建業者が合併以外の理由で解散した場合の届出義務者は、その法人の役員の全員である

4. 個人の宅建業者が死亡した場合、その相続人は、死亡の事実を知った日から30日以内に免許権者に届け出なければならず、免許は死亡の時に効力を失う
