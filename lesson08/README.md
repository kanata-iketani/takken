# 第8章 報酬とその他の業務規制

仲介手数料（報酬）には法律上の上限があり、計算問題がほぼ毎年出ます。「3％＋6万円」と「貸借は合計1か月分」をマスターし、あわせて広告や勧誘など日常業務のルールも押さえましょう。

## 1. 報酬の上限（売買の速算式 3％＋6万円）

宅建業者が受け取れる仲介手数料（**報酬**）には、国土交通大臣が定める上限があります。上限を1円でも超えて受領すれば宅建業法違反です。

### 売買・交換の媒介の速算式（税抜の物件価格で計算）

| 物件価格（税抜） | 依頼者の一方から受領できる上限 |
|---|---|
| 200万円以下 | 価格 × **5％** |
| 200万円超〜400万円以下 | 価格 × **4％ ＋ 2万円** |
| 400万円超 | 価格 × **3％ ＋ 6万円** |

試験で出るのはほとんど400万円超なので、まず「**3％＋6万円**」を体に染み込ませましょう。

### 3つの約束ごと

- この速算式は「**依頼者の一方から**」の上限。売主・買主の両方から依頼されれば、**それぞれから**上限まで受領できます
- **代理**の場合は媒介の**2倍**まで。ただし複数の業者が関与しても、**全業者の受領合計**は媒介報酬の2倍が限度です
- 消費税の**課税事業者**は、上限額に**10％上乗せ**（×1.1）できます（免税事業者は×1.04）

> 💡コツ：🔴 「400万円超は **サブロク**（3％＋6万円）」。報酬計算はこの式と×1.1の往復だけで、毎年1問が確実に取れます。

### 確認問題

**問1.** 売買価格が400万円を超える場合に、媒介の依頼者の一方から受領できる報酬の上限（消費税を考慮しない）を求める速算式はどれでしょう？

1. 価格 × 5％
2. 価格 × 4％ ＋ 2万円
3. 価格 × 3％ ＋ 6万円
4. 価格 × 3％ ＋ 2万円

<details><summary>答えと解説</summary>

正解: **3**

400万円超の速算式は「3％＋6万円」です。5％は200万円以下、「4％＋2万円」は200万円超400万円以下の式です。足す金額を2万円とする肢4のような微妙な混ぜ方も出るので、区分と式をセットで覚えましょう。

</details>

**問2.** 宅建業者Aが売主・買主の双方から媒介の依頼を受けて売買契約を成立させた場合、報酬はどうなるでしょう？

1. 双方の合計で、速算式で計算した額（一方からの上限額）までしか受領できない
2. 売主・買主それぞれから、速算式で計算した上限額まで受領できる
3. 双方から依頼を受けた場合、報酬は一切受領できない
4. 売主からのみ受領でき、買主からは受領できない

<details><summary>答えと解説</summary>

正解: **2**

速算式は「依頼者の一方から」の上限なので、双方から依頼を受ければ、それぞれから上限額まで（合計で2倍まで）受領できます。これを「合計で一方分まで」とするひっかけに注意しましょう。貸借の「合計で借賃1か月分」との違いも頻出です。

</details>

**問3.** 売買の「代理」の依頼を受けた宅建業者が依頼者から受領できる報酬の上限について、正しいものはどれでしょう？

1. 媒介の場合と同額が上限である
2. 媒介の場合の3倍が上限である
3. 上限はなく、依頼者との合意で自由に定められる
4. 媒介の場合の2倍が上限である

<details><summary>答えと解説</summary>

正解: **4**

代理の報酬は媒介の2倍が上限です。ただし取引全体で見ても、関与した業者が受け取る報酬の合計は媒介報酬の2倍を超えられません。報酬額は合意で自由に決められるものではなく、上限規制があります。

</details>

**問4.** 消費税の課税事業者である宅建業者の報酬について、正しいものはどれでしょう？

1. 速算式で計算した上限額に、10％を上乗せした額まで受領できる
2. 消費税分の上乗せは一切認められない
3. 上限額に20％を上乗せした額まで受領できる
4. 消費税込みの物件価格をそのまま速算式に当てはめて計算する

<details><summary>答えと解説</summary>

正解: **1**

課税事業者は、報酬上限額に消費税10％を上乗せ（×1.1）できます。一方、速算式に入れる物件価格は税抜価格です。「報酬には税を乗せる、物件価格は税を抜く」という方向の違いが計算問題の急所です。

</details>

## 2. 貸借の報酬（合計で借賃1か月分・居住用の特例）

アパートを借りたときの仲介手数料を思い出してください。貸借の報酬ルールは売買と発想が違います。

### 原則：合計で借賃1か月分まで

貸借の媒介・代理では、**貸主・借主から受け取る報酬の合計**が**借賃1か月分**（課税事業者は＋消費税で**1.1か月分**）以内です。売買と違い「一方からそれぞれ」ではなく「**双方合わせて**1か月分」です。内訳（貸主と借主の負担割合）は自由です。

### 居住用建物の媒介の特例

**居住用建物**の媒介では、**依頼者の一方**から受け取れるのは原則**借賃の0.5か月分**（＋消費税）まで。ただし**媒介の依頼を受けるにあたって**その依頼者の承諾を得ている場合は、この割合を超えられます（それでも合計1か月分以内）。承諾は**依頼を受ける時まで**に必要で、契約成立後に「やっぱり1か月分ください」はダメです。

### 権利金の特例（居住用建物以外）

宅地や店舗・事務所の貸借で**権利金**（返還されないもの）の授受があるときは、権利金の額を売買代金とみなして**速算式**で計算した額を上限とすることもでき、1か月分と比べて**高いほう**を選べます。**居住用建物では使えません**。

> 💡コツ：🔴 「貸借は**合計1か月**、居住用は**半月＋事前承諾**、権利金特例は**居住用NG**」の3点セットで覚えましょう。

### 確認問題

**問1.** 宅建業者Aが貸主・借主の双方から建物の貸借の媒介の依頼を受け、契約を成立させた場合の報酬について、正しいものはどれでしょう？（消費税は考慮しない）

1. 貸主・借主それぞれから借賃1か月分まで、合計2か月分まで受領できる
2. 双方から受領する報酬の合計が、借賃1か月分以内でなければならない
3. 借主からのみ、借賃2か月分まで受領できる
4. 報酬の上限はなく、合意により自由に定められる

<details><summary>答えと解説</summary>

正解: **2**

貸借の報酬は、双方から受け取る合計で借賃1か月分（課税事業者は1.1か月分）が上限です。売買のように「一方からそれぞれ上限まで」ではない点が最大の違いで、合計2か月分とする肢1が典型的なひっかけです。

</details>

**問2.** 居住用建物の貸借の媒介で、宅建業者が依頼者の一方から借賃0.5か月分を超える報酬を受領できるのは、どの場合でしょう？

1. 賃貸借契約の成立後に、その依頼者の承諾を得た場合
2. 貸主と借主の双方が宅建業者である場合
3. 媒介の依頼を受けるにあたって、その依頼者の承諾を得ている場合
4. いかなる場合も0.5か月分を超えることはできない

<details><summary>答えと解説</summary>

正解: **3**

居住用建物の媒介では一方から0.5か月分までが原則ですが、「依頼を受けるにあたって」承諾を得ていれば超えられます（それでも合計1か月分以内）。承諾のタイミングは依頼を受ける時までで、契約成立後の承諾では認められません。

</details>

**問3.** 店舗用建物の貸借（借賃月20万円、権利金1,000万円の授受あり）の媒介で、宅建業者が依頼者の一方から受領できる報酬の上限（消費税を考慮しない）はいくらでしょう？

1. 10万円
2. 36万円
3. 20万円
4. 72万円

<details><summary>答えと解説</summary>

正解: **2**

居住用建物以外で権利金の授受があるときは、権利金1,000万円を売買代金とみなして速算式で計算できます。1,000万円×3％＋6万円＝36万円が一方から受領できる上限で、借賃1か月分（20万円）より有利です。72万円は代理の2倍計算との混同です。この特例は居住用建物では使えない点もあわせて覚えましょう。

</details>

**問4.** 居住用建物の貸借の媒介における権利金の特例の適用について、正しいものはどれでしょう？

1. 礼金の授受があれば、権利金の特例を適用できる
2. 居住用建物の貸借には、権利金を売買代金とみなす特例は適用されない
3. 貸主の承諾があれば、権利金の特例を適用できる
4. 借賃が10万円以下の場合に限り、特例を適用できる

<details><summary>答えと解説</summary>

正解: **2**

権利金を売買代金とみなして速算式で計算できる特例は、宅地または居住用建物「以外」の建物（店舗・事務所など）の貸借に限られます。居住用建物では礼金があっても、当事者の承諾があっても使えません。借賃の額による区別もありません。

</details>

## 3. 報酬の計算練習（具体的な数字で）

報酬計算は手順さえ固定すれば満点が狙えます。手順は3ステップです。

### 計算の3ステップ

1. 物件価格を**税抜**に直す（土地は非課税なのでそのまま。**建物は税込表示なら税抜に戻す**）
2. **速算式**に当てはめる（400万円超なら 3％＋6万円）
3. 課税事業者なら **×1.1**

### 例題1：税抜2,000万円の土地の売買媒介（課税事業者、買主から依頼）

2,000万×3％＋6万＝66万円 → ×1.1＝**72万6,000円**が買主から受領できる上限。売主からも依頼されていれば、合計**145万2,000円**まで。

### 例題2：代金3,300万円（消費税込み）の建物の売買媒介

まず税抜に：3,300万÷1.1＝**3,000万円**。3,000万×3％＋6万＝96万円 → ×1.1＝**105万6,000円**（一方からの上限）。

### 例題3：居住用建物の貸借（借賃11万円・税込扱い、承諾なし）

一方からは0.5か月分＝5万円 → ×1.1＝**5万5,000円**まで。双方合計では1か月分×1.1＝**11万円**まで。

> 💡コツ：🔴 間違いの9割は「**建物の消費税を抜き忘れる**」こと。問題文に『消費税込み』とあったら、まず÷1.1。この一手を儀式にしましょう。

### 確認問題

**問1.** 宅建業者A（課税事業者）は、売主Bから依頼を受けて税抜1,000万円の土地の売買を媒介し、契約を成立させた。AがBから受領できる報酬の上限はいくらでしょう？

1. 36万円
2. 39万6,000円
3. 72万円
4. 79万2,000円

<details><summary>答えと解説</summary>

正解: **2**

1,000万円×3％＋6万円＝36万円、課税事業者なので×1.1で39万6,000円が正解です。36万円は消費税の上乗せを忘れた額、72万円・79万2,000円は双方から受領する場合や代理の場合の数字で、一方の依頼者Bからの上限ではありません。

</details>

**問2.** 宅建業者A（課税事業者）は、買主から依頼を受けて代金2,200万円（うち消費税200万円）の建物の売買を媒介した。買主から受領できる報酬の上限はいくらでしょう？

1. 79万2,000円
2. 145万2,000円
3. 72万6,000円
4. 66万円

<details><summary>答えと解説</summary>

正解: **3**

まず税抜価格に直します：2,200万−200万＝2,000万円。2,000万×3％＋6万＝66万円、×1.1で72万6,000円が正解です。税込2,200万円のまま計算すると79万2,000円という誤答になります。66万円は消費税の上乗せ忘れ、145万2,000円は双方から受領する場合の合計です。

</details>

**問3.** 宅建業者A（課税事業者）は、売主Bから「代理」の依頼を受けて税抜1,000万円の土地の売買契約を成立させた。AがBから受領できる報酬の上限はいくらでしょう？

1. 39万6,000円
2. 72万円
3. 118万8,000円
4. 79万2,000円

<details><summary>答えと解説</summary>

正解: **4**

媒介の上限は1,000万×3％＋6万＝36万円。代理はその2倍の72万円まで認められ、×1.1で79万2,000円が正解です。39万6,000円は媒介の場合の額、72万円は消費税の上乗せを忘れた額です。118万8,000円（3倍相当）という上限はありません。

</details>

**問4.** 宅建業者A（課税事業者）は、居住用建物の貸借について貸主・借主双方から媒介の依頼を受け、借賃月額10万円で契約を成立させた。特段の承諾を得ていない場合、Aが借主から受領できる報酬の上限はいくらでしょう？

1. 5万5,000円
2. 11万円
3. 10万円
4. 22万円

<details><summary>答えと解説</summary>

正解: **1**

居住用建物の媒介で事前の承諾がなければ、一方からは借賃の0.5か月分＝5万円、×1.1で5万5,000円が上限です。11万円は双方からの合計の上限（1か月分×1.1）、10万円は消費税を考えない1か月分です。22万円のような合計2か月分は貸借では認められません。

</details>

## 4. その他の業務規制（誇大広告・断定的判断・守秘義務など）

報酬以外にも、宅建業者が日常業務で守るべきルールがあります。どれも「お客さんをだまして契約させない」ための規制です。

### 広告のルール

- **誇大広告の禁止**：著しく事実に相違する表示、実際より著しく優良・有利と誤認させる表示は禁止。**誰も申し込まず実害がなくても違反**になります。実在しない物件を載せる「おとり広告」も違反です
- **広告開始時期の制限**：未完成物件は、**建築確認・開発許可などの前は広告できません**（貸借の媒介契約を結ぶこと自体は可。ただし広告は不可）
- **取引態様の明示**：自ら売主か、媒介か代理かを、**広告のとき**と**注文を受けたとき**の**両方**で明示します

### 勧誘・契約のルール

- **断定的判断の提供の禁止**：「必ず値上がりします」「絶対に損はしません」はNG
- **手付の貸与等による契約誘引の禁止**：手付金を貸し付けたり分割払いにして契約させるのは禁止（**手付の減額**や銀行ローンのあっせんは違反ではありません）
- **威迫行為の禁止**、相手方の判断を妨げる**重要な事実の不告知の禁止**

### 守秘義務

正当な理由がある場合を除き、業務上知った秘密を漏らしてはいけません。**廃業後・退職後も続きます**。

> 💡コツ：🟡 誇大広告は「**誤認させた時点でアウト**（実害不要）」、手付は「**まける（減額）のはOK、貸すのはNG**」と対比で覚えましょう。

### 確認問題

**問1.** 誇大広告の禁止に関する次の記述のうち、正しいものはどれでしょう？

1. 広告を見て申し込んだ者がいなければ、誇大広告をしても宅建業法違反とはならない
2. 実際より著しく優良であると誤認させる表示をすれば、実害が生じなくても宅建業法違反となる
3. 取引する意思のない実在の物件を広告することは、物件が実在する以上違反ではない
4. 口頭の勧誘と異なり、インターネット広告は誇大広告の規制対象外である

<details><summary>答えと解説</summary>

正解: **2**

誇大広告の禁止は、誤認させるような表示をした時点で成立し、申込みや損害の発生は不要です。取引する意思のない物件を載せる「おとり広告」も、物件が実在しても違反です。インターネット広告も当然に規制対象です。

</details>

**問2.** 手付に関する宅建業者の行為のうち、宅建業法に違反しないものはどれでしょう？

1. 手付金を貸し付けることにより、契約の締結を誘引した
2. 手付金の分割払いを認めることにより、契約の締結を誘引した
3. 手付金を減額することにより、契約の締結を誘引した
4. 手付金を後日支払うことを認めることにより、契約の締結を誘引した

<details><summary>答えと解説</summary>

正解: **3**

禁止されるのは手付の「貸付けその他信用の供与」（貸す・分割にする・後払いにする）による契約誘引です。手付の減額は信用の供与に当たらないため違反ではありません。銀行ローンのあっせんも同様に違反ではない、という出題もあります。

</details>

**問3.** 取引態様の明示義務について、正しいものはどれでしょう？

1. 広告をするときに明示すれば、注文を受けたときの明示は不要である
2. 注文を受けたときに明示すれば、広告のときの明示は不要である
3. 取引態様は重要事項説明で説明すれば足りる
4. 広告をするときと注文を受けたときの両方で明示しなければならない

<details><summary>答えと解説</summary>

正解: **4**

取引態様（自ら売主か、媒介・代理か）は、広告時と注文を受けた時の両方で明示が必要です。広告を見た客からの注文でも、改めて明示しなければなりません。重要事項説明の説明事項で代替できるものではありません。

</details>

**問4.** 宅建業者の守秘義務について、正しいものはどれでしょう？

1. 宅建業を廃業すれば、業務上知り得た秘密を話しても差し支えない
2. 正当な理由がある場合を除き、廃業した後も業務上知り得た秘密を他に漏らしてはならない
3. 依頼者の秘密は、取引の成立後であれば自由に漏らしてよい
4. 裁判の証人として証言を求められた場合でも、秘密を述べることは一切許されない
