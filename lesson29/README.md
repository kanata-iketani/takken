### 確認問題

**問1.** 【問1】Aは、債権者からの差押えを免れるため、Bと通謀して自己所有の甲土地をBに売却したように仮装した。その後Bは、事情を知らないCに甲土地を売却した。この場合に関する次の記述のうち、正しいものはどれでしょう？

1. AB間の売買契約は、当事者双方が合意している以上、有効である
2. Aは、AB間の売買が無効であることを、善意のCに対抗できない
3. Cが保護されるためには、甲土地の所有権移転登記を備えていることが必要である
4. Cが保護されるためには、善意であることに加えて無過失であることが必要である

<details><summary>答えと解説</summary>

正解: **2**

通謀虚偽表示による契約は無効ですが、その無効は善意の第三者に対抗できません（民法94条2項）。判例上、第三者Cは善意であれば足り、無過失や登記は要求されません。したがって肢1（有効）、肢3（登記必要）、肢4（無過失必要）はいずれも誤りです。

</details>

**問2.** 【問2】Bは、代理権がないのにAの代理人と称して、A所有の甲土地をCに売却する契約を締結した。この場合に関する次の記述のうち、正しいものはどれでしょう？

1. Aが追認すると、契約の効力は原則として契約の時にさかのぼって生ずる
2. Cは、Bに代理権がないことを知っていた場合、Aに対して追認するかどうかを催告することができない
3. Cは、Bに代理権がないことを知っていた場合でも、Bに対して無権代理人の責任（履行または損害賠償）を追及できる
4. Cは、Aが追認した後であっても、契約を取り消すことができる

<details><summary>答えと解説</summary>

正解: **1**

本人が無権代理行為を追認すると、原則として契約時にさかのぼって効力が生じます（民法116条）。催告は相手方が悪意でも行うことができるので肢2は誤り（確答がなければ追認拒絶とみなされます）。無権代理人への責任追及は相手方が悪意だとできないので肢3も誤り。相手方の取消権は本人の追認前にしか行使できず、しかも善意の相手方に限られるため肢4も誤りです。

</details>

**問3.** 【問3】所有権の取得時効に関する次の記述のうち、正しいものはどれでしょう？

1. 占有開始の時に善意無過失であった占有者は、5年間占有を継続すれば所有権を時効取得する
2. 賃借人として他人の土地を20年間占有し続けた者は、その土地の所有権を時効取得する
3. 時効期間が満了すれば、当事者が援用しなくても、当然に所有権取得の効果が確定する
4. 所有の意思をもって、平穏かつ公然に他人の土地を20年間占有した者は、占有開始時に悪意であっても所有権を時効取得する

<details><summary>答えと解説</summary>

正解: **4**

取得時効は「所有の意思をもって平穏・公然に」20年（占有開始時に善意無過失なら10年）の占有で成立し、悪意でも20年で取得できます。善意無過失の短縮期間は10年であり5年ではないので肢1は誤り。賃借人の占有には所有の意思がないため何年続けても時効取得できず、肢2も誤り。時効の効果は当事者の援用があって初めて確定するので肢3も誤りです。

</details>

**問4.** 【問4】A・B・Cが各3分の1の持分で甲建物を共有している場合に関する次の記述のうち、正しいものはどれでしょう？

1. 甲建物の雨漏りを修繕する保存行為には、持分の価格の過半数の同意が必要である
2. Aが自己の持分を第三者に売却するには、BおよびCの同意が必要である
3. 甲建物に形状または効用の著しい変更を加えるには、共有者全員の同意が必要である
4. 甲建物の管理に関する事項は、共有者全員の同意がなければ決することができない

<details><summary>答えと解説</summary>

正解: **3**

共有物に形状・効用の著しい変更（軽微でない変更）を加えるには共有者全員の同意が必要です。保存行為は各共有者が単独でできるので肢1は誤り。自己の持分の処分は各共有者が自由にでき、他の共有者の同意は不要なので肢2も誤り。管理に関する事項は持分の価格の過半数で決するため、全員の同意を要するとする肢4も誤りです。

</details>

**問5.** 【問5】不動産の物権変動と登記に関する次の記述のうち、正しいものはどれでしょう？

1. 同一の不動産が二重に譲渡された場合、先に売買契約を締結した者が常に所有権を取得する
2. 相続により不動産の所有権を取得した相続人は、自己のために相続の開始があったことを知り、かつ所有権を取得したことを知った日から3年以内に、相続登記の申請をしなければならない
3. 登記がなければ、いわゆる背信的悪意者に対しても所有権の取得を対抗できない
4. 時効により土地の所有権を取得した者は、時効完成前にその土地を譲り受けていた第三者に対し、登記がなければ所有権を対抗できない

<details><summary>答えと解説</summary>

正解: **2**

2024年施行の改正不動産登記法により相続登記の申請が義務化され、知った日から3年以内に申請しなければならず、正当な理由なく怠ると過料の対象になります。二重譲渡の優劣は契約の先後ではなく登記の先後で決まるので肢1は誤り。背信的悪意者に対しては登記がなくても対抗できるので肢3も誤り。時効完成前の第三者に対しては登記なしで時効取得を対抗できるため肢4も誤りです。

</details>

**問6.** 【問6】抵当権に関する次の記述のうち、正しいものはどれでしょう？

1. 抵当権を設定した後も、抵当権設定者は目的物を自分で使用し、収益することができる
2. 抵当権の効力が生ずるには、目的物を抵当権者に引き渡すことが必要である
3. 被担保債権が弁済により消滅しても、抵当権は登記を抹消するまで存続する
4. 抵当権者は、利息については最後の5年分についてのみ優先弁済を受けられる

<details><summary>答えと解説</summary>

正解: **1**

抵当権は目的物の占有を移さない担保物権なので、設定者は設定後も使用収益を続けられます。抵当権は設定契約の合意のみで成立し引渡しは不要なので肢2は誤り。被担保債権が消滅すれば抵当権も付従性により当然に消滅するため肢3も誤り。利息について優先弁済を受けられるのは原則として満期の到来した最後の2年分であり、肢4も誤りです。

</details>

**問7.** 【問7】債務不履行と契約の解除に関する次の記述のうち、正しいものはどれでしょう？

1. 催告による解除をするには、債務者に帰責事由があることが必要である
2. 債務の全部の履行が不能となったときは、債権者は催告をすることなく、直ちに契約を解除できる
3. 金銭債務の債務者は、不可抗力によって支払が遅れたことを証明すれば、遅延の責任を免れる
4. 契約を解除した場合には、あわせて損害賠償を請求することはできない

<details><summary>答えと解説</summary>

正解: **2**

全部の履行不能の場合は催告をしても意味がないため、無催告で直ちに解除できます。2020年施行の改正民法により、解除に債務者の帰責事由は不要とされたので肢1は誤り。金銭債務の不履行は不可抗力をもって抗弁できないので肢3も誤り。解除と損害賠償請求は併せて行うことができるため肢4も誤りです。

</details>

**問8.** 【問8】売買契約における売主の契約不適合責任（種類・品質に関する不適合）に関する次の記述のうち、正しいものはどれでしょう？

1. 買主は、不適合を知った時から1年以内に訴訟を提起しなければ、責任を追及できなくなる
2. 買主は、追完請求をすることはできるが、代金の減額を請求することはできない
3. 売主に帰責事由がない場合、買主は追完請求をすることができない
4. 買主が不適合を知った時から1年以内にその旨を売主に通知しないときは、原則として責任を追及できなくなる

<details><summary>答えと解説</summary>

正解: **4**

種類・品質の契約不適合では、買主は不適合を知った時から1年以内にその旨を売主に「通知」しないと、原則として責任追及できなくなります（売主が悪意または重過失の場合を除く）。必要なのは通知であって訴訟提起ではないので肢1は誤り。買主には追完請求・代金減額請求・損害賠償・解除の手段があり肢2は誤り。追完請求や代金減額に売主の帰責事由は不要（帰責事由が必要なのは損害賠償）なので肢3も誤りです。

</details>

**問9.** 【問9】建物の賃貸借における敷金等に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 賃借人は、賃貸人の承諾を得なくても、賃借物を自由に転貸することができる
2. 敷金は、賃貸借が終了し、かつ建物の明渡しを受けた後に、未払賃料等を控除した残額が返還される
3. 建物の明渡しと敷金の返還は、同時履行の関係に立つ
4. 賃借人は、賃貸借の存続中、敷金を未払賃料に充当するよう賃貸人に請求することができる

<details><summary>答えと解説</summary>

正解: **2**

敷金返還債務は「賃貸借の終了＋明渡し完了」の後に、未払賃料等を差し引いた残額について生じます。無断転貸は原則としてできず（承諾が必要）肢1は誤り。明渡しが先履行であり同時履行の関係には立たないので肢3も誤り。敷金の充当は賃貸人側からはできますが、賃借人の側から充当を請求することはできないため肢4も誤りです。

</details>

**問10.** 【問10】借地借家法の借地権に関する次の記述のうち、正しいものはどれでしょう？

1. 借地権の存続期間は、当事者が期間を定めなかった場合は30年となり、契約で30年より長い期間を定めたときはその期間となる
2. 当事者が存続期間を定めなかった場合、借地権の存続期間は20年となる
3. 借地権者が借地上に自己名義で登記した建物を所有していても、借地権の登記がなければ第三者に借地権を対抗できない
4. 事業用定期借地権の設定契約は、書面であれば公正証書でなくてもよい

<details><summary>答えと解説</summary>

正解: **1**

借地権の存続期間は最低30年で、期間を定めなければ30年、30年より長い定めをすればその期間になります。20年とする肢2は誤り。借地上の建物について自己名義の登記があれば、借地権の登記がなくても第三者に対抗できるので肢3も誤り。事業用定期借地権は必ず公正証書で設定しなければならないため肢4も誤りです。

</details>

**問11.** 【問11】借地借家法の建物賃貸借に関する次の記述のうち、正しいものはどれでしょう？（定期建物賃貸借については特に記載のある場合を除き考えないものとします）

1. 賃貸人が更新を拒絶するには、期間満了の1年前から6か月前までに通知すれば足り、正当事由は不要である
2. 定期建物賃貸借契約は、口頭の合意だけでも有効に成立する
3. 期間を1年未満とする建物賃貸借は、期間の定めがない建物賃貸借とみなされる
4. 建物の引渡しを受けて住んでいる賃借人も、賃借権の登記がなければ、建物の新所有者に賃借権を対抗できない

<details><summary>答えと解説</summary>

正解: **3**

普通の建物賃貸借で期間を1年未満と定めた場合は、期間の定めがないものとみなされます。賃貸人からの更新拒絶の通知には正当事由が必要なので肢1は誤り。定期建物賃貸借は書面（または電磁的記録）によらなければ締結できず肢2も誤り。建物の引渡しを受けていれば賃借権の登記がなくても新所有者に対抗できるため肢4も誤りです。

</details>

**問12.** 【問12】不法行為に関する次の記述のうち、正しいものはどれでしょう？

1. 使用者責任に基づき被害者に賠償した使用者は、被用者に対して求償することが一切できない
2. 不法行為による損害賠償債務は、被害者が履行の請求をした時から遅滞に陥る
3. 人の生命または身体を害する不法行為による損害賠償請求権は、被害者が損害および加害者を知った時から5年間行使しないときは、時効によって消滅する
4. 被害者側にも過失があった場合でも、裁判所は損害賠償額を定めるにあたりこれを考慮することができない

<details><summary>答えと解説</summary>

正解: **3**

生命・身体を害する不法行為の損害賠償請求権の消滅時効は、損害および加害者を知った時から5年（通常の不法行為は3年）です。使用者は信義則上相当な範囲で被用者に求償できるので肢1は誤り。不法行為による損害賠償債務は請求を待たず不法行為の時（損害発生時）から遅滞に陥るため肢2も誤り。被害者に過失があれば裁判所は過失相殺として考慮できるので肢4も誤りです。

</details>

**問13.** 【問13】Aが死亡し、相続人は妻B、子CおよびDである。Cが家庭裁判所に申述して相続放棄をした場合に関する次の記述のうち、正しいものはどれでしょう？

1. 法定相続分は、Bが2分の1、Dが2分の1となる
2. 法定相続分は、Bが2分の1、Cが4分の1、Dが4分の1のまま変わらない
3. 相続放棄をしたCに子（Aの孫）がいる場合、その子がCを代襲相続する
4. Cは、Aの生前であっても、家庭裁判所に申述して相続放棄をすることができた

<details><summary>答えと解説</summary>

正解: **1**

相続放棄をした者は初めから相続人でなかったものとみなされるため、相続人は配偶者Bと子Dとなり、法定相続分はBが2分の1、Dが2分の1です。Cを数に入れる肢2は誤り。相続放棄には代襲相続が生じないので肢3も誤り。相続放棄は相続開始後にしかできず、生前の放棄は認められないため肢4も誤りです。

</details>

**問14.** 【問14】建物の区分所有等に関する法律に関する次の記述のうち、正しいものはどれでしょう？

1. 共用部分に対する各共有者の持分は、規約に別段の定めがなくても、全員平等である
2. 前の所有者が滞納した管理費は、その専有部分を買い受けた特定承継人に対して請求することができない
3. 専有部分とその専有部分に係る敷地利用権は、規約に別段の定めがなくても、自由に分離して処分できる
4. 共用部分は、一部共用部分を除き区分所有者全員の共有に属し、その持分は原則として専有部分と分離して処分することができない

<details><summary>答えと解説</summary>

正解: **4**

共用部分は原則として区分所有者全員の共有であり、その持分は専有部分の処分に従い、分離して処分できません。共用部分の持分は原則として専有部分の床面積の割合によるため、当然に平等とする肢1は誤り。滞納管理費は特定承継人（買主）にも請求できるので肢2も誤り。専有部分と敷地利用権は規約に別段の定めがない限り分離処分が禁止されており、肢3も誤りです。

</details>

**問15.** 【問15】都市計画法に関する次の記述のうち、正しいものはどれでしょう？

1. 市街化調整区域とは、市街化を一切禁止すべき区域である
2. すべての都市計画区域において、区域区分（市街化区域と市街化調整区域の区分）を定めなければならない
3. 用途地域は、市街化調整区域に原則として定めるものとされている
4. 市街化区域とは、すでに市街地を形成している区域およびおおむね10年以内に優先的かつ計画的に市街化を図るべき区域である

<details><summary>答えと解説</summary>

正解: **4**

市街化区域の定義は「すでに市街地を形成している区域＋おおむね10年以内に優先的かつ計画的に市街化を図るべき区域」です。市街化調整区域は市街化を「抑制」すべき区域であって禁止区域ではないので肢1は誤り。区域区分を定めるかどうかは原則として都道府県の判断（任意）であり肢2も誤り。用途地域は市街化区域には少なくとも定め、市街化調整区域には原則として定めないため肢3も誤りです。

</details>

**問16.** 【問16】都市計画法の開発許可に関する次の記述のうち、正しいものはどれでしょう？

1. 市街化区域内で行う1,200㎡の住宅建築を目的とした開発行為には、開発許可が必要である
2. 市街化調整区域内で行う開発行為は、3,000㎡未満であれば開発許可は不要である
3. 市街化区域内であっても、農業を営む者の居住用建築物の建築を目的とする開発行為であれば、規模にかかわらず開発許可は不要である
4. 図書館の建築を目的とする開発行為であっても、市街化区域内で1,000㎡以上であれば開発許可が必要である

<details><summary>答えと解説</summary>

正解: **1**

台地・丘陵地は水はけ・地盤ともに良好で、宅地に適していることが多い地形です。旧河道はかつて川だった軟弱地盤で、宅地には不向きなので肢1は誤り。埋立地は地下水位が高く液状化の危険が大きいため肢3も誤り。谷の出口や扇状地は土石流が流れ込みやすい場所であり、危険性が低いとする肢4も誤りです。

**問24.** 【問49】建物の構造に関する次の記述のうち、最も適切なものはどれでしょう？

1. 鉄筋コンクリート造は、木造に比べて耐火性が低い
2. 木造建築物の耐震性を高めるには、壁（耐力壁）や筋かいを減らすことが有効である
3. 鉄骨造は不燃構造であるため、耐火被覆を施さなくても耐火構造となる
4. 鉄筋コンクリート造は、コンクリートが鉄筋を錆から守り、両者が互いの短所を補い合う構造である

<details><summary>答えと解説</summary>

正解: **4**

鉄筋コンクリート造は、引張りに強い鉄筋と圧縮に強いコンクリートを組み合わせ、アルカリ性のコンクリートが鉄筋の錆を防ぐ合理的な構造です。鉄筋コンクリート造の耐火性は木造より高いため肢1は誤り。耐震性を高めるには耐力壁や筋かいを増やす（バランスよく配置する）ことが有効なので肢2も誤り。鉄骨は不燃材料ですが熱に弱く、耐火構造とするには耐火被覆が必要なため肢3も誤りです。

</details>

**問25.** 【問50】本試験の統計問題（地価公示、建築着工統計など）への向き合い方として、最も適切なものはどれでしょう？

1. 統計の数値は毎年ほとんど変わらないので、数年前の教材の数値を暗記しておけば十分である
2. 地価公示や住宅着工戸数などの統計は、宅建試験の出題範囲には含まれていない
3. 統計問題は、地価公示・建築着工統計・土地白書などの最新の公表値について増減の傾向などを問う形で出題されるため、試験直前に最新データを確認して対策するのが効率的である
4. 統計問題は難問であり正解がほぼ不可能なので、対策せずに捨てるのが最善である

<details><summary>答えと解説</summary>

正解: **3**

統計問題は毎年、最新の公表値から「上昇したか下落したか」「増加したか減少したか」といった傾向を問う形で1問出題されます。数値は毎年変わるため、古い数値の暗記はかえって危険であり肢1は誤り。統計は免除科目として毎年出題される試験範囲なので肢2も誤り。最新データの傾向さえ直前に確認すれば得点しやすいサービス問題であり、捨てるべきとする肢4も誤りです。

</details>
