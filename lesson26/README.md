# 第26章 宅建業法ドリル

宅建業法の全範囲を、本試験レベルの4択50問で総点検するドリルです。個数問題にも挑戦します。間違えた問題は、解説を読んだうえで該当レッスンに戻って復習しましょう。配点20点の得点源を、ここで完成させます。

## 1. 免許・宅建士ドリル

免許と宅建士の範囲を、本試験レベルの10問で総点検します。🔴 この範囲の落とし穴トップ3です。

### 落とし穴トップ3

1. **「自ら貸借」は免許不要**——転貸でも同じです。免許が要るのは、自ら売買・交換と、売買・交換・貸借の媒介・代理
2. **罰金刑で5年アウトになる犯罪は限定列挙**——宅建業法違反・傷害などの暴力系・背任罪など。それ以外の罰金はセーフで、執行猶予は満了すれば直ちにOK
3. **登録移転は「勤務先が他県になった」ときだけ任意でできる**——住所が変わっただけでは不可、事務禁止処分の期間中も不可

> 💡コツ：迷ったら「誰が・何をした・いつから5年か」を1つずつ確認しましょう。

### 確認問題

**問1.** 次の行為のうち、宅建業の免許が必要なものはどれでしょう？

1. 自己所有の賃貸マンションを、不特定多数の者に反復継続して貸す行為
2. 自己所有のビルを一括して借り上げた会社が、反復継続して行う転貸行為
3. 不特定多数の者に対し、反復継続して自己所有の宅地を売却する行為
4. 地方公共団体が行う宅地の分譲

<details><summary>答えと解説</summary>

正解: **3**

自ら売買・交換は宅建業に当たるため免許が必要です。自ら貸借は転貸を含めて何度繰り返しても宅建業に当たりません。また、国・地方公共団体には宅建業法の規定が適用されないため、免許は不要です。

</details>

**問2.** 免許の欠格事由に関する次の記述のうち、正しいものはどれでしょう？

1. 傷害罪により罰金刑に処せられた者は、刑の執行を終わった日から5年を経過しなければ免許を受けられない
2. 道路交通法違反により罰金刑に処せられた者は、刑の執行を終わった日から5年を経過しなければ免許を受けられない
3. 拘禁刑に処せられ、その刑の執行猶予期間を満了した者は、満了の日から5年を経過しなければ免許を受けられない
4. 破産手続開始の決定を受けた者は、復権を得た日から5年を経過しなければ免許を受けられない

<details><summary>答えと解説</summary>

正解: **1**

罰金刑で5年の欠格となるのは、宅建業法違反や傷害罪などの暴力的な犯罪、背任罪などに限られるため、傷害罪の罰金は欠格事由に当たります。道路交通法違反の罰金は対象外です。執行猶予期間の満了や破産者の復権があれば、5年を待たず直ちに免許を受けられます。

</details>

**問3.** A社の免許に関する次の記述のうち、正しいものはどれでしょう？

1. A社の非常勤の役員が欠格事由に該当しても、常勤でなければA社の免許に影響しない
2. A社の事務所の一般の従業者が欠格事由に該当する場合、A社は免許を受けられない
3. 政令で定める使用人が欠格事由に該当しても、役員でなければA社の免許に影響しない
4. A社の役員が傷害罪により罰金刑に処せられ、刑の執行を終わってから5年を経過していない場合、A社は免許を受けられない

<details><summary>答えと解説</summary>

正解: **4**

法人は、役員または政令で定める使用人（支店長など）が欠格事由に該当すると免許を受けられません。役員には非常勤の者も含まれるため肢1は誤りで、政令使用人も対象なので肢3も誤りです。一般の従業者が欠格でも法人の免許には影響しません。

</details>

**問4.** 5年間免許を受けられない者に関する次の記述のうち、誤っているものはどれでしょう？

1. 不正の手段により免許を受けたことを理由に免許を取り消された者は、取消しの日から5年を経過しなければ免許を受けられない
2. 事務所をすべて廃止したとして廃業の届出をした者は、その届出の日から5年を経過しなければ免許を受けられない
3. 免許取消処分の聴聞の期日・場所が公示された日から処分決定までの間に、相当の理由なく廃業の届出をした者は、届出の日から5年を経過しなければ免許を受けられない
4. 業務停止処分に違反したことを理由に免許を取り消された者は、取消しの日から5年を経過しなければ免許を受けられない

<details><summary>答えと解説</summary>

正解: **2**

単に廃業しただけの者は欠格事由に当たらず、改めて免許を受けられます。5年の欠格となるのは、不正取得・情状が特に重い・業務停止処分違反を理由とする免許取消しを受けた場合と、取消処分を免れるための「駆け込み廃業」をした場合です。

</details>

**問5.** 免許換えに関する次の記述のうち、正しいものはどれでしょう？

1. 甲県知事免許の業者が乙県内に事務所を新設して2県に事務所を持つ場合、乙県知事への免許換えを申請する
2. 甲県知事免許の業者が、甲県内の事務所をすべて廃止して乙県内に事務所を設置する場合、乙県知事への免許換えが必要である
3. 免許換えにより新たに受けた免許の有効期間は、従前の免許の残存期間である
4. 役員の氏名に変更があった場合、免許換えの申請が必要である

<details><summary>答えと解説</summary>

正解: **2**

事務所の所在が甲県から乙県にまるごと移れば、乙県知事への免許換えです。2つ以上の都道府県に事務所を持つ場合は国土交通大臣への免許換えとなるため肢1は誤りです。免許換え後の有効期間は新たに5年であり、役員の氏名変更は30日以内の変更の届出で足ります。

</details>

**問6.** 宅建士の登録に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建試験に合格した者は、実務経験がなくても直ちに登録を受けられる
2. 登録を受けた者が住所を他県に移した場合、移転先の知事に登録移転を申請しなければならない
3. 登録を受けるには、2年以上の実務経験を有するか、国土交通大臣の登録を受けた実務講習を修了するなどの要件を満たす必要がある
4. 登録は、5年ごとに更新を受けなければ効力を失う

<details><summary>答えと解説</summary>

正解: **3**

登録には、試験合格に加えて2年以上の実務経験（または登録実務講習の修了等）が必要です。登録自体に有効期間はなく、更新も不要です（5年の有効期間があるのは宅建士証）。住所の移転だけでは登録移転はできません。

</details>

**問7.** 甲県知事の登録を受けている宅建士に関する次の記述のうち、正しいものはどれでしょう？

1. 乙県内の宅建業者の事務所の業務に従事することになったときは、乙県知事に登録移転を申請することができる
2. 乙県内に住所を移転したときは、乙県知事に登録移転を申請しなければならない
3. 事務禁止処分の期間中であっても、登録移転を申請することができる
4. 登録移転に伴い交付される宅建士証の有効期間は、新たに5年となる

<details><summary>答えと解説</summary>

正解: **1**

登録移転は、他県の事務所の業務に従事し、または従事しようとするときに「申請することができる」任意の制度です。住所の移転は理由にならず、事務禁止処分の期間中は申請できません。移転後に交付される宅建士証の有効期間は、従前の証の残存期間です。

</details>

**問8.** 宅建士証に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建士証の有効期間は10年である
2. 宅建士証の更新の際は、国土交通大臣が指定する講習を受講しなければならない
3. 試験合格の日から3年以内に宅建士証の交付を受ける場合、法定講習の受講は免除される
4. 重要事項の説明をするときは、相手方から請求がなくても宅建士証を提示しなければならない

<details><summary>答えと解説</summary>

正解: **4**

重要事項の説明の際は、請求がなくても宅建士証の提示が必要です。有効期間は5年で、交付・更新の際は登録している都道府県知事が指定する講習を交付の申請前6か月以内に受講します。この講習が免除されるのは試験合格から1年以内に交付を受ける場合です。

</details>

**問9.** 宅建士の登録に関する届出・申請についての次の記述のうち、正しいものはどれでしょう？

1. 宅建士が死亡した場合、相続人は死亡の日から30日以内に届け出なければならない
2. 宅建士が本籍を変更した場合、遅滞なく変更の登録を申請しなければならない
3. 宅建士が住所を変更した場合、変更の登録を申請する必要はない
4. 宅建士が破産手続開始の決定を受けた場合、破産管財人が届け出なければならない

<details><summary>答えと解説</summary>

正解: **2**

氏名・住所・本籍や勤務先の宅建業者の商号などに変更があれば、遅滞なく変更の登録を申請します。住所も登録簿の記載事項なので肢3は誤りです。死亡の届出は相続人が「知った日」から30日以内で、破産の場合は本人が届け出ます。

</details>

**問10.** 宅建業の免許および宅建士に関する次の記述のうち、正しいものはいくつあるでしょう？

ア 免許の更新を申請したが有効期間の満了までに処分がされない場合、従前の免許は処分がされるまで効力を有する
イ 廃業の届出をした宅建業者も、締結した契約に基づく取引を結了する目的の範囲内では、なお宅建業者とみなされる
ウ 成年被後見人または被保佐人は、一律に宅建士の登録を受けることができない

1. 一つ
2. 二つ
3. 三つ
4. 四つ

<details><summary>答えと解説</summary>

正解: **2**

正しいものはアとイの二つです。更新申請中に満了日が来ても従前の免許は処分まで有効で、廃業後も取引の結了の範囲では業者とみなされます。ウは誤りで、成年被後見人等を一律に欠格とする規定は廃止され、心身の故障により事務を適正に行えない者かどうかで個別に判断されます。

</details>

## 2. 保証金・媒介契約ドリル

営業保証金・保証協会・媒介契約を10問で総点検します。🔴 この範囲の落とし穴トップ3です。

### 落とし穴トップ3

1. **還付後の「2週間」ラッシュ**——営業保証金は通知から2週間以内に供託し、供託から2週間以内に届出。協会ルートは通知から2週間以内に還付充当金を納付。納付しないと社員の地位を失い、**1週間以内**に営業保証金を供託
2. **保管替え請求は「金銭のみ」で供託しているときだけ**——有価証券を含むなら、先に移転後の供託所へ供託してから取り戻す
3. **レインズ登録の「7日・5日」は休業日を除き、報告の「2週間・1週間」は休業日も数える**

> 💡コツ：期限の問題は「起算点→期間→届出先」の順に確認しましょう。

### 確認問題

**問1.** 営業保証金に関する次の記述のうち、正しいものはどれでしょう？

1. 本店のほかに支店を2つ設置する宅建業者が供託すべき営業保証金の合計額は、1,500万円である
2. 営業保証金は金銭で供託しなければならず、有価証券による供託は認められない
3. 地方債証券により供託する場合、その価額は額面金額の80％で評価される
4. 営業保証金は、主たる事務所の最寄りの供託所に供託する

<details><summary>答えと解説</summary>

正解: **4**

供託先は主たる事務所の最寄りの供託所です。金額は本店1,000万円＋支店500万円×2＝2,000万円なので肢1は誤りです。有価証券での供託も可能で、評価は国債100％・地方債や政府保証債90％・その他80％となるため、地方債を80％とする肢も誤りです。

</details>

**問2.** 営業保証金と事業の開始に関する次の記述のうち、正しいものはどれでしょう？

1. 免許を受けた後、営業保証金を供託すれば、届出をしなくても直ちに事業を開始できる
2. 営業保証金を供託し、その旨を免許権者に届け出た後でなければ、事業を開始してはならない
3. 免許権者は、免許をした日から1か月以内に供託の届出がないときは、直ちに免許を取り消すことができる
4. 事務所を新設したときは、営業保証金を供託する前であっても、新事務所で事業を開始できる

<details><summary>答えと解説</summary>

正解: **2**

供託に加えて「届出」まで済ませなければ事業を開始できません。新設事務所も同様に、供託と届出の後でなければ業務を開始できません。免許権者が免許を取り消せるのは、免許から3か月以内に届出がなく、催告が到達した日から1か月以内にも届出がない場合です。

</details>

**問3.** 営業保証金の還付に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建業者は、宅建業に関する取引により生じた債権を有していても、営業保証金から還付を受けることができない
2. 宅建業者に広告を依頼した広告業者は、その広告料金の債権について還付を受けることができる
3. 還付により不足が生じた場合、宅建業者は通知を受けた日から1週間以内に不足額を供託しなければならない
4. 不足額を供託したときは、供託した日から30日以内に免許権者に届け出なければならない

<details><summary>答えと解説</summary>

正解: **1**

還付を受けられるのは「宅建業に関し取引をした者」で、宅建業者は除かれます。広告料金や建築工事の請負代金は宅建業の取引から生じた債権ではないため対象外です。不足額は通知から2週間以内に供託し、供託から2週間以内に届け出ます。

</details>

**問4.** 主たる事務所を移転したため最寄りの供託所が変更した場合に関する次の記述のうち、正しいものはどれでしょう？

1. 供託している営業保証金は、供託物の種類を問わず、常に保管替えを請求できる
2. 有価証券のみで供託している場合は、保管替えを請求することができる
3. 金銭のみで供託している場合は、移転後の最寄りの供託所への保管替えを請求しなければならない
4. 保管替えを請求できない場合は、従前の供託所から営業保証金を取り戻した後に、新たな供託所に供託する

<details><summary>答えと解説</summary>

正解: **3**

金銭のみで供託している場合は、遅滞なく保管替えを請求しなければなりません。有価証券が含まれる場合は保管替えができず、先に移転後の供託所へ新たに供託し、その後に従前の分を取り戻します。「取り戻してから供託」という順序の入れ替えが定番のひっかけです。

</details>

**問5.** 保証協会と弁済業務保証金に関する次の記述のうち、正しいものはどれでしょう？

1. 保証協会に加入しようとする宅建業者は、加入した日から2週間以内に弁済業務保証金分担金を納付する
2. 保証協会は、分担金の納付を受けた日から1週間以内に、弁済業務保証金を供託所に供託しなければならない
3. 弁済業務保証金分担金は、金銭または有価証券で納付することができる
4. 社員が事務所を新設したときは、その日から1週間以内に分担金を納付しなければならない

<details><summary>答えと解説</summary>

正解: **2**

協会は納付を受けた日から1週間以内に供託します。分担金は「加入しようとする日まで」に納付する必要があり、加入後2週間ではありません。納付は金銭のみで、有価証券は使えません。事務所の新設時は2週間以内の納付です。

</details>

**問6.** 弁済業務保証金の還付等に関する次の記述のうち、正しいものはどれでしょう？

1. 保証協会の社員と宅建業に関し取引をした者は、保証協会から直接還付を受ける
2. 還付を受けられる額は、その業者が納付した分担金の額が上限となる
3. 社員の地位を失った宅建業者は、その日から2週間以内に営業保証金を供託しなければならない
4. 還付充当金を納付すべき旨の通知を受けた社員は、2週間以内に納付しなければ社員の地位を失う

<details><summary>答えと解説</summary>

正解: **4**

還付充当金は通知から2週間以内に協会へ納付しなければ、社員の地位を失います。還付は協会の認証を受けたうえで供託所から受けるもので、その限度額は「社員でないとした場合の営業保証金に相当する額」です。地位を失った後の営業保証金の供託は1週間以内です。

</details>

**問7.** 宅地の売買の媒介契約に関する次の記述のうち、正しいものはどれでしょう？

1. 専任媒介契約の有効期間を6か月と定めた場合、その期間は3か月に短縮される
2. 専任媒介契約の有効期間を6か月と定めた場合、その媒介契約自体が無効となる
3. 専任媒介契約において、依頼者の申出がなくても自動的に更新される旨の特約は有効である
4. 一般媒介契約の有効期間も、3か月を超えることができない

<details><summary>答えと解説</summary>

正解: **1**

専任媒介契約の有効期間は3か月が上限で、これを超える定めをしても契約が無効になるのではなく、3か月に短縮されます。更新は依頼者の申出がある場合に限られ、自動更新の特約は無効です。3か月の上限は専任系のみで、一般媒介契約には適用されません。

</details>

**問8.** 指定流通機構（レインズ）への登録と報告に関する次の記述のうち、正しいものはどれでしょう？

1. 専属専任媒介契約では、契約締結の日から7日以内（休業日を除く）にレインズへ登録しなければならない
2. 専任媒介契約における業務処理状況の報告は、1週間に1回以上行わなければならない

## 3. 35条・37条ドリル

重要事項説明と37条書面を10問で総点検します。🔴 この範囲の落とし穴トップ3です。

**問6.** 宅建業者Aが自ら売主として、宅建業者Bに宅地を売却する場合に関する次の記述のうち、正しいものはどれでしょう？

## 4. 8種制限・報酬ドリル

8種制限と報酬を10問で総点検します。🔴 この範囲の落とし穴トップ3です。

### 落とし穴トップ3

1. **8種制限は「業者が自ら売主×買主が非業者」のときだけ**——媒介で関与しただけの業者や、業者間の取引には適用されません
2. **クーリング・オフは「申込みをした場所」で判断**——契約をした場所ではありません。「書面で告げられた日から起算して8日」で、告げられなければいつまでも可能
3. **報酬の計算は「税抜価格に直してから」**——代金に建物の消費税が含まれていたら、まず本体価格に戻すのが第一歩

> 💡コツ：計算問題は「税抜に直す→速算式（3％＋6万円など）→業者の消費税を乗せる」の3ステップで解きましょう。

### 確認問題

**問1.** 宅建業者Aが自ら売主となる売買契約に関する次の記述のうち、正しいものはどれでしょう？

1. 買主が宅建業者である場合でも、クーリング・オフの規定は適用される
2. 宅建業者Bの媒介により、宅建業者でないCと契約を締結する場合、8種制限の適用がある
3. Aが売買を媒介するにすぎない場合でも、手付金等の保全措置の規定が適用される
4. 買主が宅建業者である場合でも、損害賠償額の予定の制限（2割）の規定が適用される

<details><summary>答えと解説</summary>

正解: **2**

8種制限は「業者が自ら売主・買主が非業者」の組合せで適用され、間に媒介業者が入っていても売主Aには適用があります。買主が宅建業者であればクーリング・オフも2割制限も適用されず、Aが媒介の立場にすぎない場合も保全措置などの8種制限は適用されません。

</details>

**問2.** 宅建業者が自ら売主となるマンションの売買におけるクーリング・オフに関する次の記述のうち、正しいものはどれでしょう？

1. 買主が自ら申し出て、買主の勤務先で買受けの申込みをした場合、クーリング・オフできる
2. テント張りの案内所で買受けの申込みをした場合、クーリング・オフできない
3. 事務所で買受けの申込みをし、喫茶店で売買契約を締結した場合、クーリング・オフできる
4. 喫茶店で買受けの申込みをし、事務所で売買契約を締結した場合、クーリング・オフできる

<details><summary>答えと解説</summary>

正解: **4**

クーリング・オフの可否は「買受けの申込みをした場所」で判断します。喫茶店で申し込めば、契約を事務所でしても解除可能です。買主が自ら申し出た勤務先・自宅は「事務所等」に当たるため解除できず、土地に定着しないテント張りの案内所は事務所等に当たらないため解除できます。

</details>

**問3.** クーリング・オフの行使と効果に関する次の記述のうち、正しいものはどれでしょう？

1. クーリング・オフの意思表示は、その書面を発した時に効力を生じる
2. クーリング・オフできる旨を書面で告げられた日から起算して10日を経過すると、クーリング・オフできなくなる
3. 買主が物件の引渡しを受けていれば、代金を完済していなくてもクーリング・オフできなくなる
4. クーリング・オフが行われた場合、業者は受領済みの手付金の半額を返還すれば足りる

<details><summary>答えと解説</summary>

正解: **1**

クーリング・オフは書面で行い、発信した時に効力が生じます。期間は書面で告げられた日から起算して8日であり、10日ではありません。解除できなくなるのは「引渡しを受け、かつ代金全部を支払った」ときで、解除されたら業者は受領した金銭の全額を速やかに返還します。

</details>

**問4.** 宅建業者Aが自ら売主として、宅建業者でないBと売買契約を締結する場合の手付に関する次の記述のうち、正しいものはどれでしょう？

1. 代金の2割を超える手付を受領する旨の特約をすれば、Aは3割の手付を受領できる
2. 手付が交付された場合、Aは、Bが履行に着手する前であれば、手付を返還して契約を解除できる
3. 手付が交付された場合、Bは、Aが履行に着手する前であれば、手付を放棄して契約を解除できる

交付された手付は解約手付とみなされ、買主Bは相手方Aが履行に着手するまで、手付を放棄して解除できます。売主Aが解除するには手付の「倍額」を現実に提供する必要があり、返還だけでは足りません。2割を超える手付の受領は特約でも不可で、買主に不利な「解除不可」特約は無効です。

</details>

**問5.** 宅建業者Aが自ら売主となる売買契約における手付金等の保全措置に関する次の記述のうち、正しいものはどれでしょう？

4. 未完成物件の売買で、代金の5％以下かつ1,000万円以下の手付金を受領する場合、保全措置は不要である

正解: **4**

保全措置が不要なのは、未完成物件なら代金の5％以下かつ1,000万円以下、完成物件なら10％以下かつ1,000万円以下の場合です。したがって完成物件の基準を5％とする肢は誤りです。指定保管機関による保全は完成物件に限られ、買主へ所有権移転登記がされた後は保全措置が不要になります。

</details>

**問6.** 宅建業者Aが自ら売主となる場合の次の記述のうち、正しいものはどれでしょう？

1. Aは、他人Bの宅地について停止条件付きでBから取得する契約を締結していれば、宅建業者でないCに売却できる
2. Aは、他人Bの宅地を取得する契約（予約を含む）を締結していれば、自己の所有に属しない宅地でも、宅建業者でないCと売買契約を締結できる

<details><summary>答えと解説</summary>

正解: **2**

他人物売買は、業者がその物件を取得する契約（予約を含む）を締結していれば可能ですが、停止条件付きの取得契約では足りません。担保責任の特約は「通知期間を引渡しから2年以上」とする場合を除き民法より買主に不利にできないため、1年の特約は無効です。8種制限なので業者間なら「責任を負わない」特約も有効です。

</details>

**問7.** 宅建業者A（消費税課税事業者）は、土地付建物（代金5,200万円。うち建物に係る消費税額200万円を含む）の売買を媒介し、売主から報酬を受けます。Aが受領できる報酬の上限はいくらでしょう？

1. 156万円
2. 162万円
3. 171万6,000円
4. 178万2,000円

<details><summary>答えと解説</summary>

正解: **3**

まず税抜価格に直します。消費税額200万円から建物本体は2,000万円、土地は3,000万円で、税抜合計5,000万円です。5,000万円×3％＋6万円＝156万円、Aは課税事業者なので1.1倍して171万6,000円が上限です。156万円は消費税の乗せ忘れ、178万2,000円は税込価格のまま計算した誤りです。

</details>

**問8.** 宅建業者A（消費税課税事業者）が居住用建物の貸借（借賃は月額10万円）を媒介する場合に関する次の記述のうち、正しいものはどれでしょう？

1. Aが貸主と借主の双方から受領できる報酬の合計額は、11万円が上限である
2. 媒介の依頼を受けるにあたって承諾を得ていなくても、Aは借主の一方から11万円を受領できる
3. 権利金の授受がある場合、Aは権利金の額を売買代金とみなして報酬を計算できる
4. Aが貸主から5万5,000円、借主から8万円を受領することは、宅建業法に違反しない

<details><summary>答えと解説</summary>

正解: **1**

貸借の媒介の報酬は、双方から受ける合計で借賃1か月分＋消費税（11万円）が上限です。居住用建物では、依頼を受けるにあたって承諾を得ている場合を除き、一方から受けられるのは0.5か月分（5万5,000円）までです。権利金を売買代金とみなす特例は居住用建物以外に限られ、肢4は合計13万5,000円で上限を超えます。

</details>

**問9.** 報酬に関する次の記述のうち、正しいものはどれでしょう？

1. 依頼者の依頼によらない通常の広告の料金は、報酬とは別に受領できる
2. 依頼者の依頼によって行う特別の広告の料金は、報酬とは別に受領できる
3. 報酬の上限額の規制は、宅建業者間の取引には適用されない
4. 媒介の報酬は、売買契約が成立しなくても請求することができる

<details><summary>答えと解説</summary>

正解: **2**

依頼者の依頼に基づく特別の広告の料金（実費）は、報酬とは別に受領できます。依頼によらない通常の広告費は報酬に含まれ、別途受領すると違反です。報酬規制は業者間の取引にも適用され、媒介報酬は成功報酬なので契約が成立しなければ請求できません。

</details>

**問10.** 宅建業者Aが自ら売主、宅建業者でないBが買主となる売買契約に関する次の記述のうち、正しいものはいくつあるでしょう？

ア 割賦販売契約の解除は、30日以上の相当の期間を定めて書面で支払いを催告し、その期間内に支払いがないときでなければできない
イ 損害賠償額の予定と違約金を合算して代金の2割を超える定めをした場合、2割を超える部分が無効となる
ウ 割賦販売において、Aは代金の3割を超える額の支払いを受けるまでは、所有権を自己に留保しておくことができる
エ クーリング・オフについて、告知の日から起算して8日の期間を10日に延長する特約は有効である

1. 一つ
2. 二つ
3. 三つ
4. 四つ

<details><summary>答えと解説</summary>

正解: **4**

四つすべて正しい記述です。割賦販売の解除には30日以上の期間を定めた書面による催告が必要で、損害賠償額の予定等は合算2割の「超える部分のみ」が無効です。所有権留保は代金の10分の3を超える支払いを受けた後は原則禁止であり、クーリング・オフの期間延長のような買主に有利な特約は有効です。

</details>

## 5. 総合ドリル（監督処分・瑕疵担保履行法を含む全範囲）

監督処分・瑕疵担保履行法・業務規制を含む、宅建業法全範囲の総合ドリルです。🔴 この範囲の落とし穴トップ3です。

### 落とし穴トップ3

1. **指示・業務停止は「免許権者＋業務地の知事」もできるが、免許取消しは免許権者だけ**——宅建士の登録消除も、登録した知事だけ
2. **誇大広告は「誤認させる表示をした時点」で違反**——申込みがゼロで実害がなくてもアウト
3. **瑕疵担保履行法は「自ら売主×非業者の買主×新築住宅」の三拍子**——媒介した業者に資力確保義務はありません

> 💡コツ：総合問題は「誰の義務・誰の権限か」を最初に確定させると、ひっかけの大半を回避できます。

### 確認問題

**問1.** 宅建業者に対する監督処分に関する次の記述のうち、正しいものはどれでしょう？

1. 甲県知事免許の宅建業者が乙県内で業務に関し宅建業法に違反した場合、乙県知事はその業者の免許を取り消すことができる
2. 指示処分は、免許権者のみが行うことができる
3. 業務停止処分の期間は、1年以内である
4. 業務停止処分をしたときは、その旨を公告する必要はない

<details><summary>答えと解説</summary>

正解: **3**

業務停止処分は1年以内の期間を定めて行われます。指示処分と業務停止処分は、免許権者に加えて業務地を管轄する知事も行えますが、免許取消しができるのは免許権者だけです。業務停止と免許取消しをしたときは公告され、公告が不要なのは指示処分です。

</details>

**問2.** 免許の取消しに関する次の記述のうち、正しいものはどれでしょう？

1. 免許を受けてから1年以内に事業を開始しない場合、免許権者はその免許を取り消さなければならない
2. 業務停止処分に違反した場合、免許権者は免許を取り消すことも、取り消さないこともできる
3. 引き続いて6か月以上事業を休止した場合、免許は必ず取り消される
4. 指示処分に従わなかった場合、免許権者は直ちに免許を取り消さなければならない

<details><summary>答えと解説</summary>

正解: **1**

免許から1年以内に事業を開始しないこと、引き続き1年以上の休業は、必要的（必ず行う）免許取消事由です。休業は6か月ではなく1年以上なので肢3は誤りです。業務停止処分違反も必要的取消事由であり「取り消さないこともできる」は誤りで、指示処分に従わない場合はまず業務停止処分の事由となります。

</details>

**問3.** 宅建士に対する監督処分に関する次の記述のうち、正しいものはどれでしょう？

1. 事務禁止処分の期間は、2年以内である
2. 登録消除処分は、宅建士の行為地を管轄する知事も行うことができる
3. 事務禁止処分を受けた宅建士は、宅建士証をその交付を受けた知事に返納しなければならない
4. 甲県知事の登録を受けた宅建士が乙県内で事務禁止事由に該当する行為をした場合、乙県知事も事務禁止処分をすることができる

<details><summary>答えと解説</summary>

正解: **4**

指示処分と事務禁止処分は、登録している知事だけでなく行為地を管轄する知事も行えます。一方、登録消除処分は登録している知事しかできません。事務禁止処分の期間は1年以内で、処分を受けたときの宅建士証は「返納」ではなく交付を受けた知事への「提出」です。

</details>

**問4.** 業務に関する規制についての次の記述のうち、正しいものはどれでしょう？

1. 手付金の分割払いを認めて契約の締結を誘引する行為は、契約が成立しなければ宅建業法に違反しない
2. 実在しない物件を広告する「おとり広告」は、問い合わせや申込みがなくても誇大広告等の禁止に違反する
3. 建築確認の申請中である旨を表示すれば、建築確認を受ける前でも新築建物の売買の広告ができる
4. 手付金を減額して契約の締結を誘引する行為は、宅建業法に違反する

<details><summary>答えと解説</summary>

正解: **2**

おとり広告を含む誇大広告等は、誤認させる表示をした時点で違反となり、実害や申込みの有無は関係ありません。手付の貸付けや分割払いによる誘引は、契約の成否にかかわらず誘引行為自体が違反です。一方、手付の減額は違反になりません。建築確認前の広告は、申請中と表示しても禁止です。

</details>

**問5.** 住宅瑕疵担保履行法に関する次の記述のうち、正しいものはどれでしょう？

1. 新築住宅の売買を媒介した宅建業者は、資力確保措置を講じる義務を負わない
2. 買主が宅建業者である場合でも、売主の宅建業者は資力確保措置を講じなければならない
3. 資力確保措置の状況の届出は、基準日から50日以内に行わなければならない
4. 住宅販売瑕疵担保保証金の額の算定では、住宅の床面積にかかわらず1戸を1戸と数える

<details><summary>答えと解説</summary>

正解: **1**

資力確保義務を負うのは自ら売主となる宅建業者であり、媒介・代理の業者は義務を負いません。買主が宅建業者の場合は適用されず、届出は基準日から3週間以内です（50日は、届出を怠った場合に新規契約が禁止されるまでの期間）。床面積55㎡以下の住宅は2戸をもって1戸と数えます。

</details>

**問6.** 標識・帳簿・従業者名簿に関する次の記述のうち、正しいものはどれでしょう？

1. 帳簿は、取引の関係者から請求があったときは、閲覧させなければならない
2. 従業者名簿の保存期間は、最終の記載をした日から5年である
3. 契約の申込みを受けない現地案内所にも、標識を掲示しなければならない
4. 報酬の額は、事務所と案内所の両方に掲示しなければならない

<details><summary>答えと解説</summary>

正解: **3**

標識は、契約や申込みをするかどうかにかかわらず、すべての案内所等に掲示が必要です。帳簿には閲覧させる義務がなく、閲覧義務があるのは従業者名簿です。従業者名簿の保存は10年であり、報酬額の掲示義務があるのは事務所だけです。

</details>

**問7.** 届出に関する次の記述のうち、正しいものはどれでしょう？

1. 専任の宅建士に不足が生じた場合、30日以内に補充などの措置をとればよい
2. 法人の宅建業者が合併により消滅した場合、消滅した法人の代表役員であった者が30日以内に届け出なければならない
3. 契約の申込みを受ける案内所の届出は、業務を開始した後、遅滞なく行えばよい
4. 役員の氏名に変更があった場合、2週間以内に免許権者に届け出なければならない

<details><summary>答えと解説</summary>

正解: **2**

合併消滅の場合は、消滅した法人の代表役員であった者が30日以内に届け出ます。専任宅建士の補充は2週間以内、案内所の届出は業務開始の10日前まで、役員の氏名の変更の届出は30日以内であり、いずれも期間や時期が誤っています。

</details>

**問8.** 業務上の義務に関する次の記述のうち、正しいものはどれでしょう？

1. 業務上知り得た秘密を守る義務は、宅建業を廃業すれば消滅する
2. 業務上知り得た秘密は、本人の承諾があっても漏らしてはならない
3. 預り金の返還を拒む行為は、金額がわずかであれば宅建業法に違反しない
4. 相手方が契約を締結しない旨の意思を表示したにもかかわらず勧誘を継続する行為は、宅建業法に違反する

<details><summary>答えと解説</summary>

正解: **4**

契約しない意思を示した相手への再勧誘は禁止されています。守秘義務は廃業後・退職後も続きますが、本人の承諾など「正当な理由」があれば秘密を告げても違反にはなりません。預り金の返還拒否は金額の大小を問わず禁止されています。

</details>

**問9.** 次の記述のうち、正しいものはどれでしょう？

1. 免許取消処分を受けた宅建業者も、取消し前に締結した契約に基づく取引を結了する目的の範囲内では、なお宅建業者とみなされる
2. 国土交通大臣は、都道府県知事免許の宅建業者に対しても、指示処分をすることができる
3. 業務の全部の停止を命じられた宅建業者は、停止期間中、停止前に締結した契約に基づく取引を結了することもできない
4. 事務禁止処分の期間中に本人の申請により登録が消除された宅建士は、その期間中であっても再び登録を受けることができる

<details><summary>答えと解説</summary>

正解: **1**

免許の取消しや失効の後も、取引を結了する目的の範囲内ではなお宅建業者とみなされ、業務停止期間中も既存契約の履行（結了）は可能です。指示処分を行えるのは免許権者と業務地の知事であり、大臣が知事免許の業者を処分することはできません。事務禁止期間中は、登録を消除しても期間が満了するまで再登録できません。

</details>

**問10.** 宅建業法の規定に関する次の記述のうち、正しいものはいくつあるでしょう？

ア 宅建業者は、事務所ごとに業務に関する帳簿を備え、取引のあったつど所定の事項を記載しなければならない
イ 契約の申込みを受ける案内所には、成年者である専任の宅建士を1人以上置かなければならない
ウ 監督処分として指示処分をしたときも、免許権者はその旨を公告しなければならない

1. 一つ
2. 二つ
3. 三つ
4. 四つ

<details><summary>答えと解説</summary>

正解: **2**

正しいものはアとイの二つです。帳簿は事務所ごとに備えて取引のつど記載し、申込み・契約をする案内所には従事者数にかかわらず専任の宅建士が1人以上必要です。ウは誤りで、公告されるのは業務停止処分と免許取消処分であり、指示処分は公告の対象ではありません。

</details>
