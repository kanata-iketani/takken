# 第27章 権利関係ドリル

権利関係の総仕上げドリルです。本試験レベルの事例問題を4分野×10問、合計40問用意しました。善意か悪意か、登記はあるか、誰に対抗できるか——問題文の事実から結論を即答する練習をします。間違えた問題は、解説を読んだうえで該当するレッスン（10〜16章・25章）に戻って復習しましょう。ここで7割取れれば、権利関係は本試験で戦えるレベルです。

## 1. 意思表示・代理・制限行為能力ドリル

### この範囲の落とし穴トップ3

🔴 第1弾は、意思表示・代理・制限行為能力者です。

1. **詐欺と強迫のちがい**: 詐欺による取消しは善意無過失の第三者に対抗できませんが、強迫による取消しは善意無過失の第三者にも対抗できます
2. **虚偽表示の第三者**: 通謀虚偽表示の無効を対抗できない第三者は「善意」で足ります。無過失も登記も不要です
3. **無権代理の相手方の権利**: 催告は悪意の相手方でもできますが、取消しができるのは善意の相手方だけです

成年年齢は**18歳**。本試験レベルの事例10問で、一気に仕上げましょう。

### 確認問題

**問1.** AとBは通謀して、A所有の甲土地をBに売却したように仮装し、B名義の所有権移転登記をした。その後Bは、事情を知らないCに甲土地を売却したが、Cはまだ移転登記を備えていない。この場合、民法の規定及び判例によれば正しいものはどれか。

1. Cは善意であっても、登記を備えていない以上、Aに所有権を対抗できない
2. AB間の売買は有効であるから、Cは当然に所有権を取得する
3. Cは善意であれば、無過失でなくても、また登記がなくても、Aに対して所有権の取得を主張できる
4. Aは、Cが善意であっても、虚偽表示による無効をCに対抗できる

<details><summary>答えと解説</summary>

正解: **3**

通謀虚偽表示による売買は無効ですが、その無効は善意の第三者に対抗できません。この第三者は善意であれば足り、無過失であることも登記を備えることも不要とされています（判例）。AB間の売買自体は無効なので「有効だから取得する」という理由付けは誤りです。

</details>

**問2.** AはBにだまされて、A所有の甲土地をBに売却した。Bは、詐欺の事実を知らず知らないことに過失もないCに甲土地を転売し、その後AはBの詐欺を理由に売買契約を取り消した。この場合、民法の規定によれば正しいものはどれか。

1. Aは取消しをもって善意無過失のCに対抗できず、Cは甲土地の所有権を取得する
2. Aは取消しにより、Cに対しても当然に所有権を主張できる
3. Cが善意であれば、過失があってもCは保護される
4. 詐欺による意思表示は当然に無効であるから、Aの取消しの意思表示は不要である

<details><summary>答えと解説</summary>

正解: **1**

詐欺による取消しは、取消し前に利害関係に入った「善意でかつ過失がない第三者」に対抗できません。保護されるには善意に加えて無過失が必要なので、過失があるCは保護されません。また詐欺による意思表示は無効ではなく「取り消すことができる」ものであり、取消しの意思表示は必要です。

</details>

**問3.** AはBに強迫されて、A所有の甲土地をBに売却した。Bは、強迫の事実を知らず知らないことに過失もないCに甲土地を転売し、Cは移転登記も備えた。その後、Aは強迫を理由に売買契約を取り消した。この場合、民法の規定によれば正しいものはどれか。

1. Cは善意無過失なので、AはCに取消しを対抗できない
2. Aは、善意無過失のCに対しても取消しを対抗し、所有権を主張できる
3. 強迫による意思表示は当然に無効であり、Aが取り消す必要はない
4. Cが登記を備えている以上、Aは所有権を回復できない

<details><summary>答えと解説</summary>

正解: **2**

強迫による取消しは、詐欺と異なり、取消し前の善意無過失の第三者にも対抗できます。だまされた者には多少の落ち度がありえますが、強迫された者を保護する必要性が高いためです。強迫も「取り消すことができる」行為であって当然無効ではなく、取消し前の第三者との関係では登記の有無は結論を左右しません。

</details>

**問4.** Aは、B所有の乙土地を隣の甲土地と勘違いして「乙土地を買いたい」と申し込み、売買契約が成立した。この錯誤は法律行為の目的および取引上の社会通念に照らして重要なものであるが、Aの重大な過失によるものであった。Bはこの錯誤について善意無過失である。この場合、民法の規定によれば正しいものはどれか。

1. Aは、重要な錯誤である以上、常に意思表示を取り消すことができる
2. 錯誤による意思表示であるから、売買契約は当然に無効である
3. Bが善意無過失であっても、Aに重大な過失があれば取り消せる
4. Aに重大な過失があるため、Aは原則として意思表示を取り消すことができない

<details><summary>答えと解説</summary>

正解: **4**

重要な錯誤による意思表示は「取り消すことができる」ものであり、無効ではありません。ただし表意者に重大な過失があるときは、原則として取消しができません。例外として取消しできるのは、相手方が錯誤につき悪意・重過失の場合や、相手方が同一の錯誤に陥っていた場合ですが、Bは善意無過失なので例外に当たりません。

</details>

**問5.** Aは、売るつもりがないのに冗談で「甲土地を100万円で売る」とBに意思表示をし、Bは、それがAの真意でないことを知りながら承諾した。この場合、民法の規定によれば正しいものはどれか。

1. 意思表示は表示どおりに効力を生じ、売買契約は有効である
2. Bが悪意であるため、Aの意思表示は無効である
3. 心裡留保による意思表示は、相手方の善意悪意を問わず常に無効である
4. Aは、錯誤を理由として意思表示を取り消すことができる

<details><summary>答えと解説</summary>

正解: **2**

心裡留保による意思表示は原則として有効ですが、相手方が真意でないことを知っていたか、知ることができたときは無効です。Bは悪意なので無効となります。常に無効なのではなく、またこの無効は善意の第三者に対抗できません。勘違いではないので錯誤の問題でもありません。

</details>

**問6.** Bは、代理権がないのにAの代理人と称して、A所有の甲土地をCに売却する契約を締結した。Cは、契約締結時にBに代理権がないことを知っていた。この場合、民法の規定によれば正しいものはどれか。

1. Cは、Aに対し相当の期間を定めて追認するかどうかを催告でき、期間内に確答がなければ追認を拒絶したものとみなされる
2. Cは、悪意であっても、Aが追認しない間は契約を取り消すことができる
3. Cは悪意であるため、催告をすることも取消しをすることもできない
4. Aが追認しても、この契約が有効となることはない

<details><summary>答えと解説</summary>

正解: **1**

無権代理の相手方の催告は、悪意の相手方でもすることができ、期間内に本人の確答がなければ追認拒絶とみなされます。一方、相手方の取消権は善意の相手方に限られるので、悪意のCは取り消せません。本人Aが追認すれば、契約は原則として契約時にさかのぼって有効になります。

</details>

**問7.** Bは、代理権がないのにAの代理人と称して、A所有の甲土地をCに売却する契約を締結した。その後Aが死亡し、BがAを単独で相続した。この場合、判例によれば正しいものはどれか。

1. Bは、本人の資格に基づいて追認を拒絶することができる
2. Aの死亡により、売買契約は当然に無効となる
3. Bは追認を拒絶することができず、売買契約は当然に有効となる
4. Cは、Bが相続した後は、Bに対して履行を請求できない

<details><summary>答えと解説</summary>

正解: **3**

無権代理人が本人を単独相続した場合、自ら無権代理行為をした者が本人の資格で追認を拒絶することは信義則上許されず、契約は当然に有効になります（判例）。したがってCはBに履行を請求できます。逆に本人が無権代理人を相続した場合には、本人は追認を拒絶できる点と対比して覚えましょう。

</details>

**問8.** AはBに対し、A所有の甲土地を売却する代理権を与えた。この場合の代理行為に関する記述として、民法の規定によれば正しいものはどれか。

1. Bは、Aの許諾がなくても、自ら甲土地の買主となる契約を有効に締結できる
2. Bが売主Aと買主Cの双方の代理人となることは、AとC双方の許諾があっても無効である
3. BがAに無断で買主Cの代理人を兼ねて締結した契約は、当然に有効である
4. BがAの許諾を得ずに自ら買主となって締結した契約は、無権代理行為とみなされる

<details><summary>答えと解説</summary>

正解: **4**

自己契約（代理人自身が相手方になる）と双方代理は、本人の利益を害するおそれがあるため、原則として無権代理行為とみなされます。したがって当然に有効にはなりません。ただし本人があらかじめ許諾した場合（双方代理なら双方の本人の許諾がある場合）や単なる債務の履行は有効にできます。

</details>

**問9.** 17歳のAは、法定代理人の同意を得ずに、自己所有の甲土地をBに売却する契約を締結した。この場合、民法の規定によれば正しいものはどれか。

1. A本人も、Aの法定代理人も、この売買契約を取り消すことができる
2. この契約を取り消すことができるのは、法定代理人に限られる
3. 成年年齢は18歳であるが、17歳のAがした契約も常に有効であり、取り消すことはできない
4. Bが、Aを成年者であると信じていた場合には、取り消すことはできない

<details><summary>答えと解説</summary>

正解: **1**

成年年齢は18歳なので17歳のAは未成年者であり、法定代理人の同意のない契約は取り消すことができます。取消しは未成年者本人も単独ででき（取消しに同意は不要）、法定代理人もできます。相手方Bが成年者と信じていただけでは取消しは妨げられず、取消しが制限されるのはAが詐術を用いた場合です。

</details>

**問10.** 成年被後見人Aは、成年後見人Cの同意を得たうえで、自己所有の甲土地をBに売却する契約を締結した。この場合、民法の規定によれば正しいものはどれか。

1. Cの同意を得ている以上、この契約を取り消すことはできない
2. Cの同意を得ていても、AまたはCはこの契約を取り消すことができる
3. 成年被後見人の行為はすべて当然に無効であり、取消しの意思表示は不要である
4. Aが日用品を購入した場合も、Cはこれを取り消すことができる

<details><summary>答えと解説</summary>

正解: **2**

成年被後見人は判断能力を欠く状態が通常であり、同意どおりに行動できるとは限らないため、成年後見人の同意を得た行為であっても取り消すことができます（同意があれば取り消せなくなる未成年者等との違いです）。行為は無効ではなく取り消しうるものであり、日用品の購入その他日常生活に関する行為は取り消せません。

</details>

## 2. 物権変動・登記・抵当権ドリル

### この範囲の落とし穴トップ3

🔴 第2弾は、物権変動・登記・抵当権です。

1. **「前」か「後」か**: 取消し・解除・時効完成の**後**に現れた第三者とは、登記の早い者勝ち（対抗関係）。**前**に現れた第三者とは、善意無過失などの条文ルールで決まります
2. **悪意者と背信的悪意者**: 単なる悪意者には登記がなければ負けますが、**背信的悪意者**には登記なしで対抗できます
3. **抵当権と賃借人**: 抵当権設定登記後の賃借人は買受人に対抗できませんが、**建物**の賃借人には買受けの時から**6か月の明渡し猶予**があります

相続登記の**3年以内の申請義務**（2024年施行）もここで確認します。

### 確認問題

**問1.** Aは、A所有の甲土地をBに売却し、その後、同じ甲土地をCにも売却した。Cは、AB間の売買の事実を知ったうえで購入し、先に所有権移転登記を備えた。Cには、Bを害する意図などの背信的な事情はない。この場合、民法の規定及び判例によれば正しいものはどれか。

1. Cは悪意であるため、登記を備えてもBに所有権を対抗できない
2. Cは単なる悪意者にすぎないので、登記を備えた以上、Bに所有権を対抗できる
3. 先に売買契約を締結したBが、登記がなくてもCに所有権を対抗できる
4. BとCは、甲土地を持分2分の1ずつで共有することになる

<details><summary>答えと解説</summary>

正解: **2**

二重譲渡の優劣は登記の先後で決まり、登記を備える第三者は善意である必要はありません（自由競争の範囲内とされます）。したがって単なる悪意者Cでも、先に登記を備えればBに勝ちます。契約の先後では決まらず、共有になることもありません。

</details>

**問2.** Aは、A所有の甲土地をBに売却した。Cは、AB間の売買の事実を知りながら、Bに高値で売りつけて利益を得る目的で甲土地をAから購入し、所有権移転登記を備えた。この場合、判例によれば正しいものはどれか。

1. 登記を備えたCが、常にBに優先する
2. Bは、Cに損害賠償を請求できるが、所有権を主張することはできない
3. 背信的悪意者であるCからの転得者は、いかなる場合もBに対抗できない
4. Cは背信的悪意者に当たり、Bは登記がなくてもCに所有権を対抗できる

<details><summary>答えと解説</summary>

正解: **4**

第一譲受人に高値で売りつける目的での購入は背信的悪意者の典型例です。背信的悪意者は信義則上、登記の欠缺を主張する正当な利益を有する「第三者」に当たらないため、Bは登記なくして対抗できます。なお背信的悪意者からの転得者は、転得者自身が背信的悪意者と評価されない限り保護されうるとするのが判例です。

</details>

**問3.** Aは、Bの詐欺によってA所有の甲土地をBに売却し、その後、詐欺に気づいて売買契約を取り消した。ところが取消し後も登記名義がBのままであったため、Bは甲土地を事情を知らないCに売却し、Cが所有権移転登記を備えた。この場合、判例によれば正しいものはどれか。

1. 取消し後に現れた第三者Cとの関係は対抗問題となり、先に登記を備えたCが優先する
2. Aはすでに取り消している以上、登記がなくてもCに所有権を対抗できる
3. 取消しにより契約は遡及的に無効となるため、Cは登記を備えていても一切保護されない
4. Cは、善意に加えて無過失であることを証明しない限り保護されない

<details><summary>答えと解説</summary>

正解: **1**

取消し「後」に現れた第三者との関係は、取消しによる復帰的物権変動とBからCへの譲渡との対抗問題となり、登記の先後で決まります（判例）。本問では登記を備えたCが優先します。善意無過失が問題になるのは取消し「前」に利害関係に入った第三者（96条3項）の場合です。

</details>

**問4.** Bは、A所有の甲土地を所有の意思をもって平穏かつ公然に占有し続け、取得時効が完成した。その後、AがCに甲土地を売却してCが所有権移転登記を備え、さらにその後、Bが時効を援用した。この場合、判例によれば正しいものはどれか。

1. Bは時効完成により当然に所有権を取得しているので、登記なくしてCに対抗できる
2. 時効取得は原始取得であるから、Bは常にCに優先する
3. Cは時効完成後に現れた第三者であるから、Bは登記がなければCに時効取得を対抗できない
4. Bは、Cに対して土地の時価相当額の支払いを請求できるにとどまる

<details><summary>答えと解説</summary>

正解: **3**

時効完成「後」に所有者から土地を取得した第三者と時効取得者とは対抗関係に立ち、登記を先に備えた方が優先します（判例）。本問のBは登記がないためCに対抗できません。逆に時効完成「前」に現れた第三者に対しては、Bは登記なくして時効取得を対抗できます。この前後の区別が最大のポイントです。

</details>

**問5.** Aが死亡し、その子Bが遺産である甲土地の所有権を相続により取得した。不動産登記法の規定によれば、相続登記の申請義務に関する記述として正しいものはどれか。

1. 相続による所有権の取得は、登記をしなければ効力を生じない
2. 相続登記の申請はあくまで任意であり、申請しなくても不利益はない
3. Bは、相続の開始を知った日から1年以内に登記を申請しなければならない
4. Bは、相続の開始および所有権の取得を知った日から3年以内に相続登記を申請する義務を負う

<details><summary>答えと解説</summary>

正解: **4**

2024年施行の改正により相続登記の申請が義務化され、相続の開始と所有権の取得を知った日から3年以内に申請しなければならず、正当な理由なく怠ると過料の対象になります。登記は効力発生要件ではないので、登記がなくても相続による取得自体は有効です。

</details>

**問6.** Aが死亡し、相続人は子BとCである。遺産分割協議により甲土地はBが単独で取得することになったが、Bが登記をしない間に、Cは自己の法定相続分である持分2分の1をDに売却し、Dは持分移転登記を備えた。この場合、民法の規定によれば正しいものはどれか。

1. Bは遺産分割により単独所有権を取得しているので、登記なくしてDに対抗できる
2. Bは、自己の法定相続分を超える部分の取得については、登記がなければDに対抗できない
3. Dは、遺産分割協議の存在を知っていた場合に限り保護される
4. 遺産分割の効力は相続開始時にさかのぼるため、Dが権利を取得する余地はない

<details><summary>答えと解説</summary>

正解: **2**

相続人は、法定相続分については登記がなくても第三者に対抗できますが、遺産分割などによって法定相続分を「超えて」取得した部分は、登記を備えなければ第三者に対抗できません。遺産分割に遡及効があっても、第三者との関係では登記が必要であり、Dの善意悪意は要件とされていません。

</details>

**問7.** AはBから融資を受け、A所有の甲土地にBのための抵当権を設定し、その登記をした。この場合、民法の規定によれば正しいものはどれか。

1. 甲土地に設定された抵当権の効力は、原則として甲土地上の建物には及ばない
2. 抵当権を設定すると、設定者Aは甲土地を使用することができなくなる
3. 抵当権設定契約は、登記をしなければ当事者間でも効力を生じない
4. 抵当権は、目的物の引渡しがなければ効力を生じない

<details><summary>答えと解説</summary>

正解: **1**

土地と建物は別個の不動産なので、土地の抵当権の効力は建物には及びません（付加一体物や従物には及びます）。抵当権は目的物を債務者・設定者の手元に残す担保なので、設定後もAは使用収益を続けられ、引渡しも不要です。設定契約は合意だけで成立し、登記は第三者への対抗要件です。

</details>

**問8.** Aは、自己所有の甲土地とその上の乙建物のうち、甲土地にのみBのための抵当権を設定した。その後抵当権が実行され、Cが競売により甲土地を買い受けた。この場合、民法の規定によれば正しいものはどれか。

1. 乙建物のために地上権は成立せず、Aは乙建物を収去して甲土地を明け渡さなければならない
2. 抵当権設定当時に甲土地が更地であった場合でも、後に建物が建てられれば法定地上権が成立する
3. 抵当権設定当時に土地と建物が同一の所有者に属していたので、乙建物のために法定地上権が成立する
4. 法定地上権は、AとCが地上権設定の合意をしなければ成立しない

<details><summary>答えと解説</summary>

正解: **3**

①抵当権設定当時に建物が存在し、②その土地と建物が同一所有者に属し、③土地・建物の一方または双方に抵当権が設定され、④競売により所有者が異なるに至ったときは、法律上当然に法定地上権が成立します（合意は不要）。設定当時更地であった場合は、後から建物を建てても法定地上権は成立しません。

</details>

**問9.** Aは、自己所有の甲建物にBのための抵当権を設定し、その登記をした。その後、CはAから甲建物を賃借して居住を始めた。抵当権が実行され、Dが競売により甲建物を買い受けた。この場合、民法の規定によれば正しいものはどれか。

1. Cは賃借権をDに対抗でき、賃貸借の期間が満了するまで居住を続けられる
2. CはDに賃借権を対抗できないが、買受けの時から6か月間は甲建物の明渡しが猶予される
3. Cは、Dの買受けと同時に直ちに甲建物を明け渡さなければならない
4. 買受けからの明渡し猶予の制度は、建物だけでなく土地の賃借人にも適用される

<details><summary>答えと解説</summary>

正解: **2**

抵当権設定登記の後に対抗要件を備えた賃借人は、買受人に賃借権を対抗できません。ただし建物の賃借人（競売手続開始前から使用収益する者）には、買受けの時から6か月間の明渡し猶予が認められるため、直ちに退去する必要はありません。この猶予制度は建物に限られ、土地の賃借人には適用されません。

</details>

**問10.** Aの所有する甲土地には、Bの1番抵当権とCの2番抵当権が設定され、いずれも登記されている。この場合、民法の規定によれば正しいものはどれか。

1. Bは、利息について、その全額をCに優先して弁済を受けることができる
2. 抵当権の順位は、いったん定まった後に変更することはできない
3. Bが被担保債権全額の弁済を受けた場合でも、Bの抵当権は消滅しない
4. Bが利息についてCに優先して弁済を受けられるのは、原則として満期となった最後の2年分に限られる

<details><summary>答えと解説</summary>

正解: **4**

後順位抵当権者など利害関係者がいる場合、抵当権者が優先弁済を受けられる利息・定期金は、原則として満期となった最後の2年分に限られます。抵当権の順位は、各抵当権者の合意（利害関係者がいればその承諾も）により変更できます。被担保債権が全額弁済されれば、付従性により抵当権は消滅します。

</details>

## 3. 債権（不履行・解除・売買・不法行為）ドリル

### この範囲の落とし穴トップ3

🔴 第3弾は、債務不履行・解除・売買・不法行為です。

1. **解除に帰責事由は不要**: 債務者に帰責事由がなくても契約は解除できます。帰責事由が必要なのは**損害賠償請求**の方。逆に**債権者の側**に帰責事由があると解除できません
2. **手付解除のタイムリミット**: 「**相手方**が履行に着手するまで」。自分が着手していても、相手方が未着手なら解除できます
3. **契約不適合の通知**: 種類・品質の不適合は「**知った時から1年**」以内の通知が必要。数量・権利の不適合には、この期間制限はありません

金銭債務の特則・連帯債務・保証も、ここで総点検しましょう。

### 確認問題

**問1.** 債務者が履行遅滞の責任を負う時期に関する記述として、民法の規定によれば正しいものはどれか。

1. 期限の定めのない債務は、債務者が履行の請求を受けた時から遅滞となる
2. 確定期限のある債務は、期限到来後に債権者が請求した時から遅滞となる
3. 不確定期限のある債務は、期限が到来すれば、債務者が知らなくても当然に遅滞となる
4. 期限の定めのない債務は、契約成立の時から当然に遅滞となる

<details><summary>答えと解説</summary>

正解: **1**

期限の定めのない債務は、履行の請求を受けた時から遅滞になります（契約成立時からではありません）。確定期限のある債務は期限到来時から当然に遅滞となり、請求は不要です。不確定期限の債務は、期限到来後に請求を受けた時、または債務者が期限の到来を知った時のいずれか早い時から遅滞となります。

</details>

**問2.** BはAから1,000万円を借り入れたが、大規模な災害の影響により、弁済期に返済することができなかった。この場合、民法の規定によれば正しいものはどれか。

1. 不可抗力による不履行なので、Bは遅延損害金の支払義務を負わない
2. Aは、遅滞によって実際に生じた損害額を証明しなければ、損害賠償を請求できない
3. 金銭債務の不履行については、Bは不可抗力をもって抗弁とすることができない
4. 遅延損害金は、約定利率が法定利率を超える場合でも、常に法定利率で計算する

<details><summary>答えと解説</summary>

正解: **3**

金銭債務には特則があり、債務者は不可抗力を抗弁にできません。また債権者は損害の証明をせずに遅延損害金を請求でき、その額は法定利率（約定利率が法定利率を超えるときは約定利率）によって計算します。したがって災害を理由に支払義務を免れることはできません。

</details>

**問3.** AB間の売買契約で、売主Aは履行期を過ぎても目的物を引き渡さない。Aの不履行についてAに帰責事由はなく、Bにも帰責事由はない。Bは相当の期間を定めて履行を催告したが、期間内に履行はなく、不履行は軽微とはいえない。この場合、民法の規定によれば正しいものはどれか。

1. Aに帰責事由がない以上、Bは契約を解除できない
2. Bは、催告をせずに直ちに解除できたのであり、催告は無意味であった
3. Bは解除できるほか、Aに帰責事由がなくても当然に損害賠償も請求できる
4. Aに帰責事由がなくても、Bは契約を解除することができる

<details><summary>答えと解説</summary>

正解: **4**

解除は債権者を契約の拘束力から解放する制度なので、債務者の帰責事由は不要です（催告して相当期間内に履行がなく、不履行が軽微でなければ解除できます）。一方、損害賠償請求には債務者の帰責事由が必要なので「当然に請求できる」は誤りです。無催告解除ができるのは履行不能や明確な履行拒絶などの場合です。

</details>

**問4.** AはBに甲土地を売却して所有権移転登記をしたが、Bが代金を支払わないため、Aは契約を解除した。解除の前に、Bは甲土地をCに転売しており、Cは所有権移転登記を備えていた。この場合、民法の規定及び判例によれば正しいものはどれか。

1. Cは、Bの代金不払いの事実について善意でなければ保護されない
2. Cは登記を備えているので、Aは解除をもってCに対抗できない
3. 解除により契約は遡及的に消滅するため、Cは登記を備えていても権利を失う
4. Cは、登記を備えていなくても当然に保護される

<details><summary>答えと解説</summary>

正解: **2**

解除の遡及効は「第三者の権利を害することができない」とされており、解除前に利害関係に入った第三者は保護されます。この第三者は善意である必要はありませんが、保護を受けるには登記を備えていることが必要とされています（判例）。Cは登記を備えているので保護されます。

</details>

**問5.** AはBに甲土地を売却する契約を締結し、Bから解約手付として100万円を受領した。Bはまだ履行に着手していないが、Aは引渡しの準備を整えるなど履行に着手している。この場合、民法の規定及び判例によれば正しいものはどれか。

1. Aは、相手方Bが履行に着手していないので、手付の倍額を現実に提供して契約を解除できる
2. Aは、自ら履行に着手している以上、もはや手付による解除はできない
3. Aは、受領した手付100万円をBに返還しさえすれば解除できる
4. Bが手付解除をする場合には、手付の放棄に加えて損害賠償もしなければならない

<details><summary>答えと解説</summary>

正解: **1**

手付解除ができなくなるのは「相手方」が履行に着手した後です。自分が着手していても、相手方Bが未着手である限りAは解除できます。売主からの手付解除には倍額（200万円）の現実の提供が必要で、受領した100万円を返すだけでは足りません。解約手付による解除では、損害賠償の問題は生じません。

</details>

**問6.** AはBから中古建物を購入して引渡しを受けたが、引渡しから6か月後に、品質に関する契約不適合を発見した。売主Bは不適合について善意無過失である。この場合、民法の規定によれば正しいものはどれか。

1. 引渡しの時から1年以内に通知しなければ、Aは担保責任を追及できない
2. Aは、不適合を知った時から1年以内に裁判上の請求までしなければ権利を失う
3. 目的物の数量が不足していた場合も、知った時から1年以内の通知を怠ると責任追及できない
4. Aは、不適合を知った時から1年以内にその旨をBに通知すれば、追完請求などをすることができる

<details><summary>答えと解説</summary>

正解: **4**

種類・品質に関する契約不適合では、買主は「不適合を知った時から1年以内」にその旨を売主に通知する必要があります。起算点は引渡し時ではなく、裁判上の請求までは不要で通知で足ります。この通知期間の制限は種類・品質の不適合に限られ、数量不足や権利の不適合には適用されません。なお売主が不適合につき悪意・重過失のときは通知を怠っても責任追及できます。

</details>

**問7.** 売買の目的物に品質に関する契約不適合があった場合の買主の救済に関する記述として、民法の規定によれば正しいものはどれか。

1. 買主は、いかなる場合もまず代金減額を請求しなければならない
2. 不適合が買主の帰責事由によって生じたものであっても、買主は追完請求ができる
3. 買主は、原則として相当の期間を定めて追完の催告をし、期間内に追完がないときに代金減額を請求できる
4. 買主が追完請求をした場合には、あわせて損害賠償を請求することはできない

<details><summary>答えと解説</summary>

正解: **3**

代金減額請求は、原則として相当期間を定めた追完の催告が先であり、期間内に追完がないときにできます（追完不能や明確な追完拒絶があれば無催告でも可能です）。不適合が買主の帰責事由による場合は追完請求も減額請求もできません。追完請求と、売主に帰責事由があるときの損害賠償請求は併せて行うことができます。

</details>

**問8.** B・C・Dの3人は、Aに対して900万円の連帯債務を負っており、負担部分は平等である。この場合、民法の規定によれば正しいものはどれか。

1. Aは、B・C・Dのうち1人を選んで全額を請求することはできず、各自に300万円ずつ請求しなければならない
2. AはBに対して900万円全額を請求でき、Bが全額を弁済したときは、BはCとDに各300万円を求償できる
3. AがBに対して履行を請求すると、その効果はCとDにも当然に及ぶ
4. Bが債務を承認して時効が更新されると、CとDについても時効が更新される

<details><summary>答えと解説</summary>

正解: **2**

連帯債務の債権者は、各債務者に対して全部または一部の履行を同時にでも順次にでも請求できます。全額を弁済した連帯債務者は、他の債務者に負担部分（本問では各300万円）を求償できます。履行の請求や承認による時効更新の効力は原則として相対効であり、他の連帯債務者には及びません。

</details>

**問9.** BのAに対する借入金債務について、CがAとの間で保証契約（連帯保証ではない）を締結する場合に関する記述として、民法の規定によれば正しいものはどれか。

1. 保証契約は、AとCが口頭で合意すれば有効に成立する
2. 連帯保証人にも、催告の抗弁権と検索の抗弁権が認められる
3. 主たる債務が弁済により消滅しても、保証債務は存続する
4. 保証契約は、書面または電磁的記録によってしなければ、効力を生じない

<details><summary>答えと解説</summary>

正解: **4**

保証契約は、書面または電磁的記録でしなければ効力を生じない要式契約です（口頭の合意では無効）。通常の保証人には催告の抗弁権・検索の抗弁権がありますが、連帯保証人にはいずれもありません。保証債務には付従性があるため、主たる債務が消滅すれば保証債務も消滅します。

</details>

**問10.** 宅建業者Aの従業員Bは、Aの事業の執行について、過失により顧客Cに損害を与えた。この場合、民法の規定及び判例によれば正しいものはどれか。

1. Cは、Bに対しても、Aに対しても、損害の全額の賠償を請求することができる
2. 使用者Aが責任を負う以上、従業員B自身は不法行為責任を負わない
3. AがCに賠償した場合、AはBに対して、賠償した全額を常に求償できる
4. Cの損害賠償請求権は、損害及び加害者を知った時から10年で時効消滅する

<details><summary>答えと解説</summary>

正解: **1**

使用者責任が成立しても被用者自身の不法行為責任はなくならず、被害者はどちらにも全額を請求できます（どちらかが支払えばその範囲で消滅します）。使用者から被用者への求償は信義則上相当と認められる限度に制限され、常に全額ではありません。不法行為の消滅時効は知った時から3年（生命・身体の侵害は5年）と行為時から20年です。

</details>

## 4. 借地借家・相続・区分所有ドリル

### この範囲の落とし穴トップ3

🔴 最終弾は、借地借家法・相続・区分所有法です。

1. **期間のルールが正反対**: 借地は最低**30年**（これより短い特約は無効）。建物賃貸借は**1年未満**の期間を定めると「期間の定めがない」扱いになります
2. **対抗要件がゆるい**: 借地は借地上建物の**自己名義**の登記があれば、借家は建物の**引渡し**を受けていれば対抗できます（家族名義の建物登記では対抗できません）
3. **相続放棄と代襲**: 放棄した者の子は**代襲相続しません**（代襲が生じるのは死亡・欠格・廃除）。配偶者と兄弟姉妹の相続分は**4分の3対4分の1**です

権利関係の総仕上げ、最後の10問です。

### 確認問題

**問1.** AとBは、Bの居住用建物の所有を目的として、A所有の甲土地について存続期間を20年と定めた賃貸借契約を締結した。この場合、借地借家法の規定によれば正しいものはどれか。

1. 存続期間は、定めたとおり20年となる
2. 期間の定めは無効となり、期間の定めのない契約となる
3. 存続期間は、一律に50年となる
4. 20年の定めは無効であり、存続期間は30年となる

<details><summary>答えと解説</summary>

正解: **4**

借地権の存続期間は最低30年であり、これより短い期間の定めは無効となって30年になります。30年より長い期間を定めることは有効です。一方、建物所有目的でない土地賃貸借や一時使用目的の借地には、この規定は適用されません。

</details>

**問2.** Bは、Aから賃借した甲土地上に乙建物を建築し、乙建物についてB名義の所有権保存登記をしているが、借地権(賃借権)の登記はしていない。その後、Aは甲土地をCに売却した。この場合、借地借家法の規定及び判例によれば正しいものはどれか。

1. 賃借権の登記がない以上、BはCに借地権を対抗できない
2. Bは、借地上の建物について自己名義の登記をしているので、借地権をCに対抗できる
3. 乙建物の登記がBの長男名義であっても、BはCに対抗できる
4. Bが乙建物に現に居住してさえいれば、登記がなくても対抗できる

<details><summary>答えと解説</summary>

正解: **2**

借地権は、賃借権の登記がなくても、借地上の建物について借地権者が自己名義の登記（保存登記で足ります）をしていれば第三者に対抗できます。この登記は借地権者本人の名義であることが必要で、長男など家族名義では対抗できません（判例）。居住の事実だけでは対抗要件になりません。

</details>

**問3.** AはBに対し、甲建物を期間10か月と定めて賃貸し（定期建物賃貸借ではない）、引き渡した。その後、Aは甲建物をCに売却した。この場合、借地借家法の規定によれば正しいものはどれか。

1. 期間10か月の定めは有効であり、期間満了により当然に契約は終了する
2. 1年未満の期間の定めは、1年に引き上げられる
3. この賃貸借は期間の定めのないものとみなされ、Bは引渡しを受けているので賃借権をCに対抗できる
4. Bは賃借権の登記をしていないので、Cに賃借権を対抗できない

<details><summary>答えと解説</summary>

正解: **3**

通常の建物賃貸借で1年未満の期間を定めると、期間の定めのない賃貸借とみなされます（1年に引き上げられるのではありません）。また建物賃貸借は、賃借権の登記がなくても建物の引渡しがあれば第三者に対抗できるので、引渡しを受けているBは新所有者Cに対抗できます。なお定期建物賃貸借であれば1年未満の期間も有効です。

</details>

**問4.** 定期建物賃貸借に関する記述として、借地借家法の規定によれば正しいものはどれか。

1. 定期建物賃貸借契約は、公正証書等の書面（または電磁的記録）によって締結し、契約前に、更新がない旨を記載した書面を交付（承諾を得て電磁的方法も可）して説明しなければならない
2. 定期建物賃貸借契約は、口頭の合意によっても有効に成立する
3. 期間を1年未満とする定期建物賃貸借は、無効である
4. 事前の説明を怠った場合でも、更新がない旨の特約は有効である

<details><summary>答えと解説</summary>

正解: **1**

定期建物賃貸借は、書面（電磁的記録でも可）によって契約し、かつ契約に先立って「更新がなく期間満了により終了する」旨を記載した書面を交付して説明する必要があります。口頭では成立せず、事前説明を怠ると更新がない旨の特約は無効となり、普通の建物賃貸借として扱われます。定期建物賃貸借では1年未満の期間の定めも有効です。

</details>

**問5.** 借地借家法上の建物買取請求権および造作買取請求権に関する記述として正しいものはどれか。

1. 賃貸人の同意を得て付加した造作の買取請求権を認めない特約は、賃借人に不利なため無効である
2. 借地契約の更新がない場合の借地権者の建物買取請求権を排除する特約は、有効である
3. 造作買取請求権を認めない特約は有効であるが、借地権者の建物買取請求権を排除する特約は無効である
4. 建物買取請求権も造作買取請求権も、特約によって自由に排除することができる

<details><summary>答えと解説</summary>

正解: **3**

造作買取請求権の規定は任意規定なので、これを認めない特約も有効です。一方、借地契約の更新がない場合の建物買取請求権を排除する特約は、借地権者に不利な特約として無効です。この「借家の造作は排除できる・借地の建物は排除できない」という対比が頻出のひっかけです。

</details>

**問6.** Aが死亡した。相続人は、配偶者Bと、AB間の子C・Dの3人であり、遺言はない。遺産が6,000万円である場合の法定相続分に従った取得額として、民法の規定によれば正しいものはどれか。

1. Bが2,000万円、Cが2,000万円、Dが2,000万円
2. Bが3,000万円、Cが1,500万円、Dが1,500万円
3. Bが4,500万円、Cが750万円、Dが750万円
4. Bが3,000万円、Cが3,000万円、Dは取得しない

<details><summary>答えと解説</summary>

正解: **2**

配偶者と子が相続人の場合、法定相続分は配偶者2分の1、子2分の1です。子が複数いるときは2分の1を均等に分けるので、Bが3,000万円、CとDが各1,500万円となります。子同士の相続分に差はなく、3等分や配偶者4分の3になる組合せでもありません。

</details>

**問7.** Aが死亡し、Aの子Bは家庭裁判所に申述して相続の放棄をした。Bには子C（Aの孫）がいる。この場合、民法の規定によれば正しいものはどれか。

1. Cは、Bを代襲してAの相続人となる
2. 相続の放棄は、他の相続人に対する意思表示だけですることができる
3. Bは、Aの生前にあらかじめ相続を放棄しておくこともできた
4. 相続を放棄したBの子Cは、Bを代襲してAを相続することはない

<details><summary>答えと解説</summary>

正解: **4**

相続を放棄した者は初めから相続人でなかったものとみなされるため、代襲相続は生じません（代襲原因は相続開始以前の死亡・欠格・廃除の3つだけです）。放棄は、自己のために相続の開始があったことを知った時から3か月以内に家庭裁判所に申述して行う必要があり、被相続人の生前に放棄することはできません。

</details>

**問8.** Aが死亡した。Aには子も直系尊属もおらず、相続人は配偶者Bと弟Cである。この場合、民法の規定によれば正しいものはどれか。

1. 法定相続分は、Bが4分の3、Cが4分の1である
2. 法定相続分は、BとCがそれぞれ2分の1である
3. 法定相続分は、Bが3分の2、Cが3分の1である
4. Cには遺留分があるため、Aが全財産をBに相続させる旨の遺言をしても、Cの取り分を奪うことはできない

<details><summary>答えと解説</summary>

正解: **1**

配偶者と兄弟姉妹が相続人となる場合の法定相続分は、配偶者4分の3・兄弟姉妹4分の1です（3分の2対3分の1は配偶者と直系尊属の場合）。また兄弟姉妹には遺留分がないため、全財産をBに相続させる旨の遺言をすれば、Cは何も取得できません。

</details>

**問9.** 遺言および遺留分に関する記述として、民法の規定によれば正しいものはどれか。

1. 自筆証書遺言は、全文をパソコンで作成したものに署名押印すれば有効である
2. Aが「全財産をBに遺贈する」と遺言して死亡した場合、Aの子Cは、遺留分侵害額に相当する金銭の支払いを請求できる
3. 遺留分を侵害する内容の遺言は、その侵害の限度で当然に無効である
4. 遺留分侵害額請求権は、相続の開始を知った時から3か月以内に行使しなければ消滅する

<details><summary>答えと解説</summary>

正解: **2**

遺留分を侵害された相続人（兄弟姉妹以外）は、受遺者等に対し遺留分侵害額に相当する「金銭」の支払いを請求できます。遺言自体は有効であり、当然に無効となるわけではありません。自筆証書遺言は原則として全文の自書が必要です（添付する財産目録はパソコン作成可）。侵害額請求権は、相続開始と侵害すべき贈与・遺贈を知った時から1年（相続開始時から10年）で消滅します。

</details>

**問10.** 建物の区分所有等に関する法律の規定によれば、集会の決議等に関する記述として正しいものはどれか。

1. 建替え決議は、区分所有者及び議決権の各4分の3以上の多数で行うことができる
2. 規約の設定・変更・廃止は、区分所有者及び議決権の各過半数の賛成で行うことができる
3. 建替え決議には区分所有者及び議決権の各5分の4以上、規約の設定・変更・廃止には各4分の3以上の多数が必要である
4. 共用部分の保存行為は、集会の決議を経なければ行うことができない

<details><summary>答えと解説</summary>

正解: **3**

建替え決議は区分所有者及び議決権の各5分の4以上、規約の設定・変更・廃止は各4分の3以上、普通決議事項は各過半数が原則です。数字を入れ替えるのが定番のひっかけです。共用部分の保存行為は各区分所有者が単独でできます。なお建替え決議の要件を緩和する法改正が成立しているため、受験年度の最新情報も確認しましょう。

</details>
