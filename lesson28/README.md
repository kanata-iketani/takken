# 第28章 法令制限・税ドリル

総仕上げドリル第3弾は「法令上の制限」と「税・その他」です。この分野のひっかけは、ほぼすべて数字の入れ替え——1000と2000、2週間と3週間、1月1日。本編（lesson17〜22）で覚えた数字を、本試験レベルの4択で即答できるか試します。間違えた問題は、該当するレッスンに戻って確認しましょう。

## 1. 都市計画法・開発許可ドリル

都市計画法・開発許可の総復習ドリルです。本編（lesson17）の内容を、本試験レベルの数字ひっかけで確認します。

### この範囲の落とし穴トップ3

1. **面積基準の混同**: 開発許可は「市街化区域1000㎡・非線引き等3000㎡・区域外10000㎡」。国土法の2000・5000と混ぜるのが出題者の定番です
2. **調整区域の例外なし**: 市街化調整区域だけは面積にかかわらず、すべての開発行為に許可が必要です
3. **公益例外のメンバー**: 駅舎・図書館・公民館・変電所は許可不要でも、**病院・学校は許可が必要**。市街化区域内では農林漁業の例外も使えません

> 🔴 迷ったら理屈に戻りましょう——「街づくりを抑制するエリアほど厳しい」。全問正解できるまで繰り返してください。

### 確認問題

**問1.** 都市計画法の区域区分（線引き）に関する記述として、正しいものはどれでしょう？

1. 市街化調整区域とは、市街化を禁止すべき区域である
2. 市街化区域には、おおむね20年以内に優先的かつ計画的に市街化を図るべき区域が含まれる
3. 市街化区域とは、すでに市街地を形成している区域と、おおむね10年以内に優先的かつ計画的に市街化を図るべき区域である
4. すべての都市計画区域で、必ず区域区分を定めなければならない

<details><summary>答えと解説</summary>

正解: **3**

市街化区域の定義は「すでに市街地＋おおむね10年以内に市街化を図るべき区域」で、この言い回しがそのまま出ます。調整区域は市街化の「禁止」ではなく「抑制」すべき区域です。また線引きは必須ではなく、行っていない非線引き区域もあります。

</details>

**問2.** 次の開発行為のうち、開発許可が必要なものはどれでしょう？

1. 市街化区域内で行う900㎡の開発行為
2. 市街化調整区域内で行う300㎡の開発行為
3. 非線引きの都市計画区域内で行う2500㎡の開発行為
4. 準都市計画区域内で行う2800㎡の開発行為

<details><summary>答えと解説</summary>

正解: **2**

市街化調整区域だけは面積にかかわらず、すべての開発行為に許可が必要です。市街化区域は1000㎡以上、非線引き区域・準都市計画区域は3000㎡以上で許可が必要なので、900㎡・2500㎡・2800㎡はいずれも基準未満で許可不要です。

</details>

**問3.** 都市計画区域および準都市計画区域の「外」で開発行為を行う場合、開発許可が必要となる規模はどれでしょう？

1. 面積にかかわらずすべて必要
2. 3000㎡以上
3. 5000㎡以上
4. 10000㎡（1ha）以上

<details><summary>答えと解説</summary>

正解: **4**

区域外は10000㎡（1ha）以上で許可が必要です。ゴロは「イチ（1000）・サン（3000）・イチマン（10000）」。面積にかかわらず必要なのは市街化調整区域、3000㎡は非線引き区域・準都市計画区域の基準で、5000㎡は国土法の事後届出の数字（混同注意）です。

</details>

**問4.** 次の建築物を建築する目的の開発行為のうち、「公益上必要な建築物」の例外に当たらず、規模によっては開発許可が必要になるものはどれでしょう？

1. 病院
2. 駅舎
3. 図書館
4. 変電所

<details><summary>答えと解説</summary>

正解: **1**

病院・学校・社会福祉施設は、公益っぽく見えても開発許可不要の例外には含まれず、原則どおり規模に応じて許可が必要です。駅舎・図書館・公民館・変電所は公益上必要な建築物として、面積にかかわらず許可不要です。

</details>

**問5.** 市街化区域内において、農業を営む者が自己の畜舎を建築する目的で1200㎡の開発行為を行う場合、正しいものはどれでしょう？

1. 農林漁業用の建築物なので、面積にかかわらず開発許可は不要である
2. あらかじめ農業委員会に届出をすれば、開発許可は不要である
3. 農林漁業の例外は市街化区域では適用されないため、開発許可が必要である
4. 市街化区域内の開発行為は、すべて開発許可が不要である

<details><summary>答えと解説</summary>

正解: **3**

農林漁業用建築物の例外は、市街化区域では使えません。市街化区域では1000㎡以上なら原則どおり許可が必要で、1200㎡は基準以上なので許可が必要です。農業委員会への届出で済むのは農地法の市街化区域内特例であり、開発許可とは別の制度です。

</details>

**問6.** 用途地域に関する記述として、正しいものはどれでしょう？

1. 市街化調整区域には、必ず用途地域を定めなければならない
2. 市街化区域には、少なくとも用途地域を定めるものとされている
3. 用途地域は全部で12種類である
4. 用途地域は、住居系3種類・商業系8種類・工業系2種類に分かれる

<details><summary>答えと解説</summary>

正解: **2**

市街化区域には「少なくとも用途地域を定める」＝必ず定めます。逆に市街化調整区域には原則として定めません（街づくりを抑制するエリアだからです）。用途地域は全13種類で、内訳は住居系8・商業系2・工業系3です。

</details>

**問7.** 開発許可を受けた開発区域内における、工事完了の公告「前」の建築制限について、正しいものはどれでしょう？

1. 原則として建築物を建築できないが、工事用の仮設建築物などは例外として建築できる
2. 予定建築物であれば、公告前でも自由に建築できる
3. いかなる建築物も、例外なく建築できない
4. 都道府県知事に届出さえすれば、どんな建築物でも建築できる

<details><summary>答えと解説</summary>

正解: **1**

完了公告前は原則として建築禁止ですが、工事用の仮設建築物などは例外として認められます。予定建築物を建てられるのは公告の「後」であり、公告前から自由に建てられるわけではありません。「例外なく禁止」や「届出だけでOK」も誤りです。

</details>

**問8.** 開発許可の手続に関する記述として、正しいものはどれでしょう？

1. 開発許可の申請は、口頭で行うこともできる
2. 知事は許可する場合のみ文書で通知し、不許可の場合は通知しなくてよい
3. 開発行為で影響を受ける公共施設の管理者との協議は、工事完了後に行えばよい
4. 申請者はあらかじめ、開発行為に関係がある公共施設の管理者と協議し、その同意を得なければならない

<details><summary>答えと解説</summary>

正解: **4**

開発許可は「事前協議・同意 → 書面で申請 → 文書で処分」という流れです。影響を受ける既存の公共施設の管理者とは、あらかじめ協議して同意を得る必要があります。申請は書面で行い、不許可の場合も文書で通知されます。

</details>

**問9.** 次の記述のうち、正しいものはいくつあるでしょう？

ア 土地区画整理事業の施行として行う開発行為には、開発許可は不要である
イ 市街化調整区域内で図書館を建築する目的で行う開発行為には、開発許可が必要である
ウ 開発行為とは、建築物の建築等の目的で行う土地の区画形質の変更をいう

1. 一つ
2. 二つ
3. 三つ
4. なし

<details><summary>答えと解説</summary>

正解: **2**

正しいのはアとウの二つです。アの土地区画整理事業など事業の施行として行う開発行為は、すでに公的チェック済みなので許可不要です。ウは開発行為の定義そのものです。イの図書館は公益上必要な建築物の例外なので、調整区域内でも許可不要であり、誤りです。

</details>

**問10.** 準都市計画区域に関する記述として、正しいものはどれでしょう？

1. 準都市計画区域は、都市計画区域の内部にのみ指定できる
2. 準都市計画区域内では、面積にかかわらずすべての開発行為に許可が必要である
3. 準都市計画区域は、都市計画区域外で、放置すれば将来の街づくりに支障が生じるおそれがある区域に指定できる
4. 準都市計画区域内では、10000㎡以上の開発行為に限り許可が必要である

<details><summary>答えと解説</summary>

正解: **3**

準都市計画区域は、高速道路のインター周辺など乱開発のおそれがある「都市計画区域の外」に指定されます。内部に指定するものではありません。開発許可の基準は3000㎡以上で、面積不問（調整区域）でも10000㎡（区域外の基準）でもありません。

</details>

## 2. 建築基準法ドリル（建築確認・道路・建蔽率容積率）

建築基準法のドリルです。建築確認・道路規制・建蔽率と容積率を横断して確認します。

### この範囲の落とし穴トップ3

1. **建築確認の基準（2025年法改正）**: 木造・非木造の区別は廃止され、「階数2以上または延べ面積200㎡超」で確認が必要。「200㎡ちょうど」は超ではありません
2. **10㎡の例外のワナ**: 増改築・移転は10㎡以内なら確認不要——ただし**防火・準防火地域内では使えません**
3. **容積率は小さい方**: 前面道路の幅員が12m未満なら「幅員×4/10（住居系）」と指定容積率の**小さい方**が限度。計算問題は必ず手を動かしましょう

> 🔴 「4m・2m・200㎡・10㎡」の数字に即答できれば、建築基準法の2問は得点源になります。

### 確認問題

**問1.** 都市計画区域および準都市計画区域の「外」において、新築するときに建築確認が必要となる建築物はどれでしょう？（いずれも特殊建築物ではないものとします）

1. 平屋建てで延べ面積150㎡の事務所
2. 階数2で延べ面積150㎡の住宅
3. 平屋建てで延べ面積200㎡の事務所
4. 平屋建てで延べ面積180㎡の住宅

<details><summary>答えと解説</summary>

正解: **2**

2025年の法改正で木造・非木造の区別は廃止され、「階数2以上または延べ面積200㎡超」の建築物は区域外でも建築確認が必要です。階数2・150㎡の住宅はこれに該当します。平屋150㎡と180㎡は基準未満、200㎡は「超」ではなくちょうどなので該当しません。

</details>

**問2.** 防火地域内にある住宅に、床面積8㎡の増築をする場合の建築確認について、正しいものはどれでしょう？

1. 防火地域内では、床面積10㎡以内の増築でも建築確認が必要である
2. 床面積10㎡以内なので、防火地域内でも建築確認は不要である
3. 増築の場合は、どの地域でも建築確認は不要である
4. 建築確認の要否は、増築後の建物の高さのみで決まる

<details><summary>答えと解説</summary>

正解: **1**

増改築・移転が10㎡以内なら確認不要という例外は、防火地域・準防火地域内では使えません。したがって8㎡の増築でも確認が必要です。「10㎡以内だから不要」と即答させるのがこのひっかけの狙いで、増築が常に不要というルールも高さのみで決まるというルールもありません。

</details>

**問3.** 建築確認に関する記述として、正しいものはどれでしょう？

1. 共同住宅は、その用途に供する床面積が100㎡を超えると建築確認が必要になる
2. 建築確認の対象となる建築物でも、大規模の修繕であれば建築確認は不要である
3. 共同住宅の用途に供する床面積が200㎡を超える建築物は、大規模の修繕をする場合も建築確認が必要である
4. 建築確認は都道府県知事のみが行い、民間の機関は関与できない

<details><summary>答えと解説</summary>

正解: **3**

共同住宅などの特殊建築物は、その用途の床面積が200㎡超（100㎡ではありません）で確認が必要となり、該当する建築物は大規模の修繕・模様替でも確認が必要です。また建築確認は建築主事等のほか、民間の指定確認検査機関も行えます。

</details>

**問4.** 住居系の用途地域内で、指定容積率200％、前面道路の幅員が4mの敷地の場合、容積率の限度はどれでしょう？

1. 100％
2. 200％
3. 240％
4. 160％

<details><summary>答えと解説</summary>

正解: **4**

前面道路の幅員が12m未満の場合、「指定容積率」と「幅員×4/10（住居系）」の小さい方が限度です。4m×4/10＝160％＜200％なので、限度は160％になります。指定容積率200％をそのまま使ったり、大きい方を選んだりするのが典型的な誤りです。

</details>

**問5.** 指定建蔽率60％の地域で、特定行政庁が指定する角地にあり、かつ防火地域内の耐火建築物を建てる場合、建蔽率の限度はどれでしょう？

1. 70％
2. 80％
3. 90％
4. 100％

<details><summary>答えと解説</summary>

正解: **2**

角地の指定で＋10％、防火地域内の耐火建築物等で＋10％、両方に当てはまるので合計＋20％となり、60％＋20％＝80％です。70％は片方しか加算していない誤り、100％になるのは指定建蔽率80％の地域で防火地域内の耐火建築物等を建てる場合です。

</details>

**問6.** 指定建蔽率80％の地域内で、防火地域内に耐火建築物を建てる場合、建蔽率はどうなるでしょう？

1. 90％が限度となる
2. 80％のまま変わらない
3. 建蔽率の制限が適用されなくなる（100％まで建てられる）
4. 60％に強化される

<details><summary>答えと解説</summary>

正解: **3**

指定建蔽率80％の地域で防火地域内の耐火建築物等を建てる場合は、建蔽率の制限自体が適用されなくなり、100％まで建てられます。＋10％で90％とするのは通常の緩和との混同で、80％のままや強化という扱いもありません。

</details>

**問7.** 幅員4m未満のいわゆる2項道路（みなし道路）に接する敷地について、正しいものはどれでしょう？

1. 原則として道路の中心線から2m下がった線が道路境界線とみなされ、セットバック部分は建蔽率・容積率の計算で敷地面積に算入されない
2. セットバック部分も、建蔽率・容積率の計算で敷地面積に算入できる
3. 2項道路とは、幅員6m以上の道で特定行政庁が指定したものをいう
4. 2項道路に接する敷地では、建築物の建て替えが一切できない

<details><summary>答えと解説</summary>

正解: **1**

2項道路では原則として中心線から2mのラインが道路境界線とみなされ、セットバック部分は敷地面積に算入できません。「算入できる」とするのが定番のひっかけです。2項道路は幅員4m未満の道が対象で、セットバックすれば建て替えも可能です。

</details>

**問8.** 接道義務に関する記述として、正しいものはどれでしょう？

1. 建築物の敷地は、道路に1m以上接していればよい
2. 建築物の敷地は、原則として道路（自動車専用道路を除く）に2m以上接しなければならない
3. 自動車専用道路に2m以上接していれば、接道義務を満たしたことになる
4. 建築物の敷地は、道路に4m以上接しなければならない

<details><summary>答えと解説</summary>

正解: **2**

接道義務は「道路に2m以上」です。ここでいう道路から自動車専用道路は除かれるため、高速道路にいくら接していても接道義務は満たせません。4mは道路の幅員の数字であり、接する長さと入れ替えるのが典型的なひっかけです。

</details>

**問9.** 用途地域ごとの用途制限に関する記述として、正しいものはどれでしょう？

1. 住宅は、商業地域には建築できない
2. 診療所は、第一種低層住居専用地域には建築できない
3. 敷地が2つの用途地域にまたがる場合、面積の小さい方の地域の制限が敷地全体に適用される
4. 住宅を建築できない用途地域は、工業専用地域のみである

<details><summary>答えと解説</summary>

正解: **4**

住宅が建てられないのは工業専用地域だけで、商業地域にも建築できます。診療所・保育所・神社などは生活に必要なので、どの用途地域にも建築できます。敷地が2地域にまたがる場合は、過半（面積の大きい方）が属する地域の制限が敷地全体に適用されます。

</details>

**問10.** 次の記述のうち、正しいものはいくつあるでしょう？

ア 日影規制は、商業地域には適用されない
イ 建築物が防火地域と準防火地域にまたがる場合、原則としてゆるい方（準防火地域）の規制が建物全体に適用される
ウ 隣地斜線制限は、第一種低層住居専用地域にも適用される

1. 一つ
2. 二つ
3. 三つ
4. なし

<details><summary>答えと解説</summary>

正解: **1**

正しいのはアの一つだけです。日影規制は商業地域・工業地域・工業専用地域には適用されません。イは誤りで、またがる場合は原則として厳しい方（防火地域）の規制が建物全体に適用されます。ウも誤りで、低層系の3地域には隣地斜線制限は適用されず、代わりに10mまたは12mの絶対高さ制限があります。

</details>

## 3. 国土法・農地法・区画整理・盛土規制ドリル

国土利用計画法・農地法・土地区画整理法・盛土規制法の横断ドリルです。

### この範囲の落とし穴トップ3

1. **数字の入れ替え**: 国土法の事後届出は「2000・5000・10000㎡、買主が契約から2週間以内」。開発許可の1000・3000と混同させる出題が定番です
2. **農地法3条だけ特別**: 許可権者は農業委員会で、市街化区域内の届出特例も**3条には使えません**
3. **仮換地のズレ**: 使用収益できるのは仮換地、所有権（売買の対象）は従前の宅地。換地処分の効果は公告の**翌日**です

盛土規制法（2023年施行）は「盛1・切2・面500」の数字で判定します。

> 🔴 4つの法律の数字を1本の表で比べられるようになれば、この分野は完成です。

### 確認問題

**問1.** 国土利用計画法の事後届出が必要となる土地売買等の契約はどれでしょう？

1. 非線引きの都市計画区域内にある6000㎡の土地の売買契約
2. 市街化区域内にある1800㎡の土地の売買契約

正解: **1**

</details>

**問2.** 国土利用計画法の事後届出について、正しいものはどれでしょう？

1. 売主が、契約締結日から2週間以内に届け出なければならない
2. 買主が、契約締結日から3週間以内に届け出なければならない
3. 権利取得者（買主）が、契約締結日から2週間以内に都道府県知事に届け出なければならない
4. 売主と買主が連名で、契約締結の1週間前までに届け出なければならない

<details><summary>答えと解説</summary>

正解: **3**

事後届出は、権利取得者（買主）が契約締結日から2週間以内に、市町村長を経由して都道府県知事に行います。届け出るのは売主ではなく買主です。3週間は知事が勧告できる期限であり、「事後」届出なので契約前に行うものでもありません。

</details>

**問3.** 国土利用計画法の事後届出の対象について、正しいものはどれでしょう？

1. 対価のある土地の売買契約は、届出の対象とならない
2. 相続による土地の取得は、面積にかかわらず届出不要である
3. 贈与による土地の取得も、面積基準を超えれば届出が必要である
4. 交換契約は対価がないため、届出の対象とならない

<details><summary>答えと解説</summary>

正解: **2**

届出の対象は、売買・交換など対価を得て権利を移転・設定する契約です。相続・贈与・抵当権の設定は対価のある契約ではないため、面積にかかわらず届出不要です。交換はお互いに土地という対価を出し合う契約なので、届出の対象になります。

</details>

**問4.** 事後届出に対する都道府県知事の勧告について、正しいものはどれでしょう？

1. 知事は、対価の額が不相当な場合、対価の額について勧告できる
2. 勧告に従わない場合、その契約は無効となる
3. 勧告は、届出の日から2週間以内に行わなければならない
4. 知事は土地の利用目的について届出の日から3週間以内に勧告でき、従わないときはその旨と内容を公表できる

<details><summary>答えと解説</summary>

正解: **4**

勧告は土地の利用目的についてのみ可能で、対価の額には口出しできません。期限は届出の日から3週間以内です（2週間は届出自体の期限）。勧告に従わなくても公表されるだけで、契約は有効のままで罰則もありません。

</details>

**問5.** 農地法に関する記述として、正しいものはどれでしょう？

1. 農地を農地のまま売買する場合（3条）の許可権者は、農業委員会である
2. 3条の許可権者は、都道府県知事等である
3. 農地に当たるかどうかは、登記簿の地目によって判断する
4. 3条の許可を受けずに締結した売買契約も、契約自体は有効である

<details><summary>答えと解説</summary>

正解: **1**

農地のまま権利が動くだけの3条の許可権者は農業委員会で、転用がからむ4条・5条の知事等とは異なります。農地かどうかは登記簿の地目ではなく現況で判断するため、地目が山林でも耕作していれば農地です。無許可の3条・5条の契約は効力を生じません（無効）。

</details>

**問6.** 市街化区域内の農地に関する特例について、正しいものはどれでしょう？

1. 市街化区域内の農地を農地のまま売買する場合も、農業委員会への届出で足りる
2. 市街化区域内の農地を宅地に転用する目的で売買する場合（5条）は、あらかじめ農業委員会に届け出れば許可不要である

4. 市街化区域内で農地を転用する場合（4条）は、面積にかかわらず知事等の許可が必要である

正解: **2**

市街化区域内の特例は、転用（4条）と転用目的の権利移動（5条）について、あらかじめ農業委員会に届け出れば許可不要とするものです。農地のまま売買する3条にはこの特例がなく、市街化区域内でも許可が必要です。届出先は知事ではなく農業委員会です。

</details>

**問7.** 相続により農地を取得した場合について、正しいものはどれでしょう？

1. 農地法3条の許可を受けなければならない
2. 許可も届出も、一切の手続が不要である
3. 3条の許可は不要だが、遅滞なく農業委員会に届け出なければならない

正解: **3**

相続・遺産分割による取得は3条の許可不要ですが、遅滞なく農業委員会への届出が必要です。「許可不要＝何もしなくてよい」とするのが定番のひっかけです。また相続で取得した農地でも、転用するなら原則どおり4条の許可（市街化区域内なら届出）が必要です。

</details>

**問8.** 土地区画整理事業の仮換地・換地処分について、正しいものはどれでしょう？

4. 保留地は、換地処分により従前の宅地の所有者全員の共有となる

正解: **1**

仮換地の指定後は「住む（使う）のは仮換地・売るのは従前地」という状態になります。所有権は換地処分まで従前の宅地に残ったままです。換地が従前の宅地とみなされるのは公告の日の「翌日」であり、保留地は施行者が取得して売却し、事業費にあてます。

</details>

**問9.** 宅地造成等工事規制区域内で、都道府県知事等の許可が必要となる工事はどれでしょう？

## 4. 税・鑑定・景表法・土地建物ドリル

税・地価公示・景品表示・土地建物のドリルです。暗記量が少なく、確実に拾える分野です。

### この範囲の落とし穴トップ3

1. **課税主体と賦課期日**: 不動産取得税は都道府県、固定資産税は市町村。固定資産税は**毎年1月1日の所有者**に課税され、年の途中で売っても納税義務者は変わりません
2. **「無効」のワナ**: 印紙を貼り忘れても契約は**有効**（過怠税は3倍）。登録免許税の課税標準は売買代金ではなく**固定資産課税台帳の登録価格**です
3. **1月1日だらけ**: 譲渡所得の長期・短期の判定も、地価公示の価格時点も1月1日。徒歩表示は「80m＝1分・端数切り上げ」

> 🟡 統計の数値は毎年変わるため、試験直前に必ず最新の公表値を確認しましょう。

### 確認問題

**問1.** 不動産に関する税の課税主体について、正しいものはどれでしょう？

1. 不動産取得税は、市町村が課する税である
2. 固定資産税は、都道府県が課する税である
3. 不動産取得税と固定資産税は、いずれも国税である
4. 不動産取得税は都道府県が、固定資産税は市町村が課する地方税である

<details><summary>答えと解説</summary>

正解: **4**

「取得は都道府県・固定は市町村」が正しい組合せで、どちらも地方税です。課税主体を入れ替えるのが4択ひっかけの定番なので、頭文字で「取得＝とどうふけん」と結び付けて覚えましょう。国税なのは登録免許税・印紙税・譲渡所得に対する所得税です。

</details>

**問2.** Aが所有する土地を、ある年の4月1日にBへ売却し、同日引き渡した場合、その年の固定資産税について正しいものはどれでしょう？

1. 買主Bが、その年の固定資産税の納税義務者となる
2. その年の1月1日現在の所有者である売主Aが、納税義務者となる
3. AとBが、所有期間に応じて法律上当然に按分して納税義務を負う
4. その年の固定資産税は、AにもBにも課されない

<details><summary>答えと解説</summary>

正解: **2**

固定資産税の納税義務者は、毎年1月1日現在の所有者として課税台帳に登録されている人です。年の途中で売却しても、その年の納税義務者は1月1日時点の所有者Aのままです。実務で行われる日割精算は当事者間の契約上の処理にすぎず、法律上の按分ではありません。

</details>

**問3.** 不動産取得税に関する記述として、正しいものはどれでしょう？

1. 相続により不動産を取得した場合、不動産取得税は課されない
2. 売買により不動産を取得した場合も、不動産取得税は課されない
3. 不動産取得税は、取得した翌年から毎年課される
4. 贈与により不動産を取得した場合は、非課税である

<details><summary>答えと解説</summary>

正解: **1**

相続による取得は形式的な権利の移転として非課税です。一方、売買・贈与・交換などによる取得には課税されます。また不動産取得税は取得時に1回だけ課される税であり、毎年課されるのは固定資産税です。

</details>

**問4.** 固定資産税の住宅用地の特例について、正しいものはどれでしょう？

1. 住宅用地は、面積にかかわらず課税標準が2分の1になる
2. 200㎡以下の小規模住宅用地の部分は、課税標準が3分の1になる
3. 200㎡以下の小規模住宅用地の部分は、課税標準が6分の1になる
4. 住宅用地の特例は、都市計画税にのみ適用され、固定資産税には適用されない

<details><summary>答えと解説</summary>

正解: **3**

固定資産税では、200㎡以下の部分（小規模住宅用地）の課税標準が6分の1になります。「6分の1」を「3分の1」や「2分の1」に差し替えるのが数字ひっかけの定番です。この特例は固定資産税の制度であり、都市計画税のみというのも誤りです。

</details>

**問5.** 印紙税に関する記述として、正しいものはどれでしょう？

1. 印紙を貼らなかった売買契約書は、契約として無効になる
2. 印紙を貼らなくても契約は有効だが、原則として本来の税額の3倍に当たる過怠税が課される
3. 国が作成した文書にも、印紙税が課される
4. 贈与契約書には、贈与する不動産の時価を記載金額として印紙税が課される

<details><summary>答えと解説</summary>

正解: **2**

印紙の貼り忘れがあっても契約自体は有効で、代わりに本来の税額＋その2倍＝3倍の過怠税が課されます。「貼らないと無効」が最頻出のひっかけです。国や地方公共団体が作成した文書は非課税で、贈与契約書は記載金額のない文書として扱われます。

</details>

**問6.** 登録免許税に関する記述として、正しいものはどれでしょう？

1. 課税標準は、実際の売買代金である
2. 売買による所有権移転登記の納税義務者は、常に買主のみである
3. 住宅用家屋の税率の軽減措置は、その敷地である土地にも適用される
4. 課税標準は固定資産課税台帳の登録価格であり、売買による移転登記では売主と買主が連帯して納付義務を負う

<details><summary>答えと解説</summary>

正解: **4**

登録免許税の課税標準は固定資産課税台帳の登録価格であり、実際の売買代金ではありません。納税義務者は登記を受ける者で、売買による移転登記では売主・買主が連帯して納付します。住宅用家屋の税率軽減は家屋のための制度で、土地には適用されません。

</details>

**問7.** 譲渡所得に関する記述として、正しいものはどれでしょう？

1. 長期譲渡所得に当たるかどうかは、譲渡した年の1月1日時点で所有期間が5年を超えるかどうかで判定する
2. 売却した日までの所有期間が5年を超えていれば、必ず長期譲渡所得となる
3. 居住用財産の3000万円特別控除は、所有期間が10年を超えていないと適用されない
4. 3000万円特別控除は、配偶者への譲渡にも適用される

<details><summary>答えと解説</summary>

正解: **1**

長期・短期は「譲渡した年の1月1日時点」で5年超かどうかで判定します。売った日まで数えると、年の途中で5年を超えた場合に判定を誤ります。3000万円特別控除は所有期間を問わず使えますが、配偶者や直系血族など特別な関係者への譲渡には適用されません。

</details>

**問8.** 地価公示法に関する記述として、正しいものはどれでしょう？

1. 標準地の正常な価格は、毎年7月1日時点で判定される
2. 標準地に建物があるときは、建物付きの状態の価格を判定する
3. 土地鑑定委員会が、2人以上の不動産鑑定士の鑑定評価を求め、毎年1月1日時点の正常な価格を判定して公示する
4. 公示区域内で土地取引をする者が公示価格を指標としなかった場合、罰則がある

正解: **3**

地価公示は「土地鑑定委員会が・標準地について・2人以上の不動産鑑定士の鑑定評価を求め・毎年1月1日時点の正常な価格を」公示する制度です。建物や借地権があっても、ないものとして（更地として）判定します。一般の土地取引では公示価格を指標とする努力義務にとどまり、罰則はありません。

</details>

**問9.** 不動産の表示に関する公正競争規約において、駅から道路距離440mのマンションの徒歩所要時間の表示として、正しいものはどれでしょう？

1. 徒歩5分

3. 徒歩4分
4. 直線距離で計算し直して表示してよい

正解: **2**

徒歩の所要時間は道路距離80mにつき1分で計算し、1分未満の端数は切り上げます。440m÷80m＝5.5分なので、切り上げて徒歩6分です。5.5分を切り捨てて5分とするのが典型的な誤りで、直線距離ではなく実際に歩く道路距離で計算します。

</details>

**問10.** 土地・建物に関する記述として、正しいものはどれでしょう？
