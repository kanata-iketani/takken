# 第11章 制限行為能力者と代理

契約の「中身」ではなく「契約をした人」に注目する章です。前半は未成年者など判断能力が十分でない人を守るしくみ、後半は他人に契約を任せる「代理」。どちらも本試験の定番で、営業担当者が会社を代理して契約する場面など、宅建の実務にも直結します。

## 1. 制限行為能力者（4つの類型と取消し）

### 判断能力が十分でない人を守るしくみ

17歳のAさんが、親に内緒で高額な土地の売買契約をBと結んでしまいました。民法は、こうした判断能力が十分でない人がした契約を、後から**取り消せる**ようにして保護しています。

### 4つの類型

| 類型 | どんな人 | 保護者 |
|---|---|---|
| 未成年者 | **18歳未満**（2022年から成年年齢は18歳） | 法定代理人（親など） |
| 成年被後見人 | 判断能力を**常に欠く** | 成年後見人 |
| 被保佐人 | 判断能力が**著しく不十分** | 保佐人 |
| 被補助人 | 判断能力が**不十分** | 補助人 |

### 🟡 押さえるべきルール

- 未成年者が法定代理人の**同意なし**でした契約は**取り消せます**。ただし、①単に権利を得、または義務を免れる行為（もらうだけ等）、②処分を許された財産（お小遣い）の処分、③許可された営業に関する行為は取り消せません
- 成年被後見人の行為は、**同意があっても取り消せます**（日用品の購入などは除く）
- 制限行為能力を理由とする取消しは、**善意無過失の第三者にも対抗できます**
- 「自分は成年者だ」などと**詐術**を用いた場合は、取り消せません

深入りは不要です。この4類型と取消しの基本が分かれば十分です。

### 確認問題

**問1.** 17歳のAは、法定代理人の同意を得ずに、自己所有の甲土地をBに売却する契約を締結した。この場合に関する記述として正しいものはどれか。

1. Aは18歳に達した時点で、この契約を取り消すことができなくなる
2. A本人またはAの法定代理人は、この契約を取り消すことができる
3. BがAを成年者であると信じていた場合、Aは取り消すことができない
4. 土地の売買契約は、未成年者が単独でしても常に有効である

<details><summary>答えと解説</summary>

正解: **2**

法定代理人の同意のない未成年者の契約は取り消すことができ、未成年者本人も単独で取り消せます。成年に達しても追認するまでは（期間内なら）取消し可能です。相手方が単に成年者と信じただけでは保護されず、Aが詐術を用いた場合に初めて取消しができなくなります。

</details>

**問2.** 17歳のAは、Bとの売買契約の際、身分証を偽造して「自分は成年者である」と信じさせた（詐術）。この場合に関する記述として正しいものはどれか。

1. Aは、制限行為能力を理由としてこの契約を取り消すことができない
2. Aは詐術を用いたが、未成年者である以上、契約を取り消すことができる
3. 詐術が用いられた契約は、当然に無効となる
4. 法定代理人が追認しない限り、この契約の効力は生じない

<details><summary>答えと解説</summary>

正解: **1**

制限行為能力者が「自分は行為能力者である」と信じさせるため詐術を用いたときは、取り消すことができません。相手方の信頼を保護するためです。契約が無効になるのではなく、取消しができなくなるだけで、契約は有効なまま確定します。

</details>

**問3.** 成年被後見人Aは、成年後見人Cの同意を得たうえで、自己所有の甲土地をBに売却した。この場合に関する記述として正しいものはどれか。

1. Cの同意を得ている以上、この契約を取り消すことはできない
2. 日用品の購入と同様に、この契約を取り消すことはできない
3. 成年被後見人の法律行為は、同意の有無にかかわらず原則として取り消すことができる
4. 成年被後見人がした契約は、常に無効である

<details><summary>答えと解説</summary>

正解: **3**

成年被後見人は判断能力を常に欠くため、たとえ成年後見人の同意を得ていても、その同意どおりに行動できる保証がなく、原則として取り消せます（日用品の購入その他日常生活に関する行為は除く）。土地の売却は日常生活に関する行為ではなく、また効果は無効ではなく取消しです。

</details>

**問4.** 17歳のAが法定代理人の同意を得ずに行った次の行為のうち、取り消すことが【できない】ものはどれか。

1. 自己所有のマンションをBに売却する契約
2. Bから2000万円を借り入れる契約
3. Bの所有する建物を購入する契約
4. Bから負担のない贈与を受ける契約

<details><summary>答えと解説</summary>

正解: **4**

単に権利を得るだけの行為（負担のない贈与を受けるなど）は未成年者に不利益がないため、同意がなくても取り消せません。売却・借入れ・購入はいずれも義務を負う行為なので、同意がなければ取り消すことができます。

</details>

## 2. 代理のきほん（顕名と効果の帰属）

### 代理のしくみ

忙しいAさん（本人）は、Bさん（代理人）に「私の甲土地を売ってきてほしい」と頼みました（**代理権の授与**）。BはCさん（相手方）と売買契約を結びます。

図式: A（本人）→ 授権 → B（代理人）⇔ 契約 ⇔ C（相手方）

🔴 このとき、契約の**効果は直接A（本人）に帰属**します。売主になるのはBではなくAです。

### 顕名（けんめい）

Bは契約の際、「**Aの代理人のBです**」と相手に示す必要があります。これを**顕名**といいます。

- 顕名をしなかった場合: Bが**自分のために**契約したものとみなされます（B自身が売主になる）
- ただし、CがBは代理人だと**知っていた、または知ることができた**ときは、本人Aに効果が帰属します

### 代理で覚えておくポイント

- 代理人は**制限行為能力者でもなれます**。未成年のBに任せたのはAの自己責任なので、Aは原則として、Bの行為能力の制限を理由に代理行為を取り消せません
- 代理人がだまされた・勘違いしたなど、意思表示の瑕疵があったかどうかは、実際に契約した**代理人Bを基準**に判断します

> 💡 コツ: 「契約するのは代理人、効果を受けるのは本人」。ここまで分かれば十分です。

### 確認問題

**問1.** Aは、Bに甲土地の売却に関する代理権を与え、Bは「Aの代理人である」ことを示したうえでCとの間で売買契約を締結した。この場合に関する記述として正しいものはどれか。

1. 売買契約の効果は直接Aに帰属し、Cに対する売主はAとなる
2. 売買契約の効果はいったんBに帰属し、その後Aに移転する
3. 契約の当事者はBであるため、代金はBの財産となる
4. AとCとの間には、契約関係は生じない

<details><summary>答えと解説</summary>

正解: **1**

有効な代理行為の効果は、代理人Bを経由することなく直接本人Aに帰属します。売主はAであり、AC間に契約関係が生じます。効果がいったんBに帰属したり、代金がBのものになったりすることはありません。

</details>

**問2.** Aから甲土地売却の代理権を与えられたBは、Aの代理人であることを示さずにCと売買契約を締結した。Cは、Bが代理人であることを知らず、知ることもできなかった。この場合に関する記述として正しいものはどれか。

1. 顕名がないため、契約は無効となる
2. 代理権は有効であるため、契約の効果は当然にAに帰属する
3. Bが自己のために契約したものとみなされ、B自身が契約の当事者となる
4. Cは、顕名がなかったことを理由に契約を取り消すことができる

<details><summary>答えと解説</summary>

正解: **3**

顕名のない代理行為は、代理人が自己のためにしたものとみなされ、B自身が売主として契約に拘束されます。ただし相手方が代理人であることを知り、または知ることができたときは本人に効果が帰属しますが、本問のCは善意無過失なので該当しません。契約が無効になったり取り消せたりするわけではありません。

</details>

**問3.** Aは、17歳のBに甲土地売却の代理権を与え、BはAの代理人としてCと売買契約を締結した。この場合に関する記述として正しいものはどれか。

1. Bは未成年者であるため、この代理行為は無効である
2. Aは、Bが未成年者であることを理由に、この契約を取り消すことができない
3. Bの法定代理人の同意がなければ、代理行為の効果はAに帰属しない
4. Cは、Bが未成年者であることを知った場合、契約を取り消すことができる

<details><summary>答えと解説</summary>

正解: **2**

制限行為能力者も代理人になることができ、代理行為の効果は本人に帰属するため、本人Aは原則として代理人の行為能力の制限を理由に取り消せません。未成年者をあえて代理人に選んだAの自己責任だからです。Bの法定代理人の同意も不要で、Cに取消権が生じるわけでもありません。

</details>

**問4.** Aの代理人Bは、Cにだまされて、A所有の甲土地をCに売却する契約を締結した。この場合に関する記述として正しいものはどれか。

1. 意思表示の瑕疵の有無は本人Aを基準に判断するため、取消しは問題とならない
2. だまされたのは代理人Bにすぎないため、契約は完全に有効である
3. 詐欺を受けたのはBであるから、Aはこの契約を取り消すことができない
4. 詐欺の有無は代理人Bを基準に判断され、本人Aはこの契約を取り消すことができる

<details><summary>答えと解説</summary>

正解: **4**

意思表示に瑕疵があったかどうかは、実際に意思表示をした代理人を基準に判断します。Bが詐欺を受けた以上、瑕疵ある意思表示となり、効果の帰属する本人Aが取消権を行使できます。本人基準で判断したり、Aが取り消せなくなったりするわけではありません。

</details>

## 3. 無権代理と表見代理（追認・催告・取消権）

### 無権代理とは

Bさんは、代理権がないのに「Aの代理人」と名乗って、Aさん所有の甲土地をCさんに売ってしまいました。これが**無権代理**です。

図式: A（本人・何も知らない）← B（勝手に代理人を名乗る）⇔ C（相手方）

🔴 無権代理による契約の効果は、**本人Aには帰属しません**。ただし、Aが**追認**すれば、契約の時にさかのぼって有効になります（逆に追認拒絶もできます）。

### 相手方Cを守る3つの手段

| 手段 | 条件 |
|---|---|
| **催告権**（追認するか確答を求める） | Cが**悪意でも行使可**。相当の期間内に確答がなければ**追認拒絶とみなす** |
| **取消権**（契約をなかったことにする） | Cが契約時に**善意**のとき。Aの追認前に限る |
| 無権代理人Bへの**責任追及**（履行または損害賠償の請求） | 原則として、Cが善意無過失のとき |

### 表見代理（ひょうけんだいり）

本人Aにも落ち度（代理権を与えたかのような外観を作ったなど）があり、Cが**善意無過失**なら、**有効な代理があったのと同じ扱い**になり、Aは契約の責任を負います。

> 💡 コツ: 「催告は悪意でもOK、取消しは善意、表見代理は善意無過失」。ここまで分かれば十分です。

### 確認問題

**問1.** Bは、代理権がないのにAの代理人と称して、A所有の甲土地をCに売却する契約を締結した。この場合に関する記述として正しいものはどれか。

1. この契約の効果は、当然にAに帰属する
2. Aが追認すれば、契約の時にさかのぼって効果がAに帰属する
3. Aが追認しても、その効果は追認の時から将来に向かってのみ生じる
4. 無権代理による契約は、Aが追認しても有効にはならない

<details><summary>答えと解説</summary>

正解: **2**

無権代理行為の効果は本人に帰属しませんが、本人が追認すれば、原則として契約の時にさかのぼって有効となります。追認の時からではなく遡及する点がポイントです。当然に帰属するわけでも、追認が無意味なわけでもありません。

</details>

**問2.** Bの無権代理行為により、AとCとの間に甲土地の売買契約が締結された形になっている。Cは、契約締結時にBに代理権がないことを知っていた。この場合に関する記述として正しいものはどれか。

1. Cは悪意であっても、Aに対し追認するかどうかを催告でき、相当の期間内に確答がなければ追認を拒絶したものとみなされる
2. 催告権は、Cが善意である場合に限って認められる
3. Aが相当の期間内に確答しない場合、追認したものとみなされる
4. Cは悪意であるため、催告・取消し・無権代理人への責任追及のすべてを行うことができる

<details><summary>答えと解説</summary>

正解: **1**

催告権は相手方が悪意でも行使でき、本人が確答しないときは「追認拒絶」とみなされます（追認とみなすのではありません）。一方、取消権は善意の相手方に、無権代理人への責任追及は原則善意無過失の相手方に限られるので、悪意のCがすべてを行えるわけではありません。

</details>

**問3.** Bの無権代理行為により、A所有の甲土地についてCとの売買契約が締結された。Cは契約時、Bに代理権がないことを知らなかった。この場合のCの取消権に関する記述として正しいものはどれか。

1. Cは、Aが追認した後であっても契約を取り消すことができる
2. Cが契約時に代理権がないことを知っていた場合でも、取り消すことができる
3. Cは、Aが追認しない間は、契約を取り消すことができる
4. Cの取消権は、無権代理人Bの同意を得なければ行使できない

<details><summary>答えと解説</summary>

正解: **3**

善意の相手方は、本人が追認しない間に限り契約を取り消せます。追認により契約は有効に確定するため、追認後は取消しできません。取消権は善意の相手方にのみ認められ、無権代理人の同意は不要です。

</details>

**問4.** Aは実際にはBに代理権を与えていなかったが、Cに対して「Bに甲土地売却の代理権を与えた」旨を表示していた。BはAの代理人と称してCと売買契約を締結し、Cは代理権がないことを知らず、知らないことに過失もなかった。この場合に関する記述として正しいものはどれか。

1. Cに過失があっても、Cが善意でありさえすれば表見代理は成立する
2. 表見代理の成立に本人側の事情は無関係であり、Aにいかなる関与がなくても成立する
3. Bに代理権がない以上、どのような場合でも契約の効果はAに帰属しない
4. Cが善意無過失であるため表見代理が成立し、有効な代理行為と同様に契約の効果がAに帰属する

<details><summary>答えと解説</summary>

正解: **4**

代理権授与の表示をした本人は、善意無過失の相手方に対して責任を負います（表見代理）。表見代理の成立には、本人に帰責性があることと、相手方の善意無過失の両方が必要です。したがって過失のある相手方は保護されず、本人の関与なしに成立するものでもありません。

</details>

## 4. 復代理・自己契約・双方代理

### 復代理（代理人がさらに代理人を選ぶ）

Aの代理人Bが多忙になり、Dさんを**復代理人**に選びました。

図式: A（本人）→ B（代理人）→ D（復代理人）⇔ C（相手方）

- 復代理人Dは、Bの代理人ではなく**A（本人）の代理人**です
- 復代理人を選任しても、**Bの代理権は消滅しません**
- 🟡 復代理人を選任できる条件が重要です

| 代理人の種類 | 復代理人を選任できる場合 |
|---|---|
| 任意代理人（頼まれてなった人） | **本人の許諾**があるとき、または**やむを得ない事由**があるとき |
| 法定代理人（親など） | **いつでも自由に**選任できる（その代わり、原則として全責任を負う） |

### 自己契約・双方代理

- **自己契約**: 売主Aの代理人Bが、**自分自身が買主**になって契約すること
- **双方代理**: Bが**売主Aと買主Cの双方の代理人**になること

どちらも本人の利益を害するおそれがあるため、原則として**無権代理行為とみなされます**（本人が追認しなければ効果が帰属しません）。ただし、①**本人があらかじめ許諾**した場合と、②**債務の履行**（すでに決まったことを実行するだけ。売買後の登記申請など）は有効です。

ここまで分かれば、代理はひとまず十分です。細かい判例まで追う必要はありません。

### 確認問題

**問1.** Bは、Aから甲土地売却の代理権を与えられた任意代理人である。この場合の復代理に関する記述として正しいものはどれか。

1. Bは、自己の判断でいつでも自由に復代理人を選任できる
2. Bが復代理人Dを選任すると、Bの代理権は消滅する
3. Bは、Aの許諾を得たとき、またはやむを得ない事由があるときに限り、復代理人を選任できる
4. 復代理人Dは、Bの代理人としてBの名において契約を締結する

<details><summary>答えと解説</summary>

正解: **3**

任意代理人が復代理人を選任できるのは、本人の許諾を得たとき、またはやむを得ない事由があるときに限られます（いつでも自由に選任できるのは法定代理人です）。復代理人を選任しても代理人の代理権は消滅せず、復代理人は本人の代理人として本人の名で行為します。

</details>

**問2.** Bは、売主Aと買主Cの双方から代理権を与えられ、双方の代理人として甲土地の売買契約を締結した。AもCも、双方代理をあらかじめ許諾していなかった。この場合に関する記述として正しいものはどれか。

1. この契約は無権代理行為とみなされ、本人が追認しなければ効果は帰属しない
2. 双方代理であっても、契約は常に有効である
3. 双方代理は常に無効であり、本人が追認しても有効にはならない
4. Bが宅建士であれば、双方代理も当然に有効となる

<details><summary>答えと解説</summary>

正解: **1**

本人の許諾のない双方代理は、本人の利益を害するおそれがあるため無権代理行為とみなされます。ただし「無効で確定」ではなく、本人が追認すれば有効にできます。宅建士であるかどうかは民法上の双方代理の効力とは関係ありません。

</details>

**問3.** AとCとの間で甲土地の売買契約がすでに成立しており、Bは、その所有権移転登記の申請について、売主A・買主C双方の代理人となって手続を行った。この場合に関する記述として正しいものはどれか。

1. 双方代理にあたるため、無権代理行為とみなされる
2. すでに成立した契約に基づく登記申請は債務の履行にあたり、双方代理であっても有効である
3. 登記申請は、必ず本人自身が行わなければならない
4. この登記申請は、取り消すことができる行為となる

双方代理が禁止されるのは、新たに本人の利益を害するおそれがあるからです。すでに成立した契約の内容を実行するだけの登記申請は「債務の履行」にあたり、利害対立のおそれがないため有効です。登記申請は代理人によることができ、取消しの問題も生じません。
