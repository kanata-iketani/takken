# 第19章 国土利用計画法・農地法

広い土地の取引を見張る国土利用計画法と、農地を守る農地法です。覚えることは「2・5・10の面積と2週間」「3条・4条・5条の表」だけと言ってよく、短時間で2問分の得点力がつくお得なレッスンです。

## 1. 国土法の事後届出 —— 2週間以内・2000/5000/10000㎡

国土利用計画法は、投機的な土地の買い占めで地価が乱れるのを防ぐための法律です。試験の中心は**事後届出制**です。

### 事後届出のきほん

一定面積以上の**土地売買等の契約**を結んだら、**権利取得者(買主)**が、**契約締結日から2週間以内**に、土地の利用目的などを**都道府県知事**に届け出ます(市町村長を経由)。「買った後に報告する」から事後届出です。

### 面積基準

| 区域 | 届出が必要な面積 |
|---|---|
| **市街化区域** | **2000㎡以上** |
| 市街化区域以外の都市計画区域(調整区域・非線引き) | **5000㎡以上** |
| 都市計画区域の**外** | **10000㎡以上** |

> 💡コツ: ゴロは「**ニー(2000)・ゴー(5000)・イチマン(10000)**」。開発許可の「1000・3000・10000」と混ざりやすいので、「国土法は**2**週間だから**2**000スタート」と結び付けて区別しましょう。

### 届出がいるのは「対価のある契約」

売買・交換など、対価を得て権利を移転・設定する契約(予約を含む)が対象です。**相続・贈与・抵当権の設定**は対象外です。

> 🔴 「誰が(買主)・いつまで(2週間)・どこで何㎡」の3点セットで毎年出ます。

### 確認問題

**問1.** 事後届出について、正しいものはどれでしょう?

1. 売主と買主が共同で届け出なければならない
2. 売主が届け出なければならない
3. 権利取得者(買主)が届け出なければならない
4. 契約を媒介した宅建業者が届け出なければならない

<details><summary>答えと解説</summary>

正解: **3**

事後届出の義務を負うのは権利取得者、つまり買主です。これから土地をどう利用するかを報告する制度なので、利用する側が届け出ると覚えましょう。売主や共同での届出、媒介業者の届出という仕組みではありません。

</details>

**問2.** 事後届出の期限として、正しいものはどれでしょう?

1. 契約締結日から2週間以内
2. 契約締結日から3週間以内
3. 契約締結日から1か月以内
4. 引渡しの日から2週間以内

<details><summary>答えと解説</summary>

正解: **1**

事後届出は契約締結日から2週間以内に行います。起算点は「契約締結日」であり、引渡しの日ではありません。3週間は知事が勧告できる期間であり、届出期限との入れ替えがひっかけの定番です。

</details>

**問3.** 市街化区域内の1500㎡の土地を購入する契約を締結した場合、事後届出は必要でしょうか?

1. 1000㎡以上なので届出が必要である
2. 市街化区域の基準である2000㎡未満なので届出は不要である
3. 面積にかかわらず届出が必要である
4. 5000㎡未満なので不要だが、知事への報告は必要である

<details><summary>答えと解説</summary>

正解: **2**

市街化区域の届出基準は2000㎡以上なので、1500㎡なら不要です。1000㎡は都市計画法の開発許可(市街化区域)の基準で、混同を狙ったひっかけです。5000㎡は市街化区域以外の都市計画区域の基準であり、別途の報告義務もありません。

</details>

**問4.** 事後届出が必要となる場合はどれでしょう?

1. 市街化区域内の3000㎡の土地を相続により取得した場合
2. 市街化区域内の3000㎡の土地に抵当権を設定した場合
3. 都市計画区域外の8000㎡の土地を売買した場合
4. 市街化調整区域内の6000㎡の土地を売買により取得した場合

<details><summary>答えと解説</summary>

正解: **4**

市街化調整区域(市街化区域以外の都市計画区域)の基準は5000㎡以上なので、6000㎡の売買は届出が必要です。相続や抵当権の設定は対価を得て権利を移転・設定する契約ではないため、面積にかかわらず届出不要です。都市計画区域外は10000㎡以上が基準なので8000㎡では不要です。

</details>

## 2. 事後届出の例外と勧告

面積基準に当てはまっても届出不要となる例外と、届出の後に知事ができる**勧告**を押さえます。

### 届出不要の主な例外

- 当事者の一方または双方が**国・地方公共団体**である場合
- **民事調停法による調停**に基づく場合
- 農地法**3条1項の許可**を受けて契約した場合(農地のまま売る場合。すでにチェック済みだから)

### 勧告のルール

| 項目 | 内容 |
|---|---|
| 何について? | **土地の利用目的についてのみ**(**対価の額は勧告できない**) |
| いつまで? | 届出の日から**3週間以内** |
| 従わなかったら? | 知事はその旨と内容を**公表できる**だけ。**契約は有効**で罰則もなし |

### 届出をしなかったら?

**罰則**(6月以下の懲役または100万円以下の罰金)はありますが、**契約自体は有効**です。

> 💡コツ: 「勧告は**目的だけ**、値段には口出しできない」「無視されても**公表どまり**」「無届でも**契約は有効**」。この3つが出ます。

> 🟡 事後届出は「ゆるい制度」というイメージで整理すると全部つながります。

### 確認問題

**問1.** 事後届出に係る知事の勧告について、正しいものはどれでしょう?

1. 土地の対価の額について勧告することができる
2. 土地の利用目的について勧告することができる
3. 利用目的と対価の額の両方について勧告しなければならない
4. 勧告に従わない場合、契約は無効となる

<details><summary>答えと解説</summary>

正解: **2**

事後届出で知事が勧告できるのは土地の利用目的についてのみで、対価の額は勧告の対象外です。買った後の届出なので、値段に口を出しても遅いからです。勧告に従わなくても公表ができるだけで、契約が無効になることはありません。

</details>

**問2.** 事後届出をしないで土地売買等の契約を締結した場合、正しいものはどれでしょう?

1. 契約は無効となる
2. 罰則の適用はないが、契約は無効となる
3. 罰則が適用されることがあるが、契約自体は有効である
4. 罰則もなく、契約も有効で、何の問題もない

<details><summary>答えと解説</summary>

正解: **3**

無届の場合は罰則(6月以下の懲役または100万円以下の罰金)の対象になりますが、契約の効力には影響せず有効です。「契約が無効になる」は誤りで、逆に「何の問題もない」も罰則がある以上誤りです。

</details>

**問3.** 事後届出が不要となるものはどれでしょう?

1. 当事者の一方が地方公共団体である市街化区域内3000㎡の土地売買
2. 宅建業者間で行う市街化区域内3000㎡の土地売買
3. 個人間で行う都市計画区域外20000㎡の土地売買
4. 法人間で行う市街化調整区域内7000㎡の土地売買

<details><summary>答えと解説</summary>

正解: **1**

当事者の一方または双方が国や地方公共団体の場合は届出不要です。宅建業者間や法人間であることは届出義務と関係なく、面積基準を満たす以上は届出が必要です(市街化区域3000㎡は2000㎡以上、区域外20000㎡は10000㎡以上、調整区域7000㎡は5000㎡以上でいずれも該当)。

</details>

## 3. 農地法3条・4条・5条 —— 権利移動と転用

農地法は「国民の食を支える農地を守る」法律です。農地を勝手に売ったりつぶしたりできないよう、3つの場面で許可制にしています。

### 3条・4条・5条の表(最重要!)

| 条文 | 何をする? | 例 | 許可権者 |
|---|---|---|---|
| **3条** | **権利移動**(農地を**農地のまま**売買・貸借) | 農家Aが農家Bに畑を売る | **農業委員会** |
| **4条** | **転用**(自分の農地を宅地などに変える) | 自分の畑に自宅を建てる | **都道府県知事等** |
| **5条** | **転用目的の権利移動**(3条+4条) | 宅地にする目的で畑を売る | **都道府県知事等** |

### おさえておくポイント

- 農地かどうかは登記簿の地目ではなく**現況**で判断(登記が山林でも、耕していれば農地)
- **無許可の3条・5条の契約は効力を生じない(無効)**。無許可転用には原状回復命令なども
- 採草放牧地は3条・5条の対象ですが、4条(転用)の対象外です

> 💡コツ: 「農地のまま動くだけなら身近な**農業委員会**、農地が**消える**(転用がからむ)なら**知事等**」と理屈で覚えると、許可権者を間違えません。

> 🔴 この表が書ければ農地法は半分終わりです。白紙に再現できるまで練習を。

### 確認問題

**問1.** 農家Aが、農家Bに農地を農地のまま売却する場合に必要な許可はどれでしょう?

1. 農地法3条の農業委員会の許可
2. 農地法4条の都道府県知事等の許可
3. 農地法5条の都道府県知事等の許可
4. 都市計画法の開発許可

<details><summary>答えと解説</summary>

正解: **1**

農地を農地のまま売買するのは「権利移動」なので3条の許可で、許可権者は農業委員会です。4条は自己の農地の転用、5条は転用目的での権利移動であり、どちらも農地がなくなる場面なので知事等が許可権者になります。土地の造成を伴わない売買に開発許可は関係ありません。

</details>

**問2.** 登記簿上の地目が山林である土地が、現に畑として耕作されている場合、農地法の適用はどうなるでしょう?

1. 登記簿上の地目が山林なので、農地法の適用はない
2. 現況が農地なので、農地法上の農地として扱われる
3. 所有者が農地と申告した場合にのみ農地として扱われる
4. 市街化区域内にある場合にのみ農地として扱われる

<details><summary>答えと解説</summary>

正解: **2**

農地に当たるかどうかは登記簿の地目ではなく現況(実際の使われ方)で判断します。現に耕作されていれば農地法上の農地です。所有者の申告や所在する区域によって農地かどうかが決まるわけではありません。

</details>

**問3.** 自己所有の農地に自宅を建てるため、農地を宅地に転用する場合に必要となる許可はどれでしょう?(市街化区域外の農地とする)

1. 農地法3条の許可
2. 許可は一切不要である
3. 農地法5条の許可
4. 農地法4条の許可

<details><summary>答えと解説</summary>

正解: **4**

権利の移動がなく、自分の農地を自分で転用するのは4条の場面で、都道府県知事等の許可が必要です。3条は農地のままの権利移動、5条は転用目的で権利を移動する場合です。市街化区域外なので届出で済む特例もなく、「許可不要」は誤りです。

</details>

**問4.** 農地法3条の許可を受けずに締結した農地の売買契約の効力について、正しいものはどれでしょう?

1. 契約は有効であり、罰則もない
2. 契約は有効だが、所有権の移転時期が1年遅れる
3. 契約はその効力を生じない
4. 農業委員会に事後報告すれば有効になる

<details><summary>答えと解説</summary>

正解: **3**

3条・5条の許可を受けない契約は効力を生じません(無効)。許可は契約の効力発生の条件そのものだからです。「有効」とする選択肢はいずれも誤りで、事後報告で治癒する制度もありません。

</details>

## 4. 農地法の許可の例外 —— 市街化区域の届出特例など

農地法にも「許可までは求めない」例外があります。ひっかけが集中するポイントです。

### 市街化区域内の特例(最頻出!)

**市街化区域内**の農地の**転用(4条)・転用目的の権利移動(5条)**は、あらかじめ**農業委員会に届出**をすれば**許可不要**です。市街化区域はどんどん市街化してよいエリアなので、農地がつぶれるのはむしろ想定どおり、という理屈です。

> ただし! **3条にはこの特例がありません**。市街化区域内でも、農地を農地のまま売買するなら**3条の許可が必要**です。

### その他の例外

| 場面 | 扱い |
|---|---|
| **相続・遺産分割**で農地を取得 | 3条の許可**不要**。ただし遅滞なく農業委員会に**届出** |
| 国・都道府県が権利を取得 | 3条の許可不要 |
| **2アール(200㎡)未満**の自己の**農業用施設**(農作業用倉庫など)への転用 | 4条の許可不要 |

> 💡コツ: 「市街化区域なら**届出でOK**、ただし**3条は例外なし**」「相続は許可不要・**届出は必要**」。この2フレーズがそのまま出題されます。

> 🔴 4条・5条と3条の扱いの違いこそが本試験の狙いどころです。

### 確認問題

**問1.** 市街化区域内の農地を、宅地に転用する目的で購入する場合、正しいものはどれでしょう?

1. あらかじめ農業委員会に届け出れば、農地法5条の許可は不要である
2. 面積にかかわらず、都道府県知事等の許可が必要である
3. 市街化区域内の農地の取引は、農地法の適用を一切受けない
4. 事後に農業委員会へ届け出れば足りる

<details><summary>答えと解説</summary>

正解: **1**

市街化区域内の農地の転用(4条)・転用目的の権利移動(5条)は、あらかじめ農業委員会に届け出れば許可不要です。したがって知事等の許可が必要とする選択肢は誤りです。農地法の適用がなくなるわけではなく、届出は「あらかじめ」である点にも注意しましょう(事後届出は国土法の制度です)。

</details>

**問2.** 市街化区域内の農地を、農地のまま耕作目的で購入する場合、正しいものはどれでしょう?

1. あらかじめ農業委員会に届け出れば、3条の許可は不要である
2. 市街化区域内の特例は3条には適用されないため、農業委員会の許可が必要である
3. 市街化区域内なので、許可も届出も不要である
4. 都道府県知事等の許可が必要である

<details><summary>答えと解説</summary>

正解: **2**

市街化区域の届出特例は4条・5条だけの制度で、3条(農地のままの権利移動)には適用されません。したがって市街化区域内でも3条の農業委員会の許可が必要です。許可権者を知事等とする選択肢も誤りで、3条の許可権者は農業委員会です。

</details>

**問3.** 相続により農地を取得した場合、正しいものはどれでしょう?

1. 農地法3条の許可を受けなければ、所有権を取得できない
2. 都道府県知事等の許可が必要である
3. 3条の許可は不要だが、遅滞なく農業委員会に届け出る必要がある
4. 許可も届出も一切不要である

<details><summary>答えと解説</summary>

正解: **3**

相続は当事者の意思による取引ではないため3条の許可は不要です。ただし農業委員会が農地の権利関係を把握できるよう、遅滞なく届け出る必要があります。「届出も一切不要」までいくと誤りになる、という二段構えのひっかけが定番です。

</details>

**問4.** 市街化調整区域内の農地150㎡を、自己の農作業用倉庫(農業用施設)の敷地に転用する場合、正しいものはどれでしょう?

1. 4条の許可が必要である
2. 農業委員会への届出のみで転用できる市街化区域の特例が適用される
3. 面積が1000㎡未満なので都市計画法の開発許可だけで足りる
4. 2アール未満の自己の農業用施設への転用なので、4条の許可は不要である

<details><summary>答えと解説</summary>

正解: **4**

2アール(200㎡)未満の自己の農業用施設への転用は4条の許可が不要です。150㎡はこれに当たります。市街化区域の届出特例は調整区域では使えません。開発許可は都市計画法の別制度であり、農地法の許可の代わりにはなりません。

</details>
