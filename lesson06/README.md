# 第6章 重要事項説明（35条書面）

契約前に宅建士が行う「重要事項説明」は、宅建業法で最も出題数の多いテーマです。誰が・いつ・誰に説明するかの型と、「貸借だと何が不要になるか」のひっかけを押さえれば大きな得点源になります。

## 1. 重要事項説明とは（誰が・いつ・誰に）

家は人生でいちばん高い買い物です。「買ってから抵当権付きだと知った」では遅いので、宅建業法は**契約の前に**物件や取引条件の大事な情報を説明させることにしました。これが**重要事項説明（重説）**で、そのとき渡す書面が**35条書面**です。

### 誰が・いつ・誰に

| 項目 | 内容 |
|---|---|
| 誰が | **宅地建物取引士**が説明（**専任でなくてよい**） |
| いつ | **契約が成立する前** |
| 誰に | **買主・借主**になろうとする者（**売主・貸主には不要**） |
| 書面 | 宅建士の**記名**が必要（押印は不要）。承諾を得れば電磁的交付も可 |

売主はその物件のことをよく知っているので説明不要、というイメージです。また、相手方が**宅建業者**の場合はプロ同士なので、35条書面の交付（電磁的方法も可）だけでよく、**説明は省略できます**。

> 💡コツ：「重説は **契約前に・宅建士が・買う側借りる側へ**」とワンフレーズで暗記。🔴 「契約後でよい」「売主にも必要」「専任の宅建士でなければならない」はすべて誤りの定番パターンです。

### 確認問題

**問1.** 重要事項説明を行う時期として、正しいものはどれでしょう？

1. 売買契約の成立前に行わなければならない
2. 売買契約の成立後、遅滞なく行わなければならない
3. 売買契約の成立と同時に行わなければならない
4. 物件の引渡しまでに行えばよい

<details><summary>答えと解説</summary>

正解: **1**

重要事項説明は、契約を結ぶかどうかの判断材料を与えるためのものなので、契約成立前に行わなければなりません。「契約成立後、遅滞なく」は37条書面の交付時期であり、ここを入れ替えるひっかけが頻出です。

</details>

**問2.** 宅建業者Aが売主B・買主C間の売買を媒介する場合、重要事項説明の相手方として正しいものはどれでしょう？

1. 売主Bに対して説明しなければならない
2. 買主Cに対して説明しなければならない
3. 売主Bと買主Cの双方に説明しなければならない
4. BとCのどちらか一方に説明すればよい

<details><summary>答えと解説</summary>

正解: **2**

重要事項説明の相手は、物件を取得しようとする買主（貸借なら借主）です。売主は自分の物件のことを知っている立場なので、説明の対象ではありません。「双方に交付」が必要なのは37条書面であり、混同を狙う問題がよく出ます。

</details>

**問3.** 重要事項説明を行う者について、正しいものはどれでしょう？

1. 専任の宅地建物取引士が行わなければならない
2. 宅建業者の代表者自身が行わなければならない
3. 宅地建物取引士であれば、専任の者でなくてもよい
4. 宅建業者の従業者であれば、宅建士でなくてもよい

<details><summary>答えと解説</summary>

正解: **3**

重要事項説明は宅建士の独占業務ですが、専任である必要はなく、パート勤務の宅建士などでもかまいません。「専任の宅建士でなければならない」は定番のひっかけです。宅建士でない従業者が説明することはできません。

</details>

**問4.** 買主が宅建業者である場合の重要事項説明について、正しいものはどれでしょう？

1. 35条書面の交付も説明も不要である
2. 35条書面を交付すればよく、説明は省略できる
3. 通常どおり、書面の交付と説明の両方が必要である
4. 口頭で説明すればよく、書面の交付は不要である

<details><summary>答えと解説</summary>

正解: **2**

相手方が宅建業者の場合、プロ同士なので説明は省略できますが、35条書面の交付（承諾を得れば電磁的方法も可）は必要です。「交付まで不要」としてしまうのが誤りのポイントです。逆に書面を交付せず口頭説明だけで済ませることもできません。

</details>

## 2. 宅建士証の提示とIT重説

重要事項説明は「国家資格者が責任を持って説明しています」と示す場面です。そこで宅建士は、重説のとき、相手から**請求がなくても宅建士証を提示**しなければなりません（違反すると10万円以下の過料）。普段の業務では「取引の関係者から請求があったとき」に提示すればよいのと対照的です。

### IT重説（オンラインでの重要事項説明）

テレビ会議などを使ったオンラインの重説も、**売買・貸借のどちらでも**認められています。ただし対面と同等の環境が条件です。

| IT重説の主な要件 |
|---|
| 映像と音声が双方向でやりとりでき、お互いの状態を確認できること |
| 35条書面（承諾があれば電子書面も可）を**説明の前に**相手へ交付しておくこと |
| 宅建士が**宅建士証を画面上に提示**し、相手が確認できたことをチェックすること |
| 映像・音声に支障が生じたら説明を中断すること |

> 💡コツ：🔴 ひっかけは2つ。「重説時の提示は請求があったときだけでよい」（→請求がなくても必要）と「IT重説は貸借に限られる」（→売買も可）です。

### 確認問題

**問1.** 重要事項説明を行う際の宅建士証の提示について、正しいものはどれでしょう？

1. 相手方から請求があったときに限り、提示すればよい
2. 請求がなくても、提示しなければならない
3. 従業者証明書を提示すれば、宅建士証の提示は不要である
4. 初めての相手方に対してのみ提示すればよい

<details><summary>答えと解説</summary>

正解: **2**

重要事項説明の際は、請求の有無にかかわらず宅建士証を提示する義務があり、違反には10万円以下の過料があります。「請求があったとき」に提示するのは重説以外の通常業務の場面です。従業者証明書は別の制度で、宅建士証の代わりにはなりません。

</details>

**問2.** IT重説（テレビ会議等による重要事項説明）について、正しいものはどれでしょう？

1. 建物の貸借の場合に限り認められる
2. 売買の場合に限り認められる
3. 売買・貸借のいずれの取引でも認められる
4. いかなる場合も認められない

<details><summary>答えと解説</summary>

正解: **3**

IT重説は、要件を満たせば売買・貸借のどちらの取引でも実施できます。かつて貸借から先行して運用された経緯から「貸借のみ」とするひっかけが出ますが、現在は売買でも認められています。

</details>

**問3.** IT重説を適法に行うための要件として、誤っているものはどれでしょう？

1. 映像と音声を双方向でやりとりできる環境で行う
2. 35条書面をあらかじめ相手方に交付しておく
3. 宅建士証を画面上に提示し、相手方が確認できたことを確かめる
4. 音声が聞き取れなくなっても、映像がつながっていれば説明を続けてよい

<details><summary>答えと解説</summary>

正解: **4**

映像や音声に支障が生じた場合は、説明を中断しなければなりません。音声が聞こえない状態での説明は対面と同等とはいえないからです。他の3つ（双方向の映像音声・書面の事前交付・画面上での宅建士証の提示確認）はいずれもIT重説の要件として正しい内容です。

</details>

**問4.** 35条書面の交付方法について、正しいものはどれでしょう？

1. 相手方の承諾を得れば、電磁的方法により提供できる
2. 電磁的方法による提供は一切認められず、必ず紙で交付しなければならない
3. IT重説を行う場合は、書面の交付自体を省略できる
4. 宅建士の記名に加えて、押印も必要である

<details><summary>答えと解説</summary>

正解: **1**

法改正により、相手方の承諾を得れば35条書面を電磁的方法で提供できます。また宅建士の押印は廃止され、記名のみで足ります。IT重説でも書面（または電子書面）の事前交付は必要で、省略はできません。

</details>

## 3. 説明事項その1：物件に関すること

35条で説明する内容は大きく「物件そのものの情報」と「取引条件」に分かれます。このチャプターは前半、**物件に関する説明事項**です。買主・借主が「知らずに契約したら困ること」をイメージすると覚えやすくなります。

### 主な説明事項（物件関係）

| 説明事項 | ひとこと |
|---|---|
| **登記された権利**の種類・内容 | 抵当権などが付いていないか。**抹消予定でも説明必要** |
| **法令上の制限**の概要 | 建て替えできない土地かも（建物の貸借ではほぼ不要） |
| **私道負担**に関する事項 | 敷地の一部が道路かも（**建物の貸借では不要**） |
| 飲用水・電気・ガスの**整備状況** | 未整備なら整備の見通しと特別の負担も説明 |
| 未完成物件の**完成時の形状・構造** | 図面が必要なら図面を交付して説明 |
| **水害ハザードマップ**上の所在地 | 水防法に基づくマップでの位置 |
| 石綿（アスベスト）の**調査結果の記録があるとき**はその内容 | 調査自体の実施義務はない |

> 💡コツ：🟡 「登記された抵当権は、引渡しまでに抹消される予定なら説明不要」は誤り（説明必要）という出題が定番です。説明時点で登記があるなら必ず説明します。

### 確認問題

**問1.** 売買の目的物に抵当権の登記があるが、売主が「引渡しまでに抹消する」と約束している場合、重要事項説明はどうなるでしょう？

1. 抹消される予定なので、説明しなくてよい
2. 買主が希望した場合に限り、説明すればよい
3. 抹消予定であっても、登記された抵当権について説明しなければならない
4. 売主の承諾を得れば、説明を省略できる

<details><summary>答えと解説</summary>

正解: **3**

登記された権利は、説明の時点で登記がある以上、抹消予定でも説明が必要です。予定どおり抹消されるとは限らず、買主の判断材料として重要だからです。買主の希望や売主の承諾で省略できるものではありません。

</details>

**問2.** 建物の貸借の媒介において、重要事項として説明する必要がないものはどれでしょう？

1. 私道に関する負担に関する事項
2. 飲用水・電気・ガスの供給施設の整備状況
3. 登記された権利の種類・内容
4. 水害ハザードマップにおける建物の所在地

<details><summary>答えと解説</summary>

正解: **1**

私道負担の説明は、建物の貸借の場合には不要です。借主は土地を利用する立場ではあっても私道の負担を直接負わないからです。インフラの整備状況・登記された権利・水害ハザードマップは建物の貸借でも説明事項です。

</details>

**問3.** 未完成の建物の売買における重要事項説明について、正しいものはどれでしょう？

1. 完成前なので、建物に関する説明は完成後に行えばよい
2. 工事完了時の形状・構造などを説明しなければならない
3. 建築確認を受けていれば、形状・構造の説明は不要である
4. 口頭での説明が難しい場合は、説明自体を省略できる

<details><summary>答えと解説</summary>

正解: **2**

未完成物件では、完成時の形状・構造など（必要に応じ図面を交付して）を説明しなければなりません。実物を見られない買主にとって最重要の情報だからです。建築確認の有無とは別の義務であり、完成後に先延ばしすることも省略することもできません。

</details>

**問4.** 建物の売買における石綿（アスベスト）に関する重要事項説明について、正しいものはどれでしょう？

1. 宅建業者は、自ら石綿の使用の有無を調査したうえで結果を説明しなければならない
2. 石綿の調査結果の記録があるときは、その内容を説明しなければならない
3. 石綿に関する事項は、重要事項説明の対象ではない
4. 昭和56年以降に建築された建物であれば説明は不要である

<details><summary>答えと解説</summary>

正解: **2**

石綿については「調査結果の記録が保存されているときに、その内容」を説明します。宅建業者自身に調査義務まではない、という点がポイントです。重要事項説明の対象ではある一方、建築年で免除される規定はありません（建築年で扱いが変わるのは耐震診断に関する説明です）。

</details>

## 4. 説明事項その2：取引条件に関すること

後半は**取引条件**の説明事項です。ここで最大の注意点は、**代金・借賃そのものの額は説明事項ではない**こと。金額は契約交渉の中心なので、説明されなくても当事者が当然知っているからです。

### 主な説明事項（取引条件関係）

| 説明事項 | ひとこと |
|---|---|
| **代金・借賃以外に**授受される金銭の額・目的 | 手付金、敷金、礼金など |
| **契約の解除**に関する事項 | どんなときに解除できるか |
| **損害賠償額の予定・違約金**に関する事項 | 違約したらいくら払うか |
| **手付金等の保全措置**の概要 | 業者が自ら売主となる場合 |
| 支払金・預り金の**保全措置を講ずるかどうか**等 | 講じない場合も「講じない」と説明 |
| 代金に関する**金銭の貸借（ローン）のあっせん**の内容と、不成立のときの措置 | ローン特約の話 |
| **契約不適合責任の履行確保措置**（保証保険契約など）を講ずるかどうか等 | 講じるならその概要も |

> 💡コツ：🟡 「代金の額」「引渡しの時期」「移転登記の申請時期」の3つは35条では説明不要（37条書面の記載事項）です。この3つを35条に混ぜるひっかけが毎年のように出ます。

### 確認問題

**問1.** 売買の媒介における重要事項説明の対象となるものは、次のうちどれでしょう？

1. 代金の額
2. 物件の引渡しの時期
3. 代金以外に授受される金銭の額および授受の目的
4. 移転登記の申請の時期

<details><summary>答えと解説</summary>

正解: **3**

手付金や固定資産税の清算金など「代金以外に授受される金銭」は、その額と目的が説明事項です。一方、代金の額・引渡し時期・移転登記の申請時期の3つは35条の説明事項ではなく、37条書面の記載事項です。この3つの混入が定番のひっかけです。

</details>

**問2.** 重要事項説明における「損害賠償額の予定・違約金」の扱いとして、正しいものはどれでしょう？

1. 定めの有無にかかわらず、説明事項とされている
2. 説明事項ではなく、37条書面にのみ記載すればよい
3. 買主から請求があった場合にのみ説明すればよい
4. 宅建業者が自ら売主となる場合にのみ説明すればよい

<details><summary>答えと解説</summary>

正解: **1**

損害賠償額の予定・違約金に関する事項は35条の説明事項です（定めをしないならその旨を含めて、契約前に知らせる必要があります）。37条書面では「定めがあるとき」に記載する事項であり、両書面での扱いの違いもあわせて覚えましょう。媒介の場合でも説明が必要です。

</details>

**問3.** 支払金・預り金の保全措置について、重要事項説明での正しい扱いはどれでしょう？

1. 保全措置を講ずる場合にのみ説明すればよい
2. 保全措置を講ずるかどうか、講ずる場合はその概要を説明する
3. 支払金・預り金は説明事項ではない
4. 金額が1円でもあれば必ず保全措置を講じなければならない

<details><summary>答えと解説</summary>

正解: **2**

支払金・預り金については「保全措置を講ずるかどうか」自体が説明事項で、講ずる場合はその概要も説明します。つまり講じない場合でも「講じない」と説明する必要があります。保全措置を講じること自体は義務ではないので、肢4も誤りです。

</details>

**問4.** 買主が銀行ローンを利用する予定の売買で、宅建業者がローンのあっせんをする場合の重要事項説明について、正しいものはどれでしょう？

1. ローンは銀行と買主の問題なので、説明事項ではない
2. あっせんの内容のみ説明すればよく、ローン不成立の場合の措置は説明不要である
3. ローン不成立の場合の措置のみ説明すればよい
4. あっせんの内容と、ローンが成立しないときの措置の両方を説明しなければならない

<details><summary>答えと解説</summary>

正解: **4**

金銭の貸借のあっせんについては、あっせんの内容と「貸借が成立しないときの措置」（いわゆるローン特約で解除できるか等）の両方が説明事項です。ローンが組めなかったときに買主がどうなるかは契約判断に直結するため、片方だけの説明では足りません。

</details>

## 5. 35条の頻出ひっかけ（貸借での違い・説明不要なもの）

35条は宅建業法で最も問題数が多い分野です。合否を分けるのは「**貸借だと何が変わるか**」と「**そもそも説明不要なもの**」の2点です。

### 建物の貸借で「不要」になる主なもの

| 項目 | 売買 | 建物の貸借 |
|---|---|---|
| 法令上の制限 | 必要 | **ほぼ不要** |
| 私道負担 | 必要 | **不要** |
| 住宅ローンのあっせん | 必要 | **不要**（そもそもローンがない） |

借主は建物を建て替えるわけではないので、建築関係の法令制限を知る必要が薄いからです。

### 逆に貸借「だけ」で必要になる主なもの

- 台所・浴室・便所などの**設備の整備状況**（建物の貸借）
- **契約期間・更新**に関する事項、**定期借家・定期借地**である旨
- **敷金**など契約終了時に精算される金銭に関する事項
- 建物の**管理が委託されているとき**は、その委託先の氏名・住所

### いつでも説明不要（37条の世界）

**代金・借賃の額／引渡し時期／移転登記の申請時期**。

> 💡コツ：🔴 「借りる人はリフォームも建て替えもしない。だから建築系は不要、その代わり住み心地とお金の精算の話が必要」とイメージで整理しましょう。

### 確認問題

**問1.** 建物の貸借の媒介において、重要事項として説明しなければならないものはどれでしょう？

1. 建蔽率・容積率などの建築基準法上の制限の概要
2. 台所・浴室・便所その他の設備の整備状況
3. 私道に関する負担に関する事項
4. 移転登記の申請の時期

<details><summary>答えと解説</summary>

正解: **2**

台所・浴室などの設備の整備状況は、建物の貸借で説明が必要な事項です。借主の住み心地に直結するからです。建蔽率などの法令制限や私道負担は建物の貸借では不要、移転登記の申請時期はそもそも35条の説明事項ではありません。

</details>

**問2.** 建物の貸借の媒介における敷金の説明について、正しいものはどれでしょう？

1. 敷金など契約終了時に精算される金銭に関する事項を説明しなければならない
2. 敷金は借賃の一部なので、説明は不要である
3. 敷金の額が借賃1か月分以下であれば、説明は不要である
4. 敷金について説明するのは、契約成立後でよい

<details><summary>答えと解説</summary>

正解: **1**

敷金その他契約終了時に精算することとされている金銭に関する事項は、貸借における説明事項です。退去時の返金トラブルを防ぐためで、金額の大小による免除はありません。敷金は借賃そのものではなく「借賃以外に授受される金銭」でもあり、説明は当然契約成立前に行います。

</details>

**問3.** 売買・貸借を通じて、35条の重要事項説明の対象とならないものはどれでしょう？

1. 契約の解除に関する事項
2. 登記された権利の種類・内容
3. 代金・借賃の額
4. 水害ハザードマップにおける物件の所在地

<details><summary>答えと解説</summary>

正解: **3**

代金・借賃の額そのものは、当事者が交渉の中心として当然知っている情報なので35条の説明事項ではありません（37条書面には必ず記載します）。契約解除・登記された権利・水害ハザードマップはいずれも説明事項です。

</details>

**問4.** 貸借の媒介における定期建物賃貸借（定期借家）の扱いについて、正しいものはどれでしょう？

1. 定期借家かどうかは契約書を見ればわかるので、説明は不要である
2. 定期建物賃貸借である旨を重要事項として説明しなければならない
3. 借主から質問があった場合にのみ説明すればよい
4. 契約期間が1年未満の場合にのみ説明すればよい

<details><summary>答えと解説</summary>

正解: **2**

定期借家（更新がない契約）であることは借主にとって重大な情報なので、重要事項として説明が必要です。契約書を読めばわかる、質問があったときだけでよい、という理屈は通りません。契約期間の長短によって説明義務が消えることもありません。

</details>

**問5.** 建物の管理が管理業者に委託されている場合の重要事項説明について、正しいものはどれでしょう？

1. 管理の委託は貸主側の事情なので、説明事項ではない
2. 管理費用の金額のみ説明すればよい
3. 借主が希望した場合に限り説明すればよい
4. 貸借の媒介では、管理を委託された者の氏名・住所を説明しなければならない

<details><summary>答えと解説</summary>

正解: **4**

貸借では、建物の管理が委託されているときはその委託先（管理業者）の氏名・住所が説明事項です。入居後の問い合わせ先として借主に必要な情報だからです。借主の希望の有無にかかわらず説明が必要で、「説明事項ではない」「金額のみでよい」は誤りです。

</details>
