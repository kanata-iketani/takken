いよいよ総仕上げです。本試験と同じ4択で、これまで学んだ全範囲を横断するミニ模試を3本用意しました。間違えた問題は、該当するレッスンに戻って復習しましょう。ここまで来たあなたなら、合格ラインは射程圏内です。

## 1. 宅建業法ミニ模試（10問）

🔴 ここからは模試です。問題を解く前に、**本試験での戦い方**を確認しましょう。

### 解く順番は「業法から」

本試験は問1〜50ですが、**問1から順に解く必要はありません**。おすすめの順番は次のとおりです。

1. **宅建業法（問26〜45）** — 得点源。頭が元気なうちに確実に取る
2. **法令上の制限・税その他（問15〜25）** — 暗記で即断できる
3. **5問免除科目（問46〜50）** — 統計・土地建物など
4. **権利関係（問1〜14）** — 時間のかかる事例問題は最後に回す

### 時間配分の目安

2時間で50問＝**1問あたり約2分**です。業法と制限は1問1分台で駆け抜けて、権利関係と見直しに時間を残しましょう。

> 💡 順番を変えて解くときの最大の敵は**マークシートのずれ**です。10問解くごとに、問題番号とマークの位置が合っているか確認するクセをつけましょう。

それでは宅建業法のミニ模試10問です。本試験のつもりで、1問2分以内を意識してどうぞ。

### 確認問題

**問1.** 宅建業の免許に関する次の記述のうち、正しいものはどれでしょう？

1. Aが、自己所有の賃貸マンションを自ら貸主として不特定多数の者に反復継続して貸す場合、免許が必要である
2. Bが、自己所有の土地を多数の区画に分割し、不特定多数の者に反復継続して売却する場合、免許が必要である
3. Cが、貸主から依頼を受けて賃貸マンションの貸借の媒介を反復継続して行う場合、貸借に関する行為なので免許は不要である
4. 国や地方公共団体が宅地を分譲する場合、免許が必要である

<details><summary>答えと解説</summary>

正解: **2**

自ら売主として不特定多数に反復継続して売却する行為は宅建業にあたり、免許が必要です。「自ら貸借」は取引にあたらないため免許不要ですが、貸借の「媒介」を業として行えば免許が必要です。国や地方公共団体には宅建業法が適用されないので免許不要です。

</details>

**問2.** 宅建業の免許の欠格要件に関する次の記述のうち、正しいものはどれでしょう？

1. 懲役刑の執行猶予期間を満了した者は、満了の日から5年を経過しなければ免許を受けられない
2. 破産手続開始の決定を受けた者は、復権を得た後5年を経過しなければ免許を受けられない
3. 道路交通法違反により罰金刑に処せられた者は、5年間免許を受けられない
4. 宅建業法違反により罰金刑に処せられた者は、刑の執行を終えた日から5年を経過しなければ免許を受けられない

<details><summary>答えと解説</summary>

正解: **4**

罰金刑で欠格になるのは、宅建業法違反や暴力的な犯罪などに限られ、その場合は5年間免許を受けられません。執行猶予は期間を満了すれば直ちに免許を受けられ、破産者も復権すれば直ちに受けられます（どちらも「5年待ち」は不要）。道路交通法違反の罰金は欠格要件ではありません。

</details>

**問3.** 宅地建物取引士に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建士の登録を受けるには、原則として2年以上の実務経験を有するか、登録実務講習を修了する必要がある
2. 重要事項の説明は、専任の宅建士でなければ行うことができない
3. 宅建士証の有効期間は10年である
4. 重要事項の説明の際、相手方から請求がなければ宅建士証を提示する必要はない

<details><summary>答えと解説</summary>

正解: **1**

登録には原則2年以上の実務経験または登録実務講習の修了が必要です。重要事項説明は宅建士であればよく、専任である必要はありません。宅建士証の有効期間は5年で、重要事項説明の際は請求がなくても宅建士証を提示しなければなりません。

</details>

**問4.** 営業保証金・保証協会に関する次の記述のうち、正しいものはどれでしょう？

1. 営業保証金の額は、主たる事務所につき500万円、従たる事務所1か所につき1,000万円である
2. 弁済業務保証金分担金の額は、主たる事務所につき60万円、従たる事務所1か所につき30万円である
3. 営業保証金は金銭でのみ供託することができ、有価証券による供託は認められない
4. 保証協会の社員となった場合でも、営業保証金を供託しなければならない

<details><summary>答えと解説</summary>

正解: **2**

分担金は主たる事務所60万円・従たる事務所1か所30万円で、保証協会に金銭で納付します。営業保証金は主たる事務所1,000万円・従たる事務所500万円（選択肢は逆）で、国債などの有価証券でも供託できます。保証協会の社員になれば営業保証金の供託は不要です。

</details>

**問5.** 媒介契約に関する次の記述のうち、正しいものはどれでしょう？

1. 専任媒介契約の有効期間は、6か月を超えることができない
2. 一般媒介契約の場合、媒介契約の内容を記載した書面（電磁的方法を含む）を交付する必要はない
3. 専属専任媒介契約では、1週間に1回以上、業務の処理状況を依頼者に報告しなければならない
4. 専任媒介契約を締結したときは、契約締結の日から5日以内に指定流通機構に登録しなければならない

<details><summary>答えと解説</summary>

正解: **3**

専属専任媒介の報告義務は1週間に1回以上です（専任媒介は2週間に1回以上）。専任媒介の有効期間は3か月以内、指定流通機構への登録は専任媒介が7日以内・専属専任が5日以内です。媒介契約書面の交付は一般媒介でも必要です。

</details>

**問6.** 重要事項の説明（35条）に関する次の記述のうち、正しいものはどれでしょう？

1. 重要事項の説明は、契約成立後、遅滞なく行えばよい
2. 売買代金の額は、重要事項として説明しなければならない
3. 買主が宅建業者である場合でも、書面の交付に加えて宅建士による口頭の説明が必要である
4. 重要事項説明書には、宅建士の記名が必要である

<details><summary>答えと解説</summary>

正解: **4**

重要事項説明書には宅建士の記名が必要です。説明は契約が成立する「前」に行わなければなりません。売買代金の額は35条の説明事項ではなく37条書面の記載事項です。買主が宅建業者の場合は書面の交付だけでよく、口頭の説明は不要です。

</details>

**問7.** 37条書面に関する次の記述のうち、正しいものはどれでしょう？

1. 37条書面は、契約の両当事者に交付しなければならない
2. 37条書面は、宅建士がその内容を説明しなければならない
3. 引渡しの時期は、定めがなければ37条書面に記載しなくてよい
4. 35条書面を交付していれば、37条書面の交付は省略できる

<details><summary>答えと解説</summary>

正解: **1**

37条書面は売主・買主など契約の両当事者に交付します（35条書面が原則買主側のみなのと対照的です）。37条書面には説明義務はありません。引渡しの時期と代金の額などは必要的記載事項で、必ず定めて記載します。35条と37条は目的の異なる別の書面なので、一方で他方を省略することはできません。

</details>

**問8.** 宅建業者が自ら売主となる売買契約のクーリング・オフに関する次の記述のうち、正しいものはどれでしょう？

1. 買主が自ら申し出て、自宅で買受けの申込みをした場合でも、クーリング・オフができる
2. クーリング・オフができる旨を書面で告げられた日から起算して8日を経過したときは、クーリング・オフができなくなる
3. 宅地建物の引渡しを受けていれば、代金の一部しか支払っていなくてもクーリング・オフはできない
4. 事務所で買受けの申込みをし、喫茶店で契約を締結した場合、クーリング・オフができる

<details><summary>答えと解説</summary>

正解: **2**

クーリング・オフは、できる旨を書面で告げられた日から起算して8日を経過するとできなくなります。買主が自ら申し出た自宅・勤務先での申込みは対象外です。できなくなるのは「引渡しを受け、かつ代金全部を支払った」ときなので、一部支払いではまだ可能です。クーリング・オフの可否は申込みの場所で判断するため、事務所で申し込んだ場合はできません。

</details>

**問9.** 宅建業者Aが自ら売主となり、宅建業者でないBと代金3,000万円の売買契約を締結する場合の手付に関する次の記述のうち、正しいものはどれでしょう？

1. Aは、600万円を超える手付を受領することができない
2. 手付を解約手付とするには、当事者間の特約が必要である
3. 「Bは手付を放棄しても契約を解除できない」という特約は、Bが承諾していれば有効である
4. Aが契約の履行に着手する前であっても、Bは手付を放棄して契約を解除することができない

<details><summary>答えと解説</summary>

正解: **1**

自ら売主制限により、手付は代金の2割（この場合600万円）を超えて受領できません。受領した手付は特約がなくても当然に解約手付の性質を持ちます。買主に不利な特約は買主の承諾があっても無効で、相手方（A）が履行に着手する前であればBは手付放棄で解除できます。

</details>

**問10.** 消費税の課税事業者である宅建業者が、土地（代金1,000万円・消費税なし）の売買の媒介をした場合、依頼者の一方から受領できる報酬の上限はいくらでしょう？

1. 30万円
2. 36万円
3. 39万6,000円
4. 72万円

<details><summary>答えと解説</summary>

正解: **3**

代金400万円超の速算式は「代金×3%＋6万円」なので、1,000万円×3%＋6万円＝36万円。課税事業者はこれに消費税10%を上乗せでき、36万円×1.1＝39万6,000円が一方から受領できる上限です。36万円は消費税を忘れた額、72万円は双方から受領する場合の合計の上限（税抜）です。

</details>

## 2. 権利関係ミニ模試（8問）

### 権利関係は「深追いしない」

🔴 権利関係（問1〜14）は宅建試験でいちばん難しい分野です。合格者でも14問中**8〜10問**取れれば十分。だからこそ、解き方の作戦が効いてきます。

### 本番での心構え

- **知らない判例や長文の問題は、飛ばす勇気**を持ちましょう。1問に5分かけるより、業法の見直しに回すほうが合計点は伸びます
- 「正しいものはいくつあるか」という**個数問題**は、全選択肢の判断が必要で時間がかかります。後回しでかまいません
- 事例問題は、**登場人物の関係図**を問題用紙の余白に書きましょう。「誰が誰に何を主張しているか」を矢印で描くだけで、正答率が目に見えて上がります

### 見直しのしかた

解き終えたら、まず**マークのずれ**を確認します。次に「自信がない」と印をつけた問題だけを見直します。そして**根拠がない限り答えを変えない**こと。迷った末に変えた答えは裏目に出がちです。

それでは権利関係のミニ模試8問。関係図を書きながらどうぞ。

### 確認問題

**問1.** AがBの詐欺によってA所有の土地をBに売却し、BがこれをCに転売した。次の記述のうち、正しいものはどれでしょう？

1. Aは、善意無過失のCに対しても、詐欺による取消しを対抗できる
2. Cが詐欺の事実を知っていた場合、Aは取消しをCに対抗できる
3. 強迫による取消しは、善意無過失の第三者に対抗できない
4. 詐欺による意思表示は、取消しを待つまでもなく当然に無効である

<details><summary>答えと解説</summary>

正解: **2**

詐欺による取消しは、善意無過失の第三者には対抗できませんが、悪意（事情を知っていた）の第三者には対抗できます。一方、強迫による取消しは善意無過失の第三者にも対抗できます（強迫された被害者を厚く守るためです）。また詐欺による意思表示は「無効」ではなく「取り消すことができる」ものです。

</details>

**問2.** AとBが通謀して、A所有の土地をBに売却したように仮装した。その後、Bがこの土地を事情を知らないCに売却した。次の記述のうち、正しいものはどれでしょう？

1. AB間の仮装の売買は有効であり、Aは取り消すことができる
2. Cに過失があれば、AはCに対して無効を対抗できる
3. Cが善意であれば、AはCに対して無効を対抗できない
4. Cは登記を備えていなければ、保護されない

<details><summary>答えと解説</summary>

正解: **3**

通謀虚偽表示は無効ですが、その無効は善意の第三者に対抗できません。虚偽表示の第三者保護の要件は「善意」だけで足り、無過失は不要です（過失があっても保護されます）。また判例は、この第三者は登記を備えていなくても保護されるとしています。仮装売買は「取り消しうる」ではなく無効です。

</details>

**問3.** Bが代理権がないのに、Aの代理人としてA所有の土地をCに売却した。次の記述のうち、正しいものはどれでしょう？

1. Aが追認すれば、契約は原則として契約の時にさかのぼって効力を生ずる
2. Cは、Bに代理権がないことを知っていた場合でも、契約を取り消すことができる
3. Cが相当の期間を定めて催告したのにAが確答しないときは、追認したものとみなされる
4. 無権代理による契約は、当然にAに対して効力を生ずる

<details><summary>答えと解説</summary>

正解: **1**

本人Aが追認すると、契約は原則として契約の時にさかのぼって有効になります。相手方Cの取消権は善意の場合にしか認められません（催告は悪意でも可能、という対比で覚えましょう）。催告に対して確答がないときは追認を「拒絶」したものとみなされます。無権代理の契約は追認がない限り本人に効力を生じません。

</details>

**問4.** Aが自己所有の土地をBに売却し、さらに同じ土地をCにも売却した（二重譲渡）。次の記述のうち、正しいものはどれでしょう？

1. 先に売買契約を締結したBが、当然に所有権の取得をCに対抗できる
2. 先に登記を備えた者が優先するが、Cが背信的悪意者である場合、Bは登記がなくてもCに対抗できる
3. Cが単にBへの売却の事実を知っていた（悪意の）場合、Cは登記を備えてもBに対抗できない
4. BとCは、登記がなくても互いに所有権の取得を対抗できる

<details><summary>答えと解説</summary>

正解: **2**

二重譲渡の優劣は契約の先後ではなく登記で決まります。ただし、相手を害する目的があるような背信的悪意者は保護に値しないため、これに対しては登記なしで対抗できます。単なる悪意者は「自由競争の範囲内」とされ、先に登記を備えれば勝てる点が重要な区別です。

</details>

**問5.** 借地借家法の借地権に関する次の記述のうち、正しいものはどれでしょう？（定期借地権等を除く）

1. 存続期間を20年と定めた場合、その期間は20年となる
2. 最初の更新後の存続期間は10年である
3. 借地上の建物が滅失すると、借地権は当然に消滅する
4. 当事者が存続期間を定めなかった場合、存続期間は30年となる

<details><summary>答えと解説</summary>

正解: **4**

借地権の存続期間は30年以上で、定めがなければ30年です。30年より短い定め（20年など）をしても30年に引き上げられます。最初の更新後の期間は20年（2回目以降は10年）です。建物が滅失しても借地権は当然には消滅しません。

</details>

**問6.** 期間の定めのある建物賃貸借（普通借家契約）に関する次の記述のうち、正しいものはどれでしょう？

1. 賃貸人が更新を拒絶するには、期間満了の1年前から6か月前までに通知し、かつ正当事由が必要である
2. 造作買取請求権は、特約によっても排除することができない
3. 期間を1年未満と定めた場合、その期間は1年とみなされる
4. 賃借人が中途解約する場合は、常に6か月前に申し入れなければならない

<details><summary>答えと解説</summary>

正解: **1**

賃貸人からの更新拒絶には、期間満了の1年前から6か月前までの通知と正当事由の両方が必要です。造作買取請求権は特約で排除できます（任意規定）。期間を1年未満と定めると「期間の定めのない」賃貸借とみなされ、1年とみなされるのではありません。期間の定めのない場合、賃借人からの解約申入れは3か月で効力を生じます。

</details>

**問7.** Aが死亡し、相続人は配偶者Bと子C・Dの3人である。Bの法定相続分はどれでしょう？

1. 3分の1
2. 2分の1
3. 3分の2
4. 4分の3

<details><summary>答えと解説</summary>

正解: **2**

配偶者と子が相続人の場合、配偶者の相続分は2分の1で、残り2分の1を子が等分します（CとDは各4分の1）。3分の2は配偶者と直系尊属の場合、4分の3は配偶者と兄弟姉妹の場合の配偶者の相続分なので、組み合わせごとに区別して覚えましょう。

</details>

**問8.** 相続の放棄に関する次の記述のうち、正しいものはどれでしょう？

1. 相続の放棄は、相続開始前でも家庭裁判所に申述してすることができる
2. 相続を放棄した者の子は、その者に代わって代襲相続する
3. 相続の放棄は、自己のために相続の開始があったことを知った時から3か月以内に、家庭裁判所に申述してしなければならない
4. 一度した相続の放棄は、3か月以内であれば自由に撤回できる

<details><summary>答えと解説</summary>

正解: **3**

放棄は「自己のために相続の開始があったことを知った時」から3か月以内に家庭裁判所へ申述します。相続開始前にはできません（遺留分の放棄と混同しないように）。放棄した者は初めから相続人でなかったものとみなされるため、その子は代襲相続しません。また、一度した放棄は原則として撤回できません。

</details>

## 3. 制限・税その他ミニ模試（8問）

最後のミニ模試です。法令上の制限と税は、**知っているかどうかで即決まる**分野。わからない選択肢があっても、確実に誤りとわかる選択肢を消していく**消去法**がよく効きます。

### 本番前日〜当日のチェックリスト

- **統計の最新値**（地価・着工戸数などの増減の方向）を確認しましたか？ 国土交通省などの公表資料を見るのは前日でも間に合います
- 数字モノ（開発許可の面積、事後届出は2週間以内、報酬の速算式…）を**最終確認**
- 当日は**受験票と腕時計**を忘れずに。会場に時計がないことがあります

### 最後の見直しは3段階で

全問解き終えたら、(1) **マークのずれ** → (2) 「正しいもの／誤っているもの」という**設問の読み違い** → (3) 自信のない問題、の順に確認します。設問の読み違いは、毎年多くの受験生がやってしまうもったいない失点です。問題文の「誤っているもの」に**印をつける習慣**をつけましょう。

🔴 ここで仕上げて、合格をつかみに行きましょう。制限・税その他の8問です。

### 確認問題

**問1.** 都市計画法の開発許可に関する次の記述のうち、正しいものはどれでしょう？

1. 市街化区域内で行う1,000㎡以上の開発行為は、原則として開発許可が必要である
2. 市街化調整区域内では、1,000㎡未満の開発行為であれば許可は不要である
3. 市街化調整区域内で農業を営む者が農業用倉庫を建築するための開発行為には、許可が必要である
4. 開発許可の申請先は市町村長である

<details><summary>答えと解説</summary>

正解: **1**

市街化区域では1,000㎡以上の開発行為に原則として許可が必要です。市街化調整区域には規模による例外がなく、小規模でも原則許可が必要です。ただし農林漁業用建築物のための開発行為は許可不要の例外です。許可権者は市町村長ではなく都道府県知事等です。

</details>

**問2.** 都市計画に関する次の記述のうち、正しいものはどれでしょう？

1. 用途地域は、市街化調整区域に必ず定めなければならない
2. 市街化区域には少なくとも用途地域を定め、市街化調整区域には原則として用途地域を定めない
3. 市街化区域とは、すでに市街地を形成している区域と、おおむね20年以内に市街化を図るべき区域をいう
4. すべての都市計画区域において、区域区分（線引き）を定めなければならない

<details><summary>答えと解説</summary>

正解: **2**

用途地域は市街化区域には少なくとも（必ず）定め、市街化調整区域には原則として定めません。市街化区域の定義は「おおむね10年以内」に優先的・計画的に市街化を図るべき区域で、20年ではありません。区域区分を定めるかどうかは原則として任意です（大都市圏など一部は義務）。

</details>

**問3.** 建築基準法の道路規制に関する次の記述のうち、正しいものはどれでしょう？

1. 建築物の敷地は、原則として幅員6m以上の道路に接しなければならない
2. 接道義務は、敷地が道路に1m以上接していれば満たされる
3. 幅員4m未満のいわゆる2項道路では、原則として道路の中心線から水平距離2m後退した線が道路の境界線とみなされる
4. セットバック部分には、建築物を建築することができる

<details><summary>答えと解説</summary>

正解: **3**

2項道路では、道路中心線から2m下がった線が道路境界線とみなされます（セットバック）。道路は原則幅員4m以上で足り、接道義務は2m以上です。セットバック部分は道路とみなされるため、建築物を建てたり塀を設けたりすることはできません。

</details>

**問4.** 建築基準法の用途制限に関する次の記述のうち、正しいものはどれでしょう？

1. 住宅は、工業地域には建築することができない
2. 住宅は、工業専用地域には原則として建築することができない
3. 診療所は、いずれの用途地域にも建築することができない
4. 神社・寺院・教会は、住居系の用途地域には建築することができない

<details><summary>答えと解説</summary>

正解: **2**

住宅が建てられないのは工業「専用」地域だけで、工業地域には建てられます（この1字の違いが定番のひっかけです）。診療所と神社・寺院・教会は、すべての用途地域で建築できる施設の代表例です。

</details>

**問5.** 農地法に関する次の記述のうち、正しいものはどれでしょう？

1. 市街化区域内の農地を転用する場合、あらかじめ農業委員会に届け出れば、4条の許可は不要である
2. 市街化区域内の農地を耕作目的で売買する場合も、農業委員会への届出で足りる
3. 3条の許可権者は、都道府県知事である
4. 相続により農地を取得した場合、3条の許可が必要である

<details><summary>答えと解説</summary>

正解: **1**

市街化区域内の特例（あらかじめ農業委員会に届出すれば許可不要）は、転用の4条・転用目的の権利移動の5条にだけあります。耕作目的の権利移動（3条）にはこの特例がなく、市街化区域内でも許可が必要です。3条の許可権者は農業委員会です。相続による取得は3条許可が不要です（届出はします）。

</details>

**問6.** 国土利用計画法の事後届出に関する次の記述のうち、正しいものはどれでしょう？

1. 届出は、契約の両当事者が共同で行わなければならない
2. 市街化区域内では、5,000㎡以上の土地売買等の契約が届出の対象となる
3. 権利取得者は、契約締結の日から2週間以内に、都道府県知事等に届け出なければならない
4. 事後届出では、土地の利用目的に加えて対価の額も審査され、対価について変更勧告を受けることがある

<details><summary>答えと解説</summary>

正解: **3**

事後届出は、権利取得者（買主）が契約締結日から2週間以内に行います。両当事者共同ではありません。市街化区域の届出対象は2,000㎡以上です（5,000㎡以上は市街化区域以外の都市計画区域）。対価の額は届出事項ではあるものの、審査・勧告の対象になるのは利用目的だけです。

</details>

**問7.** 不動産に関する税金についての次の記述のうち、正しいものはどれでしょう？

1. 不動産取得税は、市町村が課する税である
2. 相続により不動産を取得した場合、不動産取得税が課される
3. 贈与により不動産を取得した場合、不動産取得税は課されない
4. 固定資産税は、毎年1月1日現在の所有者に課される

<details><summary>答えと解説</summary>

正解: **4**

固定資産税は賦課期日である毎年1月1日現在の所有者に市町村が課します。不動産取得税を課すのは都道府県です。相続による取得は非課税ですが、贈与による取得には課税されます。「相続と贈与」の扱いの違いは最後まで狙われるポイントです。

</details>

**問8.** 印紙税・登録免許税に関する次の記述のうち、正しいものはどれでしょう？

1. 収入印紙を貼付しなかった売買契約書は、契約として無効である
2. 登録免許税は、登記を受ける者が納税義務を負う
3. 登録免許税の課税標準は、実際の売買契約で定めた代金の額である
4. 国が作成する文書にも、印紙税が課される

<details><summary>答えと解説</summary>

正解: **2**

登録免許税の納税義務者は登記を受ける者で、売買による移転登記では売主と買主が連帯して納付します。印紙を貼らなくても契約は有効です（過怠税が課されるだけ）。登録免許税の課税標準は固定資産課税台帳の登録価格であり、売買代金ではありません。国や地方公共団体が作成する文書は印紙税が非課税です。

</details>
