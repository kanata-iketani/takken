# 第1章 宅建試験のきほんと学習戦略

勉強を始める前に、宅建試験がどんな試験で、どう戦えば受かるのかを知る章です。ここでの「7割で勝ち」「宅建業法が得点源」という感覚が、この先ずっと効いてきます。

## 1. 宅建試験ってどんな試験？

**宅建（たっけん）**は、正式には「宅地建物取引士資格試験」という国家試験です。不動産の売買や賃貸の仲介をする会社には、この資格を持つ人（宅建士）を置くことが法律で義務付けられているため、不動産業界でいちばん需要のある資格です。

### 試験のかたち

- 年1回、例年 **10月の第3日曜日** に実施
- **50問・4択のマークシート**（記述はありません！）
- 試験時間は 2時間
- 合格ラインは年によって変わり、**50問中だいたい 31〜38点**（7割前後が目安）

### 出題される4つの分野

| 分野 | 問題数 | ひとこと |
|---|---|---|
| 宅建業法 | 20問 | ルールを覚えれば得点できる**最大の得点源** |
| 権利関係（民法など） | 14問 | いちばん難しい。深追いしない |
| 法令上の制限 | 8問 | 暗記中心 |
| 税・その他 | 8問 | 直前期の対策で十分 |

> 大事なのは「**満点を取る試験ではなく、7割取れば勝ちの試験**」ということです。難しい問題は捨てて、取れる問題を確実に取る。この戦略をこれから一緒に身につけていきます。

### 確認問題

**問1.** 宅建試験について、正しいものはどれでしょう？

1. 記述式の問題が出題される
2. 50問すべて正解しないと合格できない
3. 4択のマークシート式で、7割前後の得点が合格の目安である
4. 面接試験がある

<details><summary>答えと解説</summary>

正解: **3**

宅建試験は 50問・4択のマークシートのみで、記述も面接もありません。合格ラインは年により変動しますが、おおむね 7割（31〜38点）が目安です。満点を狙う試験ではなく「取れる問題を確実に取る」試験だと覚えておきましょう。

</details>

**問2.** 出題4分野のうち、最も問題数が多く「得点源」と言われる分野はどれでしょう？

1. 権利関係（民法など）
2. 宅建業法
3. 法令上の制限
4. 税・その他

<details><summary>答えと解説</summary>

正解: **2**

宅建業法は 50問中 20問と最多で、ルールを覚えれば確実に得点できるため最大の得点源です。だからこの講座でも宅建業法から学びます。逆に権利関係（14問）は難しいので、深追いせず基本だけ押さえるのが合格戦略です。

</details>

**問3.** 合格戦略として最も適切な考え方はどれでしょう？

1. 全分野を完璧にしてから過去問に進む
2. 難しい民法を最優先で極める
3. 配点の大きい宅建業法を得点源にして、難問は捨てる勇気を持つ
4. 統計問題は数年前の数値を暗記しておけばよい

<details><summary>答えと解説</summary>

正解: **3**

宅建は7割で受かる試験なので、配点の大きい宅建業法（20問）を固めるのが最短ルートです。民法の難問は上級者でも落とします。なお統計問題は毎年数値が変わるため、直前期に最新の公表値を確認する必要があります（古い数値の暗記は逆効果です）。

</details>

## 2. 合格する勉強のしかた

🟡 勉強を始める前に、「受かる人のやり方」をインストールしておきましょう。ここを知っているかどうかで、同じ勉強時間でも結果が大きく変わります。

### なぜ宅建業法から学ぶのか

宅建業法は 50問中 **20問**。しかも内容は「不動産屋さんが守るべきルール」なので、法律の知識ゼロでも**覚えれば得点に直結**します。いちばん易しくて、いちばん配点が大きい。だからこの講座は宅建業法から始めます。

### 毎日の回し方

- **短くてもいいから毎日**やる（週1回3時間より、毎日30分）
- 教科書を読んだら**すぐ問題を解く**。読むだけでは覚えられません
- 間違えた問題こそ宝物。解説を読んで「なぜ間違えたか」を言葉にする

### 過去問（問題演習）の使い方

同じ問題を**何度も繰り返す**のが正解です。目標は「正解の選択肢を選べる」ではなく、**4つの選択肢それぞれに○×の理由を言える**こと。本試験は過去問の焼き直しが多いので、これだけで合格圏に届きます。

> 💡 このアプリでは、全問正解でチャプタークリアです。間違えた問題は自動で記録されるので、解説を読んでからもう一度挑戦しましょう。わからないことは「🙋 質問」ボタンでその場で聞けます。

### 確認問題

**問1.** この講座が宅建業法から学び始める理由として、最も適切なものはどれでしょう？

1. 出題数が最も多く、覚えれば得点に直結する分野だから
2. 民法より出題数は少ないが、最も難しい分野だから
3. 毎年数値が変わるため、早く覚える必要があるから
4. 宅建業法だけ記述式で出題されるから

<details><summary>答えと解説</summary>

正解: **1**

宅建業法は50問中20問と最多で、ルールを覚えれば確実に得点できる分野です。民法（権利関係）のほうが難しいので2は逆です。毎年数値が変わるのは統計問題（直前期に対策）で、宅建試験に記述式はありません。

</details>

**問2.** 問題演習（過去問）の使い方として、最も効果的なものはどれでしょう？

1. 一度解いた問題は二度と解かず、常に新しい問題だけを解く
2. 正解できた問題の解説は読み飛ばして時間を節約する
3. 教科書を全分野読み終えるまで、問題には手を付けない
4. 同じ問題を繰り返し、選択肢ごとに○×の理由を言えるようにする

<details><summary>答えと解説</summary>

正解: **4**

本試験は過去問の焼き直しが多いため、同じ問題を繰り返して「4つの選択肢それぞれの理由」まで説明できるようにするのが最短ルートです。1は定着しません。2は正解でも理由があやふやなことがあるので危険です。3のように読むだけ期間を作ると、覚えたつもりで解けない状態になります。

</details>

**問3.** 学習の習慣について、合格者に多いスタイルはどちらでしょう？

1. 週に1回、まとめて長時間勉強する
2. 短時間でもいいので毎日続ける

<details><summary>答えと解説</summary>

正解: **2**

記憶は間隔を空けて何度も触れることで定着するため、毎日30分のほうが週1回3時間より効果的です。週1回だと前回の内容を忘れた状態から再スタートになり、効率が落ちます。

</details>

## 3. 不動産取引の全体像

🟡 法律の勉強に入る前に、「不動産の取引ってそもそも何？」を身近な例でつかんでおきましょう。ここが見えると、この先の用語がすっと頭に入ります。

### 取引は大きく2種類

- **売買**: 物件を「買う・売る」。マイホーム購入などで、大きなお金が動きます
- **賃貸**: 物件を「借りる・貸す」。アパート探しでおなじみです

### 不動産屋さんの関わり方は3つ

| 関わり方 | 意味 | 身近な例 |
|---|---|---|
| **自ら売買** | 自分が売主（買主）になる | 不動産会社が自社のマンションを販売 |
| **代理** | 本人の代わりに契約まで行う | 売主に頼まれて、会社が代わりに契約を結ぶ |
| **媒介（仲介）** | 売主と買主（貸主と借主）を引き合わせる | アパートを探すとき窓口になってくれる街の不動産屋さん |

あなたがアパートを借りるとき、不動産屋さんは「大家さんと、あなた」の間を取り持っています。これが**媒介**です。契約するのはあくまで大家さんとあなたで、不動産屋さんは橋渡し役です。

> 💡 先に1つだけ予告です。大家さんが自分のアパートを**自ら貸す**行為は、実は宅建業法の「取引」に**当たりません**。次のレッスンで何度も出てくる超重要ポイントなので、頭の片隅に置いておいてください。

### 確認問題

**問1.** アパートを探しに行ったとき、大家さんとあなたの間を取り持って部屋を紹介してくれる不動産屋さんの関わり方はどれでしょう？

1. 自ら売買
2. 代理
3. 媒介（仲介）
4. 賃貸

<details><summary>答えと解説</summary>

正解: **3**

貸主と借主を引き合わせる橋渡し役が媒介（仲介）です。自ら売買は不動産会社自身が売主・買主になること、代理は本人の代わりに契約まで行うことなので異なります。賃貸は取引の種類（借りる・貸す）であって、関わり方の名前ではありません。

</details>

**問2.** 「代理」と「媒介」の違いの説明として、正しいものはどれでしょう？

1. 代理は本人の代わりに契約まで行い、媒介は両者を引き合わせる橋渡し役である
2. 代理は賃貸専用で、媒介は売買専用である
3. どちらも不動産会社自身が売主になることを指す
4. 媒介は国の仕事で、代理は民間の仕事である

<details><summary>答えと解説</summary>

正解: **1**

代理は本人に代わって契約締結まで行うのに対し、媒介は当事者どうしを引き合わせるだけで、契約するのは当事者本人です。2のような売買・賃貸の区別はなく、どちらにも代理・媒介があります。3は「自ら売買」の説明です。4のような区別は存在しません。

</details>

**問3.** 大家さんが自分の持っているアパートを自分で入居者に貸す行為について、正しいものはどれでしょう？

1. 宅建業法の「取引」に当たる
2. 宅建業法の「取引」には当たらない

<details><summary>答えと解説</summary>

正解: **2**

自ら貸借（自分の物件を自分で貸すこと）は宅建業法の「取引」に当たりません。だから街の大家さんは宅建の免許なしでアパート経営ができるのです。これは本試験で何度も問われる最重要のひっかけポイントなので、次のレッスンでじっくり学びます。

</details>
