# 第21章 不動産の税金

不動産には「買うとき・持っているとき・売るとき」のそれぞれに税金がかかります。本試験では税から例年2問。満点は狙わず、課税主体と住宅の特例など「出るところだけ」を効率よく押さえる章です。

## 1. 税金の全体像（いつ払う税か）

不動産の税金は種類が多く見えますが、「**いつ払う税か**」で整理すると一気にシンプルになります。

### 3つの場面で整理する

| 場面 | 税金 | 誰に納める？ |
|---|---|---|
| 買う（取得する）とき | 不動産取得税 | 都道府県（地方税） |
| 買うとき | 登録免許税・印紙税 | 国（国税） |
| 持っているとき | 固定資産税・都市計画税 | 市町村（地方税） |
| 売って利益が出たとき | 譲渡所得に対する所得税 | 国（国税） |

🟡 まずはこの表を覚えましょう。「不動産取得税は都道府県、固定資産税は市町村」という**課税主体**の区別は、4択のひっかけの定番です。

> 💡 コツ: 「取得は**と**どうふけん、固定は**し**ちょうそん」と頭文字で結びつけると混同しません。

本試験では税から例年2問出ます。細かい税率の暗記より、「どの場面の税か・誰が課すか・どんな特例があるか」という骨組みを押さえることが得点への近道です。次のチャプターから、1つずつ見ていきます。

### 確認問題

**問1.** 不動産を「取得したとき」に課される地方税はどれでしょう？

1. 固定資産税
2. 不動産取得税
3. 登録免許税
4. 譲渡所得に対する所得税

<details><summary>答えと解説</summary>

正解: **2**

不動産取得税は、不動産を取得したときに都道府県が課す地方税です。固定資産税は「持っているとき」に毎年かかる税、登録免許税は登記のときにかかる国税、譲渡所得に対する所得税は「売って利益が出たとき」の国税です。

</details>

**問2.** 税金とそれを課す主体（課税主体）の組み合わせとして、正しいものはどれでしょう？

1. 不動産取得税 — 市町村
2. 固定資産税 — 都道府県
3. 不動産取得税 — 都道府県
4. 登録免許税 — 市町村

<details><summary>答えと解説</summary>

正解: **3**

不動産取得税は都道府県が課す地方税です。固定資産税は市町村（都道府県ではありません）、登録免許税は国が課す国税です。「取得税は都道府県・固定資産税は市町村」の入れ替えは本試験でも定番のひっかけなので、確実に区別しましょう。

</details>

**問3.** 次の税金のうち、国税はどれでしょう？

1. 固定資産税
2. 都市計画税
3. 印紙税
4. 不動産取得税

<details><summary>答えと解説</summary>

正解: **3**

印紙税は契約書などに課される国税です（登録免許税・譲渡所得に対する所得税も国税）。固定資産税と都市計画税は市町村が課す地方税、不動産取得税は都道府県が課す地方税です。

</details>

## 2. 不動産取得税と固定資産税

🔴 税の分野でもっともよく出る2つの税金です。似ているからこそ、対比表で違いを覚えましょう。

| | 不動産取得税 | 固定資産税 |
|---|---|---|
| 課税主体 | 都道府県 | 市町村 |
| 納税義務者 | 取得した人（**相続による取得は非課税**） | 毎年**1月1日**現在の所有者（課税台帳に登録された人） |
| 免税点 | 土地10万円・建築による家屋23万円・その他の家屋12万円 | 土地30万円・家屋20万円 |
| 住宅の特例 | 新築住宅は課税標準から**1,200万円を控除**（床面積50〜240㎡） | 新築住宅は**3年間（一定のマンションは5年間）税額が2分の1**（120㎡相当まで） |

さらに固定資産税には**住宅用地の特例**があり、200㎡以下の部分（小規模住宅用地）は課税標準が**6分の1**になります。

> 💡 ゴロ: 免税点は「取得税は **土10・建23・他12**」「固定は **土30・家20**」。数字がそのまま4択で問われます。

税率は、不動産取得税が原則4%（住宅・土地は3%とする特例があります。期限は要確認）、固定資産税が標準税率1.4%です。

### 確認問題

**問1.** 固定資産税について、正しいものはどれでしょう？

1. 都道府県が課税する
2. 毎年4月1日現在の所有者に課税される
3. 納税義務者は、原則としてその年に固定資産を使用している賃借人である
4. 市町村が、毎年1月1日現在の所有者に課税する

<details><summary>答えと解説</summary>

正解: **4**

固定資産税は市町村が課す地方税で、賦課期日である毎年1月1日現在、課税台帳に所有者として登録されている人が納税義務者です。都道府県が課すのは不動産取得税です。4月1日や賃借人という選択肢は、どちらも誤りの定番パターンです。

</details>

**問2.** 次の原因で不動産を取得した場合のうち、不動産取得税が課されないものはどれでしょう？

1. 売買による取得
2. 贈与による取得
3. 相続による取得
4. 交換による取得

<details><summary>答えと解説</summary>

正解: **3**

相続による取得は、本人の意思によらない形式的な承継なので不動産取得税は非課税です。一方、売買・交換はもちろん、贈与による取得にも課税されます。「贈与も非課税」と誤解しやすいので注意しましょう。

</details>

**問3.** 固定資産税の免税点について、土地の場合の金額はどれでしょう？

1. 10万円
2. 20万円
3. 30万円
4. 23万円

<details><summary>答えと解説</summary>

正解: **3**

固定資産税の免税点は、土地30万円・家屋20万円です（課税標準がこれ未満なら課税されません）。10万円と23万円は不動産取得税の免税点（土地10万円・建築による家屋23万円）なので、混ぜたひっかけに注意してください。

</details>

**問4.** 新築住宅（床面積50〜240㎡）を取得した場合の不動産取得税の特例として、正しいものはどれでしょう？

1. 課税標準から1,200万円が控除される
2. 税額から1,200万円が控除される
3. 課税標準が6分の1になる
4. 3年間、税額が2分の1になる

<details><summary>答えと解説</summary>

正解: **1**

新築住宅の特例は「課税標準から1,200万円を控除」です。税額から引くのではなく、税率を掛ける前の課税標準から引く点がポイントです。課税標準6分の1は固定資産税の住宅用地の特例、3年間税額2分の1は固定資産税の新築住宅の特例で、別の税の話です。

</details>

**問5.** 固定資産税の住宅用地の特例について、正しいものはどれでしょう？

1. 住宅用地はすべて非課税となる
2. 200㎡以下の部分は課税標準が3分の1になる
3. 200㎡以下の部分は課税標準が6分の1になる
4. 200㎡を超える部分のみ課税標準が6分の1になる

<details><summary>答えと解説</summary>

正解: **3**

小規模住宅用地（200㎡以下の部分）は課税標準が6分の1になります。非課税になるわけではありません。3分の1は200㎡を「超える」部分（一般住宅用地）に適用される割合なので、「以下＝6分の1、超える部分＝3分の1」とセットで覚えましょう。

</details>

## 3. 印紙税と登録免許税

どちらも「買うとき」に関わる**国税**です。地味ですが、覚えることが少なく得点しやすいテーマです。

### 印紙税

契約書などの**課税文書**に収入印紙を貼り、消印して納めます。

- 売買契約書は、記載された契約金額が課税標準になります。**贈与契約書は「記載金額のない文書」**として扱われます
- 印紙を貼らなくても**契約自体は有効**です。ただし、本来の税額＋その2倍＝**3倍の過怠税**がかかります
- **国や地方公共団体が作成した文書は非課税**です

### 登録免許税

登記を受けるときに納める税です。

- 納税義務者は**登記を受ける者**（売買なら売主と買主が連帯して納付）
- 課税標準は**固定資産課税台帳の登録価格**です（実際の売買価格ではありません！）
- 住宅用家屋の税率軽減は、自己の居住用・床面積50㎡以上などが要件で、**土地には適用されません**

🟡 ひっかけの定番は次の2つです。

> 💡 「印紙を貼り忘れた契約書は無効」→ 誤り（有効）。「登録免許税の課税標準は売買代金」→ 誤り（台帳価格）。

### 確認問題

**問1.** 土地の売買契約書に収入印紙を貼らなかった場合の扱いとして、正しいものはどれでしょう？

1. 契約は有効だが、過怠税が課されることがある
2. 契約は無効になる
3. 契約は取り消すことができるものになる
4. 印紙税の納税義務そのものが消滅する

<details><summary>答えと解説</summary>

正解: **1**

印紙を貼らなくても契約の効力には影響せず、有効です。ただし納付しなかった印紙税額とその2倍（合計3倍）の過怠税が課されます。「無効になる」「取り消せる」は定番のひっかけで、税金の問題と契約の効力は別の話だと覚えましょう。

</details>

**問2.** 印紙税について、正しいものはどれでしょう？

1. 贈与契約書には、贈与する不動産の時価を記載金額として課税される
2. 国が作成する文書にも印紙税が課される
3. 売買契約書は、買主が保管する1通にのみ印紙を貼ればよい
4. 贈与契約書は、記載金額のない文書として扱われる

<details><summary>答えと解説</summary>

正解: **4**

贈与は対価がないため、贈与契約書は「記載金額のない文書」として扱われます（時価を基準にはしません）。国や地方公共団体が作成する文書は非課税です。また、契約書を2通作成して双方が保管する場合は、2通それぞれが課税文書になります。

</details>

**問3.** 登録免許税の課税標準として、正しいものはどれでしょう？

1. 実際の売買契約で定めた代金の額
2. 固定資産課税台帳に登録された価格
3. 不動産鑑定士が評価した時価
4. 公示価格

<details><summary>答えと解説</summary>

正解: **2**

登録免許税の課税標準は、固定資産課税台帳の登録価格です。実際の売買代金ではない点が最大のひっかけポイントです。鑑定評価額や公示価格を使うという規定もありません。

</details>

**問4.** 住宅用家屋の所有権移転登記に係る登録免許税の税率軽減について、正しいものはどれでしょう？

1. 床面積の要件はない
2. 投資用（貸家用）の住宅にも適用される
3. 住宅とともに取得した土地の登記にも適用される
4. 自己の居住用で、床面積50㎡以上などの要件を満たす家屋に適用される

<details><summary>答えと解説</summary>

正解: **4**

この軽減は、自己の居住の用に供する床面積50㎡以上の家屋などの要件を満たす場合に適用されます。自分が住むことが前提なので貸家用は対象外、床面積要件もあります。そして適用されるのは家屋の登記だけで、土地には適用されません。

</details>

## 4. 譲渡所得（3,000万円特別控除をざっくり）

不動産を売って利益（譲渡所得）が出ると、所得税がかかります。給与などとは分けて計算する**分離課税**です。

### 長期と短期

**譲渡した年の1月1日時点**で所有期間が**5年を超える**と「長期譲渡所得」となり、税率が低くなります。「売った日」までで数えるのではない、という点がひっかけポイントです。

### 居住用財産の3,000万円特別控除

自分が住んでいた家（居住用財産）を売ったときは、譲渡所得から**最高3,000万円を控除**できます。

- **所有期間は問いません**（短期でも使えます）
- 配偶者や直系血族など**特別な関係者への譲渡には使えません**
- 前年・前々年に使っていると使えません（いわば3年に1度）

### 10年超なら軽減税率も

⚪ 所有期間が10年を超える居住用財産には**軽減税率の特例**もあり、3,000万円控除と**併用できます**。細かい計算式まで覚える必要はなく、「どんなときに使えるか」だけ押さえれば十分です（期限付きの特例もあるため、受験年度の制度は要確認）。

### 確認問題

**問1.** 土地を譲渡した場合に長期譲渡所得となるのは、どのような場合でしょう？

1. 譲渡した年の1月1日において、所有期間が5年を超える場合
2. 譲渡した日において、所有期間が5年を超える場合
3. 取得した年の1月1日から3年を経過した場合
4. 登記をしてから5年を経過した場合

<details><summary>答えと解説</summary>

正解: **1**

長期か短期かは「譲渡した年の1月1日時点」で所有期間が5年を超えるかで判定します。実際に売った日まで数えるのではないため、暦の上では5年以上持っていても短期扱いになることがあります。登記の時期は判定に関係ありません。

</details>

**問2.** 居住用財産の3,000万円特別控除について、正しいものはどれでしょう？

1. 所有期間が5年を超えていなければ適用できない
2. 配偶者に譲渡した場合にも適用できる
3. 所有期間にかかわらず適用できる
4. 毎年連続して適用を受けることができる

<details><summary>答えと解説</summary>

正解: **3**

3,000万円特別控除は所有期間を問わず使えるのが特徴です（長期・短期どちらでも可）。ただし配偶者や直系血族など特別な関係者への譲渡には使えず、前年・前々年に適用を受けていると使えないため「毎年使える」も誤りです。

</details>

**問3.** 所有期間10年超の居住用財産を譲渡した場合について、正しいものはどれでしょう？

1. 軽減税率の特例を使う場合、3,000万円特別控除は適用できない
2. 3,000万円特別控除を使う場合、譲渡所得は必ずゼロになる
3. 軽減税率の特例は所有期間5年超で適用できる
4. 3,000万円特別控除と軽減税率の特例は、重ねて適用できる

<details><summary>答えと解説</summary>

正解: **4**

所有期間10年超の居住用財産では、3,000万円特別控除を適用したうえで、残った譲渡所得に軽減税率の特例を重ねて使えます。軽減税率の要件は10年超であり5年超ではありません。また控除後も譲渡所得が残ることはあるので「必ずゼロ」も誤りです。

</details>
