**問1.** 【問1】制限行為能力者に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 未成年者が法定代理人の同意を得ずに行った法律行為は、単に権利を得るだけの行為であっても取り消すことができる
2. 成年被後見人が成年後見人の事前の同意を得て行った不動産の売買契約は、取り消すことができない
3. 被保佐人が保佐人の同意を得ずに自己所有の不動産を売却した場合、その売買契約は取り消すことができる
4. 未成年者が詐術を用いて自分を成年者であると相手方に信じさせて締結した契約は、取り消すことができる

<details><summary>答えと解説</summary>

正解: **3**

不動産の売却は民法13条1項の重要な財産行為なので、被保佐人が保佐人の同意（または同意に代わる家庭裁判所の許可）なしに行えば取り消せます。単に権利を得るだけの行為は未成年者が単独でできるので肢1は誤り。成年被後見人の行為は事前の同意があっても日用品の購入等を除き取り消せるので肢2も誤り。詐術を用いた制限行為能力者は保護に値しないため取消しできず、肢4も誤りです。

</details>

**問2.** 【問2】Aは代理権がないにもかかわらずBの代理人と称して、B所有の土地をCに売却する契約を締結した。民法の規定によれば正しいものはどれでしょう？

1. Bがこの契約を追認すると、契約の効力は原則として契約の時にさかのぼってBに帰属する
2. CがAに代理権がないことを知っていた場合、CはBに対して追認するかどうかを確答すべき旨の催告をすることができない
3. CがAに代理権がないことを知っていた場合でも、Bの追認前であれば、Cはこの契約を取り消すことができる
4. Bが追認を拒絶した場合、Cは善意無過失であっても、Aに対して履行や損害賠償を請求することはできない

<details><summary>答えと解説</summary>

正解: **1**

無権代理行為の追認は、別段の意思表示がなければ契約の時にさかのぼって効力を生じます（遡及効）。催告は相手方が悪意（代理権がないと知っていた）でもできるので肢2は誤り。一方、相手方からの取消しは善意の場合に限られるため肢3も誤りです。追認拒絶の場合、善意無過失の相手方は無権代理人に履行または損害賠償を請求できるので肢4も誤りです。

</details>

**問3.** 【問3】意思表示に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. AとBが通謀してA所有の土地をBに売却したように仮装した場合、事情を知らずにBからその土地を買い受けたCが保護されるためには、Cに過失がないことが必要である
2. 買主が契約の基礎とした事情（動機）についての錯誤を理由に取り消すには、その事情が法律行為の基礎とされていることが表示されていたことが必要である
3. 錯誤による意思表示の取消しは、取消し前に利害関係に入った善意無過失の第三者に対しても対抗できる
4. 表意者に重大な過失があった場合、相手方が錯誤の事実を知っていたときでも、錯誤による取消しは一切できない

<details><summary>答えと解説</summary>

正解: **2**

いわゆる動機の錯誤（基礎事情の錯誤）で取り消すには、その事情が契約の基礎とされていることが表示されていたことが必要です。虚偽表示の無効を対抗できない第三者は「善意」であれば足り、無過失は不要なので肢1は誤り。錯誤取消しは善意無過失の第三者には対抗できないので肢3も誤りです。重過失があっても、相手方が悪意または重過失のときや相手方も同一の錯誤に陥っていたときは取り消せるため、肢4の「一切できない」は誤りです。

</details>

**問4.** 【問4】不動産の物権変動と登記に関する次の記述のうち、正しいものはどれでしょう？

1. 不動産が二重に譲渡された場合、先に売買契約を締結した買主が、登記がなくても常に優先する
2. 背信的悪意者に対しては、登記がなければ所有権の取得を対抗することができない
3. 相続により不動産の所有権を取得した者は、登記を申請するかどうかは完全に自由であり、申請しなくても法律上の不利益は一切ない
4. 取得時効の完成後に、元の所有者からその不動産を買い受けて登記を備えた第三者に対しては、時効取得者は登記がなければ所有権の取得を対抗できない

<details><summary>答えと解説</summary>

正解: **4**

時効完成「後」に現れた第三者とは対抗関係に立つため、時効取得者は登記がなければ対抗できません（完成「前」の第三者には登記不要）。二重譲渡は契約の先後ではなく登記の先後で決まるので肢1は誤り。背信的悪意者には登記なくして対抗できるので肢2も誤りです。また、相続登記は義務化されており、取得を知った日から3年以内に申請しないと正当な理由がない限り10万円以下の過料の対象になるため、肢3も誤りです。

</details>

**問5.** 【問5】法定地上権に関する次の記述のうち、民法の規定および判例によれば正しいものはどれでしょう？

1. 抵当権設定当時に土地の上に建物が存在し、土地と建物の所有者が同一であった場合において、土地に設定された抵当権の実行により土地と建物の所有者が異なるに至ったときは、法定地上権が成立する
2. 更地に抵当権が設定された後にその土地上に建物が築造された場合でも、競売により土地と建物の所有者が異なれば法定地上権が成立する
3. 法定地上権が成立するためには、抵当権設定当時に建物について所有権の登記がされていたことが必要である
4. 抵当権設定当時に土地と建物の所有者が異なっていた場合でも、法定地上権は成立する

<details><summary>答えと解説</summary>

正解: **1**

法定地上権の成立要件は、①抵当権設定当時に建物が存在、②その当時土地と建物が同一所有者、③土地・建物の一方または双方に抵当権、④競売で所有者が別々になったこと、の4つです。更地に設定した後の建物には成立しないので肢2は誤り（一括競売はできますが優先弁済は土地の代金からのみ）。建物の登記は要件ではないので肢3も誤り。設定当時に所有者が異なる場合も成立しないため肢4も誤りです。

</details>

**問6.** 【問6】売買契約の目的物が品質に関して契約の内容に適合しない場合に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 買主が売主に対して目的物の修補などの追完を請求するには、売主に帰責事由があることが必要である
2. 買主が売主に対して損害賠償を請求する場合、売主に帰責事由がなくても認められる
3. 買主が相当の期間を定めて追完の催告をし、その期間内に追完がないときは、買主は不適合の程度に応じて代金の減額を請求することができる
4. 買主は、引渡しの時から1年以内に不適合の事実を売主に通知しなければ、原則として売主の責任を追及できなくなる

<details><summary>答えと解説</summary>

正解: **3**

代金減額請求は、原則として相当の期間を定めた追完の催告をし、期間内に追完がないことが要件です（追完不能などの場合は催告不要）。追完請求と解除に売主の帰責事由は不要なので肢1は誤り。逆に損害賠償請求には売主の帰責事由が必要なので肢2も誤りです。通知期間の起算点は「引渡しの時」ではなく「買主が不適合を知った時」から1年なので、肢4も誤りです。

</details>

**問7.** 【問7】売買契約において解約手付が交付された場合に関する次の記述のうち、民法の規定および判例によれば正しいものはどれでしょう？

1. 買主は、自らが履行に着手した後は、相手方である売主が履行に着手していなくても、手付を放棄して契約を解除することができない
2. 売主が手付による解除をするには、手付の倍額を現実に提供することが必要であり、口頭で倍額を償還する旨を告げるだけでは足りない
3. 手付による解除をした当事者は、相手方に対して、別途債務不履行による損害賠償義務を負う
4. 売買契約で交付された手付は、当事者間に特約がなければ違約手付と推定される

<details><summary>答えと解説</summary>

正解: **2**

売主からの手付解除は「倍額を現実に提供」することが必要で、口頭の申出だけでは解除できません。解除が制限されるのは「相手方」が履行に着手した後であり、自分が着手していても相手方が未着手なら解除できるので肢1は誤り。手付解除は債務不履行ではないため損害賠償の問題は生じず、肢3も誤りです。手付は特約がなければ解約手付と推定されるので肢4も誤りです。

</details>

**問8.** 【問8】建物賃貸借における敷金に関する次の記述のうち、民法の規定および判例によれば正しいものはどれでしょう？

1. 賃貸借契約が終了したときは、賃借人は建物の明渡しと引換えに敷金の返還を請求することができる
2. 賃借人は、賃貸借の存続中に未払賃料がある場合、賃貸人に対し、敷金をその弁済に充てるよう請求することができる
3. 賃借人が賃貸人の承諾を得て賃借権を第三者に譲渡した場合、敷金に関する権利義務は原則として新賃借人に承継される
4. 賃貸建物が譲渡されて賃貸人の地位が譲受人に移転した場合、敷金に関する権利義務は原則として新賃貸人に承継される

<details><summary>答えと解説</summary>

正解: **4**

賃貸人が交替した場合、敷金関係は（未払賃料等に充当された残額について）新賃貸人に当然に承継されます。敷金の返還は明渡しが先履行であり、同時履行の関係に立たないので肢1は誤り。敷金の充当は賃貸人側の判断ででき、賃借人からは請求できないので肢2も誤り。賃借人が交替した場合には敷金関係は原則として承継されないため、肢3も誤りです。

</details>

**問9.** 【問9】借地借家法の定期借地権に関する次の記述のうち、正しいものはどれでしょう？

1. 事業用定期借地権の設定を目的とする契約は、公正証書によってしなければならない
2. 存続期間を50年以上とする一般定期借地権の設定契約は、公正証書によらなければ効力を生じない
3. 一般定期借地権の存続期間は、30年以上であれば足りる
4. 事業用定期借地権は、従業員の社宅など居住の用に供する建物の所有を目的とする場合にも設定することができる

<details><summary>答えと解説</summary>

正解: **1**

事業用定期借地権（存続期間10年以上50年未満）の設定契約は、必ず公正証書で行わなければなりません。一般定期借地権は書面（または電磁的記録）であればよく、公正証書に限られないので肢2は誤りです。一般定期借地権の存続期間は50年以上なので肢3も誤り。事業用定期借地権は「専ら事業の用に供する建物」が対象で、居住用建物（社宅を含む）の所有目的では設定できないため肢4も誤りです。

</details>

**問10.** 【問10】定期建物賃貸借（定期借家契約）に関する次の記述のうち、借地借家法の規定によれば正しいものはどれでしょう？

1. 定期建物賃貸借契約では、期間を1年未満とすることはできない
2. 定期建物賃貸借契約は、口頭の合意によっても有効に成立する
3. 賃貸人が、契約の締結に先立ち、更新がなく期間満了により終了する旨を記載した書面を交付して（賃借人の承諾を得れば電磁的方法でもよい）説明しなかったときは、更新がない旨の定めは無効となる
4. 定期建物賃貸借において、借賃の減額請求をしない旨の特約は無効である

<details><summary>答えと解説</summary>

正解: **3**

定期建物賃貸借では、契約書とは別に、事前に「更新がなく期間満了で終了する」ことを書面（承諾があれば電磁的方法も可）で説明する義務があり、怠ると更新がない旨の定めが無効になります（＝普通借家になる）。定期借家は1年未満の期間も有効なので肢1は誤り。契約自体も書面（または電磁的記録）が必要なので肢2も誤りです。定期借家では減額請求を排除する特約も有効なため、肢4も誤りです。

</details>

**問11.** 【問11】遺言および遺留分に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 被相続人の兄弟姉妹にも、遺留分が認められる
2. 遺留分を侵害する遺贈がされた場合、遺留分権利者は、受遺者に対して遺留分侵害額に相当する金銭の支払を請求することができる
3. 相続の開始前に遺留分を放棄するには、家庭裁判所の許可を受ける必要はない
4. 自筆証書遺言は、全文・日付・氏名を自書すれば、押印がなくても有効である

<details><summary>答えと解説</summary>

正解: **2**

現行民法では、遺留分を侵害された者は目的物そのものの返還ではなく「遺留分侵害額に相当する金銭」の支払を請求します（遺留分侵害額請求権）。遺留分は兄弟姉妹には認められないので肢1は誤り。相続開始前の遺留分放棄には家庭裁判所の許可が必要なので肢3も誤りです。自筆証書遺言には押印が必要なため、肢4も誤りです（財産目録は自書不要ですが毎葉に署名押印が必要です）。

</details>

**問12.** 【問12】A・B・Cが各3分の1の持分で建物を共有している場合に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 共有建物に、その形状または効用の著しい変更を加えるには、持分の価格の過半数の同意があれば足りる
2. 共有建物の不法占拠者に対する妨害排除の請求は、共有者全員が共同で行わなければならない
3. Cが自己の持分を第三者に譲渡するには、AおよびBの同意を得なければならない
4. 共有建物をAが単独で使用している場合でも、共有建物の管理に関する事項は、持分の価格の過半数で決することができる

<details><summary>答えと解説</summary>

正解: **4**

共有物を現に使用する共有者がいても、管理に関する事項は持分価格の過半数で決定できます（令和3年民法改正で明文化）。軽微でない変更（著しい変更）には共有者全員の同意が必要なので肢1は誤り。不法占拠者への妨害排除請求は保存行為として各共有者が単独でできるので肢2も誤りです。自己の持分の処分は各共有者の自由であり、他の共有者の同意は不要なため肢3も誤りです。

</details>

**問13.** 【問13】債権譲渡に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 譲渡制限の意思表示（譲渡禁止特約）が付された債権（預貯金債権を除く）を譲渡した場合、その譲渡は無効である
2. 債権譲渡を債務者に対抗するための通知は、譲受人から債務者に対して行うことができる
3. 債権譲渡を債務者以外の第三者に対抗するには、確定日付のある証書による通知または承諾が必要である
4. 現に発生していない将来の債権は、譲渡することができない

<details><summary>答えと解説</summary>

正解: **3**

二重譲渡の譲受人など債務者以外の第三者への対抗要件は、確定日付のある証書（内容証明郵便など）による通知または承諾です。譲渡制限特約付きの債権でも譲渡自体は有効（悪意・重過失の譲受人に対して債務者が履行を拒めるだけ）なので肢1は誤り。通知は「譲渡人」から行う必要があり、譲受人からの通知では対抗できないので肢2も誤りです。将来債権も譲渡できるため肢4も誤りです。

</details>

**問14.** 【問14】弁済および相殺に関する次の記述のうち、民法の規定によれば正しいものはどれでしょう？

1. 悪意による不法行為に基づく損害賠償債務の債務者（加害者）は、被害者に対して有する貸金債権を自働債権として、その損害賠償債務と相殺することができない
2. 悪意による不法行為の被害者も、自己の損害賠償債権を自働債権として、加害者に対する債務と相殺することはできない
3. 弁済をするについて正当な利益を有しない第三者は、債務者の意思に反する場合でも、常に有効に弁済することができる
4. 時効によって消滅した債権は、その消滅以前に相殺適状にあった場合でも、自働債権として相殺に用いることができない

<details><summary>答えと解説</summary>

正解: **1**

悪意による不法行為に基づく損害賠償債権を「受働債権」とする相殺（＝加害者側からの相殺）は禁止されています。被害者を現実の賠償で救済するためです。逆に被害者側からの相殺は可能なので肢2は誤り。正当な利益のない第三者は原則として債務者の意思に反して弁済できないので肢3の「常に」は誤りです。時効消滅前に相殺適状にあった債権は自働債権として相殺できるため、肢4も誤りです。

</details>

**問15.** 【問15】都市計画法の用途地域等に関する次の記述のうち、正しいものはどれでしょう？

「必ず値上がりします」のような断定的判断の提供は、故意かどうかを問わず禁止されています。手付の貸付けや分割払いの提案による契約の誘引は、返済の見込みがあっても禁止なので肢2は誤り。契約しない旨の意思（勧誘を望まない意思を含む）を表示した相手への勧誘の継続は禁止されているので肢3も誤りです。守秘義務は宅建業を営まなくなった後も続くため、肢4も誤りです。

**問21.** 【問46】独立行政法人住宅金融支援機構に関する次の記述のうち、正しいものはどれでしょう？

2. 証券化支援事業（買取型）の対象となる貸付債権は、新築住宅の建設・購入に係るものに限られ、中古住宅の購入に係るものは含まれない

**問22.** 【問47】不動産の表示に関する公正競争規約（景品表示法に基づく表示規約）に関する次の記述のうち、正しいものはどれでしょう？

1. 「新築」と表示できるのは、建築工事完了後2年未満であって、かつ未使用の建物である
2. 徒歩による所要時間は、道路距離80mにつき1分間を要するものとして算出し、1分未満の端数は1分に切り上げて表示する

2. 後背湿地は、自然堤防に比べて水はけがよく、宅地に適している
3. 台地や丘陵地は一般に水はけがよく地盤も安定していて宅地に適しているが、その縁辺部の崖や谷の部分は、崩壊や水害の危険に注意が必要である

**問24.** 【問49】建物の構造に関する次の記述のうち、最も適切なものはどれでしょう？

1. 鉄骨構造は不燃構造であるが、火熱を受けると耐力が低下するため、耐火構造とするには耐火材料による被覆が必要である
2. 鉄筋コンクリート構造は、耐火性・耐久性に優れ、自重が非常に軽いことが特徴である
3. 免震構造とは、柱や梁を太くして建物自体の強度を高め、地震力に抵抗する構造をいう
4. 在来軸組工法の木造建築物では、筋かいなどで壁面を補強する必要はない

<details><summary>答えと解説</summary>

**問25.** 【問50】宅建試験の統計問題（問48で出題される分野）への対策として、最も適切な考え方はどれでしょう？

1. 統計問題は、数年前に公表された数値を正確に暗記しておけば十分対応できる
2. 統計問題は複雑な計算が要求されるため、最初から捨て問にするのが合理的である
3. 地価公示や建築着工統計は、統計問題の題材としてはほとんど取り上げられない
4. 地価公示・建築着工統計・法人企業統計などについて「前年と比べて増加したか減少したか」という増減の方向が問われることが多いため、試験直前に最新の公表値を確認するのが効果的である

<details><summary>答えと解説</summary>

正解: **4**

統計問題の典型的な出題のされ方は、地価の対前年変動、新設住宅着工戸数の増減、不動産業の売上高・経常利益の増減、宅建業者数の増減などを「増えたか減ったか」の形で問うものです。数値は毎年変わるため、古い数値の暗記はかえって危険であり肢1は誤り。計算は不要で、直前の確認だけで1点取れる分野なので捨てるのはもったいなく、肢2も誤りです。地価公示や建築着工統計はまさに定番の題材なので、肢3も誤りです。

</details>
