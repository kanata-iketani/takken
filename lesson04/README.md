# 第4章 営業保証金と保証協会

業者が「もしも」に備えてお金を預けておく仕組みの章です。営業保証金の1,000万・500万と、保証協会の60万・30万。数字の対比が命なので、最後の比較表まで駆け抜けましょう。

## 1. 営業保証金とは ― 本店1000万・支店500万

🔴 不動産取引は動くお金が大きいぶん、業者の不手際でお客さんが損をしたら大変です。そこで宅建業法は、**業者にあらかじめお金を預けさせておき、いざというときお客さんがそこから弁済を受けられる**仕組みを作りました。それが**営業保証金**です。

### 金額（超頻出！）

| 事務所 | 供託額 |
|---|---|
| 主たる事務所（本店） | **1,000万円** |
| その他の事務所（支店）ごと | **500万円** |

> 💡 「**本店セン（1,000）万、支店はその半分の500万**」。本店＋支店2つなら 1,000万 + 500万 × 2 = **2,000万円**です。

### どこに・どうやって預ける？

- 預け先（供託先）は、**主たる事務所の最寄りの供託所**。支店の分もまとめて本店の最寄りに供託します
- **金銭**のほか、国債などの**有価証券**でも供託できます（国債は額面の100%、地方債・政府保証債は90%、その他は80%で評価）

### いつから営業できる？

供託しただけではまだダメです。**供託した旨を免許権者（知事や大臣）に届け出た後**でなければ、事業を開始できません。「免許 → 供託 → 届出 → 営業開始」の順番です。

### 確認問題

**問1.** 本店のほかに支店を3つ設けて宅建業を営む場合、供託すべき営業保証金の合計額はいくらでしょう？

1. 1,000万円
2. 1,500万円
3. 2,500万円
4. 3,000万円

<details><summary>答えと解説</summary>

正解: **3**

本店1,000万円 + 支店500万円 × 3 = 2,500万円です。1は本店分のみ、2は支店1つ分しか計算していません。4は支店を1,000万円で計算した誤りです。「本店1,000万・支店ごとに500万」を確実に覚えましょう。

</details>

**問2.** 営業保証金の供託先として、正しいものはどれでしょう？

1. 本店の分は本店の最寄りの供託所、支店の分は各支店の最寄りの供託所
2. 支店の分も含めて、すべて主たる事務所の最寄りの供託所
3. 免許を受けた都道府県庁
4. 国土交通省

<details><summary>答えと解説</summary>

正解: **2**

営業保証金は、支店の分も含めた全額を主たる事務所（本店）の最寄りの供託所にまとめて供託します。1のように事務所ごとに分けて供託するわけではない点がひっかけどころです。3・4のような役所は供託先ではありません。

</details>

**問3.** 営業保証金と事業の開始に関する記述として、正しいものはどれでしょう？

1. 免許を受ければ、供託前でも事業を開始できる
2. 供託さえすれば、届出をしなくても事業を開始できる
3. 供託した旨を免許権者に届け出た後でなければ、事業を開始できない
4. 事業を開始してから3か月以内に供託すればよい

<details><summary>答えと解説</summary>

正解: **3**

事業を開始できるのは、供託し、かつその旨を免許権者に届け出た後です。「免許→供託→届出→営業開始」の順番を覚えましょう。1は供託前、2は届出前に開始できるとしている点が誤りで、4のような後払いは認められません。

</details>

**問4.** 営業保証金の供託方法に関する記述として、正しいものはどれでしょう？

1. 金銭のみで供託しなければならず、有価証券は使えない
2. どんな有価証券でも額面の100%で評価される
3. 不動産で供託することもできる
4. 金銭のほか、国債などの有価証券でも供託できる

<details><summary>答えと解説</summary>

正解: **4**

営業保証金は金銭のほか有価証券でも供託できるため、1は誤りです。評価額は国債が額面の100%、地方債・政府保証債が90%、その他が80%と差があるため、2も誤りです。3の不動産による供託は認められていません。

</details>

## 2. 営業保証金の還付と不足額の補充

🟡 預けた営業保証金は、実際にどう使われるのでしょうか。お客さんが払い戻しを受ける**還付**と、減った分を業者が埋め直す**補充**の流れを見ていきます。

### 還付 ― お客さんがお金を受け取る

宅建業者との**宅建業に関する取引**で損害を受け、債権を持つことになった人は、供託されている営業保証金から**還付**（弁済）を受けられます。受け取れるのは供託額の範囲内です。

> 💡 ただし、**宅建業者は還付を受けられません**。この制度はあくまで一般のお客さん（消費者）を守るためのもので、プロ同士の取引までは守りません。また「宅建業に関する取引」の債権に限られるので、たとえば事務所の内装工事代金のような債権では還付を受けられません。

### 補充 ― 減った分を2週間以内に埋める

還付が行われると、供託されている営業保証金が不足します。そのままでは次の被害者を守れないので、業者は補充しなければなりません。

| ステップ | 期限 |
|---|---|
| 免許権者から不足の**通知**を受ける → 不足額を**供託** | 通知を受けた日から **2週間以内** |
| 供託したことを免許権者に**届出** | 供託した日から **2週間以内** |

**「通知から2週間で供託、供託から2週間で届出」**。2週間が2回続くリズムで覚えましょう。

### 確認問題

**問1.** 営業保証金の還付を受けられる者として、正しいものはどれでしょう？

1. 宅建業に関する取引で生じた債権を有する者（宅建業者を除く）
2. 宅建業に関する取引で生じた債権を有する者（宅建業者を含む）
3. その業者と取引をしたすべての者（債権の種類を問わない）
4. その業者の従業員

<details><summary>答えと解説</summary>

正解: **1**

還付を受けられるのは、宅建業に関する取引から生じた債権を持つ者で、宅建業者は除かれます。消費者保護の制度だからです。2は宅建業者を含めている点が誤り、3は内装工事代金のような宅建業の取引以外の債権まで含めている点が誤りです。4の従業員の給料なども対象外です。

</details>

**問2.** 還付により営業保証金が不足した場合の手続きとして、正しいものはどれでしょう？

1. 免許権者から通知を受けた日から1週間以内に不足額を供託する
2. 免許権者から通知を受けた日から2週間以内に不足額を供託する
3. 不足したままでも、次の免許更新時に供託すればよい
4. 不足額は免許権者が代わりに供託してくれる

<details><summary>答えと解説</summary>

正解: **2**

不足の通知を受けた日から2週間以内に不足額を供託しなければなりません。1の1週間は他の数字との混同を誘うひっかけです。3のように放置すると次の被害者を守れないため認められず、4のような代位供託の制度もありません。

</details>

**問3.** 不足額を供託した後の手続きとして、正しいものはどれでしょう？

1. 供託した日から2週間以内に、その旨を免許権者に届け出る
2. 供託すれば手続きは完了し、届出は不要である
3. 供託した日から3か月以内に届け出ればよい
4. 取引の相手方に通知すれば足りる

<details><summary>答えと解説</summary>

正解: **1**

不足額を供託したときは、供託した日から2週間以内に免許権者へ届け出ます。「通知から2週間で供託、供託から2週間で届出」とセットで覚えましょう。2は届出を不要としている点が誤りで、3は期間が誤り、4のような相手方への通知で代えることはできません。

</details>

## 3. 保証協会と弁済業務保証金 ― 60万・30万の分担金

🔴 「本店だけでも1,000万円」の営業保証金は、開業したての業者には重すぎます。そこで用意されたのが**保証協会**に加入する道です。実際、ほとんどの業者はこちらを選んでいます。

### 保証協会のしくみ

保証協会は宅建業者だけが加入できる団体で、加入は**任意**。ただし**複数の協会に重ねて加入することはできません**。加入した業者（**社員**と呼びます）は、営業保証金の代わりに**弁済業務保証金分担金**を協会に納めます。

| 事務所 | 分担金 |
|---|---|
| 主たる事務所（本店） | **60万円** |
| その他の事務所（支店）ごと | **30万円** |

> 💡 **「ロクサン（60・30）の保証協会」**。1,000万・500万と比べると圧倒的に軽い負担です。分担金は加入しようとする日**まで**に、**金銭のみ**で納付します（有価証券は不可！）。協会はそれを受けて、納付から**1週間以内**に供託所へ弁済業務保証金を供託します。

### お客さんへの還付と、その後

お客さんは、業者が**営業保証金を供託していたなら受けられたはずの額**（本店のみなら1,000万円）の範囲で還付を受けられます。還付が行われたら、社員は協会から通知を受けた日から**2週間以内**に**還付充当金**を納付します。納付しないと**社員の地位を失い**、その日から**1週間以内**に営業保証金を供託しなければ営業を続けられません。

### 確認問題

**問1.** 保証協会に加入する場合の弁済業務保証金分担金の額として、正しいものはどれでしょう？

1. 主たる事務所1,000万円、その他の事務所ごとに500万円
2. 主たる事務所100万円、その他の事務所ごとに50万円
3. 主たる事務所60万円、その他の事務所ごとに30万円
4. 事務所の数にかかわらず一律60万円

<details><summary>答えと解説</summary>

正解: **3**

分担金は本店60万円、支店ごとに30万円です。1は営業保証金の額との混同を誘うひっかけです。2のような額の規定はなく、4も誤りで、支店ごとに30万円ずつ加算されます。

</details>

**問2.** 弁済業務保証金分担金の納付に関する記述として、正しいものはどれでしょう？

1. 金銭のほか、国債などの有価証券でも納付できる
2. 金銭で納付しなければならず、有価証券では納付できない
3. 加入後3か月以内に納付すればよい
4. 供託所に直接納付する

<details><summary>答えと解説</summary>

正解: **2**

分担金は金銭のみで納付しなければなりません。有価証券でも供託できる営業保証金との違いを突くのが1のひっかけです。納付期限は「加入しようとする日まで」なので3は誤りです。納付先は保証協会であり、供託所に供託するのは協会の仕事なので4も誤りです。

</details>

**問3.** 保証協会への加入に関する記述として、正しいものはどれでしょう？

1. すべての宅建業者は保証協会に加入しなければならない
2. 複数の保証協会に重ねて加入することができる
3. 保証協会に加入すれば、免許は不要になる
4. 保証協会に加入できるのは宅建業者に限られ、重ねて複数の協会に加入することはできない

<details><summary>答えと解説</summary>

正解: **4**

保証協会に加入できるのは宅建業者だけで、一つの協会にしか加入できません。加入は任意なので1は誤りです（加入しないなら営業保証金を供託します）。2は重複加入を認めている点が誤りです。3も明らかに誤りで、協会加入はあくまで営業保証金の代わりであり、免許は当然必要です。

</details>

**問4.** 還付充当金の納付に関する記述として、正しいものはどれでしょう？

1. 協会から通知を受けた日から1か月以内に納付しなければならない
2. 納付しなくても、社員の地位に影響はない
3. 還付充当金という制度は存在しない
4. 協会から通知を受けた日から2週間以内に納付しなければ、社員の地位を失う

<details><summary>答えと解説</summary>

正解: **4**

還付が行われた場合、社員は通知から2週間以内に還付充当金を協会に納付しなければならず、怠ると社員の地位を失います。地位を失った業者は1週間以内に営業保証金を供託しない限り営業を続けられません。1は期間が誤りで、2・3は制度の内容そのものが誤りです。

</details>

## 4. 営業保証金と保証協会の比較まとめ

🔴 レッスンの仕上げに、2つの制度を**表で横に並べて**整理します。本試験では「どっちの制度の話か」をすり替えるひっかけが頻出なので、違いをセットで覚えるのが最強の対策です。

### 比較表

| 項目 | 営業保証金 | 保証協会（弁済業務保証金分担金） |
|---|---|---|
| 金額 | 本店 **1,000万円**・支店 **500万円** | 本店 **60万円**・支店 **30万円** |
| 納め先 | 主たる事務所の最寄りの**供託所** | **保証協会**（協会が供託所へ供託） |
| 納め方 | 金銭 or **有価証券**もOK | **金銭のみ** |
| 営業開始まで | 供託 + **届出**の後 | 加入日までに納付（協会が1週間以内に供託） |
| 還付の限度 | 供託した営業保証金の範囲内 | **営業保証金に相当する額**の範囲内 |
| 不足したら | 通知から **2週間以内**に供託 | 通知から **2週間以内**に還付充当金を納付 |

> 💡 どちらの制度でも、お客さんが還付を受けられる限度は「営業保証金ベース」の同じ水準です。業者の負担は60万円でも、お客さんの保護は1,000万円分。だから保証協会は「安いのに手厚い」優れた仕組みなのです。

> 💡 ひっかけの王道は「**協会の分担金を有価証券で納付できる**（→できません。金銭のみ）」と「**金額のすり替え**（60万と1,000万を入れ替える）」。表の左右を意識して対比で覚えましょう。

### 確認問題

**問1.** 営業保証金と弁済業務保証金分担金の比較として、正しいものはどれでしょう？

1. どちらも金銭のほか有価証券で納めることができる
2. 営業保証金は有価証券でも供託できるが、分担金は金銭のみで納付する
3. どちらも金銭のみでしか納められない
4. 分担金は有価証券でも納付できるが、営業保証金は金銭のみである

<details><summary>答えと解説</summary>

正解: **2**

営業保証金は金銭のほか国債などの有価証券でも供託できますが、保証協会への分担金は金銭のみです。この対比はひっかけの王道で、1・3は両者を同じ扱いにしている点が、4は両者を逆にしている点が誤りです。

</details>

**問2.** 本店と支店1つで宅建業を営む場合の負担額の組み合わせとして、正しいものはどれでしょう？

1. 営業保証金なら1,500万円、保証協会なら90万円
2. 営業保証金なら2,000万円、保証協会なら120万円
3. 営業保証金なら1,000万円、保証協会なら60万円
4. 営業保証金なら1,500万円、保証協会なら900万円

<details><summary>答えと解説</summary>

正解: **1**

営業保証金は1,000万 + 500万 = 1,500万円、分担金は60万 + 30万 = 90万円です。2は支店分を本店と同額で計算した誤り、3は支店分を忘れています。4は分担金の桁が誤りです。本店と支店で金額が違うこと、両制度で桁が違うことを押さえましょう。

</details>

**問3.** 保証協会の社員である宅建業者と取引して損害を受けたお客さんが、弁済（還付）を受けられる限度額について、正しいものはどれでしょう？

1. その業者が納付した分担金の額（本店のみなら60万円）の範囲内
2. 限度額はなく、損害の全額について必ず弁済を受けられる
3. その業者が営業保証金を供託していたならば受けられたはずの額の範囲内
4. 一律で100万円まで

<details><summary>答えと解説</summary>

正解: **3**

還付の限度は、その業者が保証協会に加入していなければ供託していたはずの営業保証金に相当する額（本店のみなら1,000万円）です。業者の負担は60万円でも保護の水準は変わらない、という制度の肝です。1は分担金の額を限度とする誤り、2は無制限としている点が、4は根拠のない額である点が誤りです。

</details>

**問4.** 還付によってお金が不足した後の対応の比較として、正しいものはどれでしょう？

1. 営業保証金では通知から2週間以内に不足額を供託し、保証協会では通知から2週間以内に還付充当金を納付する
2. どちらの制度でも、通知から1週間以内に対応しなければならない
3. 営業保証金では補充が不要で、保証協会でのみ還付充当金を納付する
4. どちらの制度でも、不足分は国が負担するため業者の対応は不要である

<details><summary>答えと解説</summary>

正解: **1**

どちらの制度でも「通知から2週間以内」に、営業保証金なら不足額の供託、保証協会なら還付充当金の納付を行います。2は期間が誤りです（1週間は、協会が分担金を受けて供託する場面などの数字です）。3は営業保証金にも補充義務があるため誤りで、4のような国の負担はありません。

</details>
