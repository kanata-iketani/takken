# 第14章 債務不履行・解除・売買

「契約を結んだのに、約束が守られなかったらどうする？」を学ぶ章です。債務不履行から解除・手付・契約不適合責任まで、売買トラブルの解決ルールを順番に追いかけます。特に手付と契約不適合責任は本試験の常連です。

## 1. 債務不履行って何？（履行遅滞と履行不能）

売主Aさんが買主Bさんに「9月1日に家を引き渡す」と約束したのに、当日になっても引き渡さない——これが**履行遅滞**（遅れているが、まだ履行できる）です。一方、引渡し前に家が全焼してしまい、もう引き渡せないのが**履行不能**です。この2つをまとめて**債務不履行**と呼びます。

### いつから「遅滞」になる？

| 期限の定め方 | 遅滞になる時期 |
|---|---|
| 確定期限（9月1日など） | **期限が到来した時** |
| 不確定期限（父が死んだら等） | 期限到来後に請求を受けた時か、到来を知った時の早い方 |
| 期限の定めなし | **履行の請求を受けた時** |

### 損害賠償には「帰責事由」が必要

債務不履行で損害賠償を請求するには、原則として**債務者に帰責事由**（落ち度）が必要です。大地震で建物が滅失した場合のように、債務者に責任がなければ賠償請求はできません。

ただし**金銭債務（代金の支払いなど）は特別扱い**で、①不可抗力を理由に免責されない、②債権者は損害の証明が不要（法定利率で計算）という厳しいルールです。

> 💡 コツ：「賠償請求にはまず言い訳（帰責事由）チェック。ただし、お金の支払いだけは言い訳無用」と覚えましょう。

🟡 まずは「遅滞と不能の違い」と「金銭債務の特則」を押さえれば十分です。

### 確認問題

**問1.** 売主Aは買主Bと「9月1日に建物を引き渡す」という確定期限付きの売買契約を結んだが、9月1日を過ぎても引き渡していない。Aが履行遅滞の責任を負うのはいつからでしょう？

1. 契約を締結した時から
2. 期限である9月1日が到来した時から
3. Bが履行を催告した時から
4. Bが所有権移転登記を請求した時から

<details><summary>答えと解説</summary>

正解: **2**

確定期限のある債務は、期限が到来した時から履行遅滞となります。催告が必要なのは「期限の定めがない」債務の場合です。契約締結時や登記請求時は遅滞の起算点とは関係ありません。

</details>

**問2.** AB間の建物売買契約の締結後、引渡し前に大地震で建物が倒壊し、引渡しが不能となった。Aに落ち度はない。Bの損害賠償請求について正しいものはどれでしょう？

1. 債務者Aに帰責事由がなくても損害賠償を請求できる
2. 金銭債務以外でも、損害の証明は一切不要である
3. 債務者Aに帰責事由がないため、Bは損害賠償を請求できない
4. 損害賠償請求には必ず催告が必要である

<details><summary>答えと解説</summary>

正解: **3**

債務不履行による損害賠償請求には、原則として債務者の帰責事由が必要です。大地震という不可抗力で履行不能となった場合、Aに落ち度はないので賠償請求はできません。損害の証明が不要なのは金銭債務の特則であり、催告は損害賠償の要件ではありません。

</details>

**問3.** 買主Bが売買代金の支払いを遅滞している。売主Aの請求について正しいものはどれでしょう？

1. Aは実際の損害を証明しなくても、法定利率による遅延損害金を請求できる
2. Bが不可抗力を証明すれば、支払遅延の責任を免れる
3. Aは実際に生じた損害を証明しなければ、一切請求できない
4. 代金債務には履行遅滞のルールは適用されない

<details><summary>答えと解説</summary>

正解: **1**

金銭債務の不履行には特則があり、債権者は損害の証明をせずに法定利率（約定利率が高ければ約定利率）で賠償を請求できます。また金銭債務は不可抗力をもって抗弁とすることができないため、Bは免責されません。代金債務も金銭債務として履行遅滞のルールが適用されます。

</details>

## 2. 契約の解除（催告解除と無催告解除）

売主Aさんがいつまでも建物を引き渡してくれないとき、買主Bさんは契約をなかったことにできます。これが**解除**です。

### 解除の2パターン

| 種類 | やり方 |
|---|---|
| **催告解除** | 相当の期間を定めて催告し、期間内に履行がなければ解除できる。ただし不履行が**軽微**なときは解除できない |
| **無催告解除** | 全部が履行不能になった場合などは、催告なしで直ちに解除できる |

重要な改正ポイント：解除に**債務者の帰責事由は不要**です。解除は「契約の拘束から抜け出すための制度」だからです。逆に、**債権者側に帰責事由がある場合は解除できません**。

### 解除するとどうなる？（原状回復）

契約は最初からなかったことになり、お互いに受け取ったものを返す**原状回復義務**を負います。金銭を返すときは**受領の時からの利息**を付けます。なお、解除前に不動産を買い受けた第三者は、**登記**を備えていれば保護されます（善意・悪意を問いません）。

> 💡 コツ：「催告してダメなら解除。ただし軽微ならガマン。不能なら即解除」の流れで覚えましょう。

🟡 「帰責事由は不要」という改正点と原状回復の中身を理解しておきましょう。

### 確認問題

**問1.** 売主Aが履行期を過ぎても建物を引き渡さない。買主Bが債務不履行を理由に契約を解除する場合について、正しいものはどれでしょう？

1. 履行遅滞の場合、催告なしに直ちに解除できる
2. 債務者Aに帰責事由がなければ解除できない
3. 不履行がその契約及び取引上の社会通念に照らして軽微であっても解除できる
4. 相当の期間を定めて催告し、その期間内に履行がないときに解除できる

<details><summary>答えと解説</summary>

正解: **4**

履行遅滞による解除は、原則として相当の期間を定めた催告が必要です（催告解除）。改正民法では解除に債務者の帰責事由は不要とされました。一方、不履行が軽微なときは催告しても解除できません。無催告で解除できるのは履行不能などの場合です。

</details>

**問2.** AB間の建物売買契約の締結後、引渡し前に建物が全焼し、引渡しの全部が不能となった。買主Bの解除について正しいものはどれでしょう？

1. 相当期間を定めて催告しなければ解除できない
2. Bは催告をせずに直ちに契約を解除できる
3. Aに帰責事由がない以上、Bは解除できない
4. 解除はできず、損害賠償請求のみが認められる

<details><summary>答えと解説</summary>

正解: **2**

債務の全部が履行不能となったときは、催告をしても意味がないため、無催告で直ちに解除できます。解除に債務者の帰責事由は不要なので、Aに落ち度がなくても解除は可能です（この場合、帰責事由がないため損害賠償請求はできません）。

</details>

**問3.** 買主Bが代金の一部を支払った後、売主Aの債務不履行を理由に売買契約が解除された。解除の効果について正しいものはどれでしょう？

1. 解除しても、Aは既に受け取った代金を返還する必要はない
2. 解除前にAから不動産を買い受けた第三者は、登記がなくても常に保護される
3. 各当事者は原状回復義務を負い、Aは受領した代金に受領の時からの利息を付けて返還する
4. 原状回復義務は、解除を主張した側であるBだけが負う

<details><summary>答えと解説</summary>

正解: **3**

解除されると契約は遡って消滅し、双方が原状回復義務を負います。金銭を返還するときは受領の時からの利息を付けなければなりません。解除前の第三者は善意・悪意を問わず保護されますが、登記を備えていることが必要です。原状回復義務は双方が負います。

</details>

## 3. 手付（買主は放棄、売主は倍返し）

Aさんが3,000万円の家をBさんに売り、Bさんが**手付**として300万円を支払いました。民法では、手付は**解約手付**と推定されます。つまり、理由がなくても次の方法で契約を解除できる「キャンセル料」の役割です。

### 手付解除のルール

| 誰が | どうやって |
|---|---|
| 買主から | 手付を**放棄**する（300万円をあきらめる） |
| 売主から | 手付の**倍額を現実に提供**する（600万円を実際に差し出す。口頭で「倍返しします」はダメ） |

ただし、**相手方が履行に着手した後は解除できません**。ポイントは「相手方が」です。自分が着手していても、相手がまだなら解除できます。

**履行の着手の例**：買主が中間金を支払った、代金を用意して引渡しを求めた、売主が登記手続を進めた——など。

手付解除は債務不履行ではないので、解除された側は**別途の損害賠償を請求できません**。

> 💡 ゴロ：「**買いっぱなし（買主は放棄）、売り倍返し（売主は倍額提供）**」。そして着手チェックは「相手を見ろ」。

🔴 宅建業法の「8種制限」にもつながる超頻出テーマです。確実に得点しましょう。

### 確認問題

**問1.** 買主Bから手付300万円を受領した売主Aが、手付による解除をしたい。正しいものはどれでしょう？

1. Aは手付の倍額である600万円を現実に提供しなければ解除できない
2. Aは倍額を支払う意思を口頭で伝えれば解除できる
3. Aは受領済みの手付300万円を返還すれば解除できる
4. 売主からは手付による解除は一切できない

<details><summary>答えと解説</summary>

正解: **1**

売主からの手付解除は、手付の倍額を「現実に提供」することが必要です。口頭で伝えるだけでは足りず、受領した手付を返すだけでも足りません（倍額が必要）。売主からの解除も認められているので「一切できない」も誤りです。

</details>

**問2.** 買主Bが中間金を支払った後、売主Aが手付の倍額を現実に提供して契約を解除しようとした。この解除について正しいものはどれでしょう？

1. 倍額を現実に提供している以上、Aはいつでも解除できる
2. 中間金の支払いは履行の着手に当たらないので、Aは解除できる
3. 相手方Bが既に履行に着手しているため、Aは手付解除できない
4. A自身が履行に着手していなければ、Aは解除できる

<details><summary>答えと解説</summary>

正解: **3**

手付解除は「相手方が履行に着手した後」はできません。中間金の支払いは履行の着手に当たるとされるため、Bが着手した以上、Aは倍返しをしても解除できません。判断の基準は自分ではなく相手方の着手です。

</details>

**問3.** 売主Aは所有権移転登記の手続を進めて履行に着手したが、買主Bはまだ何もしていない。手付解除ができるのは誰でしょう？

1. AもBも解除できる
2. Aは解除できるが、Bは解除できない
3. Bは解除できるが、Aは解除できない
4. AもBも解除できない

<details><summary>答えと解説</summary>

正解: **2**

手付解除が禁止されるのは「相手方が履行に着手した後」です。Aから見ると相手方Bは未着手なので、Aは解除できます。Bから見ると相手方Aは着手済みなので、Bは解除できません。自分の着手は自分の解除を妨げない点がひっかけポイントです。

</details>

**問4.** 買主Bが手付を放棄して売買契約を解除した。売主Aは、この解除によって手付の額を超える損害を被ったと主張している。正しいものはどれでしょう？

1. 手付解除は債務不履行に当たるため、Aは損害賠償を請求できる
2. 手付の額を超える実損があれば、Aはその差額を請求できる
3. Aが裁判所に申し立てれば賠償が認められる
4. 手付解除は債務不履行ではないため、Aは損害賠償を請求できない

<details><summary>答えと解説</summary>

正解: **4**

解約手付による解除は、契約で認められた正当な解除権の行使であり、債務不履行ではありません。したがって相手方は別途の損害賠償を請求できず、手付の放棄（または倍返し）だけで決着します。差額請求や裁判所への申立てといった制度もありません。

</details>

## 4. 契約不適合責任（買主を守る4つの武器）

Bさんが買った中古住宅に、ひどい**雨漏り**が見つかりました。引き渡された物が種類・品質・数量に関して契約の内容に適合しない——このとき売主が負うのが**契約不適合責任**です。

### 買主の4つの救済手段

| 武器 | 内容 | ポイント |
|---|---|---|
| ① 追完請求 | 修補・代替物の引渡しなど | 買主に帰責事由があるときは不可 |
| ② 代金減額請求 | 代金を安くしろと請求 | 原則、追完の**催告**をしてから |
| ③ 損害賠償請求 | 損害を賠償しろと請求 | **売主の帰責事由**が必要 |
| ④ 契約の解除 | 契約をやめる | 催告解除・無催告解除のルールどおり |

### 1年の通知期間に注意

**種類・品質**の不適合は、買主が**不適合を知った時から1年以内**にその旨を売主に**通知**しないと、責任を追及できなくなります（売主が不適合を知っていた、または重過失で知らなかったときは通知不要）。一方、**数量**の不適合や権利の不適合には、この1年の通知ルールは**適用されません**。

> 💡 ゴロ：「**シナ・モノ（種類・品質）は知ってから1年通知**」。起算点は「引渡しから」ではなく「知った時から」です。

🔴 4つの救済と通知期間は毎年のように問われます。表ごと暗記しましょう。

### 確認問題

**問1.** 買主Bが購入した中古住宅に、契約内容に適合しない雨漏りが見つかった。Bの救済手段について正しいものはどれでしょう？

1. Bは直ちに契約を解除することしかできない
2. Bは売主Aに対し、修補による履行の追完を請求できる
3. 雨漏りがBの過失によって生じた場合でも、Bは追完請求できる
4. Bに認められるのは損害賠償請求のみである

<details><summary>答えと解説</summary>

正解: **2**

品質に関する契約不適合があるときは、買主は修補などの追完請求ができます。救済手段は追完請求・代金減額請求・損害賠償請求・解除の4つがあり、解除や損害賠償に限られません。ただし不適合が買主の帰責事由によるときは追完請求できません。

</details>

**問2.** 引き渡された建物に契約不適合があった場合の代金減額請求について、原則として正しいものはどれでしょう？

1. 相当の期間を定めて追完を催告し、その期間内に追完がないときに減額請求できる
2. 追完が可能な場合でも、催告をせず直ちに減額請求できる
3. 代金減額請求には売主の帰責事由が必要である
4. 代金減額請求をすると、損害賠償請求は一切できなくなる

<details><summary>答えと解説</summary>

正解: **1**

代金減額請求は、原則としてまず追完の催告をし、期間内に追完がないときにできます（追完不能などの場合は無催告で可）。売主の帰責事由が必要なのは損害賠償請求であり、減額請求には不要です。売主に帰責事由があれば損害賠償との併用も可能です。

</details>

**問3.** 買主Bは建物の引渡しから3年後に、契約内容に適合しない品質の欠陥を初めて発見した。売主Aは欠陥を知らず、重大な過失もなかった。Bの責任追及について正しいものはどれでしょう？

1. 引渡しから1年を経過しているので、もはや一切請求できない
2. 不適合を知った時から1年以内に訴訟を提起しなければならない
3. 不適合を知った時から1年以内にその旨をAに通知すれば、責任を追及できる
4. 通知は口頭では認められず、公正証書によらなければならない

<details><summary>答えと解説</summary>

正解: **3**

種類・品質の契約不適合の通知期間は「不適合を知った時から1年」であり、引渡しからの年数ではありません。求められるのは不適合の事実の通知であって、訴訟の提起までは不要です。通知の方式にも公正証書などの決まりはありません。

</details>

**問4.** 土地の売買で「300㎡」として引き渡されたが、実測したところ280㎡しかなかった（数量に関する契約不適合）。種類・品質の不適合との違いについて正しいものはどれでしょう？

1. 数量不足も、知った時から1年以内の通知をしないと責任追及できない
2. 数量不足の場合、買主には救済手段が認められていない
3. 数量不足の場合は、契約が当然に無効となる
4. 数量不足には「知った時から1年以内の通知」のルールは適用されない

<details><summary>答えと解説</summary>

正解: **4**

「知った時から1年以内の通知」ルールが適用されるのは種類・品質の不適合だけで、数量や権利の不適合には適用されません（消滅時効の一般ルールのみ）。数量不足でも追完請求・代金減額請求などの救済は可能で、契約が当然に無効となるわけでもありません。

</details>
