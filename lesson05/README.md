# 第5章 媒介契約

「売ってほしい・探してほしい」と業者にお願いする契約が媒介契約です。3種類の違いと「3か月・2週間・7日／1週間・5日」の数字セットは、宅建業法の中でも特に出題率の高い得点源です。

## 1. 媒介契約の3種類（一般・専任・専属専任）

家を売りたいとき、多くの人は不動産屋さんに「買ってくれる人を探して」とお願いします。このお願いの契約が**媒介（ばいかい）契約**です。頼み方には3種類あり、「縛りのきつさ」が違います。

### 3種類をひと目で比較

| 種類 | 他の業者にも重ねて依頼 | 自己発見取引（自分で買主を見つける） |
|---|---|---|
| 一般媒介 | ○ できる | ○ できる |
| 専任媒介 | × できない | ○ できる |
| 専属専任媒介 | × できない | × できない |

「自己発見取引」とは、依頼者が自分で相手（例えば親戚や知人）を見つけて直接契約することです。専属専任だけはこれも禁止で、いちばん縛りがきつい契約です。

なお一般媒介には、他にどの業者へ依頼したかを知らせる**明示型**と、知らせない**非明示型**があります。

> 💡コツ：依頼者への縛りがきつい契約ほど、業者に課される義務（報告やレインズ登録）が重くなります。逆に**一般媒介には法律上の規制がほとんどありません**。この対応関係が次のチャプターの土台です。

🔴 3種類の「できる・できない」の表は毎年のように問われます。まずここを完璧に。

### 確認問題

**問1.** 媒介契約に関する次の記述のうち、正しいものはどれでしょう？

1. 専任媒介契約を締結した依頼者は、自ら発見した相手方と売買契約を締結することができない
2. 専属専任媒介契約を締結した依頼者は、他の宅建業者に重ねて媒介を依頼することができる
3. 一般媒介契約を締結した依頼者は、他の宅建業者に重ねて媒介を依頼することができる
4. 一般媒介契約を締結した依頼者は、自ら発見した相手方と売買契約を締結することができない

<details><summary>答えと解説</summary>

正解: **3**

一般媒介は「他の業者への依頼も自己発見取引も自由」な、いちばん縛りのゆるい契約です。自己発見取引が禁止されるのは専属専任だけなので、肢1は誤り（専任では自己発見OK）。専属専任は1社にしか依頼できないので肢2も誤り。肢4は一般媒介の内容として逆です。

</details>

**問2.** 自分で見つけた知人と直接売買契約を結ぶこと（自己発見取引）が禁止されるのは、どの媒介契約でしょう？

1. 一般媒介契約のみ
2. 専任媒介契約のみ
3. 専任媒介契約と専属専任媒介契約の両方
4. 専属専任媒介契約のみ

<details><summary>答えと解説</summary>

正解: **4**

自己発見取引まで禁止されるのは専属専任媒介だけです。専任媒介は「他の業者に頼めない」だけで、自分で相手を見つけて契約することはできます。一般媒介にはどちらの制限もありません。「専属」という言葉に「業者に全部おまかせ」のニュアンスがある、と覚えましょう。

</details>

**問3.** 一般媒介契約について、宅建業法の規制として正しいものはどれでしょう？

1. 有効期間は3か月を超えてはならない
2. 有効期間について法律上の制限はない
3. 2週間に1回以上、業務の処理状況を報告しなければならない
4. 契約日から7日以内に指定流通機構（レインズ）へ登録しなければならない

<details><summary>答えと解説</summary>

正解: **2**

有効期間の制限・定期報告・レインズ登録の義務は、いずれも専任系（専任・専属専任）の媒介契約だけの規制です。一般媒介にはこれらの規制がなく、有効期間も自由に定められます。「一般媒介にも3か月の制限がある」とするひっかけは頻出なので要注意です。

</details>

**問4.** 一般媒介契約の「明示型」とは、どのような契約でしょう？

1. 依頼した物件の価格を広告で明示する契約
2. 媒介契約の有効期間を書面で明示する契約
3. 他にどの宅建業者へ重ねて依頼したかを依頼者が明らかにする契約
4. 依頼者が自己発見取引をしないことを明示する契約

<details><summary>答えと解説</summary>

正解: **3**

一般媒介では他の業者にも重ねて依頼できますが、その依頼先を明らかにするタイプが「明示型」、明らかにしないタイプが「非明示型」です。価格や有効期間の記載は媒介契約書面の話であり、明示型の意味ではありません。自己発見取引の禁止は専属専任の特徴です。

</details>

## 2. 専任媒介契約の規制（3か月・2週間・7日）

専任媒介は「あなたの会社だけにお願いします」という契約です。依頼者は他の業者に頼めない分、業者がサボると困ります。そこで法律は、業者に次の義務を課しました。

### 専任媒介の3つの数字

| 規制 | 内容 |
|---|---|
| 有効期間 | **3か月以内**。3か月を超える定めをしても、超える部分が **3か月に短縮** される（契約自体は有効） |
| 業務処理状況の報告 | **2週間に1回以上**（口頭やメールでもOK） |
| 指定流通機構（レインズ）への登録 | 契約日から **7日以内**（業者の休業日を除く） |

レインズとは、全国の業者が物件情報を共有するネットワークです。登録すれば他社のお客さんにも物件が見えるので、売れやすくなります。登録したら**登録を証する書面**（依頼者の承諾があれば電磁的方法も可）を遅滞なく依頼者に引き渡し、売買が成立したら遅滞なくレインズに通知します。

契約の**更新**は、依頼者からの申出がある場合に限り可能です（更新後も3か月以内）。「自動的に更新される」という特約は無効です。

> 💡コツ：ゴロ合わせは「専任は **3・2・7**（さん・に・なな）」＝3か月・2週間・7日。🔴 この3つの数字はほぼ毎年出題されます。

### 確認問題

**問1.** 宅建業者Aが依頼者Bと、有効期間を6か月とする専任媒介契約を締結した場合、この契約はどうなるでしょう？

1. 有効期間は3か月に短縮される
2. 媒介契約全体が無効となる
3. 6か月の有効期間がそのまま認められる
4. Bが承諾していれば6か月の有効期間が認められる

<details><summary>答えと解説</summary>

正解: **1**

専任媒介の有効期間は3か月以内で、これを超える定めをしたときは「3か月に短縮」されます。契約全体が無効になるわけではない点がポイントです。依頼者の承諾があっても3か月を超える期間は認められません。

</details>

**問2.** 専任媒介契約における業務処理状況の報告義務として、正しいものはどれでしょう？

1. 1週間に1回以上報告しなければならない
2. 依頼者から請求があったときだけ報告すればよい
3. 1か月に1回以上報告しなければならない
4. 2週間に1回以上報告しなければならない

<details><summary>答えと解説</summary>

正解: **4**

専任媒介では2週間に1回以上の報告が義務です。依頼者からの請求の有無にかかわらず、業者側から定期的に報告しなければなりません。1週間に1回以上は専属専任媒介の場合です。

</details>

**問3.** 専任媒介契約を締結した宅建業者の、指定流通機構（レインズ）への登録義務について正しいものはどれでしょう？

1. 契約日から5日以内（休業日を除く）に登録しなければならない
2. 契約日から7日以内（休業日を除く）に登録しなければならない
3. 依頼者の承諾があれば登録しなくてもよい
4. 契約日から2週間以内に登録しなければならない

<details><summary>答えと解説</summary>

正解: **2**

専任媒介では契約日から7日以内（業者の休業日を除く）にレインズへ登録する義務があります。これは法律上の義務なので、依頼者の承諾や特約があっても免除されません。5日以内は専属専任媒介の数字です。

</details>

**問4.** 専任媒介契約の更新に関する次の記述のうち、正しいものはどれでしょう？

1. 有効期間が満了すれば自動的に更新される
2. 「自動更新する」との特約があれば自動更新できる
3. 依頼者の申出がある場合に限り更新でき、更新後の期間も3か月以内である
4. 更新後の有効期間は6か月まで認められる

<details><summary>答えと解説</summary>

正解: **3**

専任媒介の更新は依頼者からの申出がある場合に限って可能で、更新後の有効期間も3か月以内です。自動更新の特約は依頼者に不利なものとして無効になります。更新したからといって期間の上限が延びることもありません。

</details>

## 3. 専属専任媒介の規制（1週間・5日・自己発見も不可）

専属専任媒介は「1社だけに頼み、自分で相手を見つけることもしない」という、依頼者の縛りが最大の契約です。その分、業者の義務はさらに重くなります。

### 専任媒介との違いは「数字が1段きびしい」だけ

| 規制 | 専任媒介 | 専属専任媒介 |
|---|---|---|
| 有効期間 | 3か月以内 | **3か月以内（同じ）** |
| 報告 | 2週間に1回以上 | **1週間に1回以上** |
| レインズ登録 | 7日以内 | **5日以内**（いずれも休業日を除く） |
| 自己発見取引 | できる | **できない** |

注意したいのは、**有効期間の3か月だけは専任と共通**という点です。「専属専任は有効期間も短い」というひっかけが出ますが、短くなるのは報告（2週間→1週間）と登録（7日→5日）だけです。

また、依頼者が自分で見つけた相手と直接契約すること（自己発見取引）はできず、違反すると媒介契約で定めた措置（違約金など）の対象になります。

> 💡コツ：ゴロ合わせは「専属は **3・1・5**（さん・いち・ご）」。専任の「3・2・7」とセットで口に出して覚えましょう。🔴 2つの数字セットの入れ替えひっかけが頻出です。

### 確認問題

**問1.** 専属専任媒介契約の有効期間について、正しいものはどれでしょう？

1. 専任媒介より短く、1か月以内としなければならない
2. 専任媒介と同じく、3か月以内としなければならない
3. 法律上の制限はなく、自由に定められる
4. 6か月以内としなければならない

<details><summary>答えと解説</summary>

正解: **2**

有効期間の上限3か月は、専任媒介と専属専任媒介で共通です。専属専任で短くなるのは報告の頻度（1週間に1回以上）とレインズ登録の期限（5日以内）であり、有効期間は変わりません。有効期間に制限がないのは一般媒介です。

</details>

**問2.** 専属専任媒介契約を締結した宅建業者のレインズへの登録期限として、正しいものはどれでしょう？

1. 契約日から5日以内（休業日を除く）
2. 契約日から7日以内（休業日を除く）
3. 契約日から2週間以内（休業日を除く）
4. 登録義務はない

<details><summary>答えと解説</summary>

正解: **1**

専属専任媒介のレインズ登録は契約日から5日以内（業者の休業日を除く）です。7日以内は専任媒介の数字で、この2つの入れ替えが定番のひっかけです。登録義務がないのは一般媒介の場合です。

</details>

**問3.** 専属専任媒介契約における業務処理状況の報告について、正しいものはどれでしょう？

1. 2週間に1回以上報告しなければならない
2. 1か月に1回以上報告すれば足りる
3. 依頼者の承諾があれば報告を省略できる
4. 1週間に1回以上報告しなければならない

<details><summary>答えと解説</summary>

正解: **4**

専属専任媒介の報告は1週間に1回以上です。2週間に1回以上は専任媒介の頻度です。報告義務は法律上の義務なので、依頼者の承諾があっても省略できません。

</details>

**問4.** 専属専任媒介契約を締結した依頼者Bが、自ら発見した知人Cと直接売買契約を締結した場合についての正しい記述はどれでしょう？

1. 専属専任媒介でも自己発見取引は自由にできるので、何の問題もない
2. BとCの売買契約は当然に無効となる
3. Bは媒介契約で定められた措置（違約金の支払いなど）の対象となり得る
4. Cが宅建業者でなければ問題はない

<details><summary>答えと解説</summary>

正解: **3**

専属専任媒介では自己発見取引が禁止されており、違反した場合の措置（違約金など）は媒介契約書面の記載事項にもなっています。ただしBC間の売買契約そのものが無効になるわけではありません。自己発見取引が自由なのは一般媒介と専任媒介であり、相手が業者かどうかは関係ありません。

</details>

## 4. 媒介契約書面（34条の2）

媒介契約は口約束でも成立しますが、「言った・言わない」のトラブルを防ぐため、宅建業者は**売買・交換の媒介契約**を締結したら、**遅滞なく**媒介契約書面（34条の2書面）を作成し、**記名押印**して依頼者に交付しなければなりません。依頼者の承諾があれば、電磁的方法（電子書面）による提供もできます。

### おさえるポイント

| 項目 | 内容 |
|---|---|
| 対象 | 売買・交換の媒介（**貸借の媒介には交付義務なし**） |
| 誰の記名押印？ | **宅建業者**（宅建士ではない！） |
| 一般媒介でも？ | **必要**（3種類すべてで交付義務あり） |

### 主な記載事項

- 物件の表示、**売買すべき価額**（業者が価額に意見を述べるときは、根拠を明らかにする。口頭でも可）
- 媒介契約の種類、有効期間、報酬、レインズ登録に関する事項
- 契約違反（専任なのに他社と契約した等）の場合の措置
- 国土交通大臣が定める**標準媒介契約約款**に基づくか否か

> 💡コツ：🟡 ひっかけの定番は「貸借の媒介でも交付が必要」（→不要）と「宅建士の記名押印」（→業者の記名押印）の2つです。35条・37条書面との混同を狙ってきます。

### 確認問題

**問1.** 媒介契約書面（34条の2書面）の交付義務に関する次の記述のうち、正しいものはどれでしょう？

1. 貸借の媒介契約を締結したときも、交付しなければならない
2. 一般媒介契約の場合は、交付しなくてもよい
3. 売買の媒介契約を締結したときは、一般媒介であっても交付しなければならない
4. 依頼者が宅建業者である場合は、交付しなくてもよい

<details><summary>答えと解説</summary>

正解: **3**

34条の2書面は売買・交換の媒介で交付義務があり、一般・専任・専属専任のどの種類でも必要です。一方、貸借の媒介には交付義務がありません（ここが頻出のひっかけ）。相手が宅建業者でも交付義務は免除されません。

</details>

**問2.** 媒介契約書面への記名押印について、正しいものはどれでしょう？

1. 宅地建物取引士の記名押印が必要である
2. 宅建業者の記名押印が必要である
3. 記名があれば押印は不要である
4. 依頼者の記名押印があれば、業者の記名押印は不要である

<details><summary>答えと解説</summary>

正解: **2**

34条の2書面に記名押印するのは宅建業者です。宅建士の記名が必要なのは35条書面・37条書面であり、ここを入れ替えるひっかけが定番です。なお35条・37条書面は押印が廃止されましたが、媒介契約書面には業者の記名押印が引き続き必要です。

</details>

**問3.** 宅建業者Aが、売買の媒介の依頼者Bに対し「売買すべき価額」について意見を述べる場合、正しいものはどれでしょう？

1. 意見を述べるときは、その根拠を明らかにしなければならない（口頭でもよい）
2. 意見を述べるときは、必ず書面で根拠を示さなければならない
3. 根拠を示す必要はない
4. 根拠を示したうえで、別途調査費用を請求できる

<details><summary>答えと解説</summary>

正解: **1**

業者が価額について意見を述べるときは根拠の明示が義務ですが、その方法は口頭でもかまいません。「必ず書面で」ではない点に注意しましょう。また根拠を示すための価額の査定などに要した費用は、原則として依頼者に請求できません。

</details>

**問4.** 媒介契約書面の交付方法に関する次の記述のうち、正しいものはどれでしょう？

1. 書面の交付に代えて電磁的方法で提供することは、一切認められない
2. 依頼者の承諾がなくても、電磁的方法で提供できる
3. 契約締結から1か月以内に交付すればよい
4. 依頼者の承諾を得れば、電磁的方法により提供することができる

<details><summary>答えと解説</summary>

正解: **4**

法改正により、依頼者の承諾を得れば34条の2書面を電磁的方法で提供できます。承諾なしに一方的に電子化することはできません。また交付の時期は「契約締結後、遅滞なく」であり、1か月以内といった猶予はありません。

</details>
