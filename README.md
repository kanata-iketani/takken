# 宅建どうじょう 🏠

法律も不動産もまったくの初心者が、**このアプリひとつで宅地建物取引士（宅建）試験の合格レベルに到達する**ことを目指すブラウザ学習アプリです。左に教科書、右に一問一答（4択）。答えるとその場で判定と解説が出ます。

- 全31章・127チャプター・**700問**（講義 + 分野別ドリル130問 + 本試験形式フル模試50問×3回）
- すべてオリジナル問題。教科書は専門用語をかみ砕き、ゴロ合わせと表で覚えられる超初心者仕様

## 使い方

```sh
cd takken
go -C app run .
```

ブラウザで <http://127.0.0.1:8084> を開いてください。必要なのは [Go](https://go.dev/dl/) 1.22+ だけです。

## 合格までの流れ（推奨）

| ステップ | 章 | やること |
|---|---|---|
| 1. 戦略を知る | 第1章 | 「7割で勝ち・業法が得点源」を頭に入れる |
| 2. 得点源を作る | 第2〜9章 + 第24章 | 宅建業法（本試験20問分）を固める |
| 3. 深追いせず学ぶ | 第10〜16章 + 第25章 | 権利関係（民法）は基本だけ確実に |
| 4. 暗記で稼ぐ | 第17〜22章 | 法令上の制限・税・免除科目 |
| 5. ひたすら回す | 第23・26〜28章 | ミニ模試 + 分野別ドリル156問を全問クリアまで |
| 6. 本番形式で仕上げ | 第29〜31章 | フル模試50問×3回（2時間を計って解く） |

- 全問正解でチャプタークリア ✅。間違えた問題は **にがて帳** に自動記録され、ワンクリックで解き直せます

## AI の先生（ローカルに [Claude Code](https://claude.com/claude-code) がある場合）

「🙋 質問」からいつでも使えます。なくても学習機能はすべて使えます。

| 機能 | 何をしてくれるか |
|---|---|
| 💬 質問 | いま学んでいるチャプターの文脈で、超初心者向けにかみ砕いて回答 |
| 🎤 口頭試問 | 4択の暗記では答えられない**別角度の記述問題**を出題し、あなたの答えを採点。曖昧な理解をあぶり出す |
| 📝 弱点まとめ | 全誤答・全質問をレッスン別に分析し、「苦手分野トップ3・勘違いポイント・次にやること」をノート化 |
| 🎯 専用復習問題 | 誤答の多い分野を自動特定し、**同じ論点を角度を変えた類題**にして専用章（復習問題）を生成 |
| 📰 統計・法改正ノート | AI が **Web 検索**で最新の統計数値（地価公示・着工戸数など）と法改正を調べ、出典 URL 付きの直前対策ノート+一問一答を作成 |

> 本編の固定問題では毎年変わる統計数値を出題しない設計です（古い数値の暗記は逆効果のため）。直前期は 📰 ノートを作り直して最新値で仕上げてください。法改正（相続登記義務化・盛土規制法・2025年建築確認改正など）は教材に反映済みですが、受験年度の最新情報も 📰 ノートで確認できます。

### AI 利用の管理（リポジトリ所有者向け）

AI の使用量はリポジトリ直下の **`ai-config.json`** で管理できます。GitHub 上でこのファイルを編集するだけで、**起動中のアプリに約10分以内に反映**されます（利用者側の操作・再起動は不要）。

| キー | 対象 | 値 |
|---|---|---|
| `chat_daily_limit` | 💬 自由チャット質問 | `-1`=無制限 / `0`=停止 / 正の数=1日の回数上限（既定 20） |
| `core_daily_limit` | 🎤 口頭試問・📝 弱点まとめ・🎯 復習問題・📰 統計ノート | 同上（既定 `-1`=無制限） |

チャットは一般のチャット AI でも代替できるため上限付き、アプリの学習データ（誤答・章の文脈）が必要なコア機能は無制限、という既定にしています。上限に達しても学習機能（問題演習・にがて帳など）には影響しません。オフライン時はローカルの `ai-config.json` が使われます。

## 教材データ

正データは `lessonNN/chMM.json`（教科書 `text` + 4択 `quiz`）。各章の `README.md` は答え付きの読み物として自動生成されます。編集後は次で検証してください。

```sh
go run ./tools/coursegen
```
