# 宅建どうじょう 🏠

法律も不動産もまったくの初心者が、**このアプリひとつで宅地建物取引士（宅建）試験の合格レベルに到達する**ことを目指すブラウザ学習アプリです。左に教科書、右に一問一答（4択）。答えるとその場で判定と解説が出ます。

- 全30章・125チャプター・**650問**（講義 + 分野別ドリル130問 + 本試験形式フル模試50問×2回）
- すべてオリジナル問題。教科書は専門用語をかみ砕き、ゴロ合わせと表で覚えられる超初心者仕様

## 使い方

```sh
cd takken
go -C app run .
```

ブラウザで <http://127.0.0.1:8084> を開いてください。必要なのは [Go](https://go.dev/dl/) 1.22+ だけです。

## 合格までの流れ（推奨）

| ステップ | 章 | やること |
|---|---|---|
| 1. 戦略を知る | 第1章 | 「7割で勝ち・業法が得点源」を頭に入れる |
| 2. 得点源を作る | 第2〜9章 + 第24章 | 宅建業法（本試験20問分）を固める |
| 3. 深追いせず学ぶ | 第10〜16章 + 第25章 | 権利関係（民法）は基本だけ確実に |
| 4. 暗記で稼ぐ | 第17〜22章 | 法令上の制限・税・免除科目 |
| 5. ひたすら回す | 第23・26〜28章 | ミニ模試 + 分野別ドリル156問を全問クリアまで |
| 6. 本番形式で仕上げ | 第29・30章 | フル模試50問×2回（2時間を計って解く） |

- 全問正解でチャプタークリア ✅。間違えた問題は **にがて帳** に自動記録され、ワンクリックで解き直せます
- 「🙋 質問」でその場で AI の先生に質問できます（ローカルに [Claude Code](https://claude.com/claude-code) がある場合のみ。なくても学習機能はすべて使えます）
- **弱点ノート**: あなたの誤答と質問から「苦手分野まとめ」と「あなた専用の復習問題」を自動生成します

> ⚠️ 統計問題（地価・着工戸数など）は毎年数値が変わるため、本アプリは数値を出題しません。試験直前に必ず最新の公表値を確認してください。教材は法改正（相続登記義務化・盛土規制法・2025年建築確認改正など）に配慮して作成していますが、受験年度の法改正情報もあわせて確認することをおすすめします。

## 教材データ

正データは `lessonNN/chMM.json`（教科書 `text` + 4択 `quiz`）。各章の `README.md` は答え付きの読み物として自動生成されます。編集後は次で検証してください。

```sh
go run ./tools/coursegen
```
