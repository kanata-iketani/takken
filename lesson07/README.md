# 第7章 37条書面と8種制限

契約後に交付する37条書面と、業者が自ら売主のときだけ働く8種制限を学びます。「35条との違い」と「業者間には適用なし」という2つの視点、そして8日・2割・5％・10％の数字が合否を分けます。

## 1. 37条書面とは（契約後に両当事者へ）

契約がまとまったら、「どんな内容で契約したか」を証拠として残す書面を交付します。これが**37条書面**（実務でいう契約書に相当）です。35条書面が「契約前の判断材料」なら、37条書面は「契約内容の記録」。目的が違うのでルールも違います。

### 基本ルール

| 項目 | 内容 |
|---|---|
| いつ | 契約**成立後、遅滞なく** |
| 誰に | **両当事者**（売主と買主、貸主と借主の双方） |
| 説明 | **不要**（交付するだけでよい） |
| 記名 | **宅建士の記名**が必要（押印は不要。承諾を得れば電磁的交付も可） |
| 相手が宅建業者のとき | **省略できない**（業者間でも交付必要） |

### 必ず記載する事項（必要的記載事項）の例

- 当事者の氏名・住所、物件を特定するための表示
- **代金・借賃の額**、支払時期・方法
- **引渡しの時期**
- **移転登記の申請の時期**（売買の場合）
- 既存建物のときは、構造耐力上主要な部分等の状況について**当事者双方が確認した事項**（売買の場合）

> 💡コツ：🔴 「37条書面は宅建士が説明しなければならない」は誤りの定番。説明義務があるのは35条だけです。

### 確認問題

**問1.** 37条書面について、正しいものはどれでしょう？

1. 宅地建物取引士が、内容を説明したうえで交付しなければならない
2. 説明は不要であり、交付すれば足りる
3. 契約成立前に交付しなければならない
4. 買主に交付すれば、売主への交付は不要である

<details><summary>答えと解説</summary>

正解: **2**

37条書面は契約内容の記録なので、交付すれば足り、説明義務はありません（説明が必要なのは35条書面）。交付時期は契約成立後遅滞なく、交付の相手方は売主・買主（貸主・借主）の両当事者です。

</details>

**問2.** 宅建業者Aが媒介した売買契約の両当事者がいずれも宅建業者である場合、37条書面の交付はどうなるでしょう？

1. プロ同士なので、交付を省略できる
2. どちらか一方に交付すればよい
3. 両当事者が承諾すれば、交付を省略できる
4. 業者間の取引であっても、両当事者に交付しなければならない

<details><summary>答えと解説</summary>

正解: **4**

37条書面は、相手方が宅建業者であっても省略できず、両当事者への交付が必要です。相手が業者のときに「説明」を省略できるのは35条の話であり、37条にはそもそも説明義務がなく、交付義務は常に残ります。当事者の承諾でも免除されません。

</details>

**問3.** 売買契約の37条書面に必ず記載しなければならない事項はどれでしょう？

1. 物件の引渡しの時期
2. 損害賠償額の予定（定めがない場合も含む）
3. 手付金等の保全措置の概要
4. 水害ハザードマップにおける物件の所在地

<details><summary>答えと解説</summary>

正解: **1**

引渡しの時期は、代金の額・支払時期、移転登記の申請時期などと並ぶ37条書面の必要的記載事項です。損害賠償額の予定は「定めがあるとき」に記載する任意的記載事項です。手付金等の保全措置の概要や水害ハザードマップは35条の説明事項で、37条書面の記載事項ではありません。

</details>

**問4.** 37条書面への記名と交付方法について、正しいものはどれでしょう？

1. 宅建業者の記名押印が必要で、電磁的方法による交付は認められない
2. 宅建士の記名と押印の両方が必要である
3. 宅建士の記名が必要であり、相手方の承諾を得れば電磁的方法により交付できる
4. 誰の記名も不要で、内容が正しければよい

<details><summary>答えと解説</summary>

正解: **3**

37条書面には宅建士の記名が必要です（法改正で押印は廃止されました）。また、相手方の承諾を得れば電磁的方法による交付も認められています。業者の記名押印が必要なのは媒介契約書面（34条の2）であり、混同に注意しましょう。

</details>

## 2. 35条と37条の比較（頻出！）

35条と37条の違いを入れ替えるひっかけは、宅建業法の**最頻出パターン**です。1つの表にまとめて丸ごと覚えましょう。

### 比較表

| 項目 | 35条書面（重説） | 37条書面 |
|---|---|---|
| 目的 | 契約前の判断材料 | 契約内容の記録 |
| 交付時期 | **契約成立前** | **契約成立後、遅滞なく** |
| 交付相手 | **買主・借主**になろうとする者 | **両当事者** |
| 説明 | **必要**（宅建士が） | **不要** |
| 宅建士の記名 | 必要 | 必要（**共通**） |
| 宅建士証の提示 | 請求がなくても必要 | 請求があれば提示 |
| 相手が宅建業者 | 説明省略可（交付は必要） | 交付必要（省略不可） |
| 代金・借賃の額 | 記載不要 | **必ず記載** |
| 引渡し時期・移転登記の申請時期 | 記載不要 | **必ず記載** |

どちらの書面も交付場所に決まりはなく、事務所以外で交付してもかまいません。また、どちらも宅建士が**記名**しますが、説明まで必要なのは35条だけです。

> 💡コツ：🔴 「**前に説明35条、後に記録37条**」。そして「代金の額と引渡し時期は37条だけ」。この2フレーズで比較問題の大半が解けます。

### 確認問題

**問1.** 35条書面と37条書面に共通する事項として、正しいものはどれでしょう？

1. 契約成立前に交付しなければならない点
2. 宅地建物取引士の記名が必要である点
3. 宅地建物取引士が内容を説明しなければならない点
4. 両当事者に交付しなければならない点

<details><summary>答えと解説</summary>

正解: **2**

宅建士の記名は35条書面・37条書面の両方で必要な共通点です。交付時期（前／後）、説明義務（あり／なし）、交付相手（買主借主／両当事者）はすべて両書面で異なるため、共通点とはいえません。

</details>

**問2.** 「代金の額」の取扱いとして、正しいものはどれでしょう？

1. 35条書面・37条書面のいずれにも記載しなければならない
2. 35条書面に記載すれば、37条書面への記載は不要である
3. 35条の説明事項ではないが、37条書面には必ず記載しなければならない
4. いずれの書面にも記載する必要はない

<details><summary>答えと解説</summary>

正解: **3**

代金の額は35条の説明事項ではありません（当事者が当然知っている情報のため）。一方、契約内容の記録である37条書面には必要的記載事項として必ず記載します。引渡し時期・移転登記の申請時期も同じパターンで、まとめて覚えましょう。

</details>

**問3.** 宅建士証の提示義務に関する次の記述のうち、正しいものはどれでしょう？

1. 35条の重要事項説明の際は、請求がなくても宅建士証を提示しなければならない
2. 37条書面の交付の際は、請求がなくても宅建士証を提示しなければならない
3. 35条・37条とも、請求があったときのみ提示すればよい
4. 35条・37条とも、提示義務は一切ない

<details><summary>答えと解説</summary>

正解: **1**

請求がなくても宅建士証を提示しなければならないのは、重要事項説明（35条）の場面だけです。37条書面の交付には説明義務がないため、提示は「取引の関係者から請求があったとき」の一般ルールによります。

</details>

**問4.** 宅建業者が媒介した建物の売買で、買主だけが宅建業者である場合の書面実務として正しいものはどれでしょう？

1. 買主への35条書面の交付と37条書面の交付は、いずれも省略できる
2. 買主への35条の説明は省略できるが、35条書面と37条書面の交付は必要である
3. 買主への35条の説明は省略できないが、37条書面の交付は省略できる
4. 買主が承諾すれば、すべての書面交付を省略できる

<details><summary>答えと解説</summary>

正解: **2**

相手方が宅建業者の場合に省略できるのは35条の「説明」だけで、35条書面の交付は必要です。37条書面は相手が業者でも必ず交付します。「書面交付まで全部省略できる」とするのが典型的な誤りです。

</details>

**問5.** 書面を交付する場所について、正しいものはどれでしょう？

1. 35条書面は必ず事務所で交付しなければならない
2. 37条書面は必ず契約を締結した場所で交付しなければならない
3. 35条書面・37条書面とも、交付場所に法律上の制限はない
4. いずれの書面も、案内所では交付できない

<details><summary>答えと解説</summary>

正解: **3**

35条書面も37条書面も、交付する場所についての制限はありません。喫茶店や相手方の自宅で交付してもかまいません。場所の制限と混同しやすいのはクーリング・オフ（申込みの場所が問題になる制度）なので、区別しておきましょう。

</details>

## 3. 8種制限とは（自ら売主・買主が一般人のときだけ）

プロの宅建業者が自分の物件を一般のお客さんに売るとき、知識も経験も圧倒的に業者が有利です。そこで宅建業法は、**宅建業者が自ら売主**となり、**買主が宅建業者でない**売買契約に限って、買主を守る8つの特別ルールを置きました。これが**8種制限（自ら売主制限）**です。

### 適用される場面（ここが最重要！）

| 売主 | 買主 | 8種制限 |
|---|---|---|
| 宅建業者 | 一般人（非業者） | **適用あり** |
| 宅建業者 | 宅建業者 | **適用なし**（業者間取引） |
| 一般人 | 誰でも | 適用なし（そもそも自ら売主でない） |

業者が**媒介・代理**として関わるだけの取引にも適用されません。あくまで「業者が売主」のときだけです。

### 8つのメニュー（詳細は次チャプター以降）

①クーリング・オフ ②手付額の制限（2割まで） ③手付金等の保全措置 ④自己の所有に属しない物件の売買の制限 ⑤担保責任についての特約の制限 ⑥損害賠償額の予定等の制限（2割まで） ⑦割賦販売契約の解除等の制限 ⑧所有権留保等の禁止

> 💡コツ：🔴 問題文を読んだら、まず「売主は業者か？ 買主は非業者か？」をチェック。**業者間なら8種制限は全部適用なし**。これだけで解ける問題が毎年あります。

### 確認問題

**問1.** 8種制限（自ら売主制限）が適用されるのは、次のうちどの場合でしょう？

1. 宅建業者が売主、宅建業者が買主の売買契約
2. 宅建業者でない者が売主、宅建業者が買主の売買契約
3. 宅建業者が売主、宅建業者でない者が買主の売買契約
4. 宅建業者が売買を媒介し、売主・買主とも宅建業者でない売買契約

<details><summary>答えと解説</summary>

正解: **3**

8種制限は「宅建業者が自ら売主」かつ「買主が宅建業者でない」場合にのみ適用されます。業者間の取引には適用されず、業者が買主の場合や、業者が媒介として関わるだけの場合も対象外です。

</details>

**問2.** 宅建業者Aが自ら売主として、宅建業者Bに宅地を売却する場合について、正しいものはどれでしょう？

1. 業者間の取引なので、クーリング・オフなどの8種制限は適用されない
2. 手付額の制限（代金の2割まで）だけは適用される
3. クーリング・オフの規定だけは適用される
4. 8種制限はすべて適用される

<details><summary>答えと解説</summary>

正解: **1**

買主Bも宅建業者なので業者間取引となり、8種制限は8つとも適用されません。「手付の制限だけは残る」「クーリング・オフだけは残る」といった一部適用はなく、全部が適用外になります。なお35条書面・37条書面の交付義務など8種制限以外の規制は業者間でも及びます。

</details>

**問3.** 宅建業者Aが、売主C（宅建業者でない個人）と買主D（宅建業者でない個人）の売買を媒介する場合、8種制限の適用はどうなるでしょう？

1. 買主Dを保護するため、8種制限がすべて適用される
2. Aは自ら売主ではないので、8種制限は適用されない
3. クーリング・オフの規定のみ適用される
4. 売主Cが承諾すれば8種制限が適用される

<details><summary>答えと解説</summary>

正解: **2**

8種制限は宅建業者が「自ら売主」となる場合の規制です。業者が媒介や代理として関与するだけの取引では、売主は一般人ですから適用されません。当事者の承諾によって適用の有無が変わる制度でもありません。

</details>

**問4.** 8種制限に含まれないものは、次のうちどれでしょう？

1. クーリング・オフ
2. 損害賠償額の予定等の制限
3. 手付金等の保全措置
4. 誇大広告の禁止

<details><summary>答えと解説</summary>

正解: **4**

誇大広告の禁止は、すべての宅建業者に適用される一般的な業務規制であり、8種制限ではありません。クーリング・オフ、損害賠償額の予定等の制限（2割）、手付金等の保全措置は、いずれも自ら売主の場合の8種制限に含まれます。

</details>

## 4. クーリング・オフ（8日間・事務所等以外・告知）

モデルルーム見学のあと喫茶店で勧誘され、雰囲気にのまれて申込みをしてしまった……そんな「冷静でない場所での契約」をなかったことにできる制度が**クーリング・オフ**（37条の2）です。8種制限の1つなので、業者が自ら売主・買主が非業者の場合に限ります。

### できる条件

- **事務所等以外の場所**で**買受けの申込み**をしたこと（**申込みをした場所で判断**。申込みが喫茶店なら、契約を事務所でしても解除可）
- 「事務所等」＝事務所のほか、専任宅建士の設置義務がある案内所（**土地に定着するもの**）、**買主から申し出た**場合の買主の自宅・勤務先など。テント張りの案内所は事務所等に当たりません

### できなくなる場合

| できなくなる場合 | 内容 |
|---|---|
| 告知から8日 | クーリング・オフできる旨等を**書面で告げられた日から起算して8日**を経過（告知がなければいつまでも可能） |
| 履行の完了 | **引渡しを受け、かつ代金全部を支払った**とき |

### 効果と方法

**書面（電磁的方法も可）**で行い、**発信した時**に効力が生じます。業者は損害賠償・違約金を請求できず、受け取った手付金等は速やかに全額返還します。買主に不利な特約は無効です。

> 💡コツ：🔴 ゴロは「**ハガキで8日**」。書面で告げられてから8日、行使も書面で、と覚えましょう。

### 確認問題

**問1.** 宅建業者A（売主）と宅建業者でないBの取引で、Bが喫茶店で買受けの申込みをし、後日Aの事務所で売買契約を締結した場合、クーリング・オフはできるでしょうか？

1. 契約を事務所で締結しているので、できない
2. 申込みを事務所等以外の場所でしているので、他の要件を満たせばできる
3. 喫茶店はどんな場合でも事務所等に当たるので、できない
4. 申込みと契約の場所が異なる場合は、常にできない

<details><summary>答えと解説</summary>

正解: **2**

クーリング・オフの可否は「買受けの申込みをした場所」で判断します。申込みが喫茶店（事務所等以外）なら、契約締結が事務所でも、告知から8日以内などの要件を満たす限り解除できます。契約場所で判断するという誤りが定番のひっかけです。

</details>

**問2.** クーリング・オフができなくなる場合として、正しいものはどれでしょう？

1. クーリング・オフできる旨を口頭で告げられてから8日を経過したとき
2. 物件の引渡しを受けたとき（代金は半分だけ支払済み）
3. クーリング・オフできる旨等を書面で告げられた日から起算して8日を経過したとき
4. 買受けの申込みから1か月を経過したとき

<details><summary>答えと解説</summary>

正解: **3**

8日のカウントは「書面で」告げられた日から始まります。口頭の告知では期間が進行せず、告知がなければいつまでもクーリング・オフ可能です。また「引渡しを受け、かつ代金全部を支払った」場合に初めてできなくなるので、代金の一部しか払っていない肢2の段階ではまだ可能です。

</details>

**問3.** クーリング・オフの方法と効力について、正しいものはどれでしょう？

1. 口頭で申し出た時に効力が生じる
2. 書面で行い、その書面を発信した時に効力が生じる
3. 書面で行い、その書面が宅建業者に到達した時に効力が生じる
4. 宅建業者が承諾した時に効力が生じる

<details><summary>答えと解説</summary>

正解: **2**

クーリング・オフは書面（電磁的方法も可）で行い、発信した時に効力が生じます（発信主義）。8日目にポストに投函すれば、到達が9日目以降でも有効です。民法の原則（到達主義）と異なる点が狙われます。業者の承諾は不要です。

</details>

**問4.** 買主Bが「自宅で説明を聞きたい」と自ら申し出たため、宅建業者A（売主）がBの自宅で説明し、Bがその場で買受けの申込みをした場合はどうなるでしょう？

1. 買主から申し出た自宅は事務所等に当たるので、クーリング・オフはできない
2. 自宅は常に事務所等以外の場所なので、クーリング・オフできる
3. Aから申し出た場合と同じ扱いになり、クーリング・オフできる
4. 自宅での申込みは無効となる

<details><summary>答えと解説</summary>

正解: **1**

買主が自ら申し出た場合の買主の自宅・勤務先は「事務所等」に含まれるため、そこでの申込みはクーリング・オフの対象外です。逆に業者側から「ご自宅に伺います」と申し出た場合は事務所等に当たらず、クーリング・オフ可能です。申込み自体が無効になるわけではありません。

</details>

**問5.** クーリング・オフが有効に行われた場合の効果として、正しいものはどれでしょう？

1. 宅建業者は、買主に違約金を請求できる
2. 宅建業者は、受領した手付金を半額だけ返還すればよい
3. 宅建業者は、損害賠償・違約金を請求できず、受領した手付金等を速やかに全額返還しなければならない
4. 「クーリング・オフしても手付金は返還しない」という特約があれば、その特約に従う

<details><summary>答えと解説</summary>

正解: **3**

クーリング・オフが行われると、業者は損害賠償や違約金を一切請求できず、受け取った手付金等は速やかに全額返還しなければなりません。買主に不利な特約（手付金を返さない等）は無効なので、肢4のような特約があっても従う必要はありません。

</details>

## 5. 手付金等の保全・手付2割・その他の制限

8種制限の残りは「お金」まわりです。数字が狙われます（いずれも業者が自ら売主・買主が非業者の場合の話です）。

### 手付の制限

- 手付の額は**代金の2割（10分の2）まで**。超えて受領できません
- 買主が払う手付は常に**解約手付**の性質を持ちます。相手方が履行に着手するまでは、**買主は手付を放棄**して、**売主（業者）は倍額を現実に提供**して契約を解除できます。買主に不利な特約は無効です

### 手付金等の保全措置

倒産などに備え、銀行の保証などの**保全措置を講じた後**でなければ手付金等（手付金・中間金など、引渡し前に受領する金銭）を受領できません。保全措置が不要なのは次の場合です。

| 物件 | 保全不要の範囲 |
|---|---|
| **未完成**物件 | 代金の**5％以下** かつ 1,000万円以下 |
| **完成**物件 | 代金の**10％以下** かつ 1,000万円以下 |

買主への所有権移転登記がされたときも不要です。業者が保全措置を講じないときは、買主は手付金等の**支払いを拒否**できます。

### その他

- **損害賠償額の予定・違約金**：合算して代金の**2割まで**。**超える部分が無効**
- **担保責任の特約**：契約不適合の通知期間を「**引渡しから2年以上**」とする特約を除き、民法より買主に不利な特約は無効

> 💡コツ：🔴 「**未完成5％・完成10％・どちらも1,000万円**」「手付も損賠予定も**2割**」とセットで暗記。

### 確認問題

**問1.** 宅建業者Aが自ら売主として、宅建業者でないBと代金4,000万円の売買契約を締結する場合、Aが受領できる手付の上限はいくらでしょう？

1. 400万円
2. 1,000万円
3. 1,200万円
4. 800万円

<details><summary>答えと解説</summary>

正解: **4**

手付の額は代金の2割までなので、4,000万円×20％＝800万円が上限です。これを超えて受領することはできず、買主の承諾があっても同じです。1,000万円という数字は手付金等の保全措置の基準であり、手付額の上限とは別物です。

</details>

**問2.** 宅建業者Aが自ら売主となる完成物件（代金3,000万円）の売買で、保全措置を講じずに受領できる手付金等の上限はいくらでしょう？

1. 150万円（代金の5％）
2. 300万円（代金の10％）
3. 600万円（代金の20％）
4. 1,000万円

<details><summary>答えと解説</summary>

正解: **2**

完成物件では、代金の10％以下かつ1,000万円以下なら保全措置なしで受領できます。3,000万円の10％＝300万円が上限です。5％は未完成物件の基準で、入れ替えが定番のひっかけです。20％は手付「額」の上限であり、保全措置の基準ではありません。

</details>

**問3.** 宅建業者Aが自ら売主となる売買契約で、損害賠償額の予定と違約金を合計して代金の3割と定めた場合、どうなるでしょう？

1. 定め全体が無効となり、損害賠償額の予定はなかったものとなる
2. 代金の2割を超える部分が無効となる
3. 当事者が合意しているので、3割の定めは有効である
4. 売買契約自体が無効となる

<details><summary>答えと解説</summary>

正解: **2**

損害賠償額の予定と違約金は合算して代金の2割までで、超える定めをしたときは「超える部分」だけが無効になります（定め全体や契約自体が無効になるのではありません）。当事者の合意があっても2割の上限は動きません。

</details>

**問4.** 宅建業者Aが自ら売主となる売買契約における契約不適合責任の特約として、有効なものはどれでしょう？

1. 不適合を通知すべき期間を「引渡しの日から2年間」とする特約
2. 不適合を通知すべき期間を「引渡しの日から1年間」とする特約
3. 売主は契約不適合責任を一切負わないとする特約
4. 不適合を通知すべき期間を「契約締結の日から1年間」とする特約

<details><summary>答えと解説</summary>

正解: **1**

通知期間を「引渡しから2年以上」とする特約だけは、民法（知った時から1年）より不利でも例外的に有効です。「引渡しから1年」「契約締結から1年」はこの例外に当たらず、責任を一切負わない特約とともに無効となり、民法の原則に戻ります。

</details>

**問5.** 宅建業者A（自ら売主）が手付金等の保全措置を講じない場合、宅建業者でない買主Bはどうすることができるでしょう？

1. 手付金等の支払いを拒むことができる
2. 直ちに契約を解除し、違約金を請求できる
3. 何もできず、手付金等を支払わなければならない
4. 手付金を半額に減額するよう請求できる

<details><summary>答えと解説</summary>

正解: **1**

業者が必要な保全措置を講じないときは、買主は手付金等の支払いを拒否でき、拒否しても債務不履行にはなりません。支払義務を負うとする肢3は誤りです。保全措置を講じないこと自体から直ちに違約金請求権や減額請求権が生じるわけではありません。

</details>
