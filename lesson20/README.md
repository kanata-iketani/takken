# 第20章 土地区画整理法・盛土規制法

法令上の制限の仕上げです。土地区画整理法は「減歩・換地・保留地」のストーリー、盛土規制法は2023年にできた新しい規制の数字を押さえます。最後のチャプターで分野全体の数字を横断整理して、8問中6問を狙える状態にしましょう。

## 1. 土地区画整理法のしくみ —— 減歩・換地・保留地

土地区画整理は、曲がりくねった道と不揃いな土地を、**区画を整え直して**住みよい街にする事業です。ストーリーで覚えましょう。

### 事業のストーリー

1. 地権者が土地を少しずつ出し合う → 土地は少し減るがこれが**減歩(げんぶ)**。道路・公園が整って土地の価値は上がるので損にならない、という考え方です
2. 出し合った土地の一部は売却して事業費にあてる → これが**保留地**
3. 工事後、従前の宅地の代わりに新しく割り当てられる土地 → これが**換地**

### 施行者(誰が事業をやる?)

個人、**土地区画整理組合**、区画整理会社、地方公共団体、国土交通大臣などが施行できます。特に出るのは組合です。

| 組合のポイント | 内容 |
|---|---|
| 設立 | 宅地の所有者・借地権者が**7人以上**共同して、知事の認可を受ける |
| 組合員 | 施行地区内の宅地の所有者・借地権者は**全員が組合員**(反対した人も強制加入) |

> 💡コツ: 「**減って(減歩)・売って(保留地)・もらう(換地)**」の3点セット。組合は「**7人以上**・反対者も**全員加入**」です。

> 🟡 用語の意味の入れ替えひっかけに注意しましょう。

### 確認問題

**問1.** 土地区画整理事業における「減歩」の説明として、正しいものはどれでしょう?

1. 道路や公園の用地などにあてるため、地権者の土地が従前より少し減ることをいう
2. 事業費にあてるため売却される土地のことをいう
3. 従前の宅地の代わりに割り当てられる土地のことをいう
4. 工事期間中に一時的に使用する土地のことをいう

<details><summary>答えと解説</summary>

正解: **1**

減歩は、道路・公園などの公共用地や保留地を生み出すために、各地権者の土地面積が従前より減ることです。事業費にあてるため売却される土地は「保留地」、従前の宅地の代わりに割り当てられる土地は「換地」であり、用語の入れ替えに注意しましょう。

</details>

**問2.** 土地区画整理組合の設立について、正しいものはどれでしょう?

1. 宅地の所有者・借地権者が5人以上共同して設立する
2. 宅地の所有者・借地権者が7人以上共同し、都道府県知事の認可を受けて設立する
3. 宅地の所有者のみが10人以上共同して設立し、借地権者は参加できない
4. 市町村長の許可を受ければ1人でも設立できる

<details><summary>答えと解説</summary>

正解: **2**

組合は宅地の所有者または借地権者が7人以上共同して定款と事業計画を定め、知事の認可を受けて設立します。5人や10人は数字のひっかけです。借地権者も設立に参加でき、1人で設立できる制度ではありません。

</details>

**問3.** 土地区画整理組合が設立された場合の組合員について、正しいものはどれでしょう?

1. 設立に賛成した者だけが組合員となる
2. 施行地区内の宅地の所有者のうち希望者のみが組合員となる
3. 施行地区内の宅地の所有者および借地権者は、すべて組合員となる
4. 施行地区外の者も自由に組合員になれる

<details><summary>答えと解説</summary>

正解: **3**

組合が成立すると、施行地区内の宅地の所有者と借地権者は全員が組合員になります。設立に反対した人も強制的に加入するのがポイントで、賛成者や希望者だけとする選択肢は誤りです。施行地区外の者が当然に組合員になる制度ではありません。

</details>

## 2. 仮換地と換地処分 —— 使用収益できるのは誰か

工事中の仮住まいのルールが**仮換地**、事業のフィナーレが**換地処分**です。「どの土地を使えるか」と「所有権はどこにあるか」のズレが試験の狙いどころです。

### 仮換地が指定されると

| 項目 | 内容 |
|---|---|
| 使用収益 | 従前の宅地の所有者は**仮換地を使用収益できる**ようになり、**従前の宅地は使用収益できなくなる** |
| 所有権 | **従前の宅地に残ったまま**。だから売買や抵当権の設定は**従前の宅地**について行う |

「住むのは仮換地、売るのは従前地」という不思議な状態になるのがポイントです。

### 換地処分

工事が完了すると換地処分が行われ、知事が**公告**します。効果は次のとおりです。

- **公告の日の翌日**に、換地は**従前の宅地とみなされる**(所有権がここで切り替わる)
- **保留地は施行者が取得**する(売却して事業費にあてるため)

> 💡コツ: 「使うのは仮換地・売るのは従前地」「効果は公告の**翌日**」「保留地は**施行者**のもの」。この3フレーズで得点できます。

> 🟡 「仮換地を売買する」という誤りの選択肢に反応できるようにしましょう。

### 確認問題

**問1.** 仮換地が指定された場合、従前の宅地の所有者について正しいものはどれでしょう?

1. 従前の宅地と仮換地の両方を使用収益できる
2. 仮換地を使用収益できるようになり、従前の宅地は使用収益できなくなる
3. 引き続き従前の宅地のみを使用収益できる
4. 施行者の許可を得なければ、いずれの土地も使用できない

<details><summary>答えと解説</summary>

正解: **2**

仮換地の指定により、従前の宅地の所有者は仮換地を使用収益できるようになる一方、従前の宅地は使用収益できなくなります。両方使えるわけでも、従前地だけ使えるわけでもありません。使用収益の移転は指定の効果であり、個別の許可の問題ではありません。

</details>

**問2.** 仮換地の指定後、従前の宅地の所有者が土地を売却したい場合、正しいものはどれでしょう?

1. 所有権は従前の宅地にあるので、従前の宅地を売却する
2. 使用収益している仮換地を売却する
3. 換地処分まで、いかなる土地も売却できない
4. 従前の宅地と仮換地をセットでなければ売却できない

<details><summary>答えと解説</summary>

正解: **1**

仮換地の指定があっても所有権は従前の宅地に残っているため、売買や抵当権設定は従前の宅地について行います。仮換地は使用収益の対象にすぎず、売却の対象ではありません。売却自体が禁止されるわけでも、セット売却という制度があるわけでもありません。

</details>

**問3.** 換地処分の公告があった場合の効果として、正しいものはどれでしょう?

1. 公告の日の当日に、換地が従前の宅地とみなされる
2. 公告の日から2週間後に、換地が従前の宅地とみなされる
3. 公告の日の翌日に、換地が従前の宅地とみなされる
4. 公告によって従前の宅地の所有権はすべて国に帰属する

<details><summary>答えと解説</summary>

正解: **3**

換地計画で定められた換地は、換地処分の公告の日の「翌日」から従前の宅地とみなされます。「当日」や「2週間後」は日付のひっかけです。所有権が国に帰属するという効果はありません。

</details>

**問4.** 換地処分後の保留地について、正しいものはどれでしょう?

1. 従前の宅地の所有者全員の共有となる
2. 換地処分の公告の日の翌日に、施行者が取得する
3. 市町村が無償で取得する
4. 最も面積の大きい組合員が取得する

<details><summary>答えと解説</summary>

正解: **2**

保留地は換地処分の公告の日の翌日に施行者が取得します。施行者はこれを売却して事業費にあてるのが保留地の目的だからです。地権者の共有や市町村の無償取得、特定の組合員の取得という制度ではありません。

</details>

## 3. 盛土規制法 —— 2023年にできた新しい規制

2021年の熱海の土石流災害をきっかけに、旧「宅地造成等規制法」が改正され、**2023年**に「宅地造成及び特定盛土等規制法」、通称**盛土規制法**として施行されました。**宅地だけでなく農地・森林の盛土も対象**になったのが最大の変更点です。

### 規制のしくみ

都道府県知事等は、災害のおそれが大きい市街地などを**宅地造成等工事規制区域**に指定します。区域内で次の規模の宅地造成等の工事をするには、**工事主が知事等の許可**を受けなければなりません。

| 許可が必要な工事(主なもの) | 基準 |
|---|---|
| 盛土でできる崖 | 高さ**1m超** |
| 切土でできる崖 | 高さ**2m超** |
| 盛土+切土でできる崖 | 高さ2m超 |
| 崖ができなくても盛土 | 高さ**2m超** |
| 面積 | **500㎡超** |

また、市街地から離れた場所でも、**特定盛土等規制区域**を指定して大規模な盛土などを規制できます。

> 💡コツ: ゴロは「**盛1(もりいち)・切2(きりに)・面500**」。「盛土の方が崩れやすいから基準が厳しい(1m)」と理屈をつけると忘れません。

> 🟡 新しい法律は出題されやすい注目分野。名称・2023年・数字の3点を持ち帰りましょう。

### 確認問題

**問1.** 盛土規制法(宅地造成及び特定盛土等規制法)について、正しいものはどれでしょう?

1. 規制の対象は宅地の造成に限られ、農地や森林の盛土は対象外である
2. 旧・宅地造成等規制法が改正されたもので、農地や森林の盛土も規制の対象となった
3. 2010年に施行された古い法律である
4. 盛土を全国どこでも一律に禁止する法律である

<details><summary>答えと解説</summary>

正解: **2**

盛土規制法は旧・宅地造成等規制法を改正して2023年に施行された法律で、宅地に限らず農地・森林の盛土等も対象にしたことが最大のポイントです。「宅地限定」は旧法のイメージによるひっかけです。全国一律の禁止ではなく、規制区域を指定して許可制とする仕組みです。

</details>

**問2.** 宅地造成等工事規制区域内で、知事等の許可が必要となる盛土の崖の高さの基準はどれでしょう?

1. 盛土で高さ50cm超の崖を生じるもの
2. 盛土で高さ2m超の崖を生じるもの
3. 盛土で高さ1m超の崖を生じるもの
4. 盛土で高さ3m超の崖を生じるもの

<details><summary>答えと解説</summary>

正解: **3**

盛土で高さ1m超の崖を生じる工事は許可が必要です。2m超は切土の場合の基準で、盛土と切土の数字の入れ替えが定番のひっかけです。盛土は人工の土で崩れやすいため、切土より厳しい基準になっています。

</details>

**問3.** 宅地造成等工事規制区域内の宅地造成等に関する工事について、正しいものはどれでしょう?

1. 工事主は、原則として都道府県知事等の許可を受けなければならない
2. 工事施行者が市町村長に届出をすれば足りる
3. 面積が300㎡を超える場合のみ規制の対象となる
4. 許可権者は農業委員会である

<details><summary>答えと解説</summary>

正解: **1**

規制区域内で一定規模の宅地造成等の工事を行うには、工事主が知事等の許可を受ける必要があります。届出で足りる制度ではなく、許可権者は市町村長や農業委員会ではありません。面積基準は500㎡超であり、300㎡という数字は誤りです。

</details>

## 4. 法令上の制限 総まとめ —— 数字と「誰の許可か」早見表

法令上の制限は、最後に**数字を横断して比べる**と一気に定着します。本試験のひっかけは、ほぼこの表の中の入れ替えです。

### 数字の横断表

| 制度 | 数字 |
|---|---|
| 開発許可(都市計画法) | 市街化区域**1000㎡**/非線引き・準都計**3000㎡**/区域外**10000㎡**(調整区域は面積不問) |
| 事後届出(国土法) | 市街化区域**2000㎡**/他の都市計画区域**5000㎡**/区域外**10000㎡**、契約から**2週間**以内 |
| 建築確認 | 特殊建築物**200㎡超**・階数2以上または**200㎡超**、増改築**10㎡**以内は不要(防火・準防火は除く) |
| 道路 | 幅員**4m**以上・接道**2m**以上 |
| 盛土規制法 | 盛土**1m**超・切土**2m**超・面積**500㎡**超 |

> 💡コツ: 同じ市街化区域でも「開発許可は**1000**・国土法は**2000**」。ここを混ぜるのが出題者の大好物です。

### 「誰の許可・どこへ届出」早見表

| 制度 | 相手 |
|---|---|
| 開発許可 | 都道府県知事等 |
| **農地法3条** | **農業委員会**(ここだけ別!) |
| 農地法4条・5条 | 都道府県知事等 |
| 国土法の事後届出 | 都道府県知事(市町村長経由) |
| 盛土規制法の許可 | 都道府県知事等 |

> 🔴 「農地法3条だけ農業委員会、あとはだいたい知事」。試験前日はこのチャプターだけ見直せばOKです。

### 確認問題

**問1.** 市街化区域内の土地に関する次の記述のうち、正しいものはどれでしょう?

1. 1500㎡の開発行為には開発許可が不要であり、1500㎡の土地売買には事後届出が必要である
2. 1500㎡の開発行為には開発許可が必要であり、1500㎡の土地売買の事後届出は不要である
3. 開発許可も事後届出も、市街化区域では3000㎡以上が基準である
4. 開発許可は2000㎡以上、事後届出は1000㎡以上が基準である

<details><summary>答えと解説</summary>

正解: **2**

市街化区域の基準は、開発許可が1000㎡以上、国土法の事後届出が2000㎡以上です。1500㎡は開発許可には該当しますが(1000㎡以上)、事後届出には該当しません(2000㎡未満)。2つの制度の数字を入れ替えたり混ぜたりするのが典型的なひっかけです。

</details>

**問2.** 許可権者・届出先が「農業委員会」となるものはどれでしょう?

1. 都市計画法の開発許可
2. 盛土規制法の宅地造成等に関する工事の許可
3. 農地法3条の権利移動の許可
4. 農地法5条の転用目的の権利移動の許可

<details><summary>答えと解説</summary>

正解: **3**

法令上の制限の中で農業委員会が登場するのは農地法3条(農地のままの権利移動)です。開発許可・盛土規制法の許可は知事等、農地法5条も転用がからむため知事等が許可権者です。「3条だけ農業委員会」と覚えましょう。

</details>

**問3.** 数字の組み合わせとして、正しいものはどれでしょう?

1. 建築基準法の接道義務は4m以上、道路の幅員は2m以上である
2. 国土法の事後届出は契約締結日から3週間以内に行う
3. 盛土規制法では切土で高さ1m超の崖を生じる工事から許可が必要である
4. 建築基準法上の道路は原則幅員4m以上、接道義務は2m以上である

<details><summary>答えと解説</summary>

正解: **4**

正しくは「道路の幅員4m以上・接道2m以上」です。選択肢1はこの2つを逆にしています。事後届出の期限は2週間以内(3週間は知事が勧告できる期間)。盛土規制法で1m超が基準になるのは盛土の崖で、切土は2m超です。

</details>

**問4.** 都市計画区域にも準都市計画区域にも含まれない区域内の土地(10000㎡)について、正しいものはどれでしょう?

1. この土地で行う10000㎡の開発行為には開発許可が必要であり、売買すれば事後届出も必要である
2. 開発許可・事後届出とも、区域外では一切不要である
3. 開発許可は必要だが、事後届出の制度は都市計画区域内にしか適用されない
4. 事後届出は必要だが、開発許可は5000㎡以上でなければ不要である

<details><summary>答えと解説</summary>

正解: **1**

両区域外の基準は、開発許可・事後届出ともに10000㎡以上です。10000㎡ちょうどは「以上」に当たるため、どちらも必要になります。区域外でも両制度は適用されるので「一切不要」「区域内にしか適用されない」は誤りです。5000㎡は市街化区域以外の都市計画区域における事後届出の基準です。

</details>
