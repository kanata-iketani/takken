# 第24章 宅建業法の仕上げ（瑕疵担保履行法ほか）

宅建業法もいよいよ仕上げです。毎年のように出題される住宅瑕疵担保履行法と、標識・案内所・帳簿といった事務所まわりの細かい義務を押さえ、最後に「誰が・いつまでに・どこへ」の横断整理で総点検します。

## 1. 住宅瑕疵担保履行法 ― 新築住宅の売主のセーフティネット

新築住宅を買ったのに、売主の業者が倒産して欠陥を直してもらえない……それを防ぐのが**住宅瑕疵担保履行法**です。🔴 本試験でほぼ毎年1問出る、覚えれば確実に取れるテーマです。

### 誰に・何に適用される？

- **宅建業者が自ら売主**となり、**宅建業者でない買主**に**新築住宅**を売る場合に適用（**媒介・代理は対象外**、業者間売買も対象外）
- 新築住宅＝工事完了から**1年以内**で、まだ人が住んだことのない住宅
- 守られる責任＝**構造耐力上主要な部分**と**雨水の浸入を防止する部分**の瑕疵についての、引渡しから**10年間**の担保責任

### 資力確保措置は2本立て

| 措置 | 内容 |
|---|---|
| **供託** | 住宅販売瑕疵担保保証金を供託所に供託（過去10年間に引き渡した戸数で算定。**床面積55㎡以下は2戸で1戸**と数える） |
| **保険** | 国土交通大臣が指定する保険法人の保険（期間**10年以上**）に加入 |

### 基準日の届出

毎年**3月31日（基準日）**の資力確保の状況を、基準日から**3週間以内**に免許権者へ届け出ます。届出をしないと、基準日の翌日から起算して**50日を経過した日以後**、新たに自ら売主となる新築住宅の売買契約が締結できなくなります。

> 💡コツ：供託による場合は、契約締結までに**供託所の所在地等を書面で説明**します。35条の重要事項説明とは別物で、宅建士が説明する必要はありません。

### 確認問題

**問1.** 住宅瑕疵担保履行法に基づく資力確保措置を講じる義務を負うのは、次のうちどれでしょう？

1. 新築住宅の売買を媒介する宅建業者
2. 宅建業者でない買主に対し、自ら売主として新築住宅を販売する宅建業者
3. 宅建業者である買主に対し、自ら売主として新築住宅を販売する宅建業者
4. 宅建業者でない買主に対し、自ら売主として中古住宅を販売する宅建業者

<details><summary>答えと解説</summary>

正解: **2**

義務を負うのは「自ら売主」として「宅建業者でない買主」に「新築住宅」を売る宅建業者だけです。媒介や代理をするだけの業者には義務がなく、買主が宅建業者の場合や中古住宅の売買も対象外です。三拍子がそろったときだけ、と覚えましょう。

</details>

**問2.** 住宅瑕疵担保履行法で資力確保の対象となる担保責任として、正しいものはどれでしょう？

1. 住宅のすべての部分の瑕疵について、引渡しから5年間の責任
2. 構造耐力上主要な部分と雨水の浸入を防止する部分の瑕疵について、引渡しから5年間の責任
3. 住宅のすべての部分の瑕疵について、引渡しから10年間の責任
4. 構造耐力上主要な部分と雨水の浸入を防止する部分の瑕疵について、引渡しから10年間の責任

<details><summary>答えと解説</summary>

正解: **4**

対象は「構造耐力上主要な部分」と「雨水の浸入を防止する部分」に限られ、期間は引渡しから10年間です。住宅のすべての部分が対象になるわけではなく、期間を5年とする肢も誤りです。「骨組みと雨漏りを10年守る」とイメージしましょう。

</details>

**問3.** 資力確保措置の状況の届出に関する次の記述のうち、正しいものはどれでしょう？

1. 基準日から3週間以内に、免許権者に資力確保措置の状況を届け出なければならない
2. 基準日から50日以内に、免許権者に資力確保措置の状況を届け出なければならない
3. 届出を怠っても、新たな売買契約の締結が制限されることはない
4. 届出は、免許権者ではなく国土交通大臣に対して行う

<details><summary>答えと解説</summary>

正解: **1**

基準日（毎年3月31日）から3週間以内に、免許権者（国土交通大臣または都道府県知事）へ届け出ます。届出をしないと、基準日の翌日から起算して50日を経過した日以後、新たに自ら売主となる新築住宅の売買契約を締結できなくなるため、肢3のような「制限なし」は誤りです。

</details>

**問4.** 住宅販売瑕疵担保保証金を供託する宅建業者の、供託所の所在地等の説明に関する次の記述のうち、正しいものはどれでしょう？

1. 売買契約の成立後、住宅の引渡しまでに説明すればよい
2. 説明は、宅建士が宅建士証を提示して行わなければならない
3. 売買契約を締結するまでに、書面を交付して（買主の承諾があれば電磁的方法で）説明しなければならない
4. 保険への加入により資力確保をする場合も、供託所の所在地等の説明が必要である

<details><summary>答えと解説</summary>

正解: **3**

供託により資力確保をする場合、契約締結までに書面を交付して供託所の所在地等を説明します（買主の承諾があれば電磁的方法も可）。35条の重要事項説明と異なり宅建士が行う必要はなく、保険加入による場合はこの説明自体が不要です。契約「後」では遅い点に注意しましょう。

</details>

## 2. 標識・案内所・従業者証明書

事務所や案内所に「何を掲げ、誰を置き、どこへ届け出るか」。地味な分野ですが、🟡 整理表を1枚覚えれば確実に得点できます。

### 場所ごとの整理表

| 場所 | 標識 | 報酬額の掲示 | 専任宅建士 | 届出 |
|---|---|---|---|---|
| 事務所 | ○ | **○（事務所のみ）** | 5人に1人以上 | 不要 |
| 申込み・契約をする案内所 | ○ | × | **1人以上** | **業務開始の10日前まで** |
| 申込み・契約をしない案内所（現地見学会など） | ○ | × | 不要 | 不要 |

- **標識はすべての場所に**掲示します（契約をしない案内所や、分譲する物件の所在地にも必要）
- 案内所の届出（50条2項）は、**免許権者**と**案内所の所在地を管轄する知事**の**両方**に行います
- 売主業者と媒介業者が共同で案内所を設置する場合、専任宅建士は**いずれか一方が1人**置けば足ります

### 従業者証明書

宅建業者は、従業者に**従業者証明書を携帯させなければ**業務に従事させてはいけません。従業者は、取引の関係者から請求があったときは提示します。**宅建士証での代用はできません**。

> 💡コツ：「標識はどこでも、報酬額は事務所だけ、案内所の届出は10日前に2か所へ」。この3フレーズで整理しましょう。

### 確認問題

**問1.** 宅地の分譲について、契約の申込みを受ける案内所を設置する場合の届出に関する次の記述のうち、正しいものはどれでしょう？

1. 案内所を設置した日から10日以内に、免許権者に届け出なければならない
2. 業務開始の10日前までに、案内所の所在地を管轄する知事にのみ届け出ればよい
3. 業務開始の10日前までに、免許権者と案内所の所在地を管轄する知事の両方に届け出なければならない
4. 契約の申込みを受けない案内所についても、業務開始の10日前までの届出が必要である

<details><summary>答えと解説</summary>

正解: **3**

申込み・契約をする案内所は、業務開始の「10日前まで」に、免許権者と所在地を管轄する知事の両方へ届け出ます（50条2項）。「設置後10日以内」ではなく事前の届出であり、申込み・契約をしない案内所は届出不要（標識の掲示のみ）です。

</details>

**問2.** 標識などの掲示に関する次の記述のうち、正しいものはどれでしょう？

1. 報酬の額は事務所に掲示すれば足り、案内所に掲示する必要はない
2. 標識は、契約の申込みを受ける案内所にのみ掲示すればよい
3. 分譲するマンションの所在する場所には、標識を掲示する必要はない
4. 従業者名簿は、事務所とすべての案内所に備え付けなければならない

<details><summary>答えと解説</summary>

正解: **1**

報酬額の掲示義務があるのは事務所だけです。一方、標識は申込み・契約の有無を問わず、案内所や分譲物件の所在する場所などすべてに掲示が必要です。従業者名簿や帳簿を備えるのは事務所のみで、案内所には不要です。

</details>

**問3.** 従業者証明書に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建士証を携帯している従業者には、従業者証明書を携帯させなくてもよい
2. 従業者は、取引の関係者から請求があったときは、従業者証明書を提示しなければならない
3. 一時的に業務を補助するアルバイトには、従業者証明書を携帯させる義務はない
4. 従業者は、取引の関係者から請求がなくても、常に従業者証明書を提示しながら業務を行わなければならない

<details><summary>答えと解説</summary>

正解: **2**

従業者証明書は、取引の関係者から請求があったときに提示する義務があります。宅建士証で代用することはできず、非常勤やアルバイトを含め業務に従事する者全員に携帯させる必要があります。請求がない場合まで常時提示する義務はありません。

</details>

## 3. 帳簿と従業者名簿（5年・10年と閲覧の違い）

事務所に備える2つの記録、**帳簿**と**従業者名簿**。🟡 試験では「5年と10年」「見せる・見せない」の入れ替えが定番のひっかけです。

### 比較表

| 項目 | 帳簿 | 従業者名簿 |
|---|---|---|
| 備える場所 | **事務所ごと** | **事務所ごと** |
| 記載 | 取引のあった**つど**記載 | 従業者の氏名・従業者証明書の番号など |
| 保存期間 | 各事業年度末に閉鎖し、閉鎖後**5年**（自ら売主となる**新築住宅に係るものは10年**） | 最終の記載をした日から**10年** |
| 閲覧 | 閲覧させる義務は**ない** | 取引の関係者から請求があれば**閲覧させる義務がある** |

どちらも、パソコンのデータなど電磁的記録による保存で代えることができます。備えるのは事務所だけで、案内所には不要です。

### ゴロで覚える

> 💡コツ：「**名簿は10年、みんなに見せる。帳簿は5年、誰にも見せない**」。例外は「新築住宅を自ら売ったら帳簿も10年」の1つだけです。

### 確認問題

**問1.** 帳簿と従業者名簿の保存期間の組合せとして、正しいものはどれでしょう？

1. 帳簿は閉鎖後10年、従業者名簿は最終記載日から5年保存する
2. 帳簿も従業者名簿も、5年間保存すれば足りる
3. 帳簿は閉鎖後5年保存し、自ら売主となる新築住宅に係るものも同様に5年でよい
4. 帳簿は閉鎖後5年（自ら売主となる新築住宅に係るものは10年）、従業者名簿は最終の記載をした日から10年保存する

<details><summary>答えと解説</summary>

正解: **4**

帳簿は各事業年度末に閉鎖し、閉鎖後5年間保存します。ただし自ら売主となる新築住宅に係るものは10年です。従業者名簿は最終の記載をした日から10年保存で、5年と10年を入れ替える肢はすべて誤りです。

</details>

**問2.** 帳簿と従業者名簿の閲覧に関する次の記述のうち、正しいものはどれでしょう？

1. 帳簿は、取引の関係者から請求があったときは閲覧させなければならない
2. 従業者名簿は、取引の関係者から請求があったときは閲覧させなければならない
3. 帳簿も従業者名簿も、請求があっても閲覧させる義務はない
4. 従業者名簿の閲覧に応じる義務があるのは、免許権者から求められた場合に限られる

<details><summary>答えと解説</summary>

正解: **2**

取引の関係者から請求があったときに閲覧させる義務があるのは従業者名簿だけです。帳簿には閲覧させる義務がありません。「名簿は見せる、帳簿は見せない」と対で覚えると、入れ替えのひっかけに対応できます。

</details>

**問3.** 帳簿の備付けに関する次の記述のうち、正しいものはどれでしょう？

1. 帳簿は事務所ごとに備え、宅建業に関し取引のあったつど、所定の事項を記載しなければならない
2. 帳簿は、主たる事務所に一括して備え付ければ足りる
3. 帳簿は、契約の申込みを受ける案内所にも備え付けなければならない
4. 帳簿への記載は、1年分をまとめて事業年度の末日に行えばよい

<details><summary>答えと解説</summary>

正解: **1**

帳簿は事務所ごとに備え、取引のあった「つど」記載する必要があります。主たる事務所への一括備付けや、年度末のまとめ記載では義務を果たしたことになりません。案内所に備える必要はなく、備付け場所は事務所だけです。

</details>

## 4. 業法の横断整理（誰が・いつまでに・どこへ）

宅建業法に登場する届出・期限を、**「誰が・いつまでに・どこへ」**の1枚にまとめます。🔴 直前期はこの表だけ見直せば十分です。

### 届出・期限の総まとめ

| 場面 | いつまでに | どこへ |
|---|---|---|
| 変更の届出（商号・役員・専任宅建士の氏名など） | **30日以内** | 免許権者 |
| 廃業等の届出（死亡は相続人が**知った日**から） | **30日以内** | 免許権者 |
| 案内所の届出 | 業務開始の**10日前まで** | 免許権者＋所在地の知事 |
| 営業保証金の不足額の供託 | 通知から**2週間以内**（供託後**2週間以内**に届出） | 供託所／免許権者 |
| 専任宅建士の不足の補充 | **2週間以内** | ― |
| 瑕疵担保の資力確保の届出 | 基準日から**3週間以内** | 免許権者 |
| 宅建士の死亡等の届出 | **30日以内** | 登録している知事 |

### ひっかけ総点検

- 「10日**前まで**」は案内所だけ。ほかは「〜以内」
- 死亡の起算点は「死亡の日」ではなく**知った日**（業者の相続人も宅建士の相続人も同じ）
- 「2週間」仲間（不足額の供託・専任宅建士の補充・専任媒介の報告）と「3週間」（基準日の届出）を混ぜない

> 💡コツ：数字そのものより「**前なのか、以内なのか**」「**起算点はどこか**」を意識すると、ひっかけを見抜けます。

### 確認問題

**問1.** 変更の届出に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建業者の役員の住所に変更があったときは、30日以内に免許権者に届け出なければならない
2. 事務所の専任の宅建士の氏名に変更があったときは、30日以内に免許権者に届け出なければならない
3. 商号を変更したときは、2週間以内に免許権者に届け出なければならない
4. 変更の届出を怠っても、監督処分の対象になることはない

<details><summary>答えと解説</summary>

正解: **2**

専任の宅建士の氏名は免許申請書の記載事項なので、変更後30日以内の届出が必要です。役員の「氏名」は届出事項ですが「住所」は記載事項ではないため届出不要で、商号の変更も期限は30日以内です。届出を怠れば指示処分などの対象になり得ます。

</details>

**問2.** 廃業等の届出に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建業者が死亡した場合、相続人は死亡の日から30日以内に届け出なければならない
2. 法人の宅建業者が合併により消滅した場合、存続する法人の代表役員が届け出なければならない
3. 宅建業者が破産手続開始の決定を受けた場合、免許権者への届出は不要である
4. 宅建業者が死亡した場合、相続人は死亡の事実を知った日から30日以内に届け出なければならない

<details><summary>答えと解説</summary>

正解: **4**

死亡の場合の起算点は「死亡の日」ではなく、相続人が死亡の事実を「知った日」です。合併消滅の場合は消滅した法人の代表役員であった者が、破産の場合は破産管財人が、それぞれ30日以内に届け出ます。届出が不要になる場合はありません。

</details>

**問3.** 営業保証金の還付により不足が生じた場合に関する次の記述のうち、正しいものはどれでしょう？

1. 不足額の供託の通知を受けた日から2週間以内に、不足額を供託しなければならない
2. 不足額を供託した日から30日以内に、免許権者に届け出なければならない
3. 不足額の供託は、通知を受けた日から3週間以内に行えばよい
4. 不足が生じても、次の基準日までに供託すればよい

<details><summary>答えと解説</summary>

正解: **1**

不足額は通知を受けた日から2週間以内に供託し、供託した日から2週間以内に免許権者へ届け出ます。「3週間」や「30日」との入れ替え、瑕疵担保履行法の基準日との混同を誘うのが定番のひっかけです。

</details>

**問4.** 期限に関する次の記述のうち、正しいものはどれでしょう？

1. 案内所の届出は、業務を開始した日から10日以内に行う
2. 瑕疵担保の資力確保措置の状況の届出は、基準日から2週間以内に行う
3. 専任の宅建士に不足が生じた場合は、2週間以内に必要な措置をとらなければならない
4. 宅建士が死亡した場合、相続人は死亡の事実を知った日から2週間以内に登録している知事に届け出る

正解: **3**

専任の宅建士が法定数に不足した場合は、2週間以内に補充などの措置が必要です。案内所の届出は業務開始の「10日前まで」の事前届出、資力確保の届出は基準日から「3週間以内」、宅建士の死亡等の届出は知った日から「30日以内」で、いずれも期間が異なります。
