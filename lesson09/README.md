# 第9章 監督処分・罰則

宅建業法の締めくくりは、ルール違反へのペナルティ（監督処分）です。「指示→停止→取消し」の3段階と処分権者を整理し、最後の総まとめで業法の数字を一気に復習します。

## 1. 宅建業者への監督処分（指示・業務停止・免許取消）

ルールを破った宅建業者には、行政からペナルティ（**監督処分**）が科されます。学校の指導にたとえると「注意 → 停学 → 退学」の3段階です。

### 3段階の処分

| 処分 | 内容 | 誰ができる？ |
|---|---|---|
| **指示処分** | 「こうしなさい」という是正命令 | **免許権者** ＋ **業務地を管轄する知事** |
| **業務停止処分** | **1年以内**の期間を定めて業務の全部または一部を停止 | **免許権者** ＋ **業務地を管轄する知事** |
| **免許取消処分** | 免許を取り上げる（退場） | **免許権者のみ** |

ポイントは処分権者です。指示と業務停止は、免許権者（免許を出した大臣・知事）だけでなく、**実際に業務を行っている土地の知事**もできます。しかし、いちばん重い**免許取消だけは免許権者しかできません**。免許を「出した人」だけが「取り消せる」のです。

監督処分（指示・業務停止・免許取消）をするには、公開による**聴聞**（言い分を聞く手続）が必要です。また、業務停止・免許取消をしたときは**公告**されます。

> 💡コツ：🟡 「**取消しは免許権者だけ**」。処分権者を入れ替えるひっかけが定番なので、ここだけは絶対に押さえましょう。

### 確認問題

**問1.** 甲県知事の免許を受けた宅建業者Aが、乙県内での業務に関し宅建業法に違反した場合、Aに対して指示処分をすることができるのは誰でしょう？

1. 甲県知事のみ
2. 甲県知事と乙県知事のいずれも
3. 乙県知事のみ
4. 国土交通大臣のみ

<details><summary>答えと解説</summary>

正解: **2**

指示処分は、免許権者（甲県知事）だけでなく、業務が行われた土地を管轄する乙県知事もすることができます。業務停止処分も同様です。一方、免許取消処分だけは免許権者である甲県知事しかできません。

</details>

**問2.** 業務停止処分について、正しいものはどれでしょう？

1. 停止期間は3か月以内に限られる
2. 業務の全部の停止は命じられず、一部の停止に限られる
3. 免許権者のほか、業務地を管轄する知事も命じることができ、期間は1年以内である
4. 業務停止処分は、聴聞を経ることなく直ちに行うことができる

<details><summary>答えと解説</summary>

正解: **3**

業務停止は1年以内の期間を定めて、業務の全部または一部の停止を命じる処分で、免許権者と業務地管轄の知事の双方ができます。3か月という期間制限はなく（3か月は媒介契約の数字）、監督処分を行うには公開の聴聞が必要です。

</details>

**問3.** 免許取消処分をすることができるのは誰でしょう？

1. 免許権者のみ
2. 免許権者と業務地を管轄する知事のいずれも
3. 業務地を管轄する知事のみ
4. 内閣総理大臣のみ

<details><summary>答えと解説</summary>

正解: **1**

免許取消処分ができるのは、その業者に免許を与えた免許権者（国土交通大臣または知事）だけです。業務地の知事ができるのは指示処分と業務停止処分までで、免許の取消しはできません。「出した人だけが取り消せる」と覚えましょう。

</details>

**問4.** 宅建業者に対する監督処分の手続について、正しいものはどれでしょう？

1. 指示処分をする場合に限り、聴聞が必要である
2. 監督処分をしようとするときは、公開による聴聞を行わなければならない
3. 聴聞は非公開で行わなければならない
4. 業者が違反を認めていれば、聴聞は不要である

<details><summary>答えと解説</summary>

正解: **2**

指示・業務停止・免許取消といった監督処分をするには、原則として公開による聴聞が必要です。処分される側に言い分を述べる機会を保障するためで、本人が違反を認めているかどうかで省略されるものではありません。非公開ではなく公開で行う点も問われます。

</details>

## 2. 宅建士への監督処分（指示・事務禁止・登録消除）

監督処分は業者だけでなく、**宅建士個人**にもあります。こちらも3段階で、業者の処分ときれいに対応しています。

### 3段階の処分

| 処分 | 内容 | 誰ができる？ |
|---|---|---|
| **指示処分** | 是正の指示 | **登録している知事** ＋ **業務地を管轄する知事** |
| **事務禁止処分** | **1年以内**の期間を定めて宅建士の事務（重説など）を禁止 | **登録している知事** ＋ **業務地を管轄する知事** |
| **登録消除処分** | 登録を消す（宅建士でなくなる） | **登録している知事のみ** |

業者と同じく、いちばん重い**登録消除は登録先の知事だけ**ができます。処分には公開の**聴聞**が必要な点も共通です。

### 宅建士証とのからみ

- **事務禁止処分**を受けたら、宅建士証を**登録している知事に提出**（速やかに。禁止期間が満れば返還請求できます）
- **登録消除処分**を受けたら、宅建士証を**返納**
- 提出・返納を怠ると**10万円以下の過料**です

> 💡コツ：🟡 業者とペアで整理──「指示・停止系はどこの知事でも、**消す処分は本籍地（免許権者・登録知事）だけ**」。事務禁止＝**提出**、登録消除＝**返納**の使い分けも頻出です。

### 確認問題

**問1.** 甲県知事の登録を受けている宅建士Aが、乙県内で宅建士として行う事務に関し不正な行為をした場合の監督処分について、正しいものはどれでしょう？

1. 乙県知事は、Aに対して事務禁止処分をすることができる
2. 乙県知事は、Aの登録を消除することができる
3. 甲県知事は、Aに対していかなる処分もできない
4. 国土交通大臣がすべての処分を行う

<details><summary>答えと解説</summary>

正解: **1**

指示処分と事務禁止処分は、登録先の甲県知事だけでなく業務地の乙県知事もできます。一方、登録消除処分は登録先の甲県知事しかできないため、肢2は誤りです。甲県知事はもちろん処分できますし、宅建士の監督処分を国土交通大臣が行うわけでもありません。

</details>

**問2.** 宅建士に対する事務禁止処分の期間として、正しいものはどれでしょう？

1. 6か月以内
2. 2年以内
3. 1年以内
4. 5年以内

<details><summary>答えと解説</summary>

正解: **3**

事務禁止処分は1年以内の期間を定めて行われます。業者に対する業務停止処分の「1年以内」と同じ数字なので、セットで覚えましょう。5年は免許や宅建士証の有効期間などで出てくる数字であり、事務禁止の期間ではありません。

</details>

**問3.** 事務禁止処分を受けた宅建士は、宅建士証をどうしなければならないでしょう？

1. 速やかに、交付を受けた知事に返納しなければならない
2. 速やかに、登録している知事に提出しなければならない
3. そのまま所持し続けてよい
4. 勤務先の宅建業者に預けなければならない

<details><summary>答えと解説</summary>

正解: **2**

事務禁止処分のときは宅建士証を登録知事に「提出」します。禁止期間が満了すれば返還を請求できます。「返納」が必要なのは登録消除処分を受けた場合などで、提出と返納の使い分けが頻出です。怠ると10万円以下の過料の対象になります。

</details>

**問4.** 宅建士の登録消除処分をすることができるのは誰でしょう？

1. 業務地を管轄する知事を含む、すべての知事
2. 国土交通大臣
3. 勤務先の宅建業者の免許権者
4. その宅建士が登録している知事のみ

<details><summary>答えと解説</summary>

正解: **4**

登録消除処分ができるのは、登録を受けている知事だけです。業務地の知事ができるのは指示処分と事務禁止処分までです。業者の免許取消が免許権者にしかできないのと同じ構造で、「いちばん重い処分は本籍地だけ」と整理しましょう。

</details>

## 3. どんなときにどの処分か（頻出パターン）

「この違反ならどの処分？」という当てはめ問題の頻出パターンを整理します。細かく暗記しきれなくても、**段階が上がる流れ**をつかめば解けます。

### 処分がエスカレートする流れ

| 行為 | 処分 |
|---|---|
| 指示処分に従わない | **業務停止**事由になる |
| 業務停止事由に当たり**情状が特に重い** | **免許取消**（必ず取り消される） |
| **業務停止処分に違反**して営業した | **免許取消**（必ず取り消される） |

### 必ず免許取消になる主な場合（必要的取消し）

- **不正の手段**で免許を受けた
- 業者や役員などが免許の**欠格事由**に該当することになった
- 免許を受けてから**1年以内に事業を開始しない**、または**引き続き1年以上事業を休止**した

「1年サボったら退場」はうっかり忘れがちなので注意です。

### 宅建士のパターン

- **事務禁止処分に違反**して事務を行った → **登録消除**（必ず消除）
- **不正の手段**で登録や宅建士証の交付を受けた → **登録消除**

> 💡コツ：🟡 キーワードは「**違反を重ねると一段上の処分**」「**不正取得・処分違反・1年休止は一発退場**」。この2行でパターン問題の大半に対応できます。

### 確認問題

**問1.** 宅建業者が業務停止処分に違反して業務を行った場合、どうなるでしょう？

1. 免許権者は、免許を取り消さなければならない
2. 改めて指示処分が行われる
3. より長期の業務停止処分が行われるにとどまる
4. 罰金を納付すれば、処分は行われない

<details><summary>答えと解説</summary>

正解: **1**

業務停止処分に違反して業務を行うことは、必要的免許取消事由です。免許権者は免許を取り消さなければならず、指示処分や業務停止のやり直しで済ませることはできません。金銭の納付で処分を免れる制度もありません。

</details>

**問2.** 免許に関する次の記述のうち、免許権者が免許を取り消さなければならない場合はどれでしょう？

1. 免許を受けてから6か月間、事業を開始していない場合
2. 引き続き1年以上事業を休止した場合
3. 事務所の専任宅建士が一時的に不足した場合
4. 業務停止処分を1回受けた場合

<details><summary>答えと解説</summary>

正解: **2**

引き続き1年以上の事業休止は必要的免許取消事由です（免許後1年以内に事業を開始しない場合も同様）。6か月の未開始ではまだ取消事由になりません。専任宅建士の不足は2週間以内に補充すべき義務の問題で、業務停止処分を受けたこと自体は直ちに取消事由ではありません（違反した場合や情状が特に重い場合に取消しです）。

</details>

**問3.** 宅建士が事務禁止処分に違反して、禁止期間中に重要事項説明を行った場合、どうなるでしょう？

1. 再度の事務禁止処分が行われるにとどまる
2. 指示処分が行われるにとどまる
3. 登録を消除されることになる
4. 何の処分も受けない

<details><summary>答えと解説</summary>

正解: **3**

事務禁止処分に違反して宅建士の事務を行うことは、必要的な登録消除事由です。業者が業務停止処分に違反すると免許取消になるのと同じ「処分違反は一発退場」の構造です。指示や事務禁止のやり直しで済むものではありません。

</details>

**問4.** 宅建業者が指示処分に従わなかった場合について、正しいものはどれでしょう？

1. 指示処分に従わないことは、業務停止処分の事由となる
2. 指示処分に従わなくても、特に不利益はない
3. 直ちに免許が取り消される
4. 指示処分が自動的に取り消される

<details><summary>答えと解説</summary>

正解: **1**

指示処分に従わないことは業務停止事由になります。処分の階段を一段上がるイメージです。直ちに免許取消となるわけではありませんが、情状が特に重ければ免許取消もあり得ます。従わなくても不利益がない、という肢は論外です。

</details>

## 4. 宅建業法の総まとめ（数字一覧＋横断ひっかけ）

総仕上げに、ここまでの**数字**を一覧にします。直前期はこの表を見直せばOKです。

### 数字の総整理

| テーマ | 数字 |
|---|---|
| 免許の有効期間 | **5年**（更新申請は90日前〜30日前） |
| 営業保証金 | 本店**1,000万円**・支店**500万円** |
| 弁済業務保証金分担金 | 本店**60万円**・支店**30万円** |
| 専任宅建士 | **5人に1人**以上（不足は**2週間以内**に補充） |
| 専任媒介 | **3か月・2週間に1回・7日以内** |
| 専属専任媒介 | **3か月・1週間に1回・5日以内** |
| クーリング・オフ | 告知書面から**8日** |
| 手付額／損害賠償額の予定 | ともに代金の**2割** |
| 手付金等の保全 | 未完成**5％**・完成**10％**・いずれも**1,000万円**超 |
| 報酬（400万円超の売買媒介） | **3％＋6万円**（課税業者は×1.1） |
| 業務停止・事務禁止 | **1年**以内 |

### 横断ひっかけの王道

- 「**2週間**」仲間：専任媒介の報告・専任宅建士の補充。専属専任の報告「1週間」との入れ替えに注意
- 「**2割**」仲間：手付は「**超えて受領できない**」、損賠予定は「**超える部分が無効**」と効果が違う
- 書面3兄弟：34条の2は**業者が記名押印**、35条・37条は**宅建士が記名**

> 💡コツ：🔴 数字は「単体」でなく「仲間とセット」で記憶すると、入れ替えひっかけに強くなります。

### 確認問題

**問1.** 「2週間」という期間が正しく使われているものは、次のうちどれでしょう？

1. 専属専任媒介契約における業務処理状況の報告は、2週間に1回以上行う
2. クーリング・オフは、書面で告げられた日から2週間以内に行う
3. 専任媒介契約における業務処理状況の報告は、2週間に1回以上行う
4. 専任媒介契約のレインズへの登録は、契約日から2週間以内に行う

<details><summary>答えと解説</summary>

正解: **3**

2週間に1回以上の報告は専任媒介の義務です。専属専任は1週間に1回以上、クーリング・オフは8日、専任媒介のレインズ登録は7日以内（休業日を除く）であり、いずれも数字が違います。数字の入れ替えは横断問題の王道パターンです。

</details>

**問2.** 「代金の2割」に関する次の記述のうち、正しいものはどれでしょう？

1. 宅建業者が自ら売主となる場合、代金の2割を超える手付を受領できないが、損害賠償額の予定には制限がない
2. 損害賠償額の予定が代金の2割を超えると、その定め全体が無効となる
3. 手付も損害賠償額の予定も、業者間の取引でも2割の制限を受ける
4. 宅建業者が自ら売主となる場合、手付は2割を超えて受領できず、損害賠償額の予定は2割を超える部分が無効となる

<details><summary>答えと解説</summary>

正解: **4**

手付は2割を「超えて受領できない」、損害賠償額の予定・違約金は合算2割で「超える部分が無効」と、同じ2割でも効果が異なります。どちらも8種制限なので、業者間の取引には適用されません。肢1は損賠予定の制限を否定している点が誤りです。

</details>

**問3.** 各書面への記名等に関する次の記述のうち、正しいものはどれでしょう？

1. 媒介契約書面（34条の2）には宅建業者の記名押印が、35条書面・37条書面には宅建士の記名が必要である
2. 3つの書面すべてに宅建士の記名押印が必要である
3. 3つの書面すべてに宅建業者の記名押印が必要である
4. 35条書面には宅建業者の記名押印が、37条書面には宅建士の記名が必要である

<details><summary>答えと解説</summary>

正解: **1**

34条の2書面は宅建業者の記名押印、35条・37条書面は宅建士の記名（押印は法改正で廃止）です。「誰が」の部分を入れ替えるひっかけが定番で、媒介契約書面に宅建士は登場しない点がポイントです。

</details>

**問4.** 営業保証金と弁済業務保証金分担金の額の組合せとして、正しいものはどれでしょう（本店のみの業者の場合）？

1. 営業保証金60万円・分担金1,000万円
2. 営業保証金1,000万円・分担金60万円
3. 営業保証金500万円・分担金30万円
4. 営業保証金1,000万円・分担金300万円

<details><summary>答えと解説</summary>

正解: **2**

本店（主たる事務所）の営業保証金は1,000万円、保証協会に加入する場合の分担金は60万円です。支店はそれぞれ500万円・30万円です。「お金を直接供託すると高く、協会に入ると安い」とイメージし、数字の入れ替えに注意しましょう。

</details>

**問5.** 宅建業法の数字に関する次の記述のうち、誤っているものはどれでしょう？

1. 免許の有効期間は5年である
2. 事務所には業務に従事する者5人に1人以上の割合で専任の宅建士を置かなければならない
3. クーリング・オフは、書面で告げられた日から起算して8日を経過するとできなくなる
4. 宅建業者に対する業務停止処分の期間は2年以内である
