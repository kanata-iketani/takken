# 第10章 民法のきほん（契約と意思表示）

ここから権利関係（民法など）に入ります。最初のテーマは「契約」と「意思表示」。だまされた契約・勘違いの契約はどうなるのか、事情を知らない第三者とどちらが守られるのか。権利関係は深追い禁物の分野ですが、意思表示は毎年のように出る得点源です。AさんBさんの具体例で、ゆっくり進みましょう。

## 1. 民法って何？契約はいつ成立する？

### 民法は「私人どうしのルールブック」

🟡 民法は、売買や賃貸借など、個人や会社どうしの約束ごと（契約）のルールを定めた法律です。宅建試験の「権利関係」の中心がこの民法です。

### 契約はいつ成立する？

AさんがBさんに「この土地を3000万円で売ります」と言い（申込み）、Bさんが「買います」と答えました（承諾）。この瞬間、A→Bの売買契約は成立します。

- 契約は**申込みと承諾の意思表示が合致した時**に成立します
- **口約束だけでも成立**します。契約書や手付金は原則不要です（契約書は後の争いに備えた証拠として作るもの）

### 契約自由の原則

誰と、どんな内容の契約を、どんな方式で結ぶか（そもそも結ばないか）は、法律に特別の定めがない限り当事者の自由です。これを**契約自由の原則**といいます。

> 💡 コツ: 「書面がないから契約は不成立」という選択肢は、ほとんどの場合ひっかけです。

権利関係は深い沼ですが、合格に満点は不要です。この章の基本が分かれば十分です。

### 確認問題

**問1.** Aは自己所有の甲土地をBに3000万円で売る旨を口頭で申し込み、Bは口頭で承諾した。契約書はまだ作成していない。この場合に関する記述として、民法の規定によれば正しいものはどれか。

1. 契約書を作成していないため、売買契約は成立していない
2. AB間の売買契約は、口頭の合意のみで有効に成立している
3. Bが手付金を支払った時に、初めて売買契約が成立する
4. 売買契約は、宅建士が記名した書面がなければ無効である

<details><summary>答えと解説</summary>

正解: **2**

契約は申込みと承諾の意思表示の合致だけで成立し、書面も手付金も原則不要です。契約書は証拠のために作るもので、成立要件ではありません。宅建士の書面交付は宅建業法上の義務であり、民法上の契約の成立とは別の話です。

</details>

**問2.** 契約自由の原則に関する記述として、最も適切なものはどれか。

1. 法律に特別の定めがある場合を除き、契約を締結するかどうかは当事者が自由に決められる
2. 売買契約は、必ず公正証書によって締結しなければならない
3. 申込みを受けた者は、その申込みに対する承諾を拒むことができない
4. 契約の内容は、国が定めた標準的な価格に従わなければならない

<details><summary>答えと解説</summary>

正解: **1**

契約を結ぶかどうか・誰と結ぶか・内容・方式は、原則として当事者の自由です（契約自由の原則）。公正証書などの方式も原則不要で、承諾するかどうかも自由、価格も当事者が自由に決められます。

</details>

**問3.** AはBに対し「甲建物を2000万円で売りたい」と申し込んだが、Bはまだ返事をしていない。この場合に関する記述として正しいものはどれか。

1. Aが申込みをした時点で、売買契約はすでに成立している
2. Bが代金を支払った時点で、初めて売買契約が成立する
3. Bが承諾の意思表示をした時に、売買契約が成立する
4. AとBが契約書に署名するまでは、Bが承諾しても契約は成立しない

<details><summary>答えと解説</summary>

正解: **3**

契約は申込みと承諾が合致した時、つまりBが承諾した時に成立します。申込みだけでは成立せず、代金の支払や契約書への署名は成立の要件ではありません。

</details>

## 2. 詐欺と強迫（取り消せる・第三者との関係）

### 具体例から

AさんはBさんにだまされて（詐欺）、相場3000万円の甲土地を1000万円でBに売ってしまいました。その後、Bは事情を知らないCさんに甲土地を転売しました。

図式: A →（詐欺で売却）→ B →（転売）→ C

### ルール

詐欺・強迫による意思表示は、**取り消すことができます**（当然に無効になるのではない点に注意）。🔴 ただし、第三者Cとの関係で大きな差があります。

| | 取消し | 取消し前に現れた第三者Cとの関係 |
|---|---|---|
| 詐欺 | できる | **善意無過失のCには取消しを対抗できない**（Cが勝つ） |
| 強迫 | できる | **善意無過失のCにも対抗できる**（Aが勝つ） |

脅された被害者（強迫）には落ち度がないので、だまされた人（詐欺）より手厚く守られる、と理解しましょう。

### 第三者がだました場合

AをだましたのがBではなく第三者Dだった場合、Aが取り消せるのは**相手方Bがその詐欺の事実を知り、または知ることができたとき**だけです。強迫なら、相手方が知らなくても取り消せます。

> 💡 コツ: 「詐欺は善意無過失の第三者に負ける、強迫なら勝てる」。ここまで分かれば十分です。

### 確認問題

**問1.** AはBにだまされて甲土地をBに売却し、所有権移転登記をした。その後、Bは事情を知らず知ることもできなかったCに甲土地を転売した。Aは、Cへの転売後にBの詐欺を理由として売買契約を取り消した。この場合に関する記述として正しいものはどれか。

1. 詐欺による意思表示は無効であるため、Cは所有権を取得できない
2. Aは善意無過失のCに取消しを対抗できず、甲土地を取り戻すことができない
3. Cが転売を受けた時に詐欺の事実を知っていたとしても、Cは保護される
4. Aは、だましたB本人に対しても取消しを主張することができない

<details><summary>答えと解説</summary>

正解: **2**

詐欺による取消しは、取消し前に利害関係に入った善意無過失の第三者に対抗できません。詐欺は「無効」ではなく「取消し」ができる行為であり、悪意のCは保護されません。また、詐欺をしたB本人に取消しを主張できるのは当然です。

</details>

**問2.** AはBに強迫されて甲土地をBに売却し、その後Bは事情を知らず知ることもできなかったCに転売した。Aは強迫を理由に売買契約を取り消した。この場合に関する記述として正しいものはどれか。

1. Cが善意無過失であるため、Aは取消しをCに対抗できない
2. 強迫による意思表示は取り消すことができないため、Aは甲土地を取り戻せない
3. Aが取消しをCに対抗するには、Cの悪意を証明しなければならない
4. Aは取消しを善意無過失のCにも対抗でき、甲土地の返還を求めることができる

<details><summary>答えと解説</summary>

正解: **4**

強迫による取消しは、詐欺と異なり、善意無過失の第三者にも対抗できます。強迫の被害者には落ち度がないため、第三者より手厚く保護されるからです。強迫も「取消しができる」行為であり、Cの善意悪意を問わず対抗できるので悪意の証明は不要です。

</details>

**問3.** Aは、第三者Dにだまされて、Bとの間で甲土地の売買契約を締結した。この場合に関する記述として正しいものはどれか。

1. Aは、Bの事情にかかわらず常に売買契約を取り消すことができる
2. だましたのが第三者Dである以上、AB間の契約は当然に無効である
3. Bが詐欺の事実を知らず、知ることもできなかったときは、Aは取り消すことができない
4. AはDの同意を得れば、売買契約を取り消すことができる

<details><summary>答えと解説</summary>

正解: **3**

第三者による詐欺の場合、相手方Bがその事実を知り、または知ることができたときに限り取り消せます。Bが善意無過失なら取消しはできません。契約が当然に無効になるわけではなく、だましたDの同意も関係ありません。

</details>

**問4.** AがBの強迫を受けて意思表示をした場合と、Bの詐欺を受けて意思表示をした場合に関する記述として、正しいものはどれか。

1. どちらの場合も、Aはその意思表示を取り消すことができる
2. 詐欺の場合は取り消せるが、強迫の場合は当然に無効であり、取消しの対象ではない
3. 強迫の場合、取消し前に善意無過失の第三者が現れると、Aは取消しを対抗できなくなる
4. 第三者がAを強迫した場合、相手方Bが善意無過失であれば、Aは取り消すことができない

<details><summary>答えと解説</summary>

正解: **1**

詐欺・強迫のどちらも、意思表示を「取り消すことができる」行為です（無効ではありません）。強迫による取消しは善意無過失の第三者にも対抗できます。また第三者による強迫の場合は、詐欺と異なり、相手方の善意悪意を問わず取り消せます。

</details>

## 3. 錯誤（勘違い。重要な錯誤なら取消し・動機の錯誤）

### 具体例から

Aさんは「乙土地」を買うつもりだったのに、言い間違えてBさんに「甲土地を買います」と伝えてしまいました（表示の錯誤）。また、「近くに駅ができるから」と信じて土地を買ったものの、そんな計画は存在しなかった、というケースもあります（動機の錯誤）。

### ルール

🔴 錯誤（勘違い）による意思表示は、その錯誤が**重要なもの**（その点に勘違いがなければ、普通は契約しなかったといえるもの）であれば**取り消すことができます**。2020年の民法改正で「無効」から「取消し」に変わりました。

### 動機の錯誤は「表示」がカギ

「駅ができると思った」のような**動機の錯誤**は、その事情が**契約の基礎とされていることが表示されていたとき**に限り取り消せます。心の中で思っていただけでは取り消せません。

### 取り消せない場合・第三者

- 表意者（勘違いした本人）に**重大な過失**があれば、原則として取り消せません。ただし、相手方が錯誤を知っていた（または重大な過失で知らなかった）場合や、**相手方も同じ勘違い**をしていた場合は取り消せます
- 錯誤による取消しは、**善意無過失の第三者に対抗できません**

> 💡 コツ: 「重要な錯誤＝取消し」「動機は表示されていれば」。ここまで分かれば十分です。

### 確認問題

**問1.** Aは、甲土地の近くに新駅ができると考えてBから甲土地を購入したが、実際にはそのような計画は存在しなかった。Aは、新駅ができることが契約の基礎である旨をBに表示していなかった。この場合に関する記述として正しいものはどれか。

1. 動機が表示されていなかったため、Aは錯誤を理由に取り消すことができない
2. 動機の錯誤も錯誤である以上、Aは常に取り消すことができる
3. 錯誤による意思表示は無効であるため、取消しの意思表示をするまでもない
4. Bがまだ代金を受け取っていなければ、Aは取り消すことができる

<details><summary>答えと解説</summary>

正解: **1**

動機の錯誤（基礎事情の錯誤）は、その事情が契約の基礎とされていることが表示されていたときに限り取り消せます。表示していなかった本問では取消しできません。2020年改正により錯誤の効果は無効ではなく取消しであり、代金受領の有無は関係ありません。

</details>

**問2.** Aは、自己の重大な過失により甲土地と乙土地を取り違え、Bに対し「甲土地を売る」と意思表示をした。Bは、Aの錯誤について善意無過失であった。この場合に関する記述として正しいものはどれか。

1. Aは、錯誤が重要なものであることを証明すれば取り消すことができる
2. Bが契約の履行に着手する前であれば、Aは自由に取り消すことができる
3. 錯誤による意思表示は常に無効であり、取消しを問題にする余地はない
4. Aに重大な過失があるため、Aは原則として取り消すことができない

<details><summary>答えと解説</summary>

正解: **4**

錯誤が重要なものでも、表意者に重大な過失があるときは原則として取消しできません（相手方が悪意・重過失、または同一の錯誤に陥っていた場合は例外）。重要性の証明だけでは足りず、履行の着手は手付解除の話であってここでは無関係です。錯誤の効果は無効ではなく取消しです。

</details>

**問3.** AがBに対して重要な錯誤による意思表示をした場合において、Aに重大な過失があったときに関する記述として正しいものはどれか。

1. Bも Aと同じ錯誤に陥っていた場合、契約は当然に無効となる
2. Aに重大な過失があっても、BもAと同じ錯誤に陥っていたときは、Aは取り消すことができる
3. Aに重大な過失がある場合、どのような事情があっても取り消すことはできない
4. 錯誤による取消しは、Bの同意を得なければすることができない

<details><summary>答えと解説</summary>

正解: **2**

表意者に重過失があっても、相手方が錯誤につき悪意・重過失であった場合や、相手方も同一の錯誤に陥っていた場合は取り消せます。この場合も効果は「取消し」であって当然無効ではなく、取消しは一方的な意思表示ででき、相手方の同意は不要です。

</details>

**問4.** AはBに対し重要な錯誤により甲土地を売却し、Bは、Aが取消しをする前に、事情を知らず知ることもできなかったCに甲土地を転売した。その後Aは錯誤を理由に売買契約を取り消した。この場合に関する記述として正しいものはどれか。

1. 錯誤取消しの効果は絶対的であり、AはCから甲土地を取り戻すことができる
2. Cが登記を備えていなければ、Cの善意悪意を問わずAが優先する
3. Aは、錯誤による取消しを善意無過失のCに対抗することができない
4. Cが悪意であっても、転売を受けた以上Cが保護される

<details><summary>答えと解説</summary>

正解: **3**

錯誤による取消しは、詐欺と同様、取消し前の善意無過失の第三者に対抗できません。したがってAはCから土地を取り戻せません。逆にCが悪意であれば保護されないので、「転売を受けた以上保護される」は誤りです。

</details>

## 4. 虚偽表示と心裡留保（グルの嘘・冗談と善意の第三者）

### 虚偽表示（グルの嘘）

Aさんは借金の差押えから自宅の甲土地を隠すため、Bさんと**グルになって**売ったことにし、登記もBに移しました。本当に売る気はありません。これが**虚偽表示（通謀虚偽表示）**で、AB間の売買は**無効**です。

図式: A →（仮装売買・無効）→ B →（転売）→ C

ところが、Bが裏切って、事情を知らないCさんに甲土地を転売したらどうなるでしょうか。

- 🔴 虚偽表示の無効は、**善意の第三者に対抗できません**（Cの勝ち）
- Cは**善意であればよく、無過失や登記は不要**とされています

嘘の外観を自分で作ったAが悪いので、それを信じたCを守る、という考え方です。

### 心裡留保（冗談・本心でない意思表示）

Aが売る気もないのに冗談で「甲土地を100万円で売る」とBに言った場合（**心裡留保**）は、次のとおりです。

- 原則: **有効**（冗談を言った本人より、信じた相手を守る）
- 例外: 相手方Bが冗談だと**知っていた（悪意）か、知ることができた（有過失）**ときは**無効**
- この無効も、善意の第三者には対抗できません

> 💡 コツ: 「嘘をついた人は守られず、信じた人が守られる」。ここまで分かれば十分です。

### 確認問題

**問1.** Aは、債権者の差押えを免れるため、Bと通謀して甲土地をBに売却したことにし、所有権移転登記をした。その後Bは、事情を知らないCに甲土地を売却した。Cはまだ登記を備えていない。この場合に関する記述として正しいものはどれか。

1. AB間の売買は有効であるため、Cは当然に所有権を取得する
2. Cは登記を備えていないため、Aに所有権を対抗できない
3. Cに過失がある場合、Aは無効をCに対抗することができる
4. Cは善意であれば保護され、Aは虚偽表示の無効をCに対抗できない

<details><summary>答えと解説</summary>

正解: **4**

通謀虚偽表示によるAB間の売買は無効ですが、その無効は善意の第三者に対抗できません。判例上、第三者は善意であれば足り、無過失や登記は不要とされています。したがって登記や過失の有無を保護の条件とする選択肢は誤りです。

</details>

**問2.** AとBが通謀して甲土地の仮装売買を行い、B名義の登記をした後、BはCに甲土地を売却した。Cは、売買を受けた当時、AB間の売買が仮装のものであることを知っていた。この場合に関する記述として正しいものはどれか。

1. Cは虚偽表示の事実について悪意であるため、Aは売買の無効をCに対抗できる
2. Cは登記を備えれば、悪意であっても必ず保護される
3. AB間の売買は有効であるため、Cの善意悪意は問題とならない
4. Aは、通謀の相手方であるBに対しては無効を主張できない

<details><summary>答えと解説</summary>

正解: **1**

虚偽表示の無効を対抗できないのは「善意の第三者」に対してだけです。悪意のCには無効を対抗でき、登記を備えていても保護されません。AB間の売買はそもそも無効であり、通謀の当事者Bに無効を主張できるのは当然です。

</details>

**問3.** Aは、売るつもりがないのに冗談で「甲土地を100万円で売る」とBに意思表示をした。Bは、それがAの冗談であることを知っていた。この場合に関する記述として正しいものはどれか。

1. 心裡留保による意思表示は原則どおり有効であり、Bは甲土地の引渡しを請求できる
2. Aの意思表示は取り消すことができるにとどまり、取り消すまでは有効である
3. Bが悪意であるため、Aの意思表示は無効である
4. Aは、裁判所の許可を得なければ無効を主張することができない

<details><summary>答えと解説</summary>

正解: **3**

心裡留保による意思表示は原則有効ですが、相手方が真意でないことを知っていた（悪意）か、知ることができた（有過失）ときは無効です。本問のBは悪意なので無効となります。効果は「無効」であって取消しではなく、裁判所の許可も不要です。

</details>

**問4.** Aは、売るつもりがないのに「甲土地を売る」とBに意思表示をした。Bは、それがAの真意でないことを知らず、知ることもできなかった。この場合に関する記述として正しいものはどれか。

1. Aに売る気がない以上、意思表示は無効である
2. Aの意思表示は有効であり、AB間に売買契約が成立する
3. Bが代金を支払うまでの間は、Aはいつでも無効を主張できる
4. 心裡留保による意思表示は、常に取り消すことができる

<details><summary>答えと解説</summary>

正解: **2**

心裡留保による意思表示は、相手方が善意無過失であれば原則どおり有効です。冗談を言った本人より、それを信じた相手方を保護するためです。無効となるのは相手方が悪意または有過失の場合に限られ、取消しの問題でもありません。

</details>

## 5. 意思表示の総まとめ（善意・悪意と第三者保護）

### 5つの意思表示を一気に整理

ここまで学んだルールを1つの表にまとめます。🔴 この表は本試験に直結する最重要ポイントです。

| 類型 | 効果 | 第三者が保護される条件 |
|---|---|---|
| 詐欺 | 取消しできる | 善意**無過失** |
| 強迫 | 取消しできる | **保護されない**（被害者の勝ち） |
| 錯誤（重要なもの） | 取消しできる | 善意**無過失** |
| 虚偽表示 | **無効** | **善意**（無過失は不要） |
| 心裡留保 | 原則有効（相手方が悪意・有過失なら無効） | 善意 |

### 覚え方のコツ

- 「無効」になるのは虚偽表示と心裡留保（の例外）だけ。あとは「取消し」です
- 第三者保護の手厚さは「本人の落ち度の大きさ」で決まります。自分で嘘の外観を作った虚偽表示は第三者保護が最も緩く（善意のみ）、落ち度ゼロの強迫の被害者だけは第三者にも勝てます

> 💡 コツ: 「善意」＝その事情を知らないこと、「悪意」＝知っていること。日常語の善悪とは無関係です。

この表が頭に入っていれば、意思表示の問題はほぼ戦えます。細かい学説には深入りせず、ここまでで十分です。

### 確認問題

**問1.** Aの意思表示に問題があり、取消しまたは無効の主張の前に、事情を知らず知ることもできなかった第三者Cが利害関係を持った。次のうち、Aが取消しまたは無効をCに対抗【できる】ものはどれか。

1. AがBの詐欺により意思表示をした場合
2. AがBの強迫により意思表示をした場合
3. AがBと通謀して虚偽の意思表示をした場合
4. Aが重要な錯誤により意思表示をした場合

<details><summary>答えと解説</summary>

正解: **2**

強迫による取消しだけは、善意無過失の第三者にも対抗できます。強迫の被害者には落ち度がないからです。詐欺・錯誤の取消しは善意無過失の第三者に、虚偽表示の無効は善意の第三者に、それぞれ対抗できません。

</details>

**問2.** 次のAの意思表示のうち、取消しの意思表示をしなくても、はじめから効力が生じない（無効となる）ものはどれか。

1. Bの詐欺によるAの意思表示
2. Bの強迫によるAの意思表示
3. 重要な錯誤によるAの意思表示
4. AがBと通謀してした虚偽の意思表示

<details><summary>答えと解説</summary>

正解: **4**

通謀虚偽表示は当事者双方に効果を生じさせる意思がないため、取消しを待たず無効です。詐欺・強迫・錯誤はいずれも「取り消すことができる」行為であり、取り消されるまでは有効です。

</details>

**問3.** 民法における「善意」「悪意」に関する記述として正しいものはどれか。

1. 「善意」とは、ある事情を知らないことをいう
2. 「善意」とは、相手のためを思って行動することをいう
3. 「悪意」とは、相手を害する意図をもっていることをいう
4. 「悪意」の第三者は、意思表示のどの類型においても常に保護される

<details><summary>答えと解説</summary>

正解: **1**

民法の「善意」は事情を知らないこと、「悪意」は知っていることを意味し、道徳的な善し悪しとは無関係です。害意まで要求されるのは背信的悪意者などの特別な場面だけです。また悪意の第三者は、虚偽表示・詐欺・錯誤のいずれでも保護されません。

</details>

**問4.** 意思表示に関する次の記述のうち、正しいものはどれか。

1. 心裡留保による意思表示は、相手方が善意無過失であっても無効である
2. 虚偽表示の無効は、善意の第三者に過失があることを証明すれば対抗できる
3. 詐欺による取消しは、取消し前に現れた善意無過失の第三者に対抗できない
4. 錯誤による意思表示は、重要なものでなくても取り消すことができる

<details><summary>答えと解説</summary>

正解: **3**

詐欺取消しは取消し前の善意無過失の第三者に対抗できません。心裡留保は相手方が善意無過失なら有効、虚偽表示の第三者保護は善意で足りるため過失を証明しても対抗できず、錯誤取消しには錯誤の重要性が必要です。

</details>
