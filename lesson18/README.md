# 第18章 建築基準法

建物そのもののルールが建築基準法です。建築確認・道路(4mと2m)・建蔽率と容積率の計算は、数字さえ覚えれば確実に得点できます。計算問題も電卓なしで解ける簡単なかけ算だけなので、怖がらずにいきましょう。

## 1. 建築確認 —— どんな建物のとき必要?

建物を建てる前に「設計が法律に適合しているか」を建築主事等や指定確認検査機関にチェックしてもらう手続きが**建築確認**です。欠陥建築で人が死なないようにする、安全のための入口検査です。

### 建築確認が必要になる建築物(新築)

| 建築物 | 必要になる基準 |
|---|---|
| **特殊建築物**(店舗・ホテル・共同住宅・倉庫など) | その用途の床面積が**200㎡超** |
| 一般の建築物 | **階数2以上** または 延べ面積**200㎡超**(2025年の法改正で木造・非木造の区別は廃止) |
| 都市計画区域・準都市計画区域内など | 上記未満(平屋かつ200㎡以下)でも新築には必要 |

### 増改築・移転と大規模修繕

- 増改築・移転は、床面積**10㎡以内**なら確認不要。ただし**防火地域・準防火地域内では10㎡以内でも必要**!
- 上の表の建築物は、**大規模の修繕・模様替**でも確認が必要

> 💡コツ: 数字は「**200㎡**と**10㎡**」の2つだけ。そして「防火・準防火地域では10㎡の例外が使えない」が最頻出のひっかけです。

> 🔴 建築確認はほぼ毎年出題。「どこで・何を・どれだけ」をセットで判断する練習をしましょう。

### 確認問題

**問1.** 防火地域内で、床面積8㎡の増築をする場合の建築確認について、正しいものはどれでしょう?

1. 10㎡以内の増築なので建築確認は不要である
2. 防火地域内では10㎡以内の増築でも建築確認が必要である
3. 増築はどんな場合でも建築確認が不要である
4. 100㎡以下の増築は常に建築確認が不要である

<details><summary>答えと解説</summary>

正解: **2**

増改築・移転が10㎡以内なら確認不要という例外は、防火地域・準防火地域内では使えません。火災リスクが高いエリアでは小さな増築も見逃さない、という趣旨です。「8㎡だから不要」と即断させるのが定番のひっかけです。

</details>

**問2.** その用途に供する床面積が250㎡の共同住宅を新築する場合、正しいものはどれでしょう?

1. 共同住宅は特殊建築物ではないので、区域外であれば建築確認は不要である
2. 平屋であれば建築確認は不要である
3. 200㎡を超える特殊建築物なので、どの区域でも建築確認が必要である
4. 500㎡以下なので建築確認は不要である

<details><summary>答えと解説</summary>

正解: **3**

共同住宅は特殊建築物であり、その用途の床面積が200㎡を超えれば全国どこでも建築確認が必要です。平屋かどうかは関係ありません。500㎡という基準は現在の建築確認の判断基準ではありません。

</details>

**問3.** 都市計画区域にも準都市計画区域にも含まれない区域で、平屋・延べ面積150㎡の一般の住宅を新築する場合、正しいものはどれでしょう?

1. 原則として建築確認は不要である
2. すべての新築には建築確認が必要である
3. 100㎡を超えているので建築確認が必要である
4. 住宅の新築には常に都道府県知事の許可が必要である

<details><summary>答えと解説</summary>

正解: **1**

階数1(平屋)かつ延べ面積200㎡以下の一般建築物は、都市計画区域等の外であれば建築確認は不要です。区域内なら規模を問わず新築に確認が必要なので、「どこに建てるか」で結論が変わります。100㎡という基準はなく、建築確認は知事の許可制度でもありません。

</details>

**問4.** 建築確認の要否の基準として、正しいものはどれでしょう?

1. 特殊建築物は床面積100㎡超で建築確認が必要である
2. 階数2以上または延べ面積200㎡超の建築物は、新築のほか大規模の修繕でも建築確認が必要である
3. 大規模の修繕や模様替には建築確認は一切不要である
4. 建築確認は市街化調整区域内の建築物のみが対象である

<details><summary>答えと解説</summary>

正解: **2**

階数2以上または延べ面積200㎡超の建築物は、新築だけでなく大規模の修繕・模様替でも建築確認が必要です。特殊建築物の基準は200㎡超(100㎡ではありません)。建築確認は区域を問わず適用される制度で、調整区域限定ではありません。

</details>

## 2. 道路規制 —— 幅員4m・接道2m・セットバック

火事のとき消防車が入れない、逃げ道がない——そんな街を防ぐのが道路規制です。数字は**4m**と**2m**の2つだけです。

### 建築基準法上の「道路」

- 原則: 幅員**4m以上**の道(特定行政庁が指定する区域では6m以上)
- **2項道路(みなし道路)**: 幅員4m未満でも、建築基準法の適用時にすでに建物が立ち並んでいて、**特定行政庁が指定**した道は道路とみなす

### セットバック

2項道路では、原則として**道路の中心線から2m**下がった線が道路境界線とみなされます。建て替えのときはそこまで下がって建てる(=セットバック)ことで、少しずつ道を4mに広げていく仕組みです。セットバック部分は**建蔽率・容積率の計算で敷地面積に算入しません**。

### 接道義務

建築物の敷地は、道路(**自動車専用道路を除く**)に**2m以上**接しなければなりません。

> 💡コツ: 「**道は4m・接するのは2m**」とセットで暗唱。セットバック部分を敷地面積に入れるひっかけも定番です。

> 🔴 4m・2m・中心線から2m。この3つの数字で1点取れます。

### 確認問題

**問1.** 接道義務について、正しいものはどれでしょう?

1. 建築物の敷地は、原則として道路に2m以上接しなければならない
2. 建築物の敷地は、原則として道路に4m以上接しなければならない
3. 建築物の敷地は、自動車専用道路に2m以上接していれば足りる
4. 接道義務は市街化調整区域内の敷地にのみ適用される

<details><summary>答えと解説</summary>

正解: **1**

敷地は道路に2m以上接する必要があります。4mは道路の幅員の基準で、接する長さと混同させるひっかけです。自動車専用道路は人が出入りできないため接道義務の道路から除かれます。接道義務は調整区域限定の制度ではありません。

</details>

**問2.** 幅員4m未満のいわゆる2項道路に接する敷地で建物を建て替える場合、正しいものはどれでしょう?

1. 道路の端から2m下がった線が道路境界線とみなされる
2. 原則として道路の中心線から2m下がった線が道路境界線とみなされる
3. 4m未満の道に接する敷地では建て替えが一切できない
4. セットバックするかどうかは建築主が自由に選べる

<details><summary>答えと解説</summary>

正解: **2**

2項道路では原則として「中心線から2m」の線が道路境界線とみなされます。「端から2m」ではありません。この位置まで下がれば建て替えは可能なので「一切できない」は誤りで、セットバックは法律上のルールであり任意ではありません。

</details>

**問3.** セットバック部分の取り扱いとして、正しいものはどれでしょう?

1. 建蔽率・容積率の計算上、敷地面積に算入される
2. 建蔽率の計算では算入されるが、容積率の計算では算入されない
3. 建蔽率・容積率の計算上、敷地面積に算入されない
4. 塀を設ければ建築物を建てることができる

<details><summary>答えと解説</summary>

正解: **3**

セットバック部分は道路として扱われるため、建蔽率・容積率どちらの計算でも敷地面積に算入されません。片方だけ算入というルールはありません。道路となる部分なので建築物や塀を設けることもできません。

</details>

**問4.** 建築基準法上の道路について、正しいものはどれでしょう?

1. 幅員4m未満の道は、どんな場合でも道路として扱われない
2. 幅員6m以上でなければ道路として扱われることはない
3. 私道は建築基準法上の道路になることはない
4. 原則は幅員4m以上だが、4m未満でも特定行政庁の指定により道路とみなされる場合がある

<details><summary>答えと解説</summary>

正解: **4**

原則は幅員4m以上ですが、4m未満でも建物が立ち並び特定行政庁が指定した道(2項道路)は道路とみなされます。したがって「どんな場合でも扱われない」は誤りです。6mは特定行政庁指定区域での基準にすぎず、位置指定などにより私道も道路になり得ます。

</details>

## 3. 用途制限 —— どこに何を建てられるか(代表例)

用途地域ごとに「建てられる建物・建てられない建物」が決まっています。13地域×建物の表を丸暗記するのは大変なので、試験によく出る**代表例**だけ覚えます。

### 代表例まとめ

| 建物 | 建てられない場所 |
|---|---|
| **住宅・共同住宅・図書館・老人ホーム** | **工業専用地域のみ**ダメ |
| 幼稚園・小中高校 | 工業・工業専用がダメ |
| **大学・病院** | 低層系3つ(一低・二低・田園住居)+工業・工業専用がダメ |
| **神社・教会・保育所・診療所・交番(派出所)** | **どこでも建てられる** |

工場だらけの工業専用地域に住宅は危ないから×、静かな低層住宅街に大きな大学・病院は×(でも小さな診療所・保育所は生活に必要だから○)、と理屈で整理しましょう。

### 敷地が2つの用途地域にまたがるとき

敷地の**過半(広い方)**が属する地域の用途制限が、敷地**全体**に適用されます。

> 💡コツ: 「住宅がダメなのは工専だけ」「保育所・診療所はオールマイティ」「大学・病院は低層と工業系がダメ」の3フレーズで大半の問題が解けます。

> 🟡 全部覚えず、この代表例だけ確実に。

### 確認問題

**問1.** 住宅(一戸建て)を建築できない用途地域はどれでしょう?

1. 工業地域
2. 商業地域
3. 工業専用地域
4. 準工業地域

<details><summary>答えと解説</summary>

正解: **3**

住宅が建てられないのは工業専用地域だけです。工場専用の危険なエリアに人が住むのは危ないからです。工業地域・準工業地域・商業地域では住宅を建てることができます。

</details>

**問2.** 第一種低層住居専用地域に建築できるものはどれでしょう?

1. 大学
2. 保育所
3. 病院
4. ホテル

<details><summary>答えと解説</summary>

正解: **2**

保育所・診療所・神社・交番などは生活に身近な施設として、どの用途地域でも建築できます。大学や病院は規模が大きく低層住宅街の環境になじまないため、低層系の地域(一低・二低・田園住居)では建築できません。ホテルも低層住居専用地域では建築できません。

</details>

**問3.** 敷地が第一種住居地域(60%)と近隣商業地域(40%)にまたがっている場合、用途制限はどうなるでしょう?

1. 敷地全体に、過半を占める第一種住居地域の制限が適用される
2. 敷地全体に、厳しい方の地域の制限が適用される
3. それぞれの地域の部分ごとに別々の制限が適用される
4. 建築主が有利な方の地域の制限を選択できる

<details><summary>答えと解説</summary>

正解: **1**

用途制限は敷地の過半が属する地域のルールが敷地全体に適用されます。この例では60%を占める第一種住居地域の制限です。「厳しい方」が適用されるのは防火規制(防火地域と準防火地域にまたがる場合など)の考え方で、用途制限とは異なります。部分ごとや選択制ではありません。

</details>

## 4. 建蔽率と容積率 —— 計算のきほんと緩和

敷地いっぱい・空いっぱいに建てさせないためのルールです。計算は小学生のかけ算だけです。

### 建蔽率(けんぺいりつ)= 建築面積 ÷ 敷地面積

敷地を真上から見たとき、建物が占めてよい割合です。**緩和(+できる場合)**が重要です。

| 緩和 | 内容 |
|---|---|
| 特定行政庁が指定する**角地** | **+10%** |
| **防火地域内の耐火建築物等**(準防火地域内の耐火・準耐火等も) | **+10%** |
| 両方に当てはまる | **+20%** |
| 指定建蔽率**80%**の地域で、防火地域内の耐火建築物等 | **100%**(制限なし!) |

### 容積率 = 延べ面積 ÷ 敷地面積

前面道路の幅員が**12m未満**のときは、次の**小さい方**が限度です。

- 指定容積率
- 前面道路の幅員 × **4/10**(住居系) または **6/10**(住居系以外)

例: 住居系・指定容積率300%・前面道路6m → 6×4/10=**240%** < 300% なので限度は240%。

> 💡コツ: 「角地+10・防火耐火+10・80%は100%に」「道路が狭いと容積率は**小さい方**」。この2フレーズで計算問題が解けます。

> 🔴 計算問題はサービス問題。手を動かして必ず取りましょう。

### 確認問題

**問1.** 指定建蔽率60%の地域にある200㎡の敷地が、特定行政庁の指定する角地である場合、建築面積の最高限度はいくらでしょう?(他の緩和はないものとする)

1. 120㎡
2. 140㎡
3. 160㎡
4. 200㎡

<details><summary>答えと解説</summary>

正解: **2**

角地の指定があると建蔽率は+10%で70%になります。200㎡×70%=140㎡が正解です。120㎡は緩和を忘れた場合(60%)、160㎡は+20%(角地かつ防火地域内の耐火建築物等の場合)、200㎡は建蔽率100%の場合の数字です。

</details>

**問2.** 指定建蔽率80%の地域で、防火地域内に耐火建築物を建てる場合の建蔽率はどうなるでしょう?

1. 90%になる
2. 80%のまま変わらない
3. 制限がなくなり100%となる
4. 70%に強化される

<details><summary>答えと解説</summary>

正解: **3**

指定建蔽率80%の地域で防火地域内に耐火建築物等を建てる場合は、建蔽率の制限が適用されず100%になります。通常の緩和(+10%で90%)とは別の特別ルールなので、90%と答えさせるのがひっかけです。規制が強化されることはありません。

</details>

**問3.** 住居系の用途地域(指定容積率300%)で、前面道路の幅員が6mの場合、容積率の限度はいくらでしょう?

1. 300%
2. 360%
3. 480%
4. 240%

<details><summary>答えと解説</summary>

正解: **4**

前面道路が12m未満なので、指定容積率300%と「幅員6m×4/10=240%」の小さい方である240%が限度です。300%は道路制限を忘れた答え、360%は6×6/10(住居系以外の乗数)で計算した答え、480%は8×6/10のような無関係な計算です。

</details>

**問4.** 前面道路の幅員による容積率の制限について、正しいものはどれでしょう?

1. 前面道路の幅員が12m以上の場合は、指定容積率がそのまま限度となる
2. 前面道路の幅員にかかわらず、常に指定容積率が限度となる
3. 指定容積率と道路幅員から計算した数値の大きい方が限度となる
4. 容積率とは建築面積を敷地面積で割ったものである

<details><summary>答えと解説</summary>

正解: **1**

道路幅員による制限がかかるのは幅員12m未満の場合なので、12m以上なら指定容積率がそのまま限度です。12m未満では指定容積率と「幅員×法定乗数」の小さい方(大きい方ではありません)が限度になります。建築面積÷敷地面積は建蔽率の定義です。

</details>

## 5. 高さ制限・防火地域ざっくり

最後は「余裕があれば」の分野です。深入りせず、出やすいポイントだけ拾います。

### 高さ・日当たりの制限(どこに適用されないかで覚える)

| 制限 | ポイント |
|---|---|
| 道路斜線制限 | **すべての用途地域**で適用 |
| 隣地斜線制限 | 低層系3つ(一低・二低・田園住居)には**適用なし**(絶対高さ**10mまたは12m**の制限がある方が厳しいから) |
| 北側斜線制限 | 住居専用系の地域だけに適用(北隣の家の日当たりを守る制限なので、商業地域などには不要) |
| **日影規制** | **商業地域・工業地域・工業専用地域には適用なし** |

### 防火地域・準防火地域ざっくり

- **防火地域**: 駅前など密集地。原則、階数3以上または延べ面積100㎡超は**耐火建築物等**に
- **準防火地域**: その周辺。規制は防火地域よりゆるい
- 建築物が両地域に**またがる**→ 原則**厳しい方(防火地域)**の規制を建物全体に適用

> 💡コツ: 「ビル街(商業・工業系)に日影規制なし」「またがったら厳しい方」。用途制限の「過半」との違いに注意!

> ⚪ ここは他の🔴を仕上げてから。「適用されない地域」と「厳しい方」だけ持ち帰りましょう。

### 確認問題

**問1.** 日影規制(日影による中高層の建築物の高さの制限)が適用されない用途地域はどれでしょう?

1. 商業地域
2. 第一種低層住居専用地域
3. 準住居地域
4. 近隣商業地域

<details><summary>答えと解説</summary>

正解: **1**

日影規制は商業地域・工業地域・工業専用地域には適用されません。ビル街や工場街では日当たりの保護よりも土地の高度利用が優先されるからです。低層住居専用地域や準住居地域、近隣商業地域は適用対象となり得ます。

</details>

**問2.** 建築物が防火地域と準防火地域にまたがる場合、原則としてどうなるでしょう?

1. 建物の過半が属する地域の規制が適用される
2. 原則として厳しい方である防火地域の規制が建物全体に適用される
3. ゆるい方である準防火地域の規制が適用される
4. またがる建築物は建築できない

<details><summary>答えと解説</summary>

正解: **2**

防火の規制は安全に関わるため、またがる場合は原則として厳しい方(防火地域)の規制が建物全体に及びます。「過半」で判断するのは用途制限のルールで、混同を狙った定番のひっかけです。ゆるい方が適用されることはなく、建築自体が禁止されるわけでもありません。

</details>

**問3.** 隣地斜線制限が第一種低層住居専用地域に適用されない理由として、正しいものはどれでしょう?

1. 低層住居専用地域には高さの制限が一切ないから
2. 低層住居専用地域には日影規制が適用されないから
3. 絶対高さ(10mまたは12m)の制限があり、その方が厳しいから
4. 隣地斜線制限は商業地域にのみ適用されるから

<details><summary>答えと解説</summary>

正解: **3**

低層系の地域には建物の高さを10mまたは12m以下とする絶対高さ制限があり、隣地斜線よりも厳しいため、隣地斜線制限を適用する必要がありません。「高さの制限が一切ない」はその逆です。日影規制は低層系にも適用され得ますし、隣地斜線は商業地域専用の制限ではありません。

</details>
